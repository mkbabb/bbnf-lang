## Root Cause — Codegen Regression Across W0.3 Regen

Comparing the W0.3-final regen tree against `1076e54d`
(`fix(parity/sheets/keyword+flat): emit per-branch typed payload via
push_branch_tag`):

```
$ git show 1076e54d:crates/core/src/grammar/generated/google_sheets.rs \
    | grep -c push_branch_tag
33

$ grep -c push_branch_tag crates/core/src/grammar/generated/google_sheets.rs
12
```

**21 typed-Nu8 emissions were lost across the W0.3 regen.** The lost
emissions sit on the inner alt-loop of `parse_flat_*_error_literal`
and the per-branch literal commit of `parse_keyword_*_unary_prefix`
/ `parse_keyword_*_add_op` / `parse_keyword_*_mul_op` /
`parse_keyword_*_compare_op`.

The emitter sites that produce these emissions:
- `crates/core/src/backend/rust/emitter/shapes/keyword/struct_direct.rs`
  (Keyword shape per-branch payload hoist; the `1076e54d` fix)
- `crates/core/src/backend/rust/emitter/shapes/flat/struct_direct.rs`
  (Flat shape inline-Map payload commit; the `1076e54d` fix)

Both surfaces lost their typed-payload routing during the W0.3 lowering
quartet's structural-detection refactor. The lowering quartet
(`wrap.rs::lower_mapped_factor`, `repeat.rs::lower_factor`,
`alt.rs::lower_alternation`, `mod.rs::dispatch_expression`) replaced
predicate detection with structural detection but the keyword + flat
emitters did not pick up the post-quartet IR shape for typed-Nu8 alt
branches.

Per `feedback_typed-materialization-invariant`: every `->` in the
grammar must reach the tape emitter; inference composes types, never
loses them. The 21-emission loss is a typed-materialization-invariant
violation seeded by the W0.3 regen that the keyword/flat shape
emitters did not compensate for.

discriminator emission to be **restored** (not added new). The
