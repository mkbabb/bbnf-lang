## §1 — Findings (concrete; file:line on bbnf claims, citation on external claims)

P2-F's input universe is closed over P2-B/C/D/E for implementation candidates. No new primitive is introduced here. P2-B contributes the checkasm/admission floor and the live bbnf-simd candidate inventory; P2-C contributes the Apple M5 Max/aarch64 instruction inventory plus explicit x86 diagnostic exclusion; P2-D contributes same-substrate tape/projection candidates; P2-E contributes parse-that Layer-1 vocabulary gaps. P2-A is comparator context only, and its seven row names are explicitly mapped in §2.1 so no P2-A candidate wording escapes without a verdict.

The binding P1 antecedent surface is P1-E's normalized attribution ledger: grammar-neutral scanner, tape/allocation, unicode/string, memory, and direct-parser cursor boundaries are admissible S-P2 antecedents; generated schema wrappers, checksum paths, comparator frames, and sidecar-symbolization drift are blocked or diagnostic unless converted to one of those boundaries (`restart/skinny/tranches/sk-v15/research/p1/p1e-hot-leaf-attribution.md`; `restart/skinny/tranches/sk-v15/research/p1/evidence/p1e-normalized-attribution.tsv`). P1-D supplies the current product-plane misses: `mesh` direct and `unicode_escapes` direct/typed (`restart/skinny/tranches/sk-v15/research/p1/p1d-pmu-cycles.md`). P1-F keeps CSS L4 demoted despite stale SK-V14 rows in `skinny/RESULTS.md`.

Lock 14 is the governing grammar-neutral test. A primitive may be accepted only as a byte-set, byte-range, classifier, mask algebra, digit-run, UTF-8 validation, escaped-segment stream, or same-tape operation whose policy is supplied by generated grammar facts, caller data, or opaque tape metadata. JSON punctuation, JSON escape semantics, CSS trivia policy, Sheets formula rules, and BBNF-self token roles cannot live in a generic crate (`restart/locks/LOCKS.md:349`-`419`).

Lock 1 is the governing substrate test. A SIMD mask stream may be a transient local producer, but any retained structural offsets are the tape. Retained class streams, parser-owned cursors, whitespace bitmaps, density tables, cross-call quote/escape/structural carry, public `UnionTape`, or second tape are Lock violations (`restart/locks/LOCKS.md:75`-`158`). Therefore grammar-neutrality is not enough: a candidate that is neutral algebra but reopens REDRESS 88/89 or REDRESS 96/97/98 is rejected for SK-V15 shortlist.

SK-V15 admission is Apple M5 Max/aarch64 only. x86/AVX-512/GFNI/VBMI2/VPCLMUL surfaces from P2-B/C are diagnostic pressure, not implementation or admission paths (`restart/skinny/tranches/sk-v15/HANDOFF.md`).

CSS L4, Sheets, and BBNF-self are required witnesses for generalisation, not automatic proof. CSS L4 is currently audit-demoted/contrived in SK-V15, so it can serve as a positive target only after the prune/rebuild gate repairs the generated provider and comparator plane. Sheets and BBNF-self are negative-control or generated-role witnesses: a primitive generalises when their grammar metadata can supply the policy without generic-crate branching, even if a same-wave implementation later chooses a scoped JSON-only consumer.

## §4 — Risks (REDRESS entries any candidate must NOT re-open)

REDRESS 28+33: tiny-string/Class A NEON wiring was parity-green but row-regressive. `bounded_plain_literal_span` and string-block candidates must be parameterized scalar-first primitives, not a replay of active tiny-string NEON wiring.

REDRESS 50-55: parse-time side tables, byte-class cursor sidecars, parser-local structural cursors, decoded string stats, and quote-source materializers are blocked. Byte-set/classifier candidates must stay local or write the existing tape/sink.

REDRESS 60-72: retained parse shortcuts and eager/direct string materializer families are blocked under current product contracts. Escape and segment candidates need a materially different per-grammar segment surface and same-wave consumer proof.

REDRESS 80: canada mantissa-widen/f64 fallback is blocked because the measured fallback pool was zero. UDOT/digit candidates are rejected for current S-P2 candidate status because the P1 bridge is diagnostic, not BBNF-side.

REDRESS 82-84: one-quartet unicode classifier, StringBlock16 tiny probe, and object-pair value-byte compaction were correctness/parity-green but row-rejected. Unicode batch and string span candidates must not claim those routes.

REDRESS 88: PMULL prefix-XOR as production hot body is rejected despite correctness/checkasm. P2-F rejects PMULL promotion for SK-V15 even though local prefix algebra remains a valid scalar abstraction.

REDRESS 89: CSSC CTZ/bulk consumer regressed parse rows despite correctness/integrity gates. P2-F rejects CSSC promotion for SK-V15 while accepting local scalar mask-to-position emission.

REDRESS 96/97/98: retained class columns, streaming structural cursors, and union-substrate/class-lane replay are retired. `mask_to_tape_writer_local` is legal only because the mask is consumed inside one generated function and writes the existing tape/sink; any retained `StructuralIndex`, class vector, cursor, whitespace bitmap, density table, or cross-call carry is REJECT.

CSS L4 overfit risk: SK-V15 says CSS L4 is contrived and reopened. No candidate may use stale CSS rows as proof; CSS is only a future repaired positive witness.

Sheets/BBNF-self overfit risk: claiming generality with only JSON plus prose is paper-close. A fleet-wide S-P3 shortlist should name either a generated non-JSON consumer, a negative-control witness, or a scoped JSON-only row claim that avoids Lock 14 overreach.
