### C3 — Commit-by-construction structural spine (the doc's Wave 4; the lightningcss-cross lever)

Investigation 5's profile (architecture-doc §5:319-322, **core-tree — S-P1-
re-confirm on benched path**) establishes that after the alloc floor falls, ~31%
own-compute (speculative checkpoint/rollback branch machinery) becomes the wall;
rich-AST parity is near a ~50–100 Mbps floor for the *speculative-descent* design.
lightningcss/cssparser are single-pass with NO speculative rollback. This candidate
removes speculative checkpoint/rollback from the structural backbone: the emitter
(codegen) emits NO checkpoint for pure-lexical keyword-dispatch Alts that deposit
nothing structural; the spine commits as it scans, driven by the C2 NEON structural
index. Backtracking survives only on true ambiguous leaves, not the spine.

- **File paths (skinny tree):** `skinny/crates/codegen/src/lower/tape_plan.rs`
  (`alt_label`/`AltMode` — emit commit-mode for non-depositing Alts);
  `skinny/crates/codegen/src/lower/{offset_tape.rs,event_tape.rs}` (no-checkpoint
  spine emission); `skinny/crates/runtime/src/tape/assembler.rs` (the O(1)
  `offsets.len()` checkpoint marker — already banked SK-V16; this candidate REMOVES
  checkpoints where provably unneeded, it does not add a mechanism).
- **Scalar-ref status:** N/A (codegen control-flow change, not a kernel).
- **checkasm expectation:** N/A. Correctness = 8-field equality EXACT (no row may
  break) + full parity battery + a NEW gate: the no-checkpoint Alts must be PROVEN
  non-depositing by the codegen (a structural property asserted at generation time),
  not heuristically. CH5 hidden-coupling: removing a checkpoint an Alt actually needs
  silently corrupts the tape — the gate is the equality count, which catches it.
- **Same-wave consumer:** the parser spine is itself the consumer; the codegen
  change and the regenerated parser land together. No orphan.
- **Generality EXIT gate:** commit-by-construction is a generic codegen property
  (non-depositing Alt detection), exercised on JSON (the witness — JSON's spine is
  already single-pass-ish) AND CSS. Bound, not "by construction": the codegen Alt-mode
  pass must run over the JSON grammar and emit identical commit-mode where JSON Alts
  are non-depositing, proving the property is grammar-shape-driven not CSS-keyed.
- **Falsifiability gate:** corpus `css-l4-sk-v14` + `bootstrap` + `animate` +
  `tailwindcss`, N≥50 cold median. PASS = rich CSS typed Track 1 ≥ **300 Mbps** on
  `animate`/`bootstrap`, with first cross of **> the same-run re-baselined

- **LOC budget:** ~400–700 (codegen Alt-mode emission + regen).
- **Risk class:** HIGH. Provability of non-deposition is the crux; an over-eager
  removal silently breaks the equality gate (caught, but expensive). The candidate
  most likely to need a triumvirate.
- **REDRESS pre-blocks:** all of C1's. No type-ambivalent dual representation
  (Lock 1 — "tape and OpenFrame and direct-to-struct competing for the same role").
  No speculative-rollback re-introduction disguised as a fast path.
