# Deferred lane — consumers and playground

This lane is owned but does not gate W0-W4. Each row closes SK-V26 as either
`BANKED_WITH_TRIGGER` or `RETIRED`; “later tranche” alone is not a disposition.
Implementation becomes eligible only after a public, content-addressed
parse-that artifact and the W3 BBNF vertical exist.

## Consumer truth

- Value 4.0 currently uses handwritten CSS parsing and does not depend on
  parse-that.
- cand-F/cand-O are substantive prototype evidence. cand-O's five debts must be
  closed before adoption: diagnostics, rejection cost, bounded recursion, numeric
  exactness, and generated empty-argument cases.
- Value's handwritten CSS grammar and parse-that's Rust CSS parser are not BBNF
  grammar authorities.
- Keyframes ownership is decided against the final public Value/parse-that
  contracts, not the moving worktrees.
- `mixColors`, `parseCSSValue`, color-space coverage, and gamut mapping remain
  Value-owned consumer obligations.

The first consumer trigger is: W1 Rust artifact public, W3 event vertical green,
cand-O's five named debts closed, and a Value owner authorizes a bounded Color
adoption crater. Absent all four, Value adoption is banked rather than repeatedly
rebooked. Keyframes ownership activates only when that crater exposes a concrete
contract conflict.

## Playground/design

Current facts:

- zero shadcn source/package references;
- Tailwind remains;
- component/composable/style structure has not received an accepted current
  design audit;
- GOLDEN GLASS, BREATH OF LIFE, and MOVEMENT OF MOMENTUM lack testable definitions.

Before visual implementation:

1. use the `frontend-design` skill;
2. commission two independent designs, one adjudication;
3. define the three named aesthetic/motion principles as tokens, proportions,
   interaction rules, and visual falsifiers;
4. capture every route/state/viewport baseline;
5. build the component/import DAG;
6. classify each component as product-semantic, Glass-owned, local visual, or
   vacuous.

Then:

- colocate feature-private components, composables, constants, and styles;
- strip repeated module names inside their owning module;
- keep tests in an external isomorphic tree;
- delete identity wrappers and vacuity only after visual/interaction parity;
- adopt one packed Glass artifact atomically;
- prohibit shadcn reintroduction, compatibility components, and dual style paths.

Required proof includes screenshots, keyboard/focus/accessibility, console/network,
layout shift, bundle/runtime profile, and two clean visual audits.

This lane may produce a later bounded tranche only when its ledger trigger fires.
It cannot delay parser truth.
