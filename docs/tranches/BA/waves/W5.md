# BA.W5 - Cursor Consult + LegacyPath Retirement

**Name**: W5 - Cursor Consult + LegacyPath Retirement
**Opens after**: W4 - `parse_with` As Value-API Hot Path
**Agents**: 5 parallel
**Hard gate**: `cursor.match_field` + `cursor.match_index` + `cursor.decide` collapse into `cursor.consult(&ParsedSegment)`; `LegacyPath`/`LegacySegment` shim retires; `Document::get<T>` consumes `TypedPath` directly; per-grammar `__path_plan` re-exports deleted; substrate-audit GREEN
**Status**: planned

## Scope

This wave consolidates the path-cursor surface: three call points (`cursor.match_field`, `cursor.match_index`, `cursor.decide`) collapse into one `cursor.consult(&ParsedSegment)` call. The AZ-IV.W3 `LegacyPath`/`LegacySegment` shim across `runtime/{json,css_l4,sheets,bbnf}/parse_with.rs` retires; under direct-projection's `Document::get<T>(path)` consuming `TypedPath` directly, the shim is dead. Per-grammar `__path_plan` re-exports (4 generated modules) collapse into a single source from `crate::path::cursor`.

1. Modify `crates/core/src/path/cursor.rs`: define `cursor.consult(&ParsedSegment) -> Decision`. Delete `match_field`, `match_index`, `decide` (the three legacy methods that all decoded a parsed segment in different shapes). The single `consult` call answers the question once.
2. Modify `crates/core/src/runtime/path/**`: delete `LegacyPath`, `LegacySegment` (these were the AZ-IV.W3 bridge from runtime path types to the typed `path!`-resolved path). Under direct-projection, `Document::get<T>` consumes `TypedPath` directly; the shim is dead.
3. Modify `crates/core/src/grammar/generated/**`: delete the per-grammar `__path_plan { pub use crate::path::cursor::{Decision, SegmentKind}; }` re-exports. The 4 generated modules (one per consumer grammar) source `Decision` and `SegmentKind` directly from `crate::path::cursor`.
4. Update all call sites in `crates/core/src/runtime/{json,css_l4,sheets,bbnf}/parse_with.rs` to use `cursor.consult(&parsed_segment)` instead of the legacy three-method dance.
5. Refresh the substrate-audit denominator: the four substrates removed by mechanism (`LegacyPath`, `LegacySegment`, the legacy three cursor methods, the per-grammar `__path_plan` re-exports) are no longer in the whitelist.
6. Verify per-grammar parity: every existing `Document::get<T>` call site continues to work; the change is purely a code-shape collapse, not an API-shape change. Tests in `crates/core/tests/cursor_consult_unification.rs` cover the single-method dispatch.
7. Update `docs/codegen-paths.md` with the post-W5 cursor surface; the `__path_plan` per-grammar indirection is documented as retired.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- `cursor.consult` cannot answer all three legacy questions in one method (e.g., the field-name path step has a side effect the index path step lacks; the consolidation is incomplete);
- `LegacyPath` deletion breaks an unwritten dependency (a runtime caller outside the W4-adjusted `Document::get<T>` still consumes `LegacyPath`);
- the per-grammar `__path_plan` deletion regresses a generated test (the re-exports were load-bearing in a way that wasn't surfaced in the deep audits);
- the substrate-audit denominator does not shrink by the expected count (a mechanism the wave assumed was retired turns out to have a phantom consumer);
- three diagnostic-loop iterations fail to isolate why the cursor consolidation breaks a parity test;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.
