## Repair

- `Decomposition` owns one complete node-to-component map and one borrowed
  internal-edge bucket per component. Component bases, quotient construction,
  and structural validation no longer perform a component-by-edge scan or
  clone `EdgeFact` values.
- One checked `ProjectionBudget` covers declared SCC setup, component cycle
  algebra/search, and quotient-complement algebra. Overflow, projection
  mismatch, and exhaustion return deterministic typed failures.
- Domain validation rejects escaped endpoints, duplicate typed-edge identities,
  empty edge domains, and invalid rank domains without indexing panics.
  Independent validation recomputes the complete decomposition and therefore
  rejects omitted/forged membership, digest, and cyclicity.
- Quotient completion consumes the already-proved complete component basis; it
  no longer invokes the directed-cycle search a second time.
- Valid component identity, ordering, witness canonicalization, rank, and
  serialized projection fields are unchanged. No compatibility alias, cache,
  controller, alternate path, or framework was added.
