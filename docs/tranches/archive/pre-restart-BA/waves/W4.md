# BA.W4 - `parse_with` As Value-API Hot Path

**Name**: W4 - `parse_with` As Value-API Hot Path
**Opens after**: W3 - Speculative Checkpoint Redesign
**Agents**: 5 parallel
**Hard gate**: `Document::get<T>(path)` reroutes through `parse_with`; eager `parse(input)` collapses to `parse_with(input, &EMPTY_PATH)`; sonic-class `JsonParser::get<T>(input, path)` API lands; `bbnf_get_twitter` ≤ 5× `sonic_get_twitter` same-harness samply-attributed; `__EAGER_EMPTY_PATH` literal absent
**Status**: planned

## Scope

This wave collapses the eager/lazy split: eager becomes the degenerate case of lazy (`parse_with(input, &EMPTY_PATH)`); `Document::get<T>(path)` reroutes through `parse_with`; the sonic-class `<Grammar>Parser::get<T>(input, path)` API lands. The 4196× `bbnf_get_twitter` gap closes here. F2 MASKED-DEFERRAL closes here.

1. Modify `crates/core/src/runtime/{json,css_l4,sheets,bbnf}/document.rs`: `Document::get<T>(path: TypedPath<G, T>)` reroutes through `parse_with(self.input, &path)` for path-resolved leaves. The walk-materialised-tree implementation is replaced; the typed accessor short-circuits at the first leaf the path requests.
2. Modify `crates/core/src/runtime/{json,css_l4,sheets,bbnf}/parser.rs`: `<Grammar>Parser::get<T>(input: &str, path: TypedPath<G, T>) -> Option<T>` is the sonic-class entry. It calls `parse_with(input, &path)` directly (no document materialization). Per-grammar parity: `JsonParser::get`, `CssL4Parser::get`, `SheetsParser::get`, `BbnfParser::get`.
3. Add `<Grammar>Parser::get_iter<T>(input, path: TypedPath<G, T>)` for wildcard paths: returns `impl Iterator<Item = T>` (zero-allocation; the path expression IS the iterator). `<Grammar>Parser::get_dyn(input, &runtime_path)` for dynamic paths (less common; flexible).
4. Collapse eager `parse(input)` to `parse_with(input, &EMPTY_PATH)`. The cross-grammar `__EAGER_EMPTY_PATH<Json,_>` literal retires; the generated parse fn dispatches on `path.is_empty()` at compile time (const evaluation; the eager branch is the empty-path case).
5. Profile `bbnf_get_twitter` under fat-LTO `[profile.bench]` after the regen lands. The samply trace must show `bbnf_get_twitter ≤ 5× sonic_get_twitter` same-harness; if the stretch ≤ 1.0× is achieved, document the profile evidence. F2 MASKED-DEFERRAL closes.
6. Verify per-grammar parity: every existing `Document::get<T>` call site continues to work (the typed `path!` lookup in tests resolves the same `T`); the change is purely a runtime mechanism collapse, not an API shape change.
7. Update `crates/core/tests/get_api_smoke.rs` (new) covering each grammar's `get`, `get_iter`, `get_dyn` shape; covers compile-time path-error fixtures already in AZ-IV.W2 plus runtime-execution fixtures.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the `parse_with(input, &EMPTY_PATH)` collapse breaks an unwritten dependency in a smaller grammar's eager parse (e.g., the smaller grammar's parse fn assumed materialised AST as a side effect for a non-path consumer);
- after the collapse, `bbnf_get_twitter` is still ≥ 5× `sonic_get_twitter` (the perf miss is not local-edit-recoverable; the sonic-class architecture target is failing);
- the wildcard `get_iter` zero-allocation claim fails dhat verification (the iterator allocates per yield; mechanism is wrong);
- a grammar's `path!` macro fails to resolve a `TypedPath<G, T>` whose `T` is a sum type (variant-selection step regression);
- the samply 7-artefact contract is impossible to produce because the post-W3 binary doesn't symbol-resolve under fat-LTO (environmental gating regression);
- three diagnostic-loop iterations fail to isolate the perf miss;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.

## Agent Units

### BA.W4.1 `Document::get<T>` Reroute

- Mechanism: in each `crates/core/src/runtime/{json,css_l4,sheets,bbnf}/document.rs`, the existing `Document::get<T>(path)` walks the materialised tree via `walk_path`. The new implementation calls `parse_with(self.input, &path)` and returns the result. The materialised-tree walk is replaced; the typed accessor short-circuits at the first leaf the path requests. The `Document` value still holds the input bytes for repeat queries; consecutive `get<T>` calls re-run `parse_with` against the input (the cost is path-depth, not input length, because `parse_with` short-circuits at the first leaf — verify per-grammar).
- Files: `crates/core/src/runtime/{json,css_l4,sheets,bbnf}/document.rs`.
- Sub-gate: `cargo build` compiles cleanly; existing parity tests pass; `cargo nextest run --test get_api_smoke` GREEN; `walk_path` and the materialised-tree helper functions are removed (deletion-proof).

### BA.W4.2 `<Grammar>Parser::get<T>` API

The method calls `parse_with(input, &path)` directly (no document materialization). The signature is grammar-general; `JsonParser::get`, `CssL4Parser::get`, `SheetsParser::get`, `BbnfParser::get` all share the shape.
- Files: `crates/core/src/runtime/{json,css_l4,sheets,bbnf}/parser.rs`.
