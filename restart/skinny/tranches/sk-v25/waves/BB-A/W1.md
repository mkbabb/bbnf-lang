# BB-A.W1 — complete typed multigraph P2+

## Authority

Consumes BB-A.W0. P1 is falsified evidence only: its local determinism and raw
counts do not authorize any SCC or ownership judgment.

## Required graph model

Nodes and edges carry typed `repo`, `product`, `workspace`, `package`, `feature`,
`target`, `module`, `item/artifact`, `config`, `test`, and `consumer` identity plus
phase, condition, origin, resolution confidence, and canonical source-relative ID.
Projections are distinct: containment, runtime, type, build, test, config,
provenance, dynamic load, documentation authority, and git/worktree ownership.

## Implementation

1. Derive Cargo package/dependency identities from Cargo metadata resolve graphs
   per target/feature/profile, joining cross-workspace path packages to their real
   canonical nodes rather than same-name lock entries.
2. Use a compiler-backed or explicitly bounded Rust resolver for arbitrary-depth
   `super`, aliases, reexports, nested uses, qualified paths, includes, cfgs,
   features, macro/generated unknowns, and external package ownership. Unknown
   expansion is a structured RED obligation.
3. Build TypeScript programs for playground and parse-that package faces. Resolve
   runtime/type/import/require/dynamic/export-condition/Vite alias/glob/worker/URL
   edges; parse Vue script/template/style/provide/inject/src and CSS imports.
4. Inventory every authored/config/grammar/generator/generated/fixture/test/package
   file. Connect producer -> input -> artifact -> copy/package -> load/consumer;
   generated outputs contain verifiable semantic manifests.
5. Include all graph nodes in every applicable condensation. Exclude containment,
   test ownership, and provenance from runtime dependency SCCs. Validate endpoint
   existence, conflicting IDs, projection acyclicity, and a cycle basis.
6. Enumerate git worktrees/HEAD/dirty ownership as evidence nodes without reading
   them as active product dependencies or cleaning them.
7. Emit deterministic JSON, DOT, report, condensation, boundary quotient, cycle
   basis, and audit shards. Hash SCC IDs from member identities, never ordinals.

## Mutation fixtures

- two lock versions of one crate with one satisfiable requirement;
- cross-workspace path dependency;
- `super::super`, alias, nested use, cfg-disjoint modules, include/OUT_DIR;
- `.d.ts` declaration beside `.js`/`.wasm` runtime;
- CSS import, `import.meta.glob`, `new URL`, worker, package export conditions;
- orphan node, missing endpoint, ID collision, unsupported macro, stale artifact;
- relocated clone and locale variation.

## Evidence gates

- Every required plane is implemented or the command exits nonzero with a typed
  obligation; “unsupported” can never coexist with green.
- Node coverage equals the canonical inventory and every edge endpoint exists.
- Relocated empty-output runs are byte-identical and contain no absolute checkout
  path; two local reruns match as the weaker inner gate.
- Each condensation includes isolated nodes and is acyclic; cycle counts reproduce
  from emitted edges alone.
- Mutation fixtures invert exactly; two critics plus adjudicator close P2.

## Completion

One graph becomes the only structural fact source. Any later importer/generator/
artifact/config kind must first extend its typed model and mutation bank.
