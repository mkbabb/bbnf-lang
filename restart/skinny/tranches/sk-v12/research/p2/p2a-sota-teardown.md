## §1 — Findings

The live P1 authority is pin-aware S-P1, not pre-pin research: PIN-V6 and PIN-V7 converged, the accepted hot families are the ten named in the frontmatter, and JSON-only telemetry may nominate primitive families but cannot prove CSS L4, Sheets, or BBNF-self behavior (`restart/skinny/tranches/sk-v12/research/p1/hardening/HARDENING-S-P1-CONVERGED.md:23`, `:60`, `:73`). The current result surface has 0 admitted CSS L4 rows, while JSON `parse_only` remains diagnostic, direct is a guard/routed ledger, and typed is a guard surface (`restart/skinny/tranches/sk-v12/HANDOFF.md:31`, `:54`, `:64`; `restart/skinny/tranches/sk-v12/research/p1/p1f-results-delta.md:24`, `:80`).

The admission comparator is CSS L4, not JSON parse-only. The generated CSS L4 row must beat `lightningcss_mbps + 1` on the same corpus, same output plane, same host, and strict equality semantics; the output plane must be one canonical CSS fact stream shared by generated Track 1, independent Track 2/oracle, and lightningcss (`restart/skinny/tranches/sk-v12/USER-PIN-W1-CSS-L4-SOTA.md:18`, `:31`, `:80`; `restart/skinny/tranches/sk-v12/HANDOFF.md:54`, `:77`; `restart/skinny/tranches/sk-v12/SYNTHESIS.md:42`, `:48`). Thus comparator lessons below are primitive-shape evidence only until CSS L4 generated Track 1, same-plane lightningcss output, and strict equality exist.

Lock 1 forbids importing simdjson-style retained structural indexes or asmjson-style event side streams as parallel substrates: if retained, structural projection is the tape, and transient SIMD masks must be consumed immediately (`restart/locks/LOCKS.md:52`). Lock 14 forbids JSON/CSS/Sheets policy in generic crates, so every comparator trick must be expressed as a byte-set, classifier, number, string, dispatch, tape, or output-plane primitive with per-grammar policy supplied by generated code (`restart/locks/LOCKS.md:78`).

| yyjson | Portable ANSI C, no explicit SIMD; uses scalar character-class tests, trivia skipping, and specialized minified/pretty root readers [Y1] [Y2]. | Unrolled scalar number reader handles leading-zero/error policy and raw/bignum flags; optimized string reader skips common ASCII spans and validates UTF-8/escapes [Y3] [Y4]. | Immutable/mutable document/value model; `yyjson_val` stores type in low tag bits and size in high tag bits [Y5]. | `YYJSON_READ_NOFLAG` is RFC 8259 compliant; comments, trailing commas, invalid Unicode, JSON5, and raw-number modes are opt-in flags and cannot be strict anchors [Y6]. | A compact scalar FSM/value-pool DOM with aggressive inlining and layout discipline. bbnf has generated JSON tape/direct guards, not a grammar-neutral generated value-pool DOM, and CSS L4 emission is still absent (`restart/skinny/tranches/sk-v12/research/p1/p1f-results-delta.md:26`, `:85`). |

The common comparator lesson is not "copy a JSON parser." The transferable surface is: transient byte classification; bounded string special-byte scans; quote/escape state; digit-run accumulation; generated FIRST/follow dispatch; and a row-owned output plane. All of them must be scalar-oracle-first, grammar-neutral, strict on the CSS L4/lightningcss plane, and consumed by generated code in the same wave.

## §3 — Grammar-neutrality

| Candidate | Grammar-neutrality verdict |
|---|---|
| C1 `class_mask64_transient` | Generalizes if byte classes are generated tables, not JSON constants. CSS operators/functions, Sheets formula tokens, BBNF identifiers/literals, and JSON structurals are all table data. |
| C2 `bounded_special_byte_string_end` | Generalizes if terminator/escape/control/non-ASCII policy is caller-owned. JSON strings, CSS strings/URLs, Sheets doubled quotes, and BBNF regex/literal spans differ above the stop-scan layer. |
| C3 `quote_escape_state64` | Generalizes as quote/escape/carry state only. Unicode escape semantics, CSS escapes, Sheets quotes, and regex escapes remain grammar policy. |
| C4 `digit_run_accumulate` | Generalizes at the digit-run layer. JSON numbers, CSS dimensions/percentages, Sheets formula numbers, and BBNF expression literals differ after span/accumulate. |
| C5 `generated_first_follow_probe` | Generalizes only when generated from FIRST/follow facts. A JSON object-tail probe cannot be reused as CSS comma/function or Sheets array policy. |
| C6 `grammar_output_event_sink` | Generalizes only as a generated output-plane contract. CSS fact stream, JSON typed guards, Sheets values, and BBNF-self AST/facts must be generated products with independent oracles. |
| C7 `generated_dispatch_template` | Generalizes if generic crates never branch on grammar names and per-grammar generated modules own tables/arms, satisfying Lock 14 (`restart/locks/LOCKS.md:78`). |

CSS L4 same-plane strict comparison requires a canonical fact stream whose ordering, normalization, error surface, and provenance are consumed by the gate alongside generated Track 1 Mbps, independent oracle Mbps, lightningcss Mbps, equality result, host/build flags, JSON guard state, Lock 14 status, and Lock 16 status where applicable (`restart/skinny/tranches/sk-v12/HANDOFF.md:145`). JSON `parse_only` rows cannot stand in for that plane because they use JSON corpora, JSON output planes, and sonic/serde comparators rather than a CSS L4 fact stream and lightningcss (`restart/skinny/tranches/sk-v12/research/p1/p1f-results-delta.md:89`).

## §4 — Risks

- Do not reopen parse-only as admission. The user pin keeps `parse_only` diagnostic-only, and P1-F states JSON rows cannot fill the CSS L4 `lightningcss_mbps + 1` bar (`restart/skinny/tranches/sk-v12/USER-PIN-W1-CSS-L4-SOTA.md:92`; `restart/skinny/tranches/sk-v12/research/p1/p1f-results-delta.md:89`).
- Do not add retained sidecars. simdjson's structural index is comparator evidence, but Lock 1 rejects parallel retained class lanes, structural vectors, parser-owned projections, and aux tables (`restart/locks/LOCKS.md:52`; `skinny/REDRESS.md:2910`).
- Union and ASM categories are unblocked only at category level. New plans must cite REDRESS 96/97/98 or 88/89/90, name a material differential, and carry scalar/parity/checkasm plus same-wave consumer evidence (`restart/skinny/tranches/sk-v12/USER-PIN-W1-CSS-L4-SOTA.md:39`, `:58`, `:110`).
- C3 is blocked from SIMD admission until the `escape_mask_64` xorshift falsifier is verified and resolved (`restart/skinny/tranches/sk-v12/USER-PIN-W1-CSS-L4-SOTA.md:104`; `restart/skinny/tranches/sk-v12/SYNTHESIS.md:57`).
- C4 and C5 must not launder rejected JSON residual routes back into SK-V12. Numeric direct closure and container-tail dispatch were measured-rejected in REDRESS 114 and 115 (`skinny/REDRESS.md:3359`; `skinny/REDRESS.md:3385`).
- C6 must not become a host-sink/digest shortcut. REDRESS 118 blocks output digest/hash as an unowned host sink without a legal row, consumer, and oracle (`skinny/REDRESS.md:3464`, `:3490`).
- Non-JSON generated baseline absence is still real. REDRESS 112/113 show no generated CSS L4 Track 1 or baseline row existed, even though the user pin supersedes the target choice and mandates CSS first (`skinny/REDRESS.md:3311`; `skinny/REDRESS.md:3340`; `restart/skinny/tranches/sk-v12/USER-PIN-W1-CSS-L4-SOTA.md:118`).
