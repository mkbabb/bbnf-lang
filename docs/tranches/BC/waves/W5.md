# BC.W5 — Debug, Inspect, and Minimise Tooling

**Opens after**: W4 close
**Agents**: 3 parallel
**Hard gate**: Debug and minimisation tools consume the production provenance and replay surfaces and emit stable traces or repros on canonical fixtures.
**Status**: planned

## Scope

1. Build debug and inspect tooling directly over provenance, replay, and
   recovery surfaces.
2. Add reproduction minimisation tooling over the same production data.
3. Prove these tools on canonical fixtures without opening bespoke trace
   models.

## File bounds

| File | Access |

| `crates/core/src/runtime/debug.rs` | create |

| `crates/core/tests/debug_trace_contract.rs` | create |

**Do NOT touch**: parser architecture, build/profile tooling, any `.bbnf` grammar, throughput-only optimization code.

## Phase sub-items

### BC.W5.1 Debug and inspect surfaces

Mechanism: expose stable inspection and trace APIs over provenance,
replay, and recovery data already emitted by production code.

Files touched: `crates/core/src/runtime/debug.rs`.

Sub-gate: inspection APIs can render stable node/rule/span traces on
canonical fixtures.

### BC.W5.2 Minimisation tooling

Mechanism: add reduction tooling that uses provenance and replay to
minimise failing inputs while preserving the observed substrate or error
property.

Files touched: `crates/core/src/runtime/minimise.rs`.

Sub-gate: minimisation returns a smaller reproducer on canonical failing
inputs.

### BC.W5.3 Tooling contracts

Mechanism: add tests proving that debug traces and minimised repros come
from the production surfaces rather than bespoke tooling state.

Files touched: `crates/core/tests/debug_trace_contract.rs`,
`crates/core/tests/minimise_contract.rs`.

Sub-gate: tooling contract tests pass.

## Hard gate

1. `cargo test -p bbnf --test debug_trace_contract --profile ax-iter`
