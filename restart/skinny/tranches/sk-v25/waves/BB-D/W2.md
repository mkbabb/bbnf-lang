# BB-D.W2 — hermetic WASM package and coordinate crossing

## Goal

Make WASM an ordinary locked root product member with one generated artifact and a
checked Rust/JavaScript coordinate/value contract.

## Implementation

1. Add WASM to the root workspace and resolve real local package identities through
   one lock. Remove mutation-wanting patches and sibling/manual package copies.
2. Generate one JS/types/WASM output set into a declared artifact directory with
   source/semantic/toolchain/command/output manifest. Ordinary build verifies it.
3. Transport only declared value-fabric layouts. Qualify Rust UTF-8 byte and JS
   UTF-16 code-unit positions; conversions require the exact source and reject
   surrogate/byte interior positions.
4. Make Node and browser import conditions resolve the same packed candidate and
   dynamic `.js -> .wasm` URL edge. Delete phantom declaration-as-runtime paths.
5. Add stale/missing/tampered/wrong-package/wrong-coordinate mutation probes and
   round-trip all value/diagnostic variants.

## Gates

- Cargo/package graph connects WASM directly to canonical root packages.
- Clean generation twice is byte-identical; manual copies and old output roots are
  absent.
- Ordinary playground build fails stale or mismatched WASM before browser load.
- Node/browser network evidence proves the declared JS and WASM hashes loaded.
- Coordinate/value crossings pass scalar/astral/invalid boundary properties.

## Completion

WASM is hermetic, provenanced, and semantically typed—not a copied side workspace.
