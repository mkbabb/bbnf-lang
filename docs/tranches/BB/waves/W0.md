# BB.W0 — Enumerator + VM Oracle + Ranker + `crates/ir-rewrites/` scaffold

**Opens after**: AZ close + AY-II close
**Agents**: 3 parallel
**Hard gate**: Ruler-style enumerator, e-graph residue split, VM oracle
wrapper, automatic ranker, and `crates/ir-rewrites/` scaffold are all
landed; enumeration run on JSON rediscovers ≥ 80% of Tranche H hand-
coded rules applicable to JSON.
**Status**: planned

## Scope

1. Stand up `crates/ir-rewrites/` as a new general-infra crate with the
   rule schema, RON validator, ranker, and tier classifier.
2. Land the Ruler-style CVC enumerator over `IrNode` at
   `crates/egraph/src/ruler/enumerate.rs` with a declared size bound
   and alphabet.
3. Land the e-graph residue split at `crates/egraph/src/ruler/residue.rs`
   — candidates already in the same e-class are skipped; different
   classes route to the VM oracle.
4. Land the VM oracle wrapper at `crates/egraph/src/ruler/oracle.rs`
   with per-candidate time and memory budget.
5. Author base fleet-wide rules in `crates/ir-rewrites/src/base/*.ron`:
   associativity, commutativity, identity folds, bounded unrolling.
6. Teach `bbnf_derive` to discover `grammar/<name>/rewrites/*.ron` at
   build time and compile matching rules into the grammar's cost-config.
7. Soundness check: run the enumerator on JSON; confirm rediscovery of
   Tranche H's JSON-applicable hand-coded rules at ≥ 80% rate.

## Phase sub-items

### BB.W0.1 — `crates/ir-rewrites/` scaffold

Rule schema (`Rule`, `RuleSet`, `Provenance`, `Tier`), RON validator
with file/line diagnostics, initial base rules, ranker and tiering
modules skeletoned (implementation fleshed in BB.W0.3).

Sub-gate: `cargo check -p ir-rewrites` green; `cargo test -p ir-rewrites
--test schema_roundtrip` green on base RON files.

### BB.W0.2 — Enumerator + e-graph residue + VM oracle

Ruler-style CVC enumerator over `IrNode` up to bounded term size;
e-graph residue split (same-class skip, different-class to oracle);
VM oracle wrapper that lowers `IrNode` to bytecode, runs against
fixture corpus, compares tape output under per-candidate budget.

Sub-gate: `cargo test -p egraph --test ruler_residue_split` green;
residue-first dispatch confirmed by counter-metric in test output.

### BB.W0.3 — Ranker + tiering activation

Weighted scorer across frequency, cost delta, generality, similarity,
novelty, size; classifier routes to Class 1 / 2 / 3; audit-log ndjson
writer for Class-1 auto-accepts.

Sub-gate: `cargo test -p ir-rewrites --test ranker_tiering` green;
synthetic fixtures produce the expected tier assignment.

### BB.W0.4 — `bbnf_derive` grammar-rewrite discovery

Build-time scan of `grammar/<name>/rewrites/*.ron`; schema validate;
compile into the grammar's cost-config alongside fleet-wide rules.

Sub-gate: a throwaway `grammar/json/rewrites/smoke.ron` is detected and
compiled; removing it takes effect on next build.

### BB.W0.5 — Tranche H soundness rediscovery on JSON

End-to-end run: enumerator → residue split → VM oracle → ranker → tier
report. Compare rediscovered rules against Tranche H's JSON-applicable
hand-coded set.

Sub-gate: ≥ 80% of Tranche H JSON rules appear in the rediscovery
report; misses are logged with enumeration traces.
