# SK-V15 W4 Plan: Pattern H Generated Discipline

Inputs: W4 research A-F, SPEC W4, DISPATCH W4,
`DEP-W4-PATTERN-H-PROVENANCE`, and
`DEP-W4-W6-CSS-LEGACY-RUNTIME-SHIM`.

Intervention: root runtime generators emit line-1 provenance and expose one
non-writing full-universe check. W4 closes on generated bytes reproduced by
that check, not on manual headers or write-command output.

## Scope

Owned source:

- `xtask/src/main.rs`
- `xtask/src/regen_simple_runtime.rs`
- `xtask/src/regen_css.rs`

Owned generated Pattern H outputs:

- `crates/core/src/runtime/{bbnf,bnf,css_l4,css_pretty,csv,ebnf,google_sheets,json,math}/**/*.rs`

Excluded: `crates/core/src/runtime/*.rs`, root grammar-generated files, skinny
runtime files, bench ledgers, prior tranche JSONs, CSS typed provider, Decision
Engine, and BackendShape lowerers.

## Cost

SPEC W4: High risk, manual LOC `120-280`, generated runtime checks, docs LOC
`80-180`, redress `<=30m`. Target implementation is `160-260` manual LOC.
Generated runtime diffs count as generated only if `check-runtime` reproduces
them. Active W4 plan/challenge/redress docs must fit `80-180`; if they do not,
trim docs or record REDRESS before implementation.

## Implementation

1. Add:

   ```sh
   cargo run -p xtask -- check-runtime
   cargo run -p xtask -- check-runtime --grammar css_l4
   ```

   The no-arg command is the W4 close command. `--grammar` is diagnostic only.
   Accepted IDs: `css_l4`, `math`, `csv`, `bbnf`, `bnf`, `ebnf`,
   `css_pretty`, `google_sheets`, `json`. Unknown IDs reject.

2. Split emitters into render/write/check paths:

   - `regen_simple_runtime::{run,check}(grammar)`
   - `regen_css::{run,check}()`

   `check` must not call `write_if_changed`.

3. Attach the header after `prettyplease` formatting:

   ```text
   // @generated by xtask regen-<command>; do not edit by hand.
   ```

   Command names: `regen-css`, `regen-math`, `regen-csv`, `regen-bbnf`,
   `regen-bnf`, `regen-ebnf`, `regen-css-pretty`,
   `regen-google-sheets`, `regen-json`.

4. Make no-arg `check-runtime` fail closed:

   - render final header-bearing bytes;
   - compare expected generated path set with actual Pattern H path set;
   - validate each file's header against its owning directory;
   - validate `xtask/runtime-projections/*.toml` against workspace grammar
     metadata and reject missing/extra root runtime projections;
   - validate `output_dir == crates/core/src/runtime/<module_name>`, with
     CSS L4 exactly `crates/core/src/runtime/css_l4`;
   - reject stale or unexpected files.

5. Regenerate root runtime outputs through the owning generators, then prove
   final bytes with no-arg `check-runtime`.

No W4 deletion of root runtime files, `LegacyPath`, or `LegacySegment`.
