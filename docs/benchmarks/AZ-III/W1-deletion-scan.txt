## Methodology

1. `cargo metadata --locked --no-deps --format-version 1` — see W1-metadata.txt.
2. `rg -n "crates/tape|json-prototype|tape::|Tape|Gorgeous JIT|A1"` over the
   live source tree and active docs, excluding archived audit docs
   (`docs/tranches/*/audit/*` were excluded from the unified scan but each
   token is then bucketed below for full visibility), `docs/tranches/*/archive/**`,
   `target/**`, `Cargo.lock`, `node_modules/**`, `package-lock.json`,
   `playground/public/img/*.svg`, and the AZ-III evidence file itself.
3. Per-token bucketed scans then drill into `crates/` (Rust source) only,
   so structural verdicts are based on Rust-source residue, not doc residue.

The unified raw scan is large (2667 lines, 348 distinct files); the
overwhelming majority is doc-prose archaeology in tranche specs, audit reports,
and bench archives — not live code. The classification below is by token bucket
so each W1.3 verdict is verifiable independently.
