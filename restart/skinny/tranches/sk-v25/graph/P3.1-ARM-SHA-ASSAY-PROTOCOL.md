The external build driver first executes the lane-derived Apple-ARM

sha2 -i sha2-asm` command (adding only A's command-line feature), retains its exact stdout bytes,
and computes their SHA-256 itself. Only that capture-capable driver may execute
the build argv. It canonically serializes the same argv into
`BBNF_EXPORTER_BUILD_ARGV_JSON` and embeds the computed digest as
`BBNF_EXPORTER_BUILD_FEATURE_GRAPH_HASH`. A release exporter with either value
absent, malformed, noncanonical, or empty is invalid. Each lane retains:

- canonical Cargo argv and complete `cargo tree -e features` bytes and hash;
- complete `cargo build -vv` bytes, including every emitted rustc invocation;
- sanitized build-environment, source, local-input, build-tool, toolchain,
  registry-supply, Cargo.lock, and final executable hashes;

  `sha256h`, `sha256h2`, `sha256su0`, and `sha256su1` at the frozen counts; A

The exporter receipt does not claim to reconstruct rustc argv or Cargo's
feature graph at runtime. Those are immutable external build receipts; only
their exact hashes cross the compile-time boundary.

The following gate is repeated immediately before every slot. A gate search
may last at most 20 minutes. Failure to find one passing window rejects the
entire assay; it does not create another attempt.

2. `sysctl -n hw.physicalcpu hw.logicalcpu hw.perflevel0.physicalcpu
   hw.perflevel0.logicalcpu` is, as four keyed values, exactly `18/18/6/6`.
3. `BBNF_ARCHITECTURE_WORKTREE_THREADS=18`, available work and parallelism are
   sufficient, and the emitted worktree transcript later proves `workers=18`.
4. `pmset -g ps` says exactly `Now drawing from 'AC Power'`; the unique current
   `pmset -g` row is `powermode 2`.
5. `pmset -g therm` contains both exact absence statements: no thermal warning

6. Three `sysctl -n vm.loadavg` samples, 10 seconds apart, each have one-minute

7. `ps -Ao pid=,ppid=,pcpu=,state=,comm=` is captured with the exact
   launcher/exporter/time/sample PID tree. Outside that tree, aggregate CPU is
   at most `50%` and every process is at most `25%`. Name-based exclusion is
   forbidden.
8. Frozen byte ledgers still match all bbnf source/build inputs and all
   parse-that source/build inputs. Value's Git/index/untracked namespace and

## Eight processes, fixed order

There are exactly eight first-attempt slots:

```text
A1-perf
A1-profile
B1-perf
B1-profile
B2-perf
B2-profile
A2-perf
A2-profile
```

Each perf slot launches its exporter only through:

```text
LC_ALL=C TZ=UTC BBNF_ARCHITECTURE_WORKTREE_THREADS=18 \
  /usr/bin/time -lp <bound-exporter> architecture --output <fresh-output>
```

Only `/usr/bin/time -lp` supplies perf-slot wall, user/system CPU, retired
instructions, cycles, involuntary context switches, and RSS. Each profile slot
launches a distinct exporter process, immediately attaches
`/usr/bin/sample <exact-pid> 120 1 -file <fresh-sample>`, and waits for that
exporter. A profile process contributes samples and addresses only: its timing
is never a perf observation. Output paths, PIDs, receipts, and samples are
unique per slot.

A failed or missing slot invalidates the campaign and marks every later slot
`UNRUN_AFTER_FIRST_HARD_GATE`. No substitute, rerun, reordered slot, inherited
receipt, reused PID/output, or S1 evidence is admissible.

The complete generation has exactly 16 members. RFC 6901 differences are


These are mandatory differences, not slack. A and B are installed as regular

are equal. Their executable hashes must differ before launch; the direct proxy
hash equals that executable hash. The dynamic-runtime transcript begins with
the executable hash, so its tool and build copies are equal within a lane and
differ across lanes. The sanitized build-environment transcript includes the
exact `BBNF_EXPORTER_BUILD_ARGV_JSON` and
`BBNF_EXPORTER_BUILD_FEATURE_GRAPH_HASH` name/value pairs, so its A/B hash must
differ. If any of these prerequisites does not differ exactly, there are not two
truthful subjects and the assay rejects before timing.

Every listed direct A/B leaf and every value-applicable derived leaf must differ;

## Decision

For wall, retired instructions, and user-plus-system CPU, each lane's two-run
median is `(run1 + run2) / 2`. Every B wall must be below every A wall and every
B/A median must be at most `0.90`. Aggregate profile share is
`SHA-compression samples / all samples`; B/A must be at most `0.50`, with a
nonzero denominator and B addresses inside the hardware body. Existing output
and RSS ceilings remain exact.

Mixed results, contention, missing counters, missing receipts, fallback, or
comparator failure reject S2. Promotion still requires the authority's fresh
B-only release and two governing first-attempt twins. Until then, performance
credit is zero.

`P3.1-ARM-SHA-S2-LEDGER.tsv` enumerates every S2-changed subject member except
itself; the production source census and external exact-ledger validator bind
the ledger file's own bytes without an impossible cryptographic self-reference.
