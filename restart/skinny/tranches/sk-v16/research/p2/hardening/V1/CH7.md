# S-P2 V1 CH7 Overfit-Prune

Disposition: ACCEPT.

The artifacts prune overfit sources rather than laundering them:

- x86 AVX/PEXT/GFNI/VBMI routes are rejected for SK-V16 implementation scope;
- harness checksum/local FNV are rejected as primitive sources;
- CSS broadcast and legacy fact-stream proof paths are rejected;
- JSON Unicode product shortcuts are quarantined under existing REDRESS;
- generic codegen branches are not authorized by S-P2.

Surviving candidates are expressed as grammar-neutral byte/mask/tape
operations with generated policy ownership. Where a candidate lacks a
non-JSON witness or same-wave consumer, it is explicitly quarantined.
