# BB-C.W1 — direct deterministic optimizer and decision baselines

## Goal

Give every optimization/global decision a simple correct oracle before comparing
specialized engines.

## Implementation

1. For each rewrite family, implement direct canonicalization or bounded exhaustive
   enumeration over sealed Program/AnalysisFacts with explicit costs and report.
2. For each CSP-like decision, model coupled variables and hard constraints
   directly; use deterministic enumeration or branch-and-bound on the real corpus.
3. Compare acceptance, values, spans, diagnostics, types, layouts, generated bytes,
   cost, time, peak memory, incrementality, and implementation size.
4. Return a validated solution or typed unsat/budget failure. Never choose per-node
   minima that can violate a global constraint.
5. Keep these oracles test-visible even if a later engine wins; they are the small-
   instance differential truth, not a second production route.

## Gates

- Every incumbent optimizer/solver call has a direct correct oracle and consumer
  fixture.
- Hash/order/worker permutations yield identical choice and report.
- Exhaustion/unsat publishes no partial plan.
- Complexity and performance evidence is raw and paired on Apple Silicon.

## Completion

P5 comparisons can now ask whether complexity buys something rather than assuming
it does.
