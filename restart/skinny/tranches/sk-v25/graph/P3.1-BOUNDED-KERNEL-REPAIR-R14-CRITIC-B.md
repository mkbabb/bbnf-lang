## Production proof

### 1. `H` and `P` are now distinct and correctly owned

`PreflightSerializer` already inspects each dynamic JSON string once. When that
existing inspection finds a percent byte, `hash.rs:207-213` performs two scalar
updates from the same known raw length:

- checked aggregate addition into `percent_string_bytes` (`P`); and
- scalar maximum into `max_percent_string_bytes` (`H`).

There is no second string scan and no allocation. `GraphJsonPreflight` at
`hash.rs:1266-1272` now carries exactly the five required scalar summaries
`S,R,P,H,J`; the exact dry pass and output-drift check are retained at
`hash.rs:1324-1377`.

The consumers are separated correctly:

- `validate.rs:786-788` passes aggregate `P` only to
  `percent_decode_work_bound`; and
- `validate.rs:558-606,820` passes maximum-single-string `H` only to
  `canonical_phase_peak_bytes`, which combines the retained node/edge reference
  vectors with the decoder allocation bound.

The privacy traversal decodes dynamic strings serially, so the maximum one-string
allocation, not the sum of all decoder allocations, is the correct simultaneous
heap premise. Conversely all percent-bearing bytes are visited, so aggregate `P`
is the correct work premise.

### 2. `G = 4T + 9N + 19E` is checked, charged, and precedes construction

`identity_width_construction_work` at `validate.rs:620-636` uses checked
multiplication and addition for all terms. `construct_max_identity_width` then:

1. derives `G` from already admitted cardinalities;
2. charges the exact owner `validation-identity-width-construction`;
3. emits `PhasePrecharged`; and only then
4. enters the single `graph.truth.iter().try_fold` at `validate.rs:728-750`.

The traversal allocates nothing and scans no source payload. Its source shape is
within the R13 envelope: four fixed actions per Truth row, nine for each node
Identity visit, and nineteen for an edge and its two Identity visits. Unknown
Truth contributes only its admitted outer row work. No action is refunded,
cached, tokenized, or shifted to a later owner.

### 3. `W` is grammar-total in production

`identity_total_dynamic_string_bytes` at `validate.rs:697-721` has an exhaustive
match over all nine current `Identity` variants:

- the seven one-field variants return the sole dynamic string length;
