### AY-II.W1.b — Competitor bench extension + value-lane close capture

Mechanism. Extend `competitors.rs` with a `bench_bbnf` group
mirroring the 9 existing groups. The bbnf lane invokes
`JsonParser::parse(&input)` — not `parse_with_visitor`, not a
`to_value()` bypass — and consumes the returned `Parsed` via
`black_box`. W0' delivers the value surface as a parse
side-effect, so the bench cost is the honest same-work measurement
sonic-rs / simd-json deliver:

```rust
macro_rules! bench_bbnf_json {
    ($name:ident, $file:expr) => {
        fn $name(b: &mut Bencher) {
            let input = load_json($file);
            b.bytes = input.len() as u64;
            JsonParser::parse(&input)
                .expect(concat!($file, ": bbnf parse failed"));
            b.iter(|| {
                let parsed = JsonParser::parse(black_box(&input)).unwrap();
                black_box(parsed);
            });
        }
    };
}
```

Add per-fixture entries (`bbnf_data`, `bbnf_twitter`, `bbnf_citm`,
`bbnf_canada`, `bbnf_data_xl`), a `bench_bbnf` `benchmark_group!`,
and an entry in `benchmark_main!`. Close-evidence sequence
(`bench` profile, fat-LTO, single invocation per bench):

