# BB-C.W6 — grammar/regex/self-hosting fixed point

## Goal

Close the mutual bootstrap between bbnf-lang grammars and parse-that regex/parser
generation as an explicit acyclic staged process.

## Implementation

1. Consume sealed parse-that regex syntax/HIR/VM and manifests; no host regex or
   duplicate root/skinny engine may escape semantics.
2. Generate canonical regex syntax/parser artifacts from BBNF Program through the
   sealed stage pipeline, then regenerate BBNF parsers with those artifacts.
3. Name seed, stage-1, and self-hosted artifacts and their consumers. Seeds are
   immutable bootstrap data, never alternate production routes.
4. Start from empty generated directories. Iterate until two consecutive semantic
   manifests and output bytes match; record every stage digest and negative corpus.
5. Delete Python rewrites, cargo-expand ambiguity, manual patches/copies, and legacy
   generated paths in the same change that proves the fixed point.

## Gates

- Two independent clean fixed points are byte-identical.
- Generation-time graph is acyclic and runtime graph has only declared recursion.
- Stale/missing/wrong-generator/wrong-Unicode/manual-edit mutations fail ordinary
  build/package consumption.
- Negative regex/grammar corpora preserve diagnostics, spans, and termination.

## Completion

Self-hosting is reproducible artifact truth, not an undocumented circular build.
