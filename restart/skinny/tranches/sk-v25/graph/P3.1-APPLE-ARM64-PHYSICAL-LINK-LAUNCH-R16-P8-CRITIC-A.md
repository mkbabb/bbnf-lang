Those primary headers show why Endpoint Security is relevant but not a proved
lossless nonprivileged substitute:

1. An exec event exposes its target process and version-gated cwd and Apple ARM
   image CPU type/subtype. Accessors expose the actual exec argument and
   environment vectors.
2. The acting and target process records carry audit tokens. Apple documents
   `(pid, pidversion)` as the tuple for linking events to one process execution,
   and supplies parent and responsible audit tokens in newer message versions.
3. Per-event and global sequence numbers let a client **detect that events were
   dropped**. The same documentation says drops occur when the kernel produces
   more events than the client can handle. Detection is not a guarantee of
   losslessness; a detected gap leaves the proof RED.
4. The native client route requires entitlement, FDA, and root. It is therefore
   not the requested nonprivileged observer.

The installed `eslogger` route is narrower still. Its manpage says it:

- suppresses events for every process in its process group;
- exposes notify events, not authorization events;
- is not an API and gives no performance or schema-stability guarantee; and
- lacks system-extension integrity protection.

An exec argv can reveal a direct vector or an `@response-file` token, but the
Endpoint Security exec structure contains no response-file byte payload.
Because `eslogger` receives only notification of an event that has already
occurred, a later file read cannot race-freely prove the exact bytes, encoding,
and order consumed by the child. If the response branch occurs, this observer
cannot close that proof bit.

Audit-token ancestry can bind fork/exec/exit identities. It cannot by itself
prove which request from a client caused work in a pre-existing compiler-cache
daemon: that is an IPC-causality claim, not necessarily a parent/child claim.
Time proximity, serial jobs, quiescence, target-path coincidence, and matching
configuration remain correlation rather than a request-to-process proof.
