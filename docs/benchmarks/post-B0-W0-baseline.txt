## Notes

- Pre-flight environmental condition: at HEAD 9bff7e7d the sibling
  `../parse-that/` worktree carried uncommitted in-flight edits that
  removed `egraph::SaturationCache` from public surface, making every
  workspace `cargo check` fail in ~1.5s with `E0425` against
  `bbnf-regex/src/info/mod.rs`. The measurements above were captured
  with those edits stashed (`git stash` in parse-that) and restored
  after the run. This is itself a baseline datum: the pre-B0 routine
  loop is exposed to sibling-repo drift because every default cargo
  command traverses the full patched graph.

- `scripts/test-tier.sh leaf` fails in < 1s because the script still
  names `-p bbnf-tape` after the crate rename to `tape` — the script
  never compiles anything. The leaf tier has been structurally dead
  since the rename landed; B0.W0 surfaces it via `make iter-test-leaf`,
  which inherits the same script. Repair of the package-name list is
  required for the `iter-test-leaf` alias to produce real numbers;
  B0.W0.c will re-measure after the fix lands.

- Warm `cargo check --workspace` (7.16s) reflects the full dev-profile
  fingerprint walk and linker cost with no source edits. Warm
  `cargo check --profile ax-iter --workspace` (0.23s) reflects the
  same walk on ax-iter's stripped-debuginfo artefacts. The ~30x gap is
  the routine-iteration lever B0.W0 promotes into the public command
  surface.

- `cargo test --workspace --no-run` cold = 126.10s is the compile-gate
  baseline for the full workspace test suite under the default `dev`
  profile. The warm incremental (14.40s) is the cost of re-link + test
  binary linkage with no source edits, dominated by the N aggregate
  test binaries the workspace produces.
