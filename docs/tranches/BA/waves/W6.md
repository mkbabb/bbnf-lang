5. Run samply against every Hard Gate citing performance: AU floor row, sonic-class row, speculative-checkpoint row. Save the 7-artefact contract per claim under `.profiles/samply/post-BA/`. The contract becomes canonical close discipline.
6. Run the close-honesty checklist: every claim in FINAL.md is grounded in PROGRESS.md or a cited artefact; every gate marked MET has an evidence path that resolves; every status word matches the latest gate run; every cross-tranche debt entry names BB or BC explicitly.

8. Update PROGRESS.md to match reality at close.
9. Update the parent tranche table in any cross-references; the BA wave statuses move to `complete` (or `complete_with_misses` if any non-routable carry routes to a triumvirate).

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the AU floor has any row BELOW after W3 + W2 closure (the `19/19 at-or-above` invariant fails; W3's mechanism redesign did not deliver); BA cannot close;
- `bbnf_get_twitter > 5× sonic_get_twitter` same-harness (W4's mechanism redesign did not deliver); BA cannot close without triumvirate-driven scope reveal;
- F10 watchdog rows persist (the matrix has rows that the bench harness watchdog timed out; environmental gating is not retired);
- the close-honesty checklist surfaces a stale status word, an evidence path that does not resolve, or a cross-tranche debt entry that names a generic "future tranche" placeholder rather than BB or BC;
- the samply 7-artefact contract cannot be produced for one of the perf claims because of an environmental issue (the canonicalisation is failing; the previous environmental-gating debt has not actually retired);
- three diagnostic-loop iterations fail to isolate why a perf row is BELOW;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.
