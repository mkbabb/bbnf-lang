# BB-D.W0 — one runtime and typed value fabric

## Goal

Carry TypeSolution and LoweringPlan into runtime values without per-grammar clones,
unchecked layout guesses, or wrapper sand.

## Implementation

1. Inventory tape/document/arena/cursor/value/span/visitor/view organs by invariant,
   not filename or grammar. Identify generated repetition versus true semantic
   specialization.
2. Define one revision-qualified value fabric for primitives, tuples/lists/options,
   records/variants, spans, diagnostics, captures, documents, and typed paths. Its
   layout is checked from TypeSolution plus LoweringPlan.
3. Separate borrowed input views, arena-owned values, and serialized/WASM carriers
   explicitly. Cross-source/revision/layout construction fails; no forged offsets.
4. Consolidate duplicate runtime projections into cohesive modules. Merge tiny
   wrappers that share no invariant; split god modules along stable ownership and
   lifecycle boundaries. Child filenames strip module-name stutter.
5. Generate grammar-specific kinds/accessors only from solved schemas and
   provenance; keep generic behavior handwritten and tested once.
6. Move tests to external source-isomorphic trees and add round-trip/disconnect/
   wrong-revision/invalid-span/no-panic mutations.

## Gates

- Every runtime value/span/type/layout has one owner and exact revision lineage.
- Rust/TypeScript/schema round-trips preserve value, span, variant, and diagnostics.
- Graph shows no grammar-clone runtime SCC, arbitrary layout constructor, or wrapper
  farm; complexity deltas are justified by invariants.
- Public malformed inputs fail typed without panic/UB.

## Completion

Runtime is one load-bearing consumer of semantic typing and lowering decisions.
