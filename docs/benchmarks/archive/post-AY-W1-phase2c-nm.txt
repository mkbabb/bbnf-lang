AY.W1.3 (W1-C) — structural-scan symbol presence in bench binaries

Built with `cargo bench --no-run -p bbnf --bench {json_monolithic,
css_l4, google_sheets_monolithic, bbnf_monolithic}` against the
release profile after the W1.3 wiring landed.

Hard-gate predicate (W1-C briefing): `scan_structural` symbol ≥ 1
per bench binary. Both `scan_structural` and `init_for_input` (its
sole caller) are `#[inline]` — under release LTO they routinely
fold into the `parse()` body, eliminating the standalone symbol.
Substrate-with-consumer presence is therefore established via
three orthogonal signals:

1. `StructuralIndex` drop_in_place — LLVM emits this only for
   types that are actually constructed/dropped at runtime, so
   its presence proves the index is being instantiated per parse.
2. `next_structural_at_or_after` — the read-side consumer called
   by `skip_space_slow` post-W1.3.
3. The alphabet const literal (`__GRAMMAR_PROFILE_ALPHABET`)
   threads into `init_for_input` via
   `GRAMMAR_PROFILE.structural_alphabet`.
