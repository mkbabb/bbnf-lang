## §2 — Critical Defects

1. **SC-6 StructuralAlphabet event classes leak grammar semantics.** Lock 14 requires generic crates to carry zero grammar-specific public types, grammar-named modules, grammar branches, or feature flags (`restart/locks/LOCKS.md:60`). SC-6 instance tables encode `Open(Object)`, `Close(Array)`, `DeclTerminator`, `PropValueDelim`, `RangeDelim`, and `Open(FnCall)` as event classes (`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:370`-`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:405`, `restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:424`-`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:437`). SC-6 then admits this becomes a grammar-named-by-proxy surface and requires neutral role re-expression (`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:619`-`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:630`). This is a real blocker until folded.

2. **The Lock amendment text prematurely blesses StructuralAlphabet without the neutral-role repair.** The proposed Lock 1 refinement says the structural projection is emitted as a StructuralAlphabet data table and thereby honours Lock 14 (`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:263`-`restart/skinny/tranches/sk-v8/research/p2-substrate-ceiling/SC-6-lock1-amendment-generalisation.md:280`), but §4 still contains grammar-specific event roles. ## §5 — Verdict Rationale

REVISE, not REJECT. The cohort's central move is grammar-general when kept to byte sets, generated classifier tables, opaque structural-class ordinals, one tape, and CostFacts-backed eligibility. That shape is exactly what Lock 14 permits.

The failure is narrower and sharp: SC-6's StructuralAlphabet tables still carry grammar semantic roles, and the proposed Lock amendment claims Lock 14 compliance before that repair is made. Hereupon V2 must normalize every event class to a fixed neutral role set and leave grammar meaning inside generated grammar modules. After that fold, CH2 has no remaining objection to the union substrate.
