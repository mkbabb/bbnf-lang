# W3 — Post-freeze generality proof

Purpose: freeze the compiler and declarative schemas, then prove the scalar event
vertical against a held-out grammar without an implementation escape hatch.

## Contract

The sealed plan supports exactly the W2 full-consumption scalar event sink.
Check, tape/value, borrowed/lazy, selective path, and direct typed decode remain
banked portfolio requirements. Each becomes eligible only after SK-V26 closes and
a named consumer plus semantic plane supplies a new bounded tranche trigger.

## Controls

Before freeze, the vertical must carry the public witness set:

- JSON: recursive sums, escapes, exact declared number policy;
- CSS: nested lexical regions, comments, both quote forms, recovery/error-token
  policy;
- Google Sheets: Pratt/expression path.

W0 records the feature matrix and stable witness IDs. After the compiler,
grammar/metadata schema, plugin registry, and dispatch tables are frozen, an
adjudicator selects a held-out grammar by feature coverage. The choice is not
named in advance.

Adding the held-out grammar may add only a grammar instance conforming to the
already-frozen schema. Generic source, schema, plugin, registry, and dispatch
digests must remain unchanged.

Grammar instances and metadata may contain no embedded host code, executable
actions, native callbacks, per-grammar dependency, build feature, plugin, or
format-identity dispatch. W0 seals the candidate-pool digests and selection rule;
W3 records the selected digest without changing either.

## Forbidden evidence of generality

- grammar/rule-name switches;
- raw grammar text reparsing;
- `include_str!` grammar-specific templates;
- backend filenames whose algorithms are JSON/CSS;
- executable metadata/actions, native callbacks, per-grammar dependencies, or
  per-grammar build features;
- silent fallback to sink-only, delimiter scan, Span, or boxed enum;
- hand-authored per-grammar runtime directories;
- a grep allowlist that omits the actual generated/runtime path.

## Banked sink contract

The long-horizon API vocabulary remains explicit—borrowed/owned, raw/decoded,
duplicate/order policy, validation scope, path scope, and typed-field policy—but
no unimplemented sink may be used as close evidence. The event plan must preserve
the typed facts those later sinks need without forcing their representation.

## Regeneration

Two empty output directories must reach the same byte-identical fixed point. Every
artifact records grammar, semantic IR, lowering plan, generator, toolchain, and
output digests.

## Exit

- all public witnesses and the held-out grammar pass positive, negative,
  recovery, and full-consumption event suites;
- the held-out grammar produces zero generic-source, schema, plugin, registry,
  and dispatch diff;
- generated outputs are byte-identical across two clean runs;
- no forbidden special case remains;
- one clean BBNF package consumer uses the selected event vertical;
- replaced candidate paths are named for W4 deletion.
