## §1 - Synthesis

S-P1 is converged by the V4/V5 accepted challenge cycles. Its durable limits
matter to this draft: profile rows are not admissions, direct rows are now
symbol-attributed but mostly generated envelopes, ten typed rows still lack
generated product surfaces, CSS declaration-values profiling is measured but
timer/fact-sink dominated, and structural SIMD is a scanner micro-signal rather
than union admission.

S-P2 is converged by the V3/V4 accepted challenge cycles. It authorizes S-P3
planning but carries strict limits: CSS rows 1-6 are conditional row-production
scopes, not generic primitive admissions; standalone D1 capacity, standalone
bitmap/next/bulk/byte_context/cache-hint inventory, EOR3/BCAX, and similar
support-only items are non-admissive; every JSON plane and every non-OUT_OF_SCOPE
CSS feature remains an admission target until admitted or architecturally
blocked.

Only P3-A is present at V1. P3-B wave sequencing, P3-C falsifiability gates,
P3-D telemetry-schema binding, and P3-E pre-blocked-route ledger are absent
under `restart/skinny/tranches/sk-v13/research/p3/` at draft time. This draft
therefore cites that absence and uses P3-A plus S-P1/S-P2/SYNTHESIS/HANDOFF as
the source of truth. The orchestrator may fold later P3-B through P3-E outputs
into a V2/V3 draft, but this V1 draft must not invent a narrower scope.

The user pin addendum controls the close. The prior REDRESS-119 direct fixpoint
and REDRESS-120 SK-V11 close are history only. `parse_only` is admission-
eligible again. All 17 corpora x 3 JSON planes are in G5. CSS is not complete
after the one SK-V12 declaration-values row: the target remains 24 CSS parity
features, 1 admitted and 23 still open unless later folded P3 output proves a
feature is OUT_OF_SCOPE or architecturally blocked.

## §3 - Falsifiability binding

Global JSON gate:

- Scope: all 51 JSON rows, meaning all 17 corpora across `parse_only`,
  `direct_to_struct`, and `real_typed_struct`.
- Admission formula: `Track 1 Mbps > sonic_rs_strict_mbps + 1` on the same
  corpus, same output plane, same strictness, and strict equality path.
- Source for current anchors: `skinny/RESULTS.md`; P3-A §3 carries the current
  compact threshold table for present rows. W0 must regenerate a gate-consumed
  `SK-V13-open` threshold table instead of copying stale Mbps values.
- Missing typed rows: the first row-producing wave must generate the product
  surface, capture same-run strict sonic-rs typed Mbps, then use
  `sonic_rs_real_typed_struct + 1`; absence is not an architectural block.

Global CSS gate:

- Scope: the 24 non-OUT_OF_SCOPE CSS parity features from the SK-V13 CSS parity
  matrix, including the already-admitted declaration-values row.
- Admission formula: `Track 1 Mbps > lightningcss_mbps + 1` on the same
  output plane with strict equality, feature-coverage match, and cssparser or
  hand-checked golden oracle.
- Source for current admitted CSS row: `skinny/RESULTS.md` and REDRESS-125/127
  record `css_l4/declaration_values/direct_to_struct/main` at
  `429.34420791225705 Mbps` with lightningcss `168.92962215656692 Mbps`.
- New CSS rows must capture their own same-run lightningcss and oracle artifacts
  before redress; this draft does not invent those numbers.

Decision-engine gate:

- No decision-engine wave closes on scaffold. The resolver must be consumed by
  codegen/lowering in the same wave family, old P1-P8 fallback must be deleted
  or fail-closed, JSON and CSS guard rows must pass, and abrogate criteria must
  be measured: e-graph budget, CSP solve time, stale cost rate, and rewrite
  order variance.

Union/SIMD gates:

- A union attempt must cite REDRESS 96/97/98 and name its material differential:
  codegen-private per-rule projection, e-graph selected shape, or SIMD-first
  mask-to-tape writer. A retained class column, parser-owned cursor/list, sidecar
  event vector, or public `UnionTape` rejects.
- Every SIMD/ASM primitive needs scalar reference, strict checkasm/corpus
  parity, a same-wave production consumer, feature-mask disclosure, and row
  movement or measured rejection. Checkasm-only is not admission.

## §4 - Pre-blocked routes

Every wave inherits these pre-blocks. A wave may reopen a category only by
citing the REDRESS entry, naming the material differential, passing CHALLENGE
when first-of-class, wiring the same-wave consumer, and measuring the row.

- REDRESS 28/33: no naive NEON tiny-string replay or broad string-kernel close.
- REDRESS 50-55: no parse-time aux side table, parser-local event cursor,
  structural-mask cursor, decoded-string stats sink, quote-source hash stream,
  visitor sidecar, or renamed equivalent.
- REDRESS 60-72: no direct-materialization replay, direct source-hook receiver
  shortcut, semantic fact hashing under a new name, retained string-boundary
  collapse, or direct cap replay.
- REDRESS 80: no one-row `canada` mantissa-widen patch as a number strategy.
- REDRESS 82-84: no single-quartet unicode classifier, StringBlock16 tiny
  probe, or object-pair value-byte control compaction as close.
- REDRESS 88-90: no PMULL prefix-XOR, CSSC CTZ/bulk-emission, or canary-only
  route as a performance admission.
- REDRESS 92 and 96-98: no scanner/tape isomorphism assumption, class column,
  full structural-position vector, streaming cursor, class-lane-only substrate,
  parser-owned cursor/list, aux table, or sidecar event vector.
- REDRESS 107/108 and SK-V10 proof-only escape limits: unicode work must be
  batched/policy-level and row-moving.
- REDRESS 113-120: non-JSON axis blocks and direct fixpoint history are not
  closure authority under the 2026-05-21 pin.
- REDRESS 121-127: preserve Lock 14 GrammarConfig evidence, Lock 16
  escape-mask/checkasm discipline, CSS comparator/admission evidence,
  zero-orphan evidence, and SK-V12 close lessons. The `a64_ascii_set_run_skip`
  production split may not defer again.
