# BA.W0 — Path IR + Type Checker + Parent-Pointer Micro-Bench

**Opens after**: AZ close (`StructRegistry` populated; tape fully
dissolved; direct-to-struct emitter singular).
**Agents**: 3 parallel, disjoint file bounds.
**Hard gate**: Path IR compiles against `StructRegistry` for JSON and
CSS L4; invalid paths fail at compile time with grammar-aware
diagnostics; parent-pointer micro-bench drives a measured strategy
pick.
**Status**: planned.

## Scope

1. Land the path IR — `Path`, `PathSegment`, `TypedPath<G, T>` — as a
   first-class value in `crates/core/src/path/`.
2. Land the type checker consuming AZ's `StructRegistry`. Malformed
   paths fail to compile with a diagnostic naming the offending
   segment, the struct type it was resolved against, and the valid
   alternatives at that position.
3. Run the parent-pointer micro-bench across the three candidate
   strategies (in-struct pointer, root traversal, hybrid sidecar) on
   citm / tailwind / sheets fixtures. Commit the winning strategy
   plus the measurement artefact; the pick is measurement-driven,
   not declared.

W0 ships types, type errors, and the parent-pointer decision only.
No path *execution* yet.

## Phase sub-items

### BA.W0.1 — Path IR

`Path` is a sequence of `PathSegment { Key(Sym), Index(usize),
Wildcard }`. `TypedPath<G, T>` is a `Path` annotated with the
grammar `G` it resolves against and the terminal type `T`. Display
and parse implementations match the JSONPath RFC 9535 subset
(key, index, wildcard).

Sub-gate: `Path::parse("$.pair[0].number")` round-trips through
display and parse.

### BA.W0.2 — Type checker

`type_check(path: Path, grammar: &Grammar, registry: &StructRegistry)
 -> Result<TypedPath<G, T>, PathError>`. Each segment is resolved
against the current struct position; a missing field, an index
into a non-list, or a terminal mismatch returns a `PathError`
carrying the segment, the struct name, and the valid alternatives.

Sub-gate: `tests/path_type_errors.rs` exercises five malformed
paths per production grammar (JSON, CSS L4) and asserts the
diagnostic shape.

### BA.W0.3 — Parent-pointer micro-bench

An `AscentStrategy` trait with three implementations
(`InStructPointer`, `RootTraversal`, `HybridSidecar`).
`benches/parent_pointer_strategies.rs` exercises each against
citm / tailwind / sheets fixtures for wildcard-sibling workloads
and records ns/ascent plus RSS delta. W0 closes with a committed
strategy pick and the bench artefact.

Sub-gate: measured ns/ascent and RSS deltas recorded; winning
strategy wired as the default in `ascent.rs`.

### BA.W0.4 — IR path-check pass

`crates/ir/src/passes/path_check.rs` is an IR pass that collects
every compile-time `path!` site in the workspace and validates
each against the grammar's `StructRegistry`. Runs as part of the
existing IR audit pass chain.

Sub-gate: pass runs in CI; missing `StructRegistry` entry triggers
hard failure with grammar-aware diagnostic.

## Hard gate

1. `Path::compile` against the JSON grammar returns a typed
   accessor for every Named rule. Artefact:
   `docs/benchmarks/post-BA-W0-json-coverage.txt`.
2. Invalid path compiles fail with a diagnostic naming segment +
   struct + alternatives. Artefact: `tests/path_type_errors.rs`
   snapshots.
3. Parent-pointer micro-bench artefact committed with the
   strategy pick. Artefact:
   `docs/benchmarks/post-BA-W0-ascent.json`.
4. 17-entry AU-baseline matrix no regression vs. AZ close.
   Artefact: `docs/benchmarks/post-BA-W0-mid.json`.
