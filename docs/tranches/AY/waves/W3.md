# AY.W3 — Value API: Runtime Substrate + `<Grammar>Value` Emitter + Three Bench Lanes

**Opens after**: W2 close (Named preservation unlocks TypeDesc-aware variant emission for aggregate named types)
**Agents**: 1 serial (W3a) → 1 serial (W3b depends on W3a) → 2 parallel (W3c bench + round-trip parity)
**Hard gate**: `parsed.to_value::<<Grammar>Value>()` emits + type-checks for all 4 production grammars; `Parsed::get::<T>(path)` lazy-query API present; three bench lanes populated in `post-AY-W3-value.json` (canonical / lazy-get / eager-materialized); JSON twitter eager bbnf/sonic ratio ≤ 1.5× the parse-only baseline at W3 start (A10-recommended gate); round-trip parity `serialize_compact(to_value(parse(src))) == serialize_compact(parse(src))` green across 5 JSON fixtures + 3 CSS fixtures; all 14 existing parity + canonical harnesses green.

## Scope

Per A10's three-part split:

1. **W3a — Runtime substrate**: new `crates/core/src/runtime/handle.rs` (StringHandle, CompoundHandle) + `crates/core/src/runtime/path.rs` (path-query types for lazy `get_by_path` lane). Zero emitter touch; zero regen. A10-recommended prerequisite — isolates the handle / path types from the emitter change so W3b's risk surface is minimised.

2. **W3b — Grammar-emitted `<Grammar>Value` + `parsed.to_value::<T>()`**: emit `<Grammar>Value` enum from IR's `TypeDesc` with **TypeDesc-equivalence-class collapse** (`FxHashMap<TypeDesc, usize>` at emit time; rules with identical TypeDesc collapse into a single variant). Handle-into-Tape materialisation: enum variants are either inline scalars or `StringHandle { loc: u64, len: u32 }` / `CompoundHandle` pointers reusing existing `Tape` + AoS `packed_cache` sidecar. Compound children in `Vec<Value>`; no second arena. Reuse AQ.6.C's existing per-Alt `<RuleName>Value` enums (`view/alt.rs:137-146`) at the aggregator level.

3. **W3c — Three bench lanes + round-trip parity**: extend `crates/core/benches/json/value.rs` + create matching `crates/core/tests/value_api_apples_to_apples.rs`. Three bench families:
   - **Canonical** (5 fixtures): `bbnf_canonical_<fx>` (`parse + serialize_compact`) vs `sonic_canonical_<fx>` (`from_str::<Value> + to_string`).
   - **Lazy-get** (twitter only): `bbnf_get_<fx>` (new `Parsed::get::<T>(path)`) vs `sonic_get_<fx>` (`sonic_rs::get_by_path`).
   - **Eager** (5 fixtures): `bbnf_value_<fx>` (`Parsed::to_value::<JsonParserValue>()`) vs `sonic_value_<fx>` (`from_str::<Value>`) — replaces current walker-based `walk_tape` proxy.

## Phase sub-items

### AY.W3a.1 Handle substrate (serial)

Create `crates/core/src/runtime/handle.rs`:
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct StringHandle { pub loc: u64, pub len: u32 }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct CompoundHandle { pub tape_offset: u64, pub record_count: u32 }
```
`StringHandle::loc` encodes input-byte offset (upper 48 bits) + arena-hosted flag (lower 16 bits) so grammars can mix input-borrowed and arena-decoded strings. `CompoundHandle::tape_offset` points into the Tape's column arrays.

Create `crates/core/src/runtime/path.rs`:
```rust
pub enum PathSegment<'a> { Field(&'a str), Index(usize) }
pub struct Path<'a>(&'a [PathSegment<'a>]);
```

Export from `crates/core/src/runtime/mod.rs`. Zero other file touches.

**Sub-gate**: `cargo build --workspace` clean; `cargo check -p bbnf` clean.

### AY.W3a.2 Parsed accessor methods (serial, after W3a.1)

Extend `crates/core/src/runtime/parsed.rs`:
```rust
impl<'p, R: Root> Parsed<'p, R> {
    pub fn to_value(&self) -> R::Value<'_> where R: ValueRoot { ... }
    pub fn get<T>(&self, path: Path<'_>) -> Option<T> where R: PathQuery<T> { ... }
}
```

Two new GAT-bound traits on `Root`:
```rust
pub trait ValueRoot: Root { type Value<'p>; fn view_to_value<'p>(view: Self::View<'p>) -> Self::Value<'p>; }
pub trait PathQuery<T>: Root { fn query<'p>(view: Self::View<'p>, path: Path<'_>) -> Option<T>; }
```

`ValueRoot` + `PathQuery` are emitted per grammar in W3b.

**Sub-gate**: `parsed.to_value()` + `parsed.get::<&str>(Path)` type-check on a synthetic grammar; cargo build clean.

### AY.W3b.1 `<Grammar>Value` emitter (serial, after W3a)

Create `crates/core/src/backend/rust/view/value.rs`. Emit one Rust enum per grammar:

Shape rules (per A10):
- TypeDesc-equivalence-class collapse — build `FxHashMap<TypeDesc, VariantIndex>` at emit time; rules with identical TypeDesc collapse to single variant.
- For each unique TypeDesc:
  - `Span` → `&'p str` field (or `StringHandle` if arena-decoded).
  - Scalar primitive (`U8`, `F64`, etc.) → primitive field.
  - `Tuple([T1, T2, ...])` → struct variant with named fields (names from Seq children's `Ref` targets; positional if unnamed).
  - `Vec<T>` → `Vec<<Grammar>Value<'p>>` field.
  - `Named(sid)` → dedicated variant named after the type (relies on W2 Named preservation).

Reuse AQ.6.C's existing per-Alt `<RuleName>Value` enums at `view/alt.rs:137-146` — aggregator builds `<Grammar>Value::<RuleName>(<RuleName>Value<'p>)` wrappers. A10 §d explicitly corrected this from my v1 draft's "new sub-enum `<RuleName>Alt`".

Emit `impl ValueRoot for <Grammar>` with `view_to_value` walking the root view + constructing the enum via rule-by-rule match on `rule_kind()`.

Emit `impl PathQuery<T> for <Grammar>` for common T (`&str`, `f64`, `bool`, `<Grammar>Value<'p>`) via `packed_cache` binary-search on path-encoded offsets. A10 §e corrected my v1 draft's deferral of the lazy lane — pulls in-scope here (< 100 LOC via packed_cache).

**Sub-gate**: `cargo expand -p bbnf --test json_canonical_parity` shows `pub enum JsonParserValue<'p> { … }` + `impl ValueRoot for JsonParser`.

### AY.W3c.2 Round-trip parity test (parallel agent F, after W3b)

fn assert_value_roundtrip(fixture: &str) {
    let src = load_fixture(fixture);
    let parsed = JsonEmit::parse(&src).unwrap();
    let via_view = JsonEmit::serialize_compact(parsed.node_view());

    let via_value_serialize = serialize_value(&via_value_materialize); // reuse bbnf-ser

}
