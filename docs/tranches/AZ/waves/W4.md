# AZ.W4 — Recovery Semantics + Sync-Point Resume

**Opens after**: W3 close
**Agents**: 2 parallel
**Hard gate**: Malformed corpus inputs recover to declared sync points and resume downstream parse on the AY substrate.
**Status**: planned

## Scope

1. Define grammar-derived recovery semantics and sync-point admission.
2. Resume downstream parse on the same AY substrate after recovery.
3. Prove recovery behavior on malformed canonical corpora.

| File | Access |

**Do NOT touch**: build/profile tooling, any `.bbnf` grammar syntax surface beyond semantics already admitted by the host system, throughput-only optimization code.

## Phase sub-items

### AZ.W4.1 Recovery contract

Mechanism: define grammar-derived sync-point and recovery semantics
without introducing grammar-name branches.

Files touched: `crates/core/src/runtime/recovery.rs`,
`crates/core/src/backend/rust/emitter/grammar.rs`.

Sub-gate: recovery rules compile and emit on admitted grammars.

### AZ.W4.2 Resume-after-recovery

Mechanism: resume parse from declared sync points into the canonical AY
substrate.

Files touched: `crates/core/src/runtime/recovery.rs`,
`crates/core/src/backend/rust/emitter/grammar.rs`.

Sub-gate: recovered parses produce canonical substrate output.

### AZ.W4.3 Malformed-corpus tests

Mechanism: run recovery on malformed corpus fixtures and assert sync-
point alignment plus downstream suffix parse.

Files touched: `crates/core/tests/recovery_sync.rs`,
`crates/core/src/runtime/recovery.rs`.

Sub-gate: malformed-corpus recovery tests pass.
