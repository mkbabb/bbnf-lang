## Findings

1. V4 is explicitly additive, not a replacement for the accepted V2/V3 REDRESS
   contracts. The V4 addendum says it supplements V2 and V3 and does not weaken
   their REDRESS, material-differential, state-machine, or numeric abrogate
   contracts (`restart/audit/totality/p2/T-P2-V4-FOLD-ADDENDUM.md:11`).
   Therefore the V2 REDRESS-119 row matrix and Union/PMULL/CSSC checklist remain
   binding (`T-P2-V2-FOLD-ADDENDUM.md:99`, `T-P2-V2-FOLD-ADDENDUM.md:120`).

2. The REDRESS-slice table preserves material-differential requirements. It says
   a slice may reach S-P3 only if its blocker is cleared in the wave plan
   (`T-P2-V4-FOLD-ADDENDUM.md:62`). The direct JSON rows still name strict sonic
   row movement, semantic digest or numeric mismatch as abrogate, scalar/SWAR or
   scalar digest rollback, and blockers for byte-hash substitution, missing
   parity, or missing first consumer (`T-P2-V4-FOLD-ADDENDUM.md:68`-`73`). The
   union/PMULL/CSSC slice cites REDRESS 88/89/96/97/98, has no V4 consumer, and
   remains non-shortlist until a combined matrix and exact first consumer exist
   (`T-P2-V4-FOLD-ADDENDUM.md:74`).

3. Historical rejects are not silently reopened. REDRESS 88 rejected PMULL
   prefix-XOR after correctness and disasm proof because JSON rows regressed
   (`skinny/REDRESS.md:2510`-`2535`); REDRESS 89 rejected the narrowed CSSC
   next-bit/bulk consumer after guard regressions (`skinny/REDRESS.md:2544`-
   `2585`). V4 keeps those as source-backed, non-shortlist research categories,
   not admits. Likewise, REDRESS 96/97/98 retired the retained union-substrate
   thesis after two correctness-green implementations regressed every required
   row (`skinny/REDRESS.md:2823`, `skinny/REDRESS.md:2881`,
   `skinny/REDRESS.md:2910`). V4's union row blocks replay on prior regression,
   missing consumer, parity failure, or guard regression.

4. REDRESS-119 remains fixpoint history, not direct-row close authority. REDRESS
   119 closed as measured direct fixpoint with no behavior source intervention
   and no row movement (`skinny/REDRESS.md:3497`, `skinny/REDRESS.md:3524`);
   REDRESS 120 keeps those residual rows exhausted unless a future pass names a
   material differential with fresh profile and micro-proof evidence
   (`skinny/REDRESS.md:3542`, `skinny/REDRESS.md:3549`). V4 maps selected direct
   slices to owners and blockers, but absent or coalesced direct rows are not
   admitted by omission because the V2 row matrix remains authoritative.

5. The non-shortlist blockers are honest. V4 marks `tbl_tbx_escape_decode_batch`,
   `digit_run_accumulate_udot`, `string_context_64`, and
   `cache_hint_prefetch_store` non-shortlist because their strict parity command,
   grammar policy, exact caller, or first consumer is missing
   (`T-P2-V4-FOLD-ADDENDUM.md:50`-`54`). `pmull_cssc_structural_union_emit64`
   has two existing checkasm commands but still lacks the combined density/order
   matrix and a consumer, so V4 correctly keeps it non-shortlist
   (`T-P2-V4-FOLD-ADDENDUM.md:52`). `escape_mask_64` remains prerequisite-only
   despite its strict checkasm (`T-P2-V4-FOLD-ADDENDUM.md:49`).

6. REDRESS 121-127 stay correctly classified. V4 does not turn REDRESS 122's
   escape-mask correctness prerequisite into production admission; REDRESS 126's
   4.718x delimiter microbench remains a route-production split with no generated
   CSS wiring or `RESULTS.md` movement; and REDRESS 127 remains one admitted CSS
   row with union/ASM routed separately (`skinny/REDRESS.md:3603`,
   `skinny/REDRESS.md:3768`, `skinny/REDRESS.md:3824`). The `RS-CSS-ASCII-RUN-SKIP`
   row is dispatchable only after S-P3 names the exact generated scan-block row

7. Prior guards are not demoted. V4 requires any later S-P3 selection of a

   (`T-P2-V4-FOLD-ADDENDUM.md:56`-`58`). It also preserves the normalized
   `admissibility_state` enum and forces prose labels into summary/blocker fields
