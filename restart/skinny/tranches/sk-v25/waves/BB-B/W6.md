# BB-B.W6 — atomic production transposition and incumbent deletion

## Goal

Cut production consumers to the sealed stage path and delete the mutable IR/type/
fact incumbents without aliases or dual execution.

## Implementation

1. Choose vertical slices that end in real formatter/LSP/backend/runtime/generated
   consumers, not horizontal data structures without consequence.
2. Transpose proven root behavior and selected skinny carriers into Program,
   DependencyGraph, TypeSolution, and AnalysisFacts. Each slice carries semantic
   differentials and exact artifact provenance.
3. Update APIs directly to sealed stage values. Do not add `From<GrammarIR>`, legacy
   type aliases, feature toggles, fallback solvers, or shadow writes.
4. Delete `GrammarIR` public-field authority, pointer DAG, type domain/projector,
   silent obligations/fallbacks, mutable analysis sidecars, `FactAuthority`, and
   their tests once the same-change consumer proof passes.
5. Rehouse modules by stage invariant at Goldilocks granularity; strip parent-name
   stutter and keep tests external/isomorphic.
6. After all carriers are proved, delete transposed skinny organs and update the
   disposition ledger. No whole skinny deletion until every unique carrier resolves.

## Gates

- Repository search finds one production stage path and none of the deleted symbols
  or semantic aliases.
- All grammar corpora, generated Rust/TS consumers, formatter/LSP, packages, and
  runtime faces compile and pass through the new values.
- Accepted behavior changes have explicit adjudicated corpus truth; all others are
  differential-equal in value/span/diagnostic/type/output.
- Graph re-extraction shows no old/new dual route or cross-stage back edge.
- Line/module/complexity deltas are recorded; replacement does not hide growth in
  adapters or generated templates.

## Completion

The replacement is production, the incumbent is absent, and skinny has fewer
unresolved carriers.
