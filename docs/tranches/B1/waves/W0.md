Mechanism:
- Align `.cargo/config.toml`, `Makefile`, `scripts/test-tier.sh`, and
  `docs/instructions/PROFILING.md` to the actual routine surface:
  `cargo iter-check`, `cargo iter-test-leaf`, `scripts/test-tier.sh`
  tiers, and the documented meaning of `iter-check-full`.
- Delete stale comments and stale prose that still describe
  pre-`700501f5` or pre-`ac7bc754` behavior.
- Record routine-surface timing and pass/fail output in
  `docs/benchmarks/post-B1-W0-routine.txt`.
- Downgrade `iter-check-full` from the routine-alias comment block
  to an explicit close-ceremony alias (it still routes through
  `--workspace`, but the prose names it as heavy close-proof).
- Add a new `iter-check-lsp` alias checking `bbnf-analysis` +
  `bbnf-lsp` alone under `--profile ax-iter`; records the fast-path
  validation command for the crates currently excluded from
  `iter-check`.
- Add a new `make ay-prime` Makefile target that seeds
  `target/.bbnf-cache/` by running `cargo check -p bbnf-bootstrap
  --lib` (+ optionally `-p gorgeous --lib`) once. Reports the
  resulting cache-entry count.
- `.cargo/config.toml` carries a comment-block naming the
  three-alias cost model: routine (`iter-check`) / lsp-validate
  (`iter-check-lsp`) / close-gate (`iter-check-full`).
