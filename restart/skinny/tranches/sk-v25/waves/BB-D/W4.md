# BB-D.W4 — packed sibling transposition

## Goal

Adopt current parse-that, value.js, keyframes.js, and glass-ui packages as packed
consumers with explicit API disposition and no workspace-source shortcuts.

## Order

1. sealed parse-that package and value/diagnostic/coordinate contract;
2. Value V-next's separately accepted versioned return, currently targeting
   value.js 5 while its active P00–P07 lane remains on published parse-that 1.0;
3. keyframes.js 7 only after its own separately accepted packed return and declared
   value contracts;
4. exactly packed glass-ui 7.0.0 components/tokens/styles after local behavior
   parity and only after the parser/BBNF semantic locks have closed. Value V-next's
   separate future Glass 8 release does not change this campaign's owner-selected
   7.0.0 target.

## Implementation

1. Pack exact candidates, install into clean worktrees, record archive/resolution/
   runtime hashes, and update one boundary at a time.
2. Classify each API KEEP/REPLACE/DELETE with behavior evidence. Make clean breaks;
   no aliases, dual props, fallback imports, or compatibility modules.
3. Preserve local HeaderRibbon semantics until packed Glass proves all behavior.
   Use Glass flattening/component organization idioms without copying its internals.
4. Run each sibling’s own tests plus bbnf component/browser crater before moving to
   the next. Feed defects back to the owning repo, repack, and rerun.
5. Remove stale direct dependencies and lock identities made unnecessary by the
   transposition.
6. Treat the current Glass working checkout as read-only owner state. Re-pin its
   clean commit at execution time, pack it, and prove archive and resolved-byte
   hashes before the first import. Never consume a workspace/source link.
7. Replace Glass 3.x atomically. Delete all compatibility props, token fallbacks,
   duplicate style faces, and adapters in the same cut; 3.x and 7.0.0 may not
   coexist in source, lockfile, bundle, or runtime graph.
8. Refuse any Value P03 parser patch or V-next return whose append-only coordination
   event is expired, V3-pinned, overlaps the active major-session paths, or lacks
   exact content receipts. A live untracked tree requires a full file-ledger hash;
   a stable coarse porcelain digest is insufficient.

## Gates

- Resolution evidence proves packed bytes, not source links/workspace aliases.
- No stale sibling major, dual API, fallback, or undeclared provider edge remains.
- Manifest, lock, packed archive, module graph, and runtime bundle each expose only
  Glass 7.0.0, from one proven package identity.
- Type/build/unit/component/browser gates pass after each package cut.
- Graph and lockfile expose one canonical identity per package face.

## Completion

The constellation is a directed packed supply chain with no hidden reverse coupling.
