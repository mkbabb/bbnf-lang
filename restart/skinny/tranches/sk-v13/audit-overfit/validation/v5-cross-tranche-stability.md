**First appearance: SK-V12 W1b-1.**

- Each provider's `emit_runtime_files()` wraps 4 template files (config.rs, generated.rs, mod.rs, parser.rs) with a fake `@generated by skinny bbnf-codegen` header.

## §6 Surprising Findings

### 6.1 Lock 14 Non-Enforcement During SK-V12 CSS Admit

SK-V12 SYNTHESIS.md §0.1 Close Condition (4): "Lock 14 passes by executable evidence." SK-V12 close records `lock14=pass:lock14_baseline::validate` in REDRESS 126. Yet audit Agent 3 (sk-v13-audit-overfit-lock14-scan.md §2 CRITICAL) identifies 3 CRITICAL Lock 14 violations in runtime lib.rs and codegen dispatch—violations that predate SK-V12 and are still present at SK-V12 close. **Lock 14 "pass" was a gate signal, not a code audit.** The gate checked that the admitted CSS row did not *add new* violations, but did not retroactively enforce the pre-existing 3 CRITICAL violations.

### 6.2 SK-V9 W3 Union Hypothesis Falsified But Framework Survives

SK-V9 proposes union-substrate (structural index retained alongside offset tape). SK-V10 W3 rejects it (REDRESS 96/97/98); S-P2 substrat-ceiling finding is refuted by W3 measured miss on every must-improve row. Yet the W8/W9 framework (per-grammar policy + CostFacts wiring) ships as scaffold in SK-V13. Agent 5 (SYNTHESIS-AUDIT-OVERFIT.md §Decision-engine fold) finds W5–W7 (regex extraction, e-graph, CSP solver) are real-landing; W8–W9 (per-grammar policy, union surfacing) are SCAFFOLD-ONLY with zero runtime wiring. **The defeated hypothesis left framework debris (W8/W9 scaffold) that blocks new work until completion (PRUNE-5).**

### 6.3 Corpus Mismatch Pattern: CSV-Sized Data as Production Bench

SK-V13 Agent 1 (SYNTHESIS-AUDIT-OVERFIT.md §CSS L4) finds CSS L4 corpus is 85–357 bytes embedded in bench source. SK-V12 CSS admit targets "Bootstrap + Tailwind + Material + Animate (~960 KB)" per scoping, but landing corpus is bench micro-fixtures. **Corpus inflation risk:** a 351-byte nested_layout measurement at 52,234 Mbps (422 Mbps vs lightningcss) likely represents token-only or fast-fail paths, not representative throughput. SK-V10/SK-V11 JSON rows carry proper corpora (twitter 2.5 MB, citm 1.7 MB, etc.); CSS L4 does not.

### 6.4 Decision-Engine CSP Solver Acceptance Without Consumer

W7 CSP solver wires into `compile()` with 6 constraints (parity, recognizer, substrate, SIMD, capacity). Agent 5 verifies it runs and drives P1–P8 cascade facts. Yet no production grammar-specific policy surface is wired to consume the solver's shape selections. W8 (per-grammar policy wiring) is SCAFFOLD. **The CSP solver shipped as shipped wiring infrastructure, not a shape-selector; shape selection remains hardcoded fallback (hand-written templates).**
