# BA.W1 — Cross-Grammar Hybrid Expansion

**Opens after**: W0 close
**Agents**: 3 parallel
**Hard gate**: The AY hybrid substrate and specialization discipline show measurable wins on at least two non-JSON grammar families without grammar-name routing.

## Scope

1. Carry the AY substrate and shared-cost decisions into CSS hot paths.
2. Carry the same mechanisms into Sheets or BBNF where the facts admit
   it.
3. Prove the expansion remains grammar-derived.

## Phase sub-items

### BA.W1.1 CSS hybrid carry-forward

Mechanism: apply packed-layout, navigation, and specialization decisions
to CSS hot paths where grammar facts admit them.

Files touched: `crates/core/src/backend/rust/emitter/grammar.rs`,
`crates/core/src/backend/rust/emitter/shapes/compound.rs`,
`crates/core/tests/css_l4_parity.rs`.

Sub-gate: CSS parity tests pass on the broadened runtime path.

### BA.W1.2 Sheets or BBNF hybrid carry-forward

Mechanism: apply the same fact-driven mechanisms to whichever of Sheets
or BBNF admits them most profitably first.

Files touched: `crates/core/src/backend/rust/emitter/shapes/pratt.rs`,
`crates/core/tests/google_sheets_parity.rs`,
`crates/core/tests/bbnf_parity.rs`.

Sub-gate: the chosen non-JSON grammar passes parity tests on the
broadened runtime path.

### BA.W1.3 Generality proof

Mechanism: verify that the broadened mechanisms are admitted by grammar
facts and not by grammar-name branching.

Files touched: `crates/core/src/backend/rust/emitter/grammar.rs`,
`crates/core/tests/css_l4_parity.rs`,
`crates/core/tests/google_sheets_parity.rs`,
`crates/core/tests/bbnf_parity.rs`.

Sub-gate: wire-contract and parity tests pass without grammar-name
dispatch.

## Hard gate

1. CSS and at least one of Sheets/BBNF improve versus AY close on their
   designated benchmark entries. Artefact:
   `docs/benchmarks/post-BA-W1-mid.json`.
2. Updated parity tests pass on the broadened path. Artefact:
   `docs/benchmarks/post-BA-W1-parity.txt`.
3. `cargo expand -p bbnf --bench css_l4` or the chosen grammar bench
   shows the broadened mechanisms emitted from grammar facts. Artefact:
   `docs/benchmarks/post-BA-W1-expand.txt`.
