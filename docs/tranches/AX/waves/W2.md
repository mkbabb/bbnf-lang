# AX.W2 — Parity Harnesses CI-Gated

**Opens after**: W1 close
**Agents**: 3 parallel (JSON parity, CSS parity, Sheets+BBNF self-parity)
**Hard gate**: Zero divergence on every comparator on master; CI blocks PR on failure.

## Scope

Per AX invariant 20, semantic `*_parity.rs` AST-level harnesses are the correctness oracle inherited from W0a pre-pivot (`bbnf_ast_parity`, `json_value_parity`, `sheets_expr_parity`, `css_l4_parity`, `sonic_rs_parity`, `lightningcss_parity` survive W0b's `tape_parity_*.rs` retirement). W2 EXPANDS that substrate: corpus from ~5 → ≥ 200 fixtures per grammar; three new comparators (simdjson OnDemand, serde_json, cssparser); CI-gate enforcement. No new shape-parity-vs-walker harness — that category retired with W0b.

Land five structural-parity harnesses, CI-gated from the first commit of this wave. Every subsequent optimization wave (W4–W14) runs against these gates; any regression fails the wave at commit time. Binary pass/fail per invariant 5 — no tolerances.

1. **JSON × sonic-rs**: `bbnf::json::Value::from(input)` deep `PartialEq` to `sonic_rs::Value::from(input)`.
2. **JSON × simdjson OnDemand**: schema-driven extraction parity via `simd-json` crate bindings.
3. **JSON × serde_json**: round-trip through `serde_json::Value` with zero divergence for borrow-unsafe-input fallback path.
4. **CSS × lightningcss**: field-equivalent `StyleSheet` per-variant. Divergence documented per-field.
5. **CSS × cssparser**: token-level parity.
6. **Sheets × self**: `Ast::from(serialize(Ast::from(parse(input)))) == Ast::from(parse(input))` for every corpus input.
7. **BBNF × self**: same self-parity shape.

## Phase sub-items

### W2.1 JSON parity triple

Three comparators for JSON. Each asserts zero divergence on ≥ 200 fixtures. Fixtures include the five bench corpus files (data_s, twitter, citm, canada, data_xl) + synthetic corner cases.

```rust
#[test] fn json_sonic_parity_twitter() {
    let input = std::fs::read_to_string("data/json/twitter.json").unwrap();
    let bbnf_val = bbnf::json::Value::from_str(&input).unwrap();
    let sonic_val = sonic_rs::from_str::<sonic_rs::Value>(&input).unwrap();
    assert_eq!(bbnf_val, sonic_val); // deep PartialEq
}
```

Equivalent for simdjson OnDemand (schema-driven) and serde_json (round-trip).

### W2.2 CSS parity pair

lightningcss variant-level equivalence. For each of ~50-80 lightningcss AST variants, a test fixture + assertion. Any divergence documented in `css_divergence.md` with rationale (e.g. comment preservation, vendor-prefix variance, custom-property representation).

cssparser token-level parity: bbnf's tokeniser output matches cssparser's on normalize/bootstrap/tailwind corpus.

### W2.3 Sheets + BBNF self-parity

No external comparator. Round-trip: parse → `Ast::from` → serialize → parse → `Ast::from` → assert equal to first `Ast::from`. For every corpus fixture + synthetic edge cases per grammar.

### W2.4 CI integration

GitHub Actions (or equivalent) step running `cargo test --test parity --release`. PR blocks on failure. Existing sonic-rs + lightningcss parity tests from AW-IV.W5.2 are superseded by this superset; retire the old tests in-wave.

## Hard gate

1. Zero divergence: `bbnf::json::Value` vs `sonic_rs::Value` on ≥ 200 fixtures.
2. Zero divergence: `bbnf::json::Value` vs simdjson OnDemand (schema-driven subset).
3. Zero divergence: `bbnf::json::Value` round-trips through `serde_json::Value`.
4. Zero divergence: `bbnf::css::StyleSheet` vs `lightningcss::StyleSheet` on ≥ 200 fixtures; divergence doc per field.
5. Zero divergence: bbnf CSS tokens vs cssparser on normalize/bootstrap/tailwind.
6. Sheets + BBNF self-parity round-trips zero divergence.
7. CI gate active; PR fails on harness regression.
