# AX.W8 — Speculative Parsing + Shape-Transition Markov Predictor

**Opens after**: W7 close
**Agents**: 3 parallel (codegen-time matrix miner, predictor + online tuning, rollback scratchpad + orchestration)
**Hard gate**: CSS bootstrap hot-predict hit-rate ≥ 0.75; twitter rollback ≤ 5%; on-correct speedup ≥ 1.05×; pre-parity fuzz zero rollback-tape divergence.

## Scope

Per aw5-n2.1. High-repetition workloads (CSS ruleBlock, JSON uniform arrays, BBNF rule lists) exhibit strong compound-to-compound shape transitions. Predictor mines transition matrix at codegen time; online EWMA blending available via `ParseOptions::tune_online`.

1. **Shape-transition matrix at codegen**: new IR pass mines per-grammar transition frequency from corpus samples. Emits `SHAPE_TRANSITIONS: &'static [[f32; 11]; 11]` per grammar into `generated.rs`. Wire-contract: matrix populated for every primary grammar.
2. **Online predictor (opt-in)**: `ParseOptions::tune_online = true` blends codegen-time matrix with online EWMA observations (α = 0.01).
3. **Rollback scratchpad orchestration**: per-compound speculation with snapshot + commit-or-rewind. Confidence threshold > 0.6 for speculation; below threshold falls through to sequential parse.
4. **W8.4 pre-parity fuzz**: speculate + rollback fuzz on ≥ 50 inputs per grammar; every speculation rollback path compared tape-identical to non-speculative path. Fails wave if any non-identical rollback observed.

## Phase sub-items

### W8.1 Shape-transition matrix miner

Per-grammar: walk `grammar/<grammar>/corpus/*` samples through shape classifier; accumulate per-pair `(ShapeTag_A, ShapeTag_B)` transition frequencies. Emit normalized matrix into `generated.rs` as `pub const SHAPE_TRANSITIONS: &[[f32; 11]; 11]`.

### W8.3 Rollback scratchpad + speculation orchestration

Per-compound:
1. At compound close, predictor returns top-1 next-shape with confidence.
2. If confidence > 0.6, open speculative `Columns` scratchpad + save `ShapeSnapshot` (placeholder — AY will provide full type; W8 uses a minimal speculative-state tuple).
3. Speculatively parse predicted shape's open pattern.
4. When actual next-shape resolves: match → commit speculative writes; mismatch → `Columns::rewind(snapshot.columns_len)` + re-parse from snapshot.

### W8.4 Pre-parity fuzz

≥ 50 inputs per grammar. Every speculation attempt's rollback path parsed sequentially → tape A. Same input parsed with speculation enabled → tape B. Assert `tape A == tape B` bit-for-bit. **Fails wave if any divergence.** Sanity-check that speculation doesn't silently corrupt output.
