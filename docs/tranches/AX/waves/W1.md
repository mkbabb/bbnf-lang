### Principle

`NodeView<'p>` + `TapeCursor<'p>` is the user-facing AST. No owning `<Grammar>Ast` enum emits. Clone-across-thread solved by `Parsed<T>` owning `(Tape, Arc<str>)`; views are `Copy` on `&Parsed`. The shape emitter's typed-payload accessors (W0a.2.p/q) + `serialize_compact` (`#[parser(serialize)]`-derived) + `_prettify` (`#[parser(prettify)]` + `@pretty`-derived) form the full user surface. External-comparator parity holds when both parties emit the same canonical form from the same input.

### W1r.1 — IR-derived `BINDINGS`

Replace the static `BINDINGS` slice + `COLOR_FIELDS` const at `crates/core/src/backend/rust/view/named_types.rs` with a builder that walks `ir.types` for every `TypeDesc::Named(sid)` and resolves its declared tuple-of-scalars shape from the rule body:

```rust
pub struct RustNamedTypes<'ir> {
    strings: &'ir [String],
    bindings: rustc_hash::FxHashMap<StringId, Vec<TypeDesc>>,
}

impl<'ir> RustNamedTypes<'ir> {
    pub fn from_ir(ir: &'ir GrammarIR) -> Self {
        let mut bindings = FxHashMap::default();
        for (node_id, td) in ir.types.iter() {
            if let TypeDesc::Named(sid) = td {
                let shape = infer_named_shape(ir, *node_id);
                bindings.insert(*sid, shape);
            }
        }
        Self { strings: &ir.strings, bindings }
    }
}

impl<'ir> NamedTypeResolver for RustNamedTypes<'ir> {
    fn resolve_named(&self, sid: StringId) -> Option<TypeDesc> {
        self.bindings.get(&sid).map(|s| TypeDesc::Tuple(s.clone()))
    }
}
```

`infer_named_shape` walks the declaring rule's body for its tuple of scalars (U8 discriminator + field types from `ir.types`). `Color` / `ColorMix` now land via the same mechanism as every other grammar-declared named type. The static slice + hand-picked names are deleted outright.

**Hard gate**: `cargo expand -p bbnf --lib` shows every grammar-declared `-> input : <Name>` resolves via the new builder. `cargo test -p bbnf_ir --test payload_layouts` green. `Color` / `ColorMix` continue to resolve (they remain grammar-declared in `grammar/css/pretty.bbnf` and derived forms).

### W1r.2 — JSON canonical-form parity

Create `crates/core/tests/json_canonical_parity.rs`. For every fixture under `crates/core/tests/data/json/`:

```rust
#[test]
fn canonical_parity_<fixture>() {
    let src = include_str!("data/json/<fixture>.json");
    let bbnf_canonical = JsonParser::parse(src)
        .map(|p| JsonParser::serialize_compact(p.root_view()))
        .unwrap();
    let oracle = sonic_rs::from_str::<sonic_rs::Value>(src).unwrap();
    let oracle_canonical = sonic_rs::to_string(&oracle).unwrap();
    assert_eq!(bbnf_canonical, oracle_canonical);
}
```

No `PartialEq`, no `From<sonic_rs::Value>`, no hand-coded Value type. `sonic-rs` stays dev-dep only.

**Hard gate**: `cargo test -p bbnf_core --test json_canonical_parity` green on data / twitter / citm / canada / data_xl.

### W1r.3 — CSS L4 canonical-form parity

Create `crates/core/tests/css_l4_canonical_parity.rs`. For every fixture under `crates/core/tests/data/css/`:

```rust
#[test]
fn canonical_parity_<fixture>() {
    let src = include_str!("data/css/<fixture>.css");
    let bbnf_canonical = CssL4Parser::stylesheet_prettify()
        .parse(src)
        .map(|ops| pprint::render(&ops, shared_printer()))
        .unwrap();
    let oracle = lightningcss::stylesheet::StyleSheet::parse(
        src,
        ParserOptions::default(),
    ).unwrap();
    let oracle_canonical = oracle
        .to_css(PrinterOptions { minify: false, .. })
        .unwrap()
        .code;
    assert_eq!(token_normalize(&bbnf_canonical), token_normalize(&oracle_canonical));
}
```

`token_normalize` is grammar-derived — it uses `CssL4Parser`'s own tokenizer rules to canonicalize whitespace + comments identically on both sides. Divergences resolve in bbnf's `@pretty` directives OR in the shared normalizer — never in a per-comparator bridge. `lightningcss` stays dev-dep only.

**Hard gate**: `cargo test -p bbnf_core --test css_l4_canonical_parity` green on bootstrap / normalize / tailwind.
