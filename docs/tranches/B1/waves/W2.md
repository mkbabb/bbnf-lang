**Opens after**: W1 hard gate green
**Covers**: migration Steps 9-11
**Agents**: 3 parallel (W2.a, W2.b, W2.c)
**Total budget**: ~4 hours wall, 6-8 agent-hours
**Hard gate**: CI runs nextest under the pin; every script in the abrogation catalog has an action outcome; sibling repos share the same pinned nightly
**Status**: planned

## Scope

1. Update `.github/workflows/ci.yml` so the CI default path uses
   `taiki-e/install-action@nextest` and runs
   `cargo nextest run --workspace --profile ci`. Land
   `bench-iai.yml` from W1.c's draft as a separate workflow.
2. Execute the abrogation catalog end-to-end: every script listed
   in `docs/tranches/meta-audit/08-abrogation-catalog.md §Part 1`
   and every Makefile target listed in §Part 2 has a single
   outcome — DELETED (with its CI step removed in the same commit),
   REWRITTEN (to parse divan JSON or call a cargo alias), or
   explicitly KEPT (with a named justification).
3. Propagate the pinned nightly + minimal `.cargo/config.toml` to
   `../parse-that` and `../pprint` per
   `docs/tranches/B1/patches/cross-repo-propagation.md`. Extended
   fleet modernization (gorgeous sibling, csp-solver, csc411,
   crates/ai, etc.) is named here but not landed in B1.

**Opens**: W1 close.
**Agent count**: 1.
**Hard cap**: 40 min.

- Rewrite `.github/workflows/ci.yml`:
  - Add `taiki-e/install-action@nextest` step.
  - Replace `cargo test --workspace` with `cargo nextest run
    --workspace --profile ci`.

    `target/nextest/ci/junit.xml`.

  bench-iai.yml` (dry-inspection locally); confirm both parse.

  `docs/benchmarks/post-B1-W2-ci.txt`.

### B1.W2.b — Script abrogation per catalog (Step 10)

**Opens**: W1 close (parallel with W2.a and W2.c).
**Agent count**: 1.
**Hard cap**: 3 hours.
**Role**: single owner to avoid racing on the scripts/ directory;
the catalog's per-script actions are executed sequentially.

Mechanism:
- Open `docs/tranches/meta-audit/08-abrogation-catalog.md §Part 1`
  as the worklist. For each script listed, execute its action
  column verbatim:
  - DELETE scripts: `git rm <script>`; in the same commit, delete
    every reference to that script from `Makefile`, `.github/
    workflows/*.yml`, `docs/instructions/PROFILING.md` (W3
    consolidates that file — W2.b's job is to emit the ledger
    row naming the doc reference that W3 must delete).
  - REWRITE scripts: apply the per-script draft in
    `docs/tranches/B1/patches/scripts/*.action`. Re-run the
    script on current repo state; confirm exit 0.
  - KEEP scripts: record justification in the ledger; no code
    change required beyond the cargo-alias substitution where
    named.
- Specific high-impact entries:
  - `scripts/bootstrap-bbnf.sh`: REWRITE — delete the
    unconditional `rm -rf target/.bbnf-cache/` at line 28; add a
    content-hash guard that clears only stale entries. Re-run
    cycle-1 and cycle-2; cycle-2 must be ≤ 10% of cycle-1.
  - `scripts/bench_regression.sh`: REWRITE — replace bencher
    stdout parsing with divan JSON parsing (reads
    `docs/benchmarks/post-B1-W1-divan-*.json`).
  - `scripts/profile.sh`: DELETE — `cargo bench-json` + samply is
    the replacement; remove CI and Makefile references in the
    same commit.
  - `scripts/check-cst-invariants.sh`: DELETE — CI step removed
    in the same commit per W1-C recommendation absorbed into B1.
  - `scripts/cost-grid-sweep.sh`: DELETE — successor measurement
    lives in divan.
- After every script action lands, append a row to
  `docs/benchmarks/post-B1-W2-abrogation-ledger.txt` with columns:
  `script | action | commit-sha | validation-note`.

Files touched: all scripts listed in the abrogation catalog §Part 1,
per the action column. `docs/benchmarks/post-B1-W2-abrogation-
ledger.txt`.

Sub-gate:
- Every script in the catalog has a ledger row.
- No DELETE row corresponds to a commit that still references the
  deleted script elsewhere in the tree.
- `bash scripts/bootstrap-bbnf.sh` cycle-2 ≤ 10% of cycle-1 (rows
  append to `docs/benchmarks/post-B1-W0-proof.txt` as
  `bootstrap-cycle-1`, `bootstrap-cycle-2`).
- `scripts/bench_regression.sh` successfully parses divan JSON.

### B1.W2.c — Cross-repo pin propagation (Step 11)

**Opens**: W1 close (parallel with W2.a and W2.b).
**Agent count**: 1.
**Hard cap**: 90 min.
**Scope**: three repos only — bbnf-lang (source of truth; no
edit), `../parse-that`, `../pprint`. Wider fleet (gorgeous
sibling, csp-solver, csc411) is named but not landed.

Mechanism:
- Copy bbnf-lang's `rust-toolchain.toml` to
  `../parse-that/rust-toolchain.toml` verbatim. Same pin date.
- Copy bbnf-lang's `rust-toolchain.toml` to
  `../pprint/rust-toolchain.toml` verbatim.
- If `../parse-that/.cargo/config.toml` does not exist, create it
  from `docs/tranches/B1/patches/cross-repo-propagation.md
  §parse-that/.cargo/config.toml`. If it does exist, add only the
  `-Zthreads=8 -Zshare-generics=y` rustflags and the
  `[profile.ax-iter]` block; do NOT rewrite existing aliases.
- Same for `../pprint/.cargo/config.toml` using the minimal
  template.
- Run `cd ../parse-that && cargo check` under the new pin;
  confirm exit 0. Run `cd ../pprint && cargo check` under the new
  pin; confirm exit 0.
- Run `cd bbnf-lang && cargo iter-check` — with all three path-
  patched repos on the same pin, workspace compile must succeed.
- Record outcomes in `docs/benchmarks/post-B1-W2-cross-repo.txt`
  as a table: `repo | pin | check-exit | config-present |
  notes`.
- **Explicitly out of scope for B1**: gorgeous sibling,
  csp-solver, csc411, crates/ai. Named in the ledger with action
  `DEFERRED to post-B1 appurtenant tranche`. No code change to
  those repos.

Files touched: `../parse-that/rust-toolchain.toml`,
`../parse-that/.cargo/config.toml` (if absent),
`../pprint/rust-toolchain.toml`,
`../pprint/.cargo/config.toml` (if absent),
`docs/benchmarks/post-B1-W2-cross-repo.txt`.

Sub-gate:

- `cd ../pprint && cargo check` exits 0.
- `cd bbnf-lang && cargo iter-check` exits 0 under the triad pin.
- Cross-repo ledger complete.
