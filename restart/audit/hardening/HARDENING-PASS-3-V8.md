V8 is a simplification audit, not a regression scan. V7 ratified the post-Phase-7 fold; V7.1 closed the cite-hygiene punch list. The question PASS-3 must now answer is narrower and harder: **does the user-facing runtime carry V1 surface that exceeds meta-grammar mandate?** PASS-3 is the largest user-surface document in the cohort; it is also the most exposed to ASPIRATIONAL drift, because runtime conveniences disguise themselves as user mandates.

The V8 verdict vocabulary differs from V1-V7. Lens I produces SIMPLIFY / CONSOLIDATE / KEEP; Lens J produces LEVERAGE / HYBRID / KEEP; Lens K produces LOAD-BEARING / ASPIRATIONAL / SPECULATIVE. A KEEP under V8 must explicitly defeat the steelman that the apparatus is contrivance, that the host already provides the facility, or that the surface is V2-deferable.

**Final decision: AMENDMENT-REQUIRED (V1 surface trimming).**

PASS-3 is fundamentally sound — the tape/direct union, `path!`/`select!`, visitors, recovery semantics, and bench discipline all survive Lens I/J/K under steelman. But three surfaces carry V1 weight that cannot be defended adversarially: (i) **DAP integration** — the prompt explicitly questions whether DAP is V1 mandatory, V2 deferral, or test-infrastructure load-bearing; PASS-3 §6 names a `dap/` directory inside the language server, but no V1 user-mandate surfaces in §2-§5 to justify it; (ii) **LSP fault-tolerant fallback as primary surface** — the incremental parse machinery (ReparsePlan + reuse maps + invalidated queries + RecoveryFacts + LSP silence policy) overlaps four facilities where two would compose; (iii) **diagnostic-code cardinality** — `BBNF-VISIT001/002/003` + three `BBNF-PATH-*` codes carry visitor + path schemas; some are friction-forecast load-bearing, others are aspirational. The amendment is narrow and surgical; PASS-3's core narrative survives intact.
