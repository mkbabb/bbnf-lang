summary sections are expanded into executable standalone specifications under
`waves/BB-A/` through `waves/BB-E/`; those files, not this synopsis, own wave gates.

## Product DAG

```text
parse-that T (execution/package)
  ↓
parse-that U (Rust/regex/isomorphism/consumer)
  ├─────────────────────────────┐
  ↓                             ↓
BB-A truth/graph/shell ─→ BB-B program/solve/types
                              ↓
                       BB-C analysis/lower/generate
                              ↓
                       BB-D runtime/value/frontend
                              ↓
                       BB-E gestalt and omega
```

BB-A graph extraction begins in parallel with parse-that T. BB-B may prototype its
greenfield values, but production integration waits for the canonical graph and
parse result/crossing contracts. Grammar-driven regex bootstrap in BB-C waits for
parse-that U's canonical regex HIR and generator.

## BB-B — immutable program, solver, and type system

Goal: replace `GrammarIR` and shape propagation with sealed stage values and a real
grammar type system.

### B.W0 — born-RED algebra and semantic oracles

- Add type-domain law/property tests, constraint-permutation tests,
  contradictory-ground termination, and named no-fallback mutations.
- Add full grammar acceptance/value/span/diagnostic differentials around every
  rewrite and stage transposition.
- Rename the incumbent scalar vocabulary to its honest layout role in the prototype
  so semantic and storage types cannot be conflated.

Gate: incumbent fails every new counterexample; oracle corpora themselves reproduce
deterministically.

### B.W1 — `Program` and identity

- Build immutable arena-backed grammar `Program`, stable `NodeId`, `SourceMap`,
  revision digest, explicit `NodeRemap`, and exact serialization.
- Make semantic rewrites consume a revision and return a new revision plus
  provenance; raw pointers and mutation-derived identity disappear.
- Parse one grammar into this value without copying analysis sidecars onto it.

Gate: two builds have identical bytes/IDs/digests; randomized insertion order is
canonicalized; invalid remaps fail closed.

### B.W2 — dependency graph and deterministic worklist

- Derive one typed grammar dependency graph from `Program`, including rule, node,
  reference, recursion, and producer/consumer edges.
- Compute SCC condensation once and solve monotone analyses with a bounded,
  deterministic worklist and explicit report.
- Prove incremental edits equal clean recomputation and expose invalidation causes.

Gate: order, hash seed, and worker-count permutations produce identical solutions;
budget exhaustion returns a named diagnostic, never partial facts.

### B.W3 — semantic type kernel

- Implement `TypeTerm`, variables, substitutions, equality unification, schemes at
  declared reusable boundaries, closed/open record and variant rows, tuples, lists,
  options, functions, spans, transforms, explicit recursive binders, and
  occurs-check.
- Attach constraint provenance and produce immutable `TypeSolution` keyed by program
  revision and node.
- Compare simple equality/rows with algebraic-subtyping and effect-row prototypes
  only on consumers that require their added expressivity.

Gate: principal examples, row extension, recursion, failure diagnostics, and
constraint permutations pass; no unknown becomes a layout type.

### B.W4 — grammar constraint generation

- Generate semantic constraints for every grammar operator, host function, map,
  recovery, skip/projection, recursion, and public rule boundary.
- Separate type equality, grammar obligations, and layout requirements because one
  solver should not decide unrelated domains.
- Make all unannotated host behavior an explicit diagnostic rather than `Span`.

Gate: every grammar node has a solution or named diagnostic; coverage mutation of
any operator fails; all nine manifest grammars reach a stable result.

### B.W5 — immutable analysis products

- Replace dynamic sidecars with typed `AnalysisFacts` products keyed by revision and
  node; define ownership for nullability, FIRST/FOLLOW, width, recognizers,
  materialization, payload, shape, and host facts.
- Analyses consume only prior sealed stages and return values plus reports.
- Delete `FactAuthority`; privacy and type signatures enforce authority.

Gate: no production read of mutable program facts; disconnect mutations reach real
lowering/emission consumers and fail.

### B.W6 — root carrier transposition

- Transpose root grammar behavior and selected skinny arena/runtime lessons into
  `Program -> Graph -> TypeSolution -> AnalysisFacts` in one production cut.
- Remove `GrammarIR`, pointer DAG, old type CSP/projector, silent obligations, and
  their direct-field consumers rather than maintaining adapters.
- Preserve differential behavior or record an approved intentional break with new
  corpus truth.

Gate: repository search finds one stage path; old types/modules/symbols are absent;
all grammar corpora and package consumers compile against the new values.

### B.W7 — BB-1/2/3 apotheosis pass

- Two critics assume the type/graph/stage carrier is wrong; the third proves every
  claim.
- Correct findings, rerun property/differential/incremental/serialization gates,
  and require two consecutive clean audits.

Gate: zero open semantic or state-ownership defect; P1–P4 prototype claims are
production-proved.

## BB-C — analysis, optimizer islands, lowering, and generation

Goal: make optimization and generation explicit, total, bounded, and reproducible.

### C.W0 — ambient optimizer removal

- Remove G3 immediately with its empty-input counterexample.
- Turn incomplete saturation, extraction failure, cycle, missing child, and missing
  best-node cases into typed failures.
- Disable ambient whole-program e-graph writeback until a bounded family wins P5.

Gate: no semantic rewrite can run without a translation validator and run report.

### C.W1 — direct analysis baseline

- Implement direct deterministic algorithms for every current e-graph/CSP use,
  including rewrite families and backend decisions.
- Measure result quality, time, memory, incrementality, and implementation size.

Gate: each incumbent organ has a correct direct oracle; fallback cannot discard a
hard constraint.

### C.W2 — bounded equality islands

- Define small semantic languages whose constructors expose every child to
  congruence; prove each rewrite by exhaustive/property differential or a checked
  equivalence witness.
- Compare table/direct normalization with e-graph extraction and retain e-graphs
  only where they win a named corpus.

Gate: acceptance, value, span, diagnostic, and canonical output are equal across
rewrite order/cap permutations; incomplete saturation fails.

### C.W3 — genuine global decisions

- Identify only decisions with coupled variables and hard global constraints.
- Compare direct enumeration/branch-and-bound with CSP; return solution plus report
  or named failure, never independent minima.

Gate: a witness proves the chosen solver changes a correct decision; budget/unsat
paths satisfy every hard constraint or fail.

### C.W4 — sealed lowering plan

- Consume `Program + Graph + TypeSolution + AnalysisFacts` and return immutable
  `LoweringPlan` with selected recognizers, layouts, runtime capabilities, costs,
  and provenance.
- Prohibit backend reads from earlier mutable phases.

Gate: lowering serializes exactly; codegen takes only the plan and source tables;
missing decisions are typed errors.

### C.W5 — layout-driven generators

- Replace special-case simple-runtime/CSS template monoliths with one cohesive
  layout-driven generator whose grammar-specific data is declarative.
- Emit external tests and provenance sidecars alongside artifacts.
- Keep generated large files whole when their regeneration and consumer boundaries
  are clearer than artificial fragments.

Gate: every grammar regenerates twice byte-identically; adding a synthetic grammar
requires data, not a source arm.

### C.W6 — grammar/regex bootstrap

- Regenerate regex syntax from BBNF into canonical regex HIR through parse-that U.
- Then regenerate BBNF parsers from the sealed stage pipeline until two consecutive
  fixed points are byte-identical.
- Distinguish seed, stage-1, and self-hosted artifacts with digests and negative
  corpora.

Gate: empty generated directories reach the fixed point without Python rewriting,
untracked patches, cargo-expand ambiguity, or host-regex semantic escape.

### C.W7 — performance and optimizer apotheosis

- Run paired benchmarks/profiles for direct, retained e-graph, retained CSP,
  interpreter, VM, and generated faces.
- Audit every optimizer/generator cluster twice after corrections.

Gate: every retained complex engine has a measured advantage and no semantic debt;
all losing organs are deleted.
