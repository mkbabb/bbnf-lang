### F01 — BLOCKER, NEW: the external matrix is fail-open on unknown statuses

`common.terminal()` defines terminality as “not one of six known incomplete
strings.” Any typo or invented status is therefore complete. `matrix.validate()`
checks only the presence of a status and equality with this negative-list result.
The following mutation is accepted:

```sh
python3 -B - <<'PY'

sys.path.insert(0, 'src')
import matrix
d = json.load(open('data/matrix.json'))
r = d['rows'][0]
for plane in matrix.REQUIRED_PLANES:
    r[plane]['status'] = 'TYPO_COUNTS_AS_TERMINAL'

print(r['terminal_state'], r['id'])
PY
```

Output: `MAPPED algorithm::css-align-3:algorithm:1`. This directly defeats the

the validator cannot protect its future closure.

### F02 — BLOCKER, NEW: “parsed CSS grammar” includes malformed syntax, equations, prose, and programs

The value lexer accepts almost any residual byte sequence as `ATOM`; the parser
allows empty operands and arbitrary stacks of raw multipliers. Independent probes
all return ASTs instead of errors:

```text
a &&        -> all-order(a, empty)
| a         -> alternative(empty, a)
a || || b   -> any-order(a, empty, b)
a {wat}     -> repeat(a, "{wat}")
a ???       -> repeat(a, "?", "?", "?")
a !!        -> repeat(a, "!", "!")
a = prose   -> sequence(a, "=", prose)
a ; prose   -> sequence(a, ";", prose)
```

The stored output calls 529 prod and 240 legacy definitions `PARSED`. At least 126
of the legacy successes are visibly not CSS grammar: 85 come from Compositing
equations and 41 from Filter Effects SVG/C-like code. The AST corpus contains 68
atom values `=`, 47 `;`, 19 `:`, code fragments such as `HREF=`, `operator=`,
`0.0f;`, and equation symbols. For example,
`CSS2:legacy-grammar:2:definition:1` parses an HTML `MEDIA=... HREF=...` fragment,
while `filter-effects-1:legacy-grammar:11` emits C statements as 33 definitions.

This is the balanced-token confabulation the successor contract forbids. The 26
visible parse failures drastically understate failure because invalid input mostly
“parses.”

### F03 — BLOCKER, NEW: railroad and legacy adapters validate shape, not grammar semantics

`railroad_expression()` accepts every alphabetic operator and arbitrary nesting.
`Bogus: payload` returns a `railroad-node`; `Choice:\n  Bogus: x` also succeeds.
Only `N` and `T` receive partial interpretation. Actual output contains 17 operator
spellings (`Choice`, `Seq`, `Sequence`, `C`, `Stack`, `Skip`, and others) with no
operator vocabulary, arity, cardinality, or agreement checks. All 46 normative
railroad blocks are nevertheless `PARSED_RAILROAD`.

`legacy_definitions()` is only colon/semicolon scraping. It cannot distinguish
CSS2/Yacc productions from equations, JavaScript, SVG attributes, pseudocode, or C.
No dialect-specific reference/import rules or differential oracle exists. The
railroad and legacy planes are therefore not parsed grammar closure.

### F08 — BLOCKER, NEW: profile precedence silently deletes scoped CSS features

Every definition is placed in one global unqualified namespace. `priority()` then
assigns hardcoded scalar scores from scope labels, so a single higher-scored
definition wins regardless of export locality, extension relation, or the reason a
spec is in the union.

There are 132 repeated names and 64 with differing AST hashes. Eighteen are visible
conflicts, but **46 differing repeated names are silently resolved by priority**.
The clearest counterexample is CSS Color: Color 4 scores 504 because it is
`current-work:testing`, while Color 5 scores 455 as a Snapshot pre-CR/rough member.
The active `color`, `color-base`, `color-function`, `color()`, `hwb()`, `lab()`,
`lch()`, `oklab()`, `oklch()`, and modern rgb/hsl definitions therefore come from
Color 4 and drop Color 5 relative-color, `color-mix()`, `contrast-color()`, and
other scoped additions. The artifact calls this
`CSS-SNAPSHOT-2026-L4-UNION`, but implements replacement by an invented score, not
the union or an explicit profile.

Local names from unrelated equation/code blocks also collide globally (`a`, `s`,
`hue`, `position`, `media`). This poisons both profile decisions and reference
targets.
