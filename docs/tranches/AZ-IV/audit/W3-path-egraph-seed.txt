-----

Three hand-authored Class-1 path-shape rewrites land at
crates/ir/src/rewrites/path_seed.rs, registered into the

the egraph saturation layer carry path-shape simplifications

Rewrites authored
-----------------

1. duplicate_prefix_elimination
   LHS: Seq([Field("statuses"), Field("statuses"), Var(0)])
   RHS: Seq([Field("statuses"), Var(0)])
   Class: Class-1 (RHS strictly smaller, sub-tree of LHS)
   Note: a second visit on the same struct field is the identity.

2. redundant_variant_select_removal
   LHS: Seq([VariantName("Color"), VariantName("Color"), Var(0)])
   RHS: Seq([VariantName("Color"), Var(0)])
   Class: Class-1
   Note: a second variant projection on an already-narrowed sum
   value is the identity (the path_check IR pass narrows once).

3. adjacent_accessor_fusion
   LHS: Seq([Field("statuses"), Index(0), Var(0)])
   RHS: Seq([FieldIndex("statuses", 0), Var(0)])
   Class: Class-1
   Note: a Field-then-Index pair lifts to a compound positional
   accessor — one decision rather than two for downstream codegen
   and the discovery cohort.

Encoding
--------

bbnf-ir cannot import bbnf-core (the dependency edge runs the
other way), so the rewrites encode Path IR segments through the
existing Pattern alphabet:

| Path-IR segment           | Encoded atom                            |
|---------------------------|-----------------------------------------|
| Field("<name>")           | Atom::Rule("path:Field:<name>")         |
| Index(<n>)                | Atom::Rule("path:Index:<n>")            |
| VariantName("<v>")        | Atom::Rule("path:Variant:<v>")          |
| Wildcard                  | Atom::Rule("path:Wildcard")             |
| fused Field+Index         | Atom::Rule("path:FieldIndex:<f>:<n>")   |

Rest-of-path tails are pattern variables (Atom::Var(0)). Paths
sit inside Pattern::Seq, left-to-right.

Loader registration
-------------------

RuleSet::merge_path_seed (crates/ir/src/rewrites/mod.rs) pulls
the seed_ruleset() output and pushes each rule into the host
ruleset with a freshly-assigned sequential id. This is the
named entry-point the egraph saturation layer consumes.

Test fixtures
-------------

crates/ir/tests/path_seed_rewrites.rs carries six unit tests:

  rewrites_path_seed_duplicate_prefix_fires_on_fixture
  rewrites_path_seed_redundant_variant_select_fires_on_fixture
  rewrites_path_seed_adjacent_accessor_fusion_fires_on_fixture
  rewrites_path_seed_ruleset_carries_three_rules
  rewrites_path_seed_loader_merges_into_per_grammar_set
  rewrites_path_seed_ron_round_trips_intact

Each rewrite test asserts: (a) the rule's LHS matches the hand-
built fixture path tree, (b) the RHS shrinks the path, (c) the
classifier places the rule in Class-1, (d) the witness is sound.
The loader and round-trip tests pin RuleSet::merge_path_seed +
RuleSet save/load symmetry.
