## Finding 1 — M01 does not kill the claimed invariant

2. it changes `rhs_text` from the exact structural value span
   `value_lo..value_hi` to `factor_hi..value_hi`.

The mutant log fails because `rhs_text` becomes `-> 1u8`, so
`direct_numeric_suffix` correctly refuses to treat it as one numeric literal.
Nothing in the log makes the deleted assertion causal. A one-hunk mutation that
deletes only lines 155–157 leaves `rhs_text`, map construction, and every
canonical parser-produced view unchanged. That conceptual mutant survives the
frozen fixture set.

the generated schema makes a direct value-expression child conclusive map

deleted under KISS. If the assertion is a required independent invariant, R5

coupled slice mutation cannot stand in for either decision.

`block_comment_slash_arrow_is_not_a_map` as the M01 no-false-owner control. The

## Finding 2 — cancellation isolation fabricates an unreachable stats cell

`solve_exact_constrained` calls:

```text
cancellation_observed(csp.stats().cancelled, cancellation_requested(config))
```

The local CSP solver sets `stats.cancelled = true` only in
`solver/search.rs:224-228`, immediately after the configured `CancelToken`
returns true. `CancelToken` is one shared `Arc<AtomicBool>` and exposes only
`cancel()` and `is_cancelled()`; there is no reset. The solve configuration
holds a clone of that same token. Therefore, after search returns:

```text
stats.cancelled == true  =>  cancellation_requested(config) == true
```

M06's `(true, false)` oracle is not a production state. It proves only the
truth table of a helper introduced to make the requested mutation killable.
The smallest correct response to the R4 coupled-proof concern was to prove this
implication and delete the redundant stats leg, not retain dead logic and test
an invented state.

M07's `(false, true)` cell is reachable when cancellation occurs after the
solver's last cadence check. R5 already retains the stronger
`cancellation_on_final_singleton_leaf_discards_incumbent` production fixture.
But the M07 campaign selected only the direct helper test. Thus the current
token behavior is favorable in source and baseline evidence, while its claimed
surgical mutation proof remains incomplete.

private production transaction/functions, cancel the real token between exact
