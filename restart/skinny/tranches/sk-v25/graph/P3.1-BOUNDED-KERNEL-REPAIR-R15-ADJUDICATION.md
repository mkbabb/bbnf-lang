### Official primary-source basis and questions

The official [Cargo configuration reference](https://doc.rust-lang.org/cargo/reference/config.html#targettriplelinker)
defines `target.<triple>.linker` as a string program path passed to rustc via
`-C linker`; the same reference separately defines a runner as a program path
that may carry arguments and runs only after an executable exists. The official
[rustc codegen reference](https://doc.rust-lang.org/stable/rustc/codegen-options/index.html#linker)
