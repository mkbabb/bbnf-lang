# BA.W3 - Speculative Checkpoint Redesign

**Name**: W3 - Speculative Checkpoint Redesign
**Opens after**: W2 - Direct-Projection Codegen
**Agents**: 5 parallel
**Hard gate**: `Vec<OpenFrame>::clone` not in samply top-3; `Checkpoint = (stack_depth, arena_count)` value-typed snapshot; predictive first-byte dispatch in JSON; speculative-checkpoint cost ≤ 14% of inclusive samples on `bbnf_value_twitter`; ≥ 80% inclusive-sample reduction per DEEP-B
**Status**: planned

## Scope

This wave eliminates the 86.07%-of-inclusive-samples `Vec<OpenFrame>::clone` discipline. `Checkpoint` becomes a value (`(stack_depth, arena_count)`); speculative branches use predictive first-byte dispatch where alphabets are disjoint; the `parse_wrap_*` byte-dispatch towers are regenerated against the new mechanism.

1. Define `crates/core/src/runtime/checkpoint.rs`: `Checkpoint` as `pub struct Checkpoint { stack_depth: u32, arena_count: u32 }` (value type, not a clone). The runtime holds one `Vec<OpenFrame>` across the parse; on speculative branch entry, the parser snapshots `(stack_depth, arena_count)`; on rollback, `truncate(stack_depth)` + `arena.truncate(arena_count)` restores. No clone.
2. Define `crates/core/src/backend/rust/emitter/dispatch.rs`: predictive first-byte dispatch table generator. For each Alt/sum branch point in the grammar, the emitter computes the first-byte alphabet of each branch; if the alphabets are disjoint, the generated dispatch is a single byte-match (no speculative branches at all). For overlapping alphabets, the emitter falls back to the speculative path, which now uses the value-typed checkpoint.
3. Regenerate `crates/core/src/grammar/generated/{json,css_l4,sheets,bbnf,bnf,csv,ebnf,math,css_pretty}/**` against the new dispatch + checkpoint. Verify per-grammar that disjoint alphabets produce predictive dispatch and overlapping alphabets produce speculative dispatch with value-typed checkpoint.
4. Update generated `parse_wrap_*` body emit: replace `let __cp = builder.checkpoint();` (which deep-cloned the in-flight `Vec<OpenFrame>`) with `let __cp = Checkpoint::snapshot(stack_depth, arena_count);` value snapshot. On rollback, `builder.restore(__cp)` does `Vec::truncate` (O(1), no allocation).
5. Profile under fat-LTO `[profile.bench]` after the regen lands. The samply trace on `bbnf_value_twitter` must show `Vec<OpenFrame>::clone` outside the top-3 hotspots; speculative-checkpoint cost ≤ 14% of inclusive samples.
6. Close the AU floor 19/19 at-or-above on `docs/benchmarks/post-BA.json` (the W2 close was preliminary; W3 finalises the AU floor closure). AF MASKED-DEFERRAL fully closes here.
7. Verify per-grammar that the JSON byte-alphabet disjointness analysis is correct: a synthetic test grammar with intentionally overlapping alphabets must fall back to speculative dispatch; a grammar with disjoint alphabets must produce predictive dispatch.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the predictive first-byte dispatch analysis surfaces a grammar shape it cannot decide (e.g., a Repeat whose first-byte alphabet is genuinely ambiguous; the analyser's heuristic is incomplete);
- after the regen, `Vec<OpenFrame>::clone` is still in the samply top-3 (the mechanism redesign did not deliver; root cause is not local-edit-recoverable);
- the AU floor row regresses from W2's preliminary at-or-above to BELOW after W3's regen (a different mechanism is the bottleneck; scope reveal beyond W3 file bounds);
- the value-typed checkpoint introduces a correctness regression in a parity test (the `Vec::truncate` rollback semantics differ from the deep-clone restore in some edge case);
- three diagnostic-loop iterations fail to isolate the perf miss;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.

## Agent Units

### BA.W3.1 Checkpoint Value Type

- Mechanism: define `Checkpoint` as a value type. No `Vec` clone. `pub struct Checkpoint { stack_depth: u32, arena_count: u32 }` (8 bytes). `Checkpoint::snapshot(builder)` returns the value; `builder.restore(checkpoint)` does `stack.truncate(checkpoint.stack_depth)` + `arena.truncate(checkpoint.arena_count)`. The truncate operations are O(1) for `Vec<OpenFrame>` because the dropped tail is just shrinking the length pointer (the dropped `OpenFrame` values are POD or Drop-trivial — verify per-grammar).
- Files: `crates/core/src/runtime/checkpoint.rs`, `crates/core/src/runtime/mod.rs` (register).
- Sub-gate: type compiles; `crates/core/tests/checkpoint_value.rs` covers snapshot/restore on a synthetic 1000-frame stack; the test asserts the post-restore stack is byte-equal to the pre-snapshot stack on a Repeat that pushes then rolls back.

### BA.W3.2 Predictive Dispatch Emitter

- Mechanism: implement the first-byte alphabet analyser. For each Alt/sum branch point in the grammar, walk every branch's `first` set (the first-byte alphabet, computed from the grammar's terminals + prefix-fixed rules). If the alphabets are pairwise disjoint, emit a single byte-match dispatch (no speculative branch). If not, fall back to the speculative path with the value-typed checkpoint.
- Files: `crates/core/src/backend/rust/emitter/dispatch.rs`, `crates/core/src/backend/rust/emitter/mod.rs` (register).
- Sub-gate: emitter compiles; named test in `crates/core/tests/predictive_first_byte.rs` runs the analyser against synthetic grammars (one disjoint, one overlapping) and verifies the dispatch shape; the test asserts disjoint produces a byte-match and overlapping produces a speculative-with-checkpoint pattern.

### BA.W3.3 Shapes Integration

- Mechanism: modify `crates/core/src/backend/rust/emitter/shapes/**` (alt, repeat, optional, sum) to consume W3.1 + W3.2. Replace `builder.checkpoint()` (deep clone) with `Checkpoint::snapshot(builder)` (value). Replace `builder.restore(__cp)` (Vec restore from clone) with `builder.restore(__cp)` (truncate). For Alt/sum branch points where W3.2's analyser confirms disjoint alphabets, emit predictive dispatch; for overlapping, emit speculative-with-value-checkpoint.
- Files: `crates/core/src/backend/rust/emitter/shapes/**`.
- Sub-gate: `cargo build` compiles cleanly; `cargo xtask regen --check` produces fresh outputs (W3.4); the regenerated outputs no longer contain `__cp = builder.checkpoint()` (the old clone-based call site).

### BA.W3.4 Regenerate + Builder Integration

The builder now exposes `snapshot(&self) -> Checkpoint` (returning the value) and `restore(&mut self, cp: Checkpoint)` (truncate semantics).
