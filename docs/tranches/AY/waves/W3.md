Per A5 three-surface design + A10 TypeDesc-collapse + Handle-into-Tape materialization + AU archaeology's json-prototype speed-ceiling:

1. **W3a Runtime substrate** (A10 §d correction): new `crates/core/src/runtime/handle.rs` (StringHandle, CompoundHandle) + `crates/core/src/runtime/path.rs` (path-query types for lazy `get_by_path` lane). Zero emitter touch, zero regen. Prerequisite — isolates handle / path types from emitter change.

2. **W3b Grammar-emitted `<Grammar>Value` + `parsed.to_value::<T>()`**: emit `<Grammar>Value` enum from IR's `TypeDesc` with TypeDesc-equivalence-class collapse (`FxHashMap<TypeDesc, usize>` at emit time; rules with identical TypeDesc collapse into a single variant). Handle-into-Tape materialisation reusing existing `Tape` (flat AoS post-W1) + AoS `packed_cache` sidecar. **Additionally: emit per-shape inline fn pattern matching json-prototype's speed-ceiling layout** — five `#[inline(always)]` per-shape functions (parse_object_value_inline / parse_array_value_inline / parse_string_value_inline / parse_number_value_inline / parse_literal_value_inline), monomorphised at the value-materialisation call site. LLVM inlines the full tree-build into a single flat function per grammar — matching json-prototype's 0.89-0.94× sonic ceiling.

3. **W3c Two perf benches + one correctness test** (reframed from v1's "three lanes"):
   - **Correctness (W1r.2 landed)**: `canonical_parity_<fx>` — `serialize_compact(parse(src)) == sonic_rs::to_string(sonic_rs::from_str::<Value>(src))`. Already a `#[test]`, not a bench.
   - **Perf bench — lazy**: `bbnf_get_twitter` (`Parsed::get::<&str>(path)`) vs `sonic_get_twitter` (`sonic_rs::get_by_path(src, path)`). Twitter only.
   - **Perf bench — eager**: `bbnf_value_<fx>` (`Parsed::to_value::<JsonParserValue>()`) vs `sonic_value_<fx>` (`from_str::<sonic_rs::Value>`). 5 fixtures.
   - Canonical is NOT a bench lane; it's a correctness gate. Eager is the BEAT-sonic headline metric.

## Phase sub-items

### AY.W3a.1 Handle substrate (serial)

Create `crates/core/src/runtime/handle.rs`:
```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct StringHandle { pub loc: u64, pub len: u32 }
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct CompoundHandle { pub tape_offset: u64, pub record_count: u32 }
```

`StringHandle::loc` encodes input-byte offset (upper 48 bits) + arena-hosted flag (lower 16). `CompoundHandle::tape_offset` points into the Tape's AoS `Vec<TapeRec>` (post-W1 flat-AoS restoration).

### AY.W3b.1 `<Grammar>Value` emitter with TypeDesc-collapse (serial, after W3a)

Create `crates/core/src/backend/rust/view/value.rs`. Per A10:

- TypeDesc-equivalence-class collapse: `FxHashMap<TypeDesc, VariantIndex>` at emit time; rules with identical TypeDesc collapse to single variant.
- Variant shape rules:
  - `Span` → `&'p str` (or `StringHandle` if arena-decoded).
  - Scalar primitive → primitive field.
  - `Tuple([T1, T2, ...])` → struct variant with named fields (names from Seq children's `Ref` targets; positional if unnamed).
  - `Vec<T>` → `Vec<<Grammar>Value<'p>>` field.
  - `Named(sid)` → dedicated variant named after the type (relies on W2 Named preservation).
- Reuse AQ.6.C's existing per-Alt `<RuleName>Value` enums at `view/alt.rs:137-146` — aggregator wraps.

Emit `impl ValueRoot for <Grammar>` with `view_to_value` walking the root view + constructing the enum via rule-by-rule match on `rule_kind()`.

Emit `impl PathQuery<T> for <Grammar>` for common T (`&str`, `f64`, `bool`, `<Grammar>Value<'p>`) via `packed_cache` binary-search on path-encoded offsets (< 100 LOC).

**Sub-gate**: `cargo expand -p bbnf --test json_canonical_parity` shows `pub enum JsonParserValue<'p> { … }` + `impl ValueRoot for JsonParser`.

### AY.W3c.1 Bench lanes (parallel agent E, after W3b)

Extend `crates/core/benches/json/value.rs` with two perf lanes:

**Lazy lane** (twitter only):
```rust
fn bbnf_get_twitter(b: &mut Bencher) {
    let src = load_fixture("twitter.json");
    b.iter(|| {
        let parsed = JsonParser::parse(&src).unwrap();
        black_box(parsed.get::<&str>(path!("statuses", 0, "text")))
    });
}
fn sonic_get_twitter(b: &mut Bencher) {
    b.iter(|| black_box(sonic_rs::get_by_path(&src, "statuses.0.text")));
}
```

**Eager lane** (5 fixtures each):
```rust
fn bbnf_value_twitter(b: &mut Bencher) {
    let src = load_fixture("twitter.json");
    b.iter(|| {
        let parsed = JsonParser::parse(&src).unwrap();
        black_box(parsed.to_value())
    });
}
fn sonic_value_twitter(b: &mut Bencher) {
    b.iter(|| black_box(sonic_rs::from_str::<sonic_rs::Value>(&src).unwrap()));
}
```
