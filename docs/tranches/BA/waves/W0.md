# BA.W0 — Shared-Cost Optimizer Second Pass

**Opens after**: AY close
**Agents**: 3 parallel
**Hard gate**: Grammar extraction, regex extraction, projection, and specialization share a second optimization pass with one cost surface and produce measurable wins on the canonical runtime path.

## Scope

1. Define a second-pass shared-cost optimization plan across grammar,
   regex, projection, and specialization decisions.
2. Wire the participating passes to consume that shared plan.
3. Prove runtime benefit on the canonical path and delete any now-
   redundant local cost islands.

## Phase sub-items

and admission contract across grammar, regex, projection, and
specialization decisions.

`crates/ir/src/passes/csp_strategy/mod.rs`.

consumers.

### BA.W0.2 Consumer adoption

through the shared-cost plan rather than isolated local objectives.

Files touched: `crates/ir/src/egraph/mod.rs`,
`crates/ir/src/passes/materialization/mod.rs`,
`crates/core/src/pipeline/compile.rs`.

Sub-gate: emitted plans show shared-cost decisions for canonical-path
specializations.

### BA.W0.3 Contract tests and pruning

Mechanism: add wire-contract tests for the second pass and delete any
redundant cost islands left consumerless.

`crates/core/src/pipeline/compile.rs`.

Sub-gate: contract tests pass and redundant cost islands are deleted.

1. `cargo test -p bbnf --test gate_predicate_wire_contract --profile ax-iter`
   passes with second-pass assertions. Artefact:
