# BC.W2 — TS + WASM Emitter Scaffolds

**Name**: W2 — TS + WASM Emitter Scaffolds
**Opens after**: BC.W1 close (Rust emitter consumes typed IR exclusively; regen-equality with BB close artefact verified)
**Hard gate**: TS + WASM emitter scaffolds compile against the IR contract; both produce non-empty syntactically-valid output for at-least-one trivial grammar (BNF or CSV); production activation explicitly defers to BD+
**Status**: planned

## §1 Deliverable

Hereupon `crates/core/src/codegen/ts/` and `crates/core/src/codegen/wasm/` (or post-BC.W3 split paths `bbnf-codegen/src/ts/`, `bbnf-codegen/src/wasm/`) land as scaffolds. Each implements the `Emitter` trait surface formalised in BC.W0; each takes typed IR and emits target-language source/bytes; each is NOT activated for production — `emit()` returns `unimplemented!()` for non-trivial cases. The same-wave consumer is the trivial-grammar smoke test (BNF or CSV); the production consumer is BD per carry-tag BC→BD.C1.

The wave proves the IR contract supports TS + WASM by mechanism: the scaffolds compile against the contract, produce non-empty syntactically-valid output for the trivial grammar, and fail gracefully on rules requiring host-fn shims (host-fn TS/WASM resolution is BD scope per `audit/HARDENING-SYNTHESIS-2026-05-03.md:42-43, 56-58`). Era V's substrate-without-consumer failure mode is structurally precluded because the smoke-test consumer lands in the same wave as the scaffold.

The TS scaffold emits the JSON `object` parse fn per `audit/RESTART-SKETCH-2026-05-03.md:559-577`:

```ts
export type JsonValue =
  | { kind: 'null' }
  | { kind: 'bool';   value: boolean }
  | { kind: 'number'; value: number }
  | { kind: 'string'; value: string }
  | { kind: 'array';  items: JsonValue[] }
  | { kind: 'object'; pairs: JsonPair[] };
export interface JsonPair { key: string; value: JsonValue }

export function parseObject(ctx: ParseCtx): JsonValue {
  if (ctx.bytes[ctx.pos] !== 0x7b /* { */) throw syntaxErr(ctx.pos);
  // ... (per RESTART-SKETCH:561-577)
}
```

The WASM scaffold emits a WAT skeleton for the same `object` rule. Both fail with `unimplemented!()` on rules requiring host-fn shims (e.g., CSS L4's `parse_hex_color` host fn).

## §4 Invariants

§I1. **Lock 5 (IR + per-backend lower)**: the TS + WASM scaffolds compile against the typed IR contract; the contract supports them by mechanism (cross-backend trait conformance test).

§I2. **No production activation**: `emit()` returns `unimplemented!()` for non-trivial cases; the production consumer is BD per carry-tag BC→BD.C1.

§I3. **Same-wave consumer**: the trivial-grammar smoke test (BNF or CSV) is the W2 wave's same-wave consumer; the smoke test asserts non-empty syntactically-valid output. The scaffold-without-runtime-exercise is the correct ratification of Lock 5 IR shape support — NOT Era V substrate-first/consumer-later. The mechanism: the contract requires the scaffold to compile AND produce output, not just exist. Compile-only would be Era V; compile-plus-smoke-output is consumer-arrived-in-same-wave.

§I4. **Lock 13 (cohesive encapsulation)**: `crates/core/src/codegen/{ts,wasm}/` mirror each other in module structure; each has 4-6 cohesive children; each child < 500 LOC; each exports a uniform sub-API (`fn lower(&typed_ir, &mut ctx) -> String` / `Vec<u8>`).

§I5. **Host-fn deferral**: rules requiring host-fn shims fail gracefully; BD lands the host-fn resolution per backend. The deferral is named in carry-tag BC→BD.C1.

§I6. **No source mutation outside `crates/`**: the wave touches `crates/core/src/codegen/{ts,wasm}/` and `crates/core/tests/`; no edits to BA's or BB's domain.

§I7. **No grammar source edits**: BC.W2 does NOT edit `grammar/<name>/` files; BB.W3 owns auto-detection consumption of grammar source; BC operates on the IR contract output.

§I8. **Lock 6 (xtask emits committed source)**: TS + WASM scaffold output is part of xtask emission; the trivial-grammar smoke test fixtures land at `crates/core/tests/fixtures/`; production output (via BD activation) will land at `bbnf-codegen/src/{ts,wasm}/generated/` paths.

## §10 Lock 5 ratification posture

The wave's central claim is Lock 5 ratification: the IR contract supports TS + WASM by mechanism. The mechanism is: (1) the typed IR alphabet derived at BC.W0 is backend-agnostic; (2) the `Emitter` trait surface compiles against typed IR; (3) two backend impls (TS, WASM) compile against the trait; (4) two backends produce non-empty output for at-least-one trivial grammar. The four-step mechanism is the proof; the trivial-grammar smoke test is the same-wave consumer per Lane 2 (Sequencing); the production consumer is BD per the user's TS/WASM punt. The scaffold-without-runtime-exercise is correct because Lock 5's claim is "IR shape supports them via the Emitter trait" — not "IR shape activates them in production". The activation is BD scope.
