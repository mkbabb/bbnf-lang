# CH6 Anti-Paper-Close Challenge - SK-V13 Alpha V3

Disposition: ACCEPT.

Alpha V3 preserves the V2 anti-paper-close contract and folds the remaining
SIMD grammar-policy blocker into the current packet. The packet no longer has
a support-only, deferred, scaffold-only, ordinary measured-reject, weaker
scoping, old GO/slack, missing rolling-delta, or SIMD-policy support-only path
to close. Remaining risk is downstream S-P3 enforcement, not Alpha contract
shape.

## Findings

### F1 - ACCEPT: close still requires full ADMIT or architectural block

`SYNTHESIS.md` keeps the addendum as conflict authority over any clause that
treats CSS as one-row complete, treats `parse_only` as diagnostic-only, permits
JSON below strict sonic-rs, or permits ordinary fixpoint close
(`SYNTHESIS.md:25-28`). The close condition is still full ADMIT or
architectural-level intrinsic-block proof for every remaining row or feature;
implementation-limited misses reopen and force REJECT plus immediate SK-V14
bracketing (`SYNTHESIS.md:32-36`).

This blocks ordinary measured-reject close. A measured rejection may route
REDRESS or prove a production split failed, but it cannot close a row unless it
is elevated to architectural-block proof.

### F2 - ACCEPT: support-only, deferred, and scaffold-only closure remains barred

`SYNTHESIS.md` requires every behavior wave to move a row toward SOTA or prove
architectural block, and declares support-only landings invalid unless
same-wave wired to a measured consumer (`SYNTHESIS.md:206-210`). It also blocks
future-tranche deferral except for the automatic bracket after rejected close
(`SYNTHESIS.md:216-217`).

The same rule is operational in the handoff refusal list: support-only
primitives, union substrates, resolver infrastructure, or codegen paths reject
without same-wave measured consumers (`HANDOFF.md:147-148`). Source/gate edits
also reject without telemetry and rolling delta updates (`HANDOFF.md:163`).

### F3 - ACCEPT: weaker scoping precedence is still subordinate

V3 keeps the explicit precedence guard. `SYNTHESIS.md`, `HANDOFF.md`, and the
2026-05-21 addendum override weaker scoping prose; S-P3 may not inherit labels
such as optional, fallback, diagnostic, support-only, scaffold-only, or
future-tranche for pinned CSS/JSON/G2-G7 work. Those items must become admitted
row targets, architectural-block proofs, or user re-pin issues
(`SYNTHESIS.md:218-222`).

`HANDOFF.md` makes this a downstream REVISE condition for any plan that carries
weaker labels instead of converting them to row targets, architectural-block
proofs, or user re-pin issues (`HANDOFF.md:149-152`).

### F4 - ACCEPT: old GO, slack, and REDRESS fixpoint outcomes cannot overclaim full SOTA

The JSON rule is still current-row and strict-comparator based. All 17 corpora
across `parse_only`, `direct_to_struct`, and `real_typed_struct` must beat
sonic-rs strict on the same plane/corpus/strictness or carry per-row
architectural-block proof (`SYNTHESIS.md:97-104`). REDRESS-119/120 are history
only and do not block fresh SK-V13 reopens (`SYNTHESIS.md:105-106`).

Alpha-C carries the accounting consequence: 51 JSON rows, including 10 absent
typed rows, plus 23 CSS parity features after the SK-V12 row are mandatory
admit-or-block work; REDRESS history and old GO/slack outcomes are not closure
authority (`alpha-C-redress-digest.md:213-221`).

### F5 - ACCEPT: rolling delta remains a gate

`SYNTHESIS.md` requires `restart/skinny/ROLLING-SOTA-DELTA.md` for every JSON
row/plane and every CSS feature, with `row`, `plane`, `T1_current`, `T1_sota`,
`margin`, and `tranche_admitted` columns (`SYNTHESIS.md:187-194`). It states
the rolling table is a close gate, not a status appendix; negative margins
remain open and margin regressions fail G7 unless covered by
architectural-block/user re-pin (`SYNTHESIS.md:196-200`).

`HANDOFF.md` requires S-P3 to include rolling-delta production and gate
consumption in the concrete wave plan (`HANDOFF.md:135-136`) and rejects
source/gate edits without rolling delta updates (`HANDOFF.md:163`).

### F6 - ACCEPT: G-SIMD-GRAMMAR-POLICY cannot become support-only closure

The V2 blocker is folded into V3. Any SPEC wave that wires `bbnf-simd` into
CSS, union, JSON `parse_only`, or shared generated code must include
`G-SIMD-GRAMMAR-POLICY`; the classifier must use the consuming grammar's
quote/escape/control policy or a no-string policy, with scalar parity,
JSON/CSS checkasm or differential coverage, same-wave measured row consumption,
no public substrate API, and no retained sidecar classifier state
(`SYNTHESIS.md:226-231`).

The pre-block list also rejects non-JSON/shared `bbnf-simd` alphabet-only
dispatch unless the policy proves the selected path cannot inherit JSON
quote/escape/control constants (`SYNTHESIS.md:248-250`). The handoff mirrors
this as a REVISE condition (`HANDOFF.md:155-159`). Alpha-E adds the same
consumer-bound form: the policy is prerequisite, must be consumed by a
same-wave measured row, cannot add public substrate/API shape, cannot ship
sidecar state, and the current hardcoded JSON constants are not admissible for
non-JSON consumers (`alpha-E-candidate-shortlist.md:420-429`).

This is enough for CH6. G-SIMD-GRAMMAR-POLICY is a behavior gate tied to row
measurement, not a support-only proof that can close a tranche by itself.

## Required Carry-Forward

S-P3 must preserve these rules in `SPEC.md` and `DISPATCH-PROMPT.md`:

1. Behavior-wave exit requires named row movement or architectural-block proof.
2. Scaffold/support/checkasm/resolver/codegen-only landings are not
   close-bearing.
3. Old A/GO, slack, measured-reject, and REDRESS-119/120 fixpoint results are
   baseline history only under the addendum.
4. Weaker scoping labels are non-authoritative for pinned CSS/JSON/G2-G7 work.
5. `ROLLING-SOTA-DELTA.md` production and gate consumption are mandatory close
   conditions.
6. `G-SIMD-GRAMMAR-POLICY` is mandatory for any applicable `bbnf-simd` consumer
   and must be consumed by same-wave measured rows; it cannot be counted as
   support-only closure.

With those carry-forward constraints, Alpha V3 CH6 accepts.
