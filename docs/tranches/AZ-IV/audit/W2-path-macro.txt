Architecture caveat (per dispatch §Architecture caveat)
--------------------------------------------------------

The dispatch noted that no production grammar yet exposes a
`StructRegistry` const at the codegen module level. The W2.4 landing
embeds a per-grammar synthetic fixture inside the proc-macro crate
(`crates/bbnf-path/src/registry.rs`) keyed by grammar marker
identifier. The fixture mirrors the canonical struct shape of each
grammar (Json `Document`/`Status`, CssL4 `Stylesheet`/`Rule`/`Declaration`,
Bbnf `Grammar`/`Rule`, Sheets `Formula`) so the hard-gate scenarios
resolve end-to-end. When `cargo xtask regen` exposes the production
const per grammar (W4 codegen / W5 binding), the fixture lookup swaps
to the production const without changing the macro's public surface.
