## §2 — Recommendations (named falsifiability gates)

- `G-W2-FIFTEEN-SOURCES`: the W2 plan must name the 15 `grammar/css/l4/*.bbnf` inputs and prove they are part of the `regen-css` input contract, even when the skinny runtime profiles still aggregate seven provider outputs.
- `G-W2-DUAL-TREE-DESTINATIONS`: the plan must distinguish root grammar-generated output (`crates/core/src/grammar/generated/css_l4.rs` and sidecar), core runtime output (`crates/core/src/runtime/css_l4/`), and skinny runtime output (`skinny/crates/runtime/src/grammars/css_l4_*`) instead of collapsing them into one target.
- `G-W2-SKINNY-SEVEN-PROFILES`: the skinny side of `regen-css` should keep seven output directories aligned with the existing exports in `skinny/crates/runtime/src/lib.rs:6-25`.
