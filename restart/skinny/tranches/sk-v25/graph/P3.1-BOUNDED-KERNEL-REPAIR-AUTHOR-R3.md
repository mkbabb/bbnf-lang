## R3 mechanism

### Canonical wire authority

`GraphArtifact::validate_canonical` checks the exact graph schema, nested
set-like ordering, strict top-level ordering and uniqueness, typed identity and
domain validity, and the recursive portable-string policy without changing the
artifact. `project` and `validate_structural` both require that validator.
Graph and projection wire structs now use recursive `deny_unknown_fields`
coverage in their actual schema domains. Constructors continue to normalize
the condition vectors they own.

Projection derivation now has one failpoint-bearing producer entry and one
failpoint-free rebuild entry over the same private bounded implementation.
Structural validation retains its typed local diagnostics, then compares the
entire rebuilt cluster set, quotient, projection, and projection set exactly.

### One indexed cluster graph

Cluster construction charges its declared domain before allocation and creates
one checked, canonical node/edge index with one undirected adjacency. Component
coverage, member order, node facts, edge identities, endpoint containment, and
duplicate identities are checked at that boundary. Connectivity, incidence,
degree, articulation, signals, and partition membership consume this index;
they no longer rescan raw edges for every node.

Articulation is iterative Tarjan over indexed adjacency. Partitioning is an
iterative worklist: articulation vertices are deterministically isolated in
one linear pass, residual connected groups are queued, and biconnected
oversize groups grow deterministic bounded shards. No recursive partition or
remove-each-node reachability assay remains.

### Honest shared budgets

SCC's public convenience API no longer creates a standard budget internally.
The caller supplies the one projection budget used by decomposition.

Cycle setup is charged before members, edge indexes, outgoing adjacency,
witnesses, or GF(2) rows are allocated. Checked costs include row word counts,
elimination work, witness edge storage, validation rows, complement rows, and
rank-domain indexes. Candidate search and candidate-row materialization retain
deterministic incremental charges. Completion and validation use the same
caller-owned projection budget.
