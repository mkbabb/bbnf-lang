# P5 — JSON lazy get (path query)

**Unit:** sk-v27 LW2.CON-1 (spec only). **Goal:** G-J4, stretch (Wave F, U18). **Family:** none in LW2.

## What an arm does

Given an input and a fixed list of JSON Pointer paths (RFC 6901), it returns the value at each path, building only what the paths need. The output-parity class is **GET**: the verdict and, after ACCEPT, the digest over the list of (path, P4 canonical form of the value, or `absent`).

## Policies

- **UTF-8 validation:** the whole input is validated (P1's rule). An arm that validates only the bytes it visits is a different plane (unchecked get) and is not paired with a validating arm; its row says so.
- **Escapes:** the returned strings and every key compared against a path segment are unescaped (P4's rule).
- **Number fidelity:** returned numbers follow P4's rule.
- **Duplicate keys:** a path segment selects the last member with that key (the P4 canonical form's choice).
- **Error offsets:** not compared on P5.

## Witness inputs

`bench/planes/witness/json/`, with the path list `/0`, `/a`, `/k` + the `esc-key` key, and `/` (the root).

## Equal work

The paths and their order are fixed by the cell; every arm resolves every path, and the checksum covers every returned value in full.

## Comparators

simdjson On-Demand (C++, observational), sonic-rs `get`/`get_many`, simd-json lazy values. Rows are "no comparator" until an equal-work API is named.
