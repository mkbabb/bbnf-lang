disclosure not co-located with claim; JSON > simdjson-class (5) — sonic-rs strict gated,
simdjson DOM absent; value API completeness (18) — skinny lazy API exists, totality eager
path is hand-written per-grammar, not generated; dav1d hybrid emitter (19) — architectural
plan is thorough; `ext/x86/` and live NEON hot-path wiring absent at HEAD.

The single most load-bearing gap remains the thermally mixed bench claim: the compound
"CSS 1.5–3.3× AND JSON 51/51 >SOTA" assertion appears without noting that CSS uses
cold per-parse N=200 and JSON uses Criterion warm-cache throughput — the two figures
are not comparable on the same thermal plane until the H1 close runs.
