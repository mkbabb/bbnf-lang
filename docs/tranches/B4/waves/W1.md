**Status**: planned (forward-pointer; implementation in a later dispatch)

deferred. The migration retained `FusedOutput<R>` as the parameterised
type; consumer fixtures still write the unparameterised `FusedOutput`
form, surfacing as E0107 "missing generics for struct `FusedOutput`"
through `#[derive(Parser)]` macro expansion in five test sources. The
five fixtures are enumerated in `AY-II/PATH-FORWARD.md` §"Immediate
cleanup targets already identified".
