Arm primary sources confirm the inventory surface: ACLE maps `vmull_p64` to `PMULL`/`PMULL2`; CSSC support includes CTZ; DotProd exposes `UDOT`/`SDOT`; TBL/TBX are A64 table lookup instructions; byte equality maps to `CMEQ`; and shifts include `USHR`/`URSHR` families. Sources are listed in §5.

## §3 — Grammar-neutrality

A64-CLASSIFY-TBL4-STRUCTURAL is grammar-neutral when expressed as `byte_class_from_eq_set` or a generated byte-set classifier. JSON structural bytes, CSS delimiters/operators, Sheets separators/operators, and BBNF-self punctuation can all supply grammar-owned alphabets. The policy owner must be `generated_grammar`; retained state must be `local_loop` or `generated_function`, never a parser-owned sidecar.

A64-MOVEMASK-U8X16-COMPARE is grammar-neutral as a byte classifier and mask packer. It is JSON-overfit only when the needle set is hard-coded to JSON roles in a generic crate.

A64-WIDE-SHIFT-MOVEMASK-FOLD is grammar-neutral only as an implementation detail of mask packing, digit packing, or escape-nibble folding. A standalone wide-shift primitive with no grammar-level byte-set or scalar semantic is not shortlist-safe.

A64-UDOT-DIGIT4-MAC is grammar-neutral in principle, but is REJECTed as a SK-V15 S-P2 implementation candidate because current P1 evidence does not name a surviving BBNF-side numeric hot leaf. It remains diagnostic inventory only.

A64-TBL-UNICODE-X4-BATCH generalizes to JSON `\uXXXX` and CSS hex escape handling only if the grammar supplies escape syntax and semantic output. It does not generalize as a sink-local digest-hash accelerator.

A64-CSSC-CTZ-BULK-EMIT and A64-PMULL-PREFIX-XOR are grammar-neutral bit-mask algebra, but both are currently REDRESS-blocked on the SK-V15 host path. Grammar-neutrality does not override measured regression.

X86-DIAGNOSTIC-ONLY is not a grammar-neutral admission primitive for this tranche because the admission surface is native Apple M5 Max/aarch64.

## §4 — Risks

Do not reopen a retained sidecar or second scanner. Lock 1 rejects retained class/mask streams, parser-owned cursor/list state, public substrate APIs, `UnionTape`, and second tapes unless G-Omega amends the lock (`restart/locks/LOCKS.md:118`).
