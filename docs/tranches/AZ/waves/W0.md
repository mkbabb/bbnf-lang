# AZ.W0 — Provenance Side Metadata

**Opens after**: AY close
**Agents**: 3 parallel
**Hard gate**: Stable node, rule, span, and shape provenance exists on the AY substrate with feature-off regression bounded to `<= 3%`.

## Scope

1. Add stable provenance payloads for node/rule/span/shape identity on
   the AY substrate or side metadata where hot-path cost demands it.
2. Emit provenance from the grammar-derived parser on the same runtime
   path.
3. Add production consumers and wire-contract tests for provenance
   inspection.

## File bounds

| File | Access |
|---|---|
| `crates/core/src/runtime/provenance.rs` | create |
| `crates/core/src/runtime/parsed.rs` | modify |
| `crates/core/src/backend/rust/emitter/grammar.rs` | modify |
| `crates/core/tests/provenance_contract.rs` | create |

**Do NOT touch**: packed substrate layout semantics from AY, replay/recovery logic, build/profile tooling, any `.bbnf` grammar.

## Phase sub-items

### AZ.W0.1 Provenance substrate

Mechanism: define stable provenance payloads keyed by canonical node
order and spans, choosing inline fields versus side tables only where
feature-off cost demands it.

Files touched: `crates/core/src/runtime/provenance.rs`,
`crates/core/src/runtime/parsed.rs`.

Sub-gate: provenance structures compile and can be queried from parsed
runtime objects.

### AZ.W0.2 Emission wiring

Mechanism: emit provenance population from the same grammar-derived
parser path that fills the AY substrate.

Files touched: `crates/core/src/backend/rust/emitter/grammar.rs`,
`crates/core/src/runtime/parsed.rs`.

Sub-gate: `cargo expand -p bbnf --bench json_monolithic` shows emitted
provenance writes in the production parser path.

### AZ.W0.3 Contract activation

Mechanism: add end-to-end tests and basic inspection helpers so the
provenance surface is exercised immediately.

Files touched: `crates/core/tests/provenance_contract.rs`,
`crates/core/src/runtime/provenance.rs`.

Sub-gate: provenance contract tests pass on canonical fixtures.

## Hard gate

1. `cargo expand -p bbnf --bench json_monolithic` shows provenance
   writes on the production parser path. Artefact:
   `docs/benchmarks/post-AZ-W0-expand.txt`.
2. `cargo test -p bbnf --test provenance_contract --profile ax-iter`
   passes. Artefact: `docs/benchmarks/post-AZ-W0-contract.txt`.
3. Feature-off regression versus AY close is `<= 3%` on the eager JSON
   5-fixture geomean. Artefact: `docs/benchmarks/post-AZ-W0-mid.json`.
