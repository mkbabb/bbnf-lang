# AX.W7 — Gradient / LazyValue / On-Demand Materialization

**Opens after**: W6 close
**Agents**: 4 parallel (core LazyRef + should_descend, JSON wrapper, CSS wrapper, Sheets + BBNF wrappers)
**Hard gate**: Twitter-ignore-keys ≥ 2× baseline; `parse_into::<V>()` O(subtree); per-grammar fixture coverage.

## Scope

Simdjson OnDemand analog, grammar-agnostic by construction via shape-tag re-entry.

1. **`LazyRef` tape kind**: new `TapeKind::LazyRef { input_start: u32, input_end: u32, shape_tag: ShapeTag }`.
2. **`should_descend` visitor hook**: extend `GrammarVisitor` trait with `fn should_descend(&mut self, path: &VisitorPath) -> bool { true }`. Default = descend. When returns false, shape emitter emits `LazyRef` and seeks matching close.
3. **`seek_matching_close` mechanism**: uses W5 kind-separated streams when available OR per-shape bracket-balance scan (`prefix_xor_64` over `{`/`}` on JSON). No new IR pass — mines from existing `structural_alphabet` + shape tag.
4. **Per-grammar `*LazyValue` wrappers**: `JsonLazyValue`, `CssLazyDeclaration`, `CssLazyRule`, `SheetsLazyFormula`, `BbnfLazyRule`. Each exposes `parse_into::<V>()`, `as_raw_bytes()`, `shape_tag()`. Field-complete per invariant 18.

### W7.2 Shape emitter compound-opening consumer

Every `shapes/{object,array,arglist,wrap}.rs` compound-opening arm:

```rust
if !visitor.should_descend(&path) {
    let close_pos = seek_matching_close(input, pos, shape_tag);
    visitor.lazy_compound(input_start, close_pos, shape_tag);
    pos = close_pos;
    return Ok(());
}
// otherwise parse normally ...
```
