## Scope

Three lever clusters shipped together because they co-touch the shape emitter + `simd-scan` surfaces.

1. **JSON-targeted SIMD micro-levers** (seven items):
   - Paired `stp` for span writes (W1 landed the primitive; this wave activates in shape emitter compound-open arms).
   - `unreachable_unchecked` at exhaustive dispatcher default arms (per `DisjointFirstMiner` proof).
   - Scan-kernel fusion (aw5-n1 R2): fuse `skip_space` + `first_quote_or_backslash` into one stripe-level pass eliminating duplicate 16-byte loads.
   - AltReorder by corpus frequency (aw5-n1 R6): emit Alt branches in frequency-descending order from corpus stats.
   - `vpaddq_u8` movemask cascade — port sonic-simd's 4-stage reduction; replace `vaddv_u8` path on M-series (3 cyc critical path vs 24 cyc).
   - `vdotq_s32` canada fraction packadd — FEAT_DotProd 4-lane accumulator with `[1,10,100,1000]` pattern.
   - PMULL verification — confirm `vmull_p64` emits on aarch64-apple-darwin via `cargo asm`; gate check only, no new code.

2. **Miner inheritance — L1 + L2 (Agent 5)**:
   - **L1 disjoint_first_tables → shape emitter**: `shapes/{keyword,wrap,unordered,flat}.rs` emit `static DISPATCH_TABLE: [u8; 256]` from `ir.disjoint_first_tables`, replacing hand-coded byte-match cascades with one indexed load per Alt. Walker-only consumer dies at W0b; shape emitter inherits.
   - **L2 keyword_branches → PHF in shape emitter**: `shapes/keyword.rs` reads `ir.keyword_branches.get(&body_id)` + emits PHF when `|branches| ≥ 3`. Same pattern AW-IV.W3.2 used for walker.

3. **Scanner generalization (Agent 3, AN.2 → AO.2 chronic)**: collapse `css_ident_fast` / `css_ws_comment_fast` / `css_string_fast` / three `scan_{digits,alnum,hex}_mut` into `RegexClass`-dispatched primitives. Keeps W4 levers drop-in-replaceable per RegexClass; enables scan-fusion cleanly.

## Phase sub-items

### W4.1 Scanner generalization (Agent 3 chronic)

Consolidate the scanner zoo into RegexClass-dispatched primitives. Pre-requisite for §W4.3 scan-fusion. Delete per-grammar scanner re-exports per AN.2 plan.

### W4.2 Miner inheritance L1 + L2

- `shapes/keyword.rs`: read `ir.keyword_branches` for PHF generation. Threshold ≥ 3.
- `shapes/{wrap,unordered,flat}.rs`: read `ir.disjoint_first_tables` for `DISPATCH_TABLE` emission.
- `shapes/object.rs` + `shapes/array.rs`: consume `ir.disjoint_first_tables` for opening-byte dispatch.

Wire-contract test: every per-shape emitter's emitted function must reference `ir.disjoint_first_tables[N]` or `ir.keyword_branches[N]` per rule; miner-output reads non-empty for every primary grammar.

### W4.3 Scan-kernel fusion (aw5-n1 R2)

Detect adjacent-stripe scan calls at emit time: `skip_space` followed by `first_quote_or_backslash` over the same input range. Fuse into one stripe-level pass producing both bitmaps. Eliminates duplicate 16-byte loads at JSON string-adjacent-to-whitespace sites.

### W4.4 AltReorder (aw5-n1 R6)

Mine corpus frequency per Alt per grammar. Emit branches in frequency-descending order from grammar-corpus statistics.

### W4.5 JSON micro-kernels

- `unreachable_unchecked` at proven-dead dispatcher defaults (emitter-side, one-line per dispatcher).
- `vpaddq_u8` cascade replacing `vaddv_u8` in `simd-scan::neon::movemask`.
- `vdotq_s32` in `simd-scan::str2int` fraction path.
- PMULL verification via `cargo asm`; if shift-XOR surfaces, correct cfg gate.
