# AY-II.W0 — Fused Substrate + Unified Emitter + Grammar-Derived Typed Semantics

**Opens after**: tranche open
**Agents**: 5 parallel (W0.a / W0.b / W0.c / W0.d / W0.e on disjoint file bounds)
**Hard gate**: Fused parse + value pipeline is one path; `push_compound` + `note_push` + `SIB_SKIP_STAMPED_BIT` + `navigate_tape` all retired; `Columns::rollback_to` is the sole retry primitive; projection admission + helper + consumer counts agree per grammar; typed CSS semantic projection emits from CSP + egraph facts with no hardcoded bindings; structural scan is grammar-activated via emitted policy on the canonical path; full fat-LTO 5-bench matrix + lightningcss-parity + typed-accessor-surface tests all green at wave close with no panic on any grammar.
**Status**: planned

## Scope

Five convergent architectural transpositions land atomically in
one wave. No piece of the W5.a/b/c + W6.a/b/c experiment survives
unchanged: the substrate collapses back to single-pass finaliser
stamping, gains a rollback primitive, gains a fused value-
construction path, and the direct-to-struct + typed-semantic
surface completes across all four grammars.

### Shared design constraints

All sub-agents inherit:

- **No grammar-name dispatch.** Zero matches for
  `JsonParser|CssL4Parser|BbnfParser|GoogleSheetsParser` as
  routing predicates in new / modified code.
- **Grammar-derived semantics.** Every typed projection,
  materializer, and structural-scan activation is emitted from
  CSP-inferred type facts + egraph-derived projections. No
  hand-coded binding tables. No hardcoded grammar type names.
- **`cargo expand` is primary evidence.** Source-only claims are
  supplementary; a gate closes on expanded output the compiler
  actually sees.
- **Peer-first bench references.** Spot benches cite competitor
  targets where available (`crates/core/benches/json/competitors.rs`,
  `crates/core/benches/css/competitors.rs`).

## Phase sub-items

### AY-II.W0.a — Substrate rollback + unified compound API

Owner: tape crate.

Mechanism:

1. Delete `TapeBuilder::open_compound`, `close_compound`,
   `open_stack`, `OpenFrame`, `note_push`.
2. Delete `TapeRec::SIB_SKIP_STAMPED_BIT` + its `extra`-bit
   accessor. Reclaim or reserve the bit with a doc comment.
3. Restore `finaliser::finalise` as the sole stamp source for
   `sib_skip`. Strip the skip-pre-stamped branch from the
   finaliser loop.
4. Add `Columns::rollback_to(open_offset: u32)` — truncates
   `kinds`, `flags`, `extra`, `span_lo`, `span_hi`, `child_off`,
   `sib_skip`, `pay_narrow`, `pay_wide`, `pay_agg`,
   `frame_depth` back to `open_offset` slots. Idempotent.
   Signals checkpoint/restore intent to the fused pipeline (see
   W0.c — `ValueBuilder::rollback_to` mirrors this).
5. Unified compound emission API. W0.a picks the idiomatic name
   (either rehabilitated `open_compound/close_compound` against
   rollback-aware semantics, OR a single `begin_compound / end_compound`
   pair against Columns). Publishes the signature for W0.b + W0.c
   + W0.e to adopt.
6. Update `close_compound` tests to assert finaliser-only
   stamping semantics. Retire `w5_close_stamp_activation.rs`.
7. Cursor API additions supporting structural-scan migration
   (W0.e consumer): expose `Cursor::scan_structural_bounded(end_span)`
   or equivalent — a lightweight primitive W0.e wires per grammar.
   (W0.a defines the signature; W0.e populates the consumers.)

Sub-gate:
- `cargo iter-check` exit 0.
- `make iter-test-leaf` exit 0.
- `nm target/release/deps/json_monolithic-*` shows `note_push`
  absent; `Columns::rollback_to` symbol present.
- Spot bench `cargo bench --profile bench -p bbnf --bench
  json_monolithic twitter` does not regress vs AY-I baseline.

### AY-II.W0.b — Emitter unification

Owner: emitter shapes.

Mechanism:

1. Every `quote! { ... builder.push_compound(...) ... }` +
   paired `builder.mark_children()` converts to W0.a's unified
   API.
2. Every retry-IIFE site (`wrap.rs`, `keyword.rs`, `inline.rs`,
   `alt_dispatch.rs`, `flat.rs`, `array.rs` Shape-2,
   `pratt.rs` reducer) replaces `columns_mut().truncate(save)`
   with `columns_mut().rollback_to(open_off)`. W0.b coordinates
   with W0.c to mirror the `ValueBuilder::rollback_to` call at
   every retry site (fused pipeline semantics — parse retry
   rolls back both substrates atomically).
3. CSS Shape-2 + Sheets `columns.rs:409 index out of bounds`
   panic (from W6.c) resolves transitively via rollback_to.
4. `shapes/dispatcher.rs` + `shapes/mod.rs` audited; any dead
   dispatch entry retired.
5. `cargo expand -p bbnf --bench json_monolithic` + `--bench css_l4`
   + `--bench google_sheets_monolithic` + `--bench bbnf_monolithic`
   show zero `push_compound`, zero `mark_children` per grammar.

Sub-gate:
- `cargo iter-check` exit 0.
- `target/expand/ay-{json,css,sheets,bbnf}.rs` all zero
  `push_compound`.
- CSS + Sheets bench compile clean (no panic).
- Spot bench `make ay-bench-close WAVE=W0b-spot` across 5 bench
  binaries produces no panic.

### AY-II.W0.c — Fused pipeline + runtime consumer unification

Owner: runtime + fused value pipeline + view.

Mechanism:

1. Introduce `crates/core/src/runtime/value_builder.rs` —
   `ValueBuilder<R: Root>` parallel to `TapeBuilder`. Holds an
   arena / slab for `<Grammar>Value` construction, a frame stack
   that mirrors the tape's open/close discipline, and a
   `rollback_to(checkpoint)` primitive symmetric with
   `Columns::rollback_to`.
2. Parse entry in `grammar.rs` (coordinate with W0.b) allocates
   BOTH `TapeBuilder` AND `ValueBuilder<R>`. Each shape's emitted
   body writes to both in lockstep:
   - Structural shapes push a value frame on compound entry,
     pop on compound exit into the parent frame.
   - Leaf shapes push a scalar value alongside the tape record.
   - Retry-IIFE sites call both rollback primitives in lockstep.
3. `Parsed` gains an owned `value: <R as Root>::Value<'static>`
   or equivalent slab-backed handle populated at parse time.
4. `Parsed::to_value() -> R::Value<'_>` becomes a thin
   lifetime-bounded projection over the already-constructed
   value. No parse invocation. No `parse_with_visitor` call. No
   tape-walking-materializer path. The grammar-emitted
   `<Grammar>Value` structure lives in the slab; `to_value`
   returns a reference / clones-by-arc / zero-copies-into-out.
5. Delete `navigate_tape` from `runtime/path.rs` + every test
   assertion referencing it. `__path_walk` routes through
   emitted navigation primitives (W0.e coordinates).
6. `view/mod.rs` + `view/value.rs` audit — every
   tape-reconstruction fallback retired. `view()` stays as a
   zero-copy structural view; `to_value()` rides the fused
   pipeline.
7. `value_api_apples_to_apples.rs` updated — assertions verify
   no reparse (by construction — parse call count instrumented
   at `ParserState::new` or the parse-entry symbol).

Sub-gate:
- `cargo iter-check` exit 0.
- `make ay-test-value-api` green.
- `grep 'parse_with_visitor\|<.*Parser>::parse\b' crates/core/src/runtime/parsed.rs`
  returns zero matches.
- Spot bench `bbnf_value_twitter / sonic_value_twitter` ≤ 1.20
  (W1 tightens to ≤ 1.15 on the close matrix).
- Samply on eager JSON twitter shows `ValueBuilder::push` or
  equivalent as a named hot-path owner; no double-parse
  attribution.

### AY-II.W0.d — Projection totality + grammar-derived typed CSS semantics

Owner: emitter projection + IR payload layout + typed-CSS tests.

Mechanism:

1. Projection totality audit: emit one `materialize_projection_*`
   helper per `PROJECTION_DIRECT_TO_STRUCT` entry (currently 71
   entries vs 69 helpers vs 2 resolver shims per AUDIT-B §4).
   Resolver-backed admissions (`Color`, `String`) gain runnable
   helpers that project directly from the fused
   `ValueBuilder` slab (coordinate with W0.c).
2. `crates/core/tests/projection_totality.rs` — wire-contract
   test that asserts:
   ```
   <Grammar>::PROJECTION_DIRECT_TO_STRUCT.len()
     == count of emitted materialize_projection_* fns
     == count of production consumer call sites
   ```
   per grammar and in aggregate. Fails the wave if any grammar
   carries a consumerless admission.
3. Grammar-derived typed CSS semantic projection. Extend
   `ir::passes::payload::layout` (and any helper pass the
   emitter reads) so that EVERY grammar rule carrying a declared
   type annotation (`-> TypeName`) produces:
   - an emitted `<Grammar><RuleCamel><Projection|Struct>` with
     fields derived from the grammar's declared field order and
     the CSP-inferred field types;
   - an emitted materializer that constructs that struct from
     the fused slab directly;
   - a production consumer via `<Grammar>Value` variant or via
     `Parsed::get<T>()` routing.
   CSS L4's typed surfaces — `Color`, `Declaration`, `Value`,
   `Selector` families that lightningcss's AST represents —
   all emit from CSP + egraph facts. No hand-coded mapping
   table. If the grammar declares it, the emitter synthesizes
   the Rust type.
4. Tests `lightningcss_parity.rs` + `css_l4_canonical_parity.rs`
   + `typed_accessor_surface.rs` — assertion-tightening only
   (not harness rewriting). Remove any surviving `#[ignore]`
   tags from typed-color / typed-accessor assertions; the
   W0.d landing must not add new `#[ignore]`. `named_type_preservation.rs`
   updated so `admitted_projection_surfaces` asserts the totality
   invariant referenced above.

Sub-gate:

- `cargo test -p bbnf --test named_type_preservation --profile ax-iter`

### AY-II.W0.e — Structural-scan integration + navigation/query fast path

Owner: structural-scan substrate + cursor API + emitter navigation
policy + runtime `get()` consumer.

Mechanism:

1. Promote `StructuralIndex` + `scan_structural` from standalone
   functions to universally-available substrate services. Add
   cursor methods: `Cursor::object_key_seek(key_span)`,
   `Cursor::bounded_lookahead(end_span)`, and whatever the
   fused pipeline needs for CSS token-boundary assist where
   grammar facts justify it.
2. Grammar-derived activation via emitter policy. Extend the
   emitter (coordinate with W0.b's `shapes/dispatcher.rs` region)
   so that for each grammar, the CSP-inferred alphabet density +
   digraph signature + declared structural markers drive a
   per-grammar per-rule emission decision: does the parse path
   for this rule wire the structural-scan fast path? The policy
   output is a const table (`STRUCTURAL_SCAN_POLICY` per
   grammar) that the generated parser dispatches on. No
   runtime flag. No hand-routed grammar specialization.
3. Delete `runtime/path.rs::navigate_tape` + its 4 associated
   test assertions. `__path_walk` (emitter) routes through the
   cursor API for all grammars; where the policy admits
   structural-scan (e.g. hot object-key seek), the emitter
   inlines the scan primitive.
4. `Parsed::get<T>(path) -> Option<T>` — routes through cursor
   navigation + emitted materializer; where the structural-scan
   policy fires, uses `object_key_seek`. Fully grammar-derived;
   no hand-written path-walking logic per grammar.
5. `byte_class.rs` (per file bounds) reads the alphabet /
   digraph facts the emission policy consumes. If the current
   pass does not publish these facts with the shape the policy
   needs, extend minimally — do not introduce a new facts API.

Sub-gate:
- `cargo iter-check` exit 0.
- `navigate_tape` symbol absent from `target/release/deps/*`
  `nm` output.
- `cargo expand -p bbnf --bench json_monolithic` shows

  `__path_walk` where the policy admits.
- `cargo expand -p bbnf --bench css_l4` + `--bench
  google_sheets_monolithic` show per-grammar policy tables
  distinct from JSON (no one-size-fits-all const).
- Spot bench `cargo bench --profile bench -p bbnf --bench
