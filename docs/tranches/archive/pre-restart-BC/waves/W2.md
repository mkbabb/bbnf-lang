# BC.W2 - Worktree Fixture Symlink Contract

**Name**: W2 - Worktree Fixture Symlink Contract
**Opens after**: W1 - AUDIT-B Routed Splits
**Agents**: 5 parallel
**Hard gate**: `xtask worktree-init` materializes every grammar's data + `rewrites/*.ron`; named test in `xtask/tests/worktree_init.rs`; W6.2 known-miss fully closes for the fleet
**Status**: planned

## Scope

1. Extend `xtask/src/worktree_init.rs` (BA.W0 created) to cover BB-introduced `grammar/<name>/rewrites/*.ron` files. The xtask command discovers every grammar's fixture and rewrites directory; symlinks (or hard-copies on platforms without symlink support) the trees on worktree open.
2. Codify the contract: every BB-discovered rule has a per-rule fixture corpus that the worktree-init step must materialize. The contract integrates with the W3 CI gate (a PR that adds a rule must include the fixture; xtask verifies).
3. Update `xtask/tests/worktree_init.rs` (BA.W0 stub) with full fleet-coverage tests: every grammar's data + rewrites materialise on a fresh worktree open.
4. Document the contract in `docs/tranches/BC/audit/W2-fixture-contract.md`.
5. The W6.2 known-miss (worktree fixture symlink contract for the fleet) closes here.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- a grammar's fixture tree has a structure that cannot symlink cleanly (e.g., an absolute-path reference in a `.ron` file);
- the BB-introduced rewrites tree has a per-grammar test fixture that requires file-system case-sensitivity sensitivity (Mac default vs Linux);
- the contract's CI integration requires changes outside the W2 file bounds (e.g., a workflow file W3 owns);
- three diagnostic-loop iterations fail to isolate why a grammar's fixture does not materialize;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).
