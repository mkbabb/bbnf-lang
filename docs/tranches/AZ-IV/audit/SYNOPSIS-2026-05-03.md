## I — The Architectural Defect, Two Altitudes

Two readings, same defect:

- **DEEP-A** (architectural): `project_types` populates the `StructRegistry` at codegen time — but the parser never consumes it. Every emitted parse fn constructs `__layout: StructLayout { rule_type: TypeDesc::Span, fields: vec![] }` (10 emission sites in `crates/core/src/backend/rust/emitter/shapes/`). The static REGISTRY emitted at `crates/core/src/grammar/generated/json.rs:276` carries rich `BoxedEnum`/`Tuple`/`HeterogeneousAltJoin` typings; the parse-time literals carry empty `Vec`. Type inference output is thrown away at the parse boundary. `SimpleStructBuilder::push_leaf_with_*` deposits `V::unit()` for 5 grammars (BNF, EBNF, CSV, CSS Pretty, Math), discarding typed leaf payloads outright.

- **DEEP-B** (samply, 25 963 samples, fat-LTO `[profile.bench]`): **86.07% of inclusive samples on `bbnf_value_twitter` are `Vec<OpenFrame>::clone` from `<JsonStructBuilder as StructBuilder>::checkpoint`**. The speculative-branch deep-clone discipline that's mandatory *because* compile-time-resolved direct projection isn't emitted. Same mechanism at JSON's altitude → CSS L4 (DEEPX-2 verified: 1 407 `checkpoint()` sites in `css_l4.rs`, 5 545 declarations × ~7 failed branches × 7.6 MB cloned per bootstrap parse) → Sheets (DEEPX-3 verified: same `Vec<Frame>::clone` exposed worse by Pratt depth) → BBNF (DEEPX-4 verified: 217 checkpoint sites in `bbnf.rs`, identical magnitude class).

These are the same defect at different altitudes:

> **The parser does runtime checkpoint-and-rollback over an untyped slab because compile-time-resolved direct projection isn't emitted.** The cost is dominated by `Vec<OpenFrame>::clone` per speculative branch.

This single mechanism explains every chronic post-AZ-IV problem:

| Symptom | Root cause |
|---|---|
| 4196× sonic_get_twitter gap | `bbnf_get_*` calls eager `parse + walk` instead of routing to `parse_with`; *and* the parse itself is dominated by checkpoint clones |
| 5.22× sonic_value_twitter gap | checkpoint clone cost on speculative branches |
| 18/19 AU floor BELOW | every typed builder requires checkpoint discipline; AU's flat per-grammar arenas had no equivalent |
| `ts_node_execute` RED | TS backend's `runtime::ts::emit_value` is the same defect at the TS-emit altitude (aggregates emitted as spans, not iterables) |
| `substrate_audit` RED | 32 zero-caller `pub` substrates is the cumulative tail of substrate-first/consumer-forward discipline (DEEPX-5 archaeology) |

**The fix is one mechanism**: direct-projection codegen consuming the `StructRegistry` that `project_types` already populates, with cheap `(stack_depth, arena_count)` value-typed checkpoints, with predictive first-byte dispatch where alphabets are disjoint, with `Document::get<T>(path)` rerouting through `parse_with` so eager is the degenerate case of lazy with `&EMPTY_PATH`. **One mechanism, four+ closures.**
