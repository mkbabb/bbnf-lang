# AZ-I.W1 — `StructRegistry` + `project_types` closure (JSON + CSS L4 + Sheets)

**Opens after**: AZ-I.W0 close
**Agents**: 3 parallel (one per grammar)
**Hard gate**: `project_types` closes on JSON, CSS L4, and Sheets;
`StructRegistry` non-empty for every Named rule in these three
grammars; IR audit pass reports 100% `->` coverage on the three;
no AU-baseline regression.
**Status**: planned

## Scope

1. Run `project_types` to fixed point across JSON, CSS L4, and
   Sheets grammars. Resolve every named-rule type, every `->`
   field, every compound closure. Hard-fail-and-block on any
   unclosed edge (Q2 disposition).
2. Populate `StructRegistry` with a `StructLayout` per Named rule
   in each of the three grammars. Expected counts: JSON ~7, Sheets
   ~8, CSS L4 ~60 (see RESEARCH.md §6).
3. Wire the emitter to read `StructRegistry` for every compound
   emission on the three grammars. The tape continues to accept
   emissions in parallel (bridge mode) — W2 and W3 sever the tape
   path; W1 only populates the registry.
4. Re-run the IR audit pass from W0; assert 100% coverage on the
   three grammars.
5. No bench-delta gain; no bench-delta regression.

## Phase sub-items

### AZ-I.W1.1 — JSON `project_types` closure + registry

Fix-point `project_types` over `grammar/json/json.bbnf`. Register
`StructLayout` for `value`, `array`, `object`, `pair`. Verify with
the audit pass.

Sub-gate: `cargo test -p bbnf-ir --test project_types_json` green;
audit pass reports 100% on JSON.

### AZ-I.W1.2 — Sheets `project_types` closure + registry

Fix-point on Sheets; register `sheet`, `row`, `cell`, `formula`,
`reference`, and formula/value sub-shapes.

Sub-gate: audit pass reports 100% on Sheets.

### AZ-I.W1.3 — CSS L4 `project_types` closure + registry

Fix-point on CSS L4 (the largest surface). Register `stylesheet`,
at-rule kinds, selector kinds, `declaration`, and every typed-value
enum (`<length>`, `<color>`, `<angle>`, `<time>`, `<resolution>`,
`<percentage>`, `<dimension>`, `<image>`, `<gradient>`, `<function>`,
`<calc>`).

Sub-gate: audit pass reports 100% on CSS L4.

### AZ-I.W1.4 — Emitter registry-read + bridge mode

Emitter consults `StructRegistry` on every compound emission for
the three grammars; the existing tape emission path continues to
run in parallel. The bridge is the transition invariant for W2/W3.

Sub-gate: emitter calls `StructRegistry::layout(rule_id)` on every
compound boundary in the three grammars; tape records still
produced; bench unchanged from W0 baseline.
