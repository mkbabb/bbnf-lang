# B7.W1 — parse-that: divan migration + nextest CI + inline-test cleanup

**Opens after**: tranche open (parallel with W0 + W2)
**Repo**: `parse-that` (`/Users/mkbabb/Programming/parse-that`)
**Agents**: 4 parallel (A2, A3, A4, A5)
**Status**: planned

## Scope

W1 closes parse-that's modernization gap on three axes:

1. **Bench harness consolidation onto divan.** All 16 bench
   targets retire `bencher = "0.1.5"`; the dev-dep replaces with
   `divan = "0.1"`; each bench file ports to `#[divan::bench]`.
2. **CI rewire onto nextest + pinned toolchain.** The CI workflow
   invokes `cargo nextest run --profile ax-iter`; the workflow
   reads `rust-toolchain.toml` as the authoritative pin (no
   floating `dtolnay/rust-toolchain@nightly`). The `.cargo/config.
   toml` declares `ax-iter`, `ay-final`, `bench-ci` profile aliases
   mirroring bbnf-lang.
3. **Test-surface cleanup.** All 69 inline `#[test]` items in
   `rust/parse_that/src/` migrate to `tests/` directory
   equivalents.
