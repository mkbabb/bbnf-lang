## Executive Summary

V2 preserves the V1 finding: the P1-P8 priority cascade is not an
optimizer, and the defensible SK-V13 decision engine is candidate
generation plus equality saturation, feasibility constraints, and active
cost extraction. V2 removes the convergence blockers. Citations ground
candidates only; they do not admit a route. Every decision-engine route
below now declares transfer facts, substrate target, retention lifetime,
policy owner, LOC/risk/rollback envelope, stale-cost threshold, and
abrogate gate. `CollapsedStage` is explicitly a transient emitted-kernel
strategy, not a retained FSM or mask substrate. The dead
dead Sneller source repository citation is removed; the Sneller blog is
architecture pressure only for branchless AVX-512 ideas and carries no
M5/aarch64 admission authority. T-P3 may use this dossier to write locks
diffs only when JSON/CSS equality, generated grammar facts, and bounded
extraction reports are named in the same wave.

## Substrate-Kind Rules

Every e-graph node, rewrite guard, CSP filter, cost extraction result, union
candidate, imported scanner plan, and emitted-kernel strategy must declare:

```text
substrate_target = local_temp_only | existing_tape | direct_sink | admitted_fact_output
retention_lifetime = local_loop | generated_function | output_row
policy_owner = generated_grammar | caller_data | none
```

Extraction rejects any candidate requiring retained class/mask streams,
parser-owned cursor/list state, public substrate API, `UnionTape`, or a
second tape unless G-Omega explicitly amends Lock 1. `CollapsedStage` masks,
classes, and FSM state are local temporaries consumed inside the emitted
function or emitted directly as the admitted output row. They are never a
generic retained substrate.

## Active Cost Evidence Contract

`CostFacts` becomes executable only when every selected and rejected candidate
records:

```text
profile_id
profile_tranche
corpus_or_feature
output_plane
throughput_mbps
cycles_per_byte
ipc
materialization_bytes
generated_loc_delta
feature_gate
scalarization_profile
evidence_freshness_days
extraction_method
frontier_status
stale_or_static_fallback
```

The stale/static fallback ceiling is 30 percent of candidate expressions per
grammar and per output plane. Above that, extraction is non-admissible and the
wave either refreshes evidence or records measured rejection. A static cost may
break ties inside a measured equivalence class; it cannot carry an admission
row.

## Abrogate Gates

| gate | threshold | disposition |
|---|---|---|
| e-graph saturation | >50,000 e-nodes, >10,000 e-classes, >30 iterations, or >512 MiB resident memory before equality-preserving extraction | measured reject; reduce rewrite set or abrogate resolver route. |
| CSP solve | >1s per grammar or unresolved UNSAT cause | measured reject; do not fall back silently to cascade admission. |
| stale cost evidence | >30% of candidate expressions use stale/static fallback | reject extraction; refresh profile evidence or demote candidate. |
| generated LOC growth | exceeds the candidate's ledger `loc_budget` upper bound, or a stricter SPEC wave budget if S-P3 names one, without traced O(N) reason | halt wave; inspect generator expansion before admission. |
| row regression | any previously admitted JSON/CSS row silently demotes | reject unless architectural-block disposition is recorded. |
| parity/checkasm/equality | any scalar, checkasm, strict equality, or oracle failure | reject; no support-only landing. |
| substrate-kind | candidate requires retained sidecar, second tape, or public substrate API | reject unless user amends Lock 1 at G-Omega. |

## Architectural Assertions Defended

| assertion | defence | adoption rule |
|---|---|---|
| Backend-shape selection should be a search/extraction problem. | Equality saturation keeps alternative forms simultaneously and lets a cost model extract the winner. This is the class of problem where destructive fixed ordering loses information. | Introduce `BackendExprLanguage` over BIR/shape candidates, bounded by node/iteration caps and per-rule generated-fact guards. |
| Cost must become an executable contract. | Published and local egraph extraction take a `CostModel`; current skinny `CostFacts` only records the outcome after the fact. | `CostFacts` must include objective axes, evidence freshness, frontier status, extraction method, and a gate-consumed report. |
| CSP belongs after candidate generation, not as a paper optimizer. | Constraint solvers are suitable for feasibility and objective constraints, but local `CspScheduler` is currently a saturation scheduler. | Use CSP for feature compatibility, same-wave consumer, parity oracle availability, substrate-kind rejection, generated-size budget, and guard-row constraints. |
| `SinkOnly` is real when tied to a consumer. | Projection-aware parsers such as Mison show that known consumer shapes can avoid general materialization. | A `SinkOnly` row admits only with strict same-plane comparator, independent oracle, and generated consumer, not digest-only correctness. |
| `CollapsedStage` is a transient emitted strategy. | asmjson/Sneller-style material is architecture pressure for branchless direct pipelines, but it does not admit M5/aarch64 retained state. | Any SK-V13 use must be an ARMv9.2-specific candidate with scalar reference, checkasm, equality, local temporary lifetime, and row movement. |
| The five-shape enum can remain a V1 fence. | Finite candidate sets are normal in code generation; local `BackendShape` already has the intended names. | Treat the five shapes as the allowed search domain. Do not add `BackendShape` variants in T-P3 unless G-Omega explicitly changes the lock. |
