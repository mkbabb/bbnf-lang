# BB.W4 — FINAL: cost-model integration + CI auto-accept + review-ledger close

**Opens after**: W3 close
**Agents**: 1 serial
**Hard gate**: BB closes only if cost-model integration holds, CI runs
Class-1 auto-accept on every incoming enumeration batch, the review
ledger is complete, `FINAL.md` records deltas and reversals, and the
full 17-entry matrix is at or above AZ close on every entry.
**Status**: planned

## Scope

1. Fold the accepted-rule cost deltas back into the cost-config and
   confirm the CSP solver uses them at emission time.
2. Stand up a CI job that runs the enumerator on every grammar on
   schedule (or on IR / cost-model change), auto-accepts Class 1, opens
   review issues for Class 2 and Class 3.
3. Calibrate ranker weights against observed W1–W3 distributions;
   commit the calibration audit under `docs/rules/ranker-calibration-
   W4.md`.
4. Close the review ledger: every accepted and rejected rule across
   W1–W3 has its markdown + audit-log entry.
5. Author `docs/tranches/BB/FINAL.md` with the accepted-rule count per
   grammar, codegen shrink per grammar, bench deltas, reversals, and
   any routed follow-on work.

## Phase sub-items

### BB.W4.1 — Cost-model integration verification

Re-emit every production grammar's `generated.rs`; confirm the CSP
solver consumes the accepted-rule cost deltas; measure end-to-end
bench delta vs AZ close.

Sub-gate: at least one grammar shows a measurable throughput gain on
the 17-entry matrix; no grammar regresses.

### BB.W4.2 — CI auto-accept job

A scheduled + change-triggered CI workflow runs the enumerator on every
grammar, auto-accepts Class 1, and opens labelled review issues for
Class 2 and Class 3 with the per-rule markdown pre-filled.

Sub-gate: CI job lands and runs green on the first schedule tick;
issue templates render with the correct rule markdown.

### BB.W4.3 — Ranker calibration audit

Inspect W1–W3 tier-distribution data; if Class 3 share exceeded 10%
at any wave, adjust the similarity / novelty weights and re-tier the
existing backlog to confirm the target distribution holds. Calibration
decisions and rationale committed.

Sub-gate: `docs/rules/ranker-calibration-W4.md` lands; ≥ 90% of
aggregated W1–W3 accepts land in Class 1 + 2 after calibration.

### BB.W4.4 — Review ledger close + FINAL.md

Every accepted and rejected rule across W1–W3 has its markdown.
`FINAL.md` records per-grammar counts, shrink, bench deltas, any
reversals taken mid-tranche, the calibration outcome, and any routed
follow-on work.

Sub-gate: ledger complete; `FINAL.md` passes documentation review.

## Hard gate

1. `cargo test --workspace --profile ax-iter` green.
2. 17-entry AU-baseline matrix at or above AZ close on every entry; at
   least one entry shows measurable throughput gain.
3. At least one grammar's `generated.rs` shrinks ≥ 10 LOC cumulative
   across BB.
4. CI workflow lands and runs green once.
5. Ranker calibration holds ≥ 90% Class 1 + 2 on the aggregated W1–W3
   backlog.
6. `docs/tranches/BB/FINAL.md` lands with deltas and reversals.
