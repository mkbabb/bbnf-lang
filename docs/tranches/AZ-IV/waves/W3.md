**Status**: planned

## Scope

1. Refresh the post-AZ-IV benchmark matrix under the intended fat-LTO close profile and bench-iter comparison profile.
2. Require active measured rows for `json.data_xl`, `css.tailwind`, and `compile_css_l4`; commented-out or watchdog-only rows cannot close.
3. Add substrate activation counters or logs where benches otherwise hide whether rewrites/CSP/SIMD/regex paths fired.
4. Run workspace health gates with current docs and generated outputs.
5. Close all AZ-III carries or route only named residuals with exact next destination.
6. Prove direct StructDirect document/value/path projection performance, not only parse-only throughput.
7. Compare fat-LTO results row-by-row against post-AU floors and post-AZ same-profile baselines.
8. Produce `FINAL.md` only at close.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- a watchdog row remains, a benchmark row is commented out, or profiling does not isolate a root cause;
- benchmark evidence contradicts parity evidence;
- same-harness sonic-rs projection rows beat bbnf projection rows without a routed root cause;
- post-AU or post-AZ floors fail without a profile-backed disposition;
- generated output drifts after W3 measurement;
- close docs cannot cite resolving artefacts for every MET gate;
- a residual item lacks a named next destination;
- three diagnostic-loop iterations fail to isolate a regression root cause;
- a non-routable carry from `AZ-IV.md` §Non-Routable Carries cannot close in W3 with the evidence available; this is a thesis-invalidating scope reveal and triggers triumvirate review of the AZ-IV thesis itself, not a successor routing (per `audit/HARDENING-2026-05-01-boole.md` Amendment 3).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate. JSONL transcript quiet >15 minutes is an orchestrator-side auto-trigger; record the condition and dispatch time in `PROGRESS.md` alongside the wave's evidence ledger.

## Hard Gate

1. `cargo xtask regen --check` passes after all generated-output commits.
2. `cargo fmt --all -- --check` passes.
3. `cargo clippy --profile ax-iter` passes or records an environmental blocker.
4. Focused and workspace nextest gates pass per current test-tier instructions.
5. Fat-LTO and bench-iter matrices are saved under `docs/benchmarks/AZ-IV/`.
6. `post-AZ-IV.json` includes row-by-row AU floor, post-AZ same-profile deltas, AZ-III bench-iter deltas, status `MEASURED`, and pass/fail.
7. `cargo bench --profile bench -p bbnf --features competitor --bench json_value` or the current equivalent shows every `bbnf_value_*` row at parity-or-better with the paired `sonic_value_*` row, or each miss has a saved profile and named route.
8. `json.data_xl`, `css.tailwind`, and `compile_css_l4` are active measured Divan rows with no watchdog close.
9. Profiles for `data_xl`, `tailwind`, `compile_css_l4`, and every target miss include `profile.json.gz`, `profile.json.syms.json`, `syms-proof.txt`, and a hotspot summary that names the exact function or regex that consumed the watchdog budget. The summary carries either (a) a routed fix landing in W3 commits, or (b) a triumvirate-accepted blocker with profile evidence proving the limit is non-actionable. "Profile saved" without a named consumer is not valid close evidence (per `audit/HARDENING-2026-05-01-boole.md` Amendment 3).
10. IAI baseline/current instruction counts are non-null and compare within the repo's configured threshold, or W3 records why the platform gate could not run.
11. `docs/tranches/AZ-IV/audit/W2-substrate-denominator.md` has no unowned substrate rows.
12. `git diff --check` passes.
13. `FINAL.md` cites commits and artefacts for every gate, miss, deletion, and handoff.
14. **Non-routable carries closure**: every row in `AZ-IV.md` §Non-Routable Carries has a resolving artefact path that proves landed evidence (not "routed forward"). A row that reaches W3 close without resolving evidence triggers a triumvirate thesis review per `ORCHESTRATION.md` §Triumvirate, not a new tranche letter.
15. **Close-honesty checklist**: per `docs/precepts/instructions/tranche/SPEC.md` §Close, the orchestrator runs the checklist before declaring close — every claim grounded in `PROGRESS.md` or a cited artefact, every gate marked MET with a resolving evidence path, every status word matching the latest gate run, every cross-tranche debt entry naming a destination. Mismatches reconcile before close, not after.

Long-running profile commands follow the profiling instructions and do not share target dirs with concurrent cargo. Divan close evidence uses the repo bench profiles and one invocation per target; ad hoc timers, warm-only measurements, hidden threshold edits, and commented-out bench rows are invalid close evidence.
