# AX.W5 — CSS SIMD Levers + ShapeRef at Shape-Emit

**Opens after**: W4 close
**Agents**: 3 parallel (TBL-4 + kind-streams, SIMD-speculative Alt + bloom dedup, ShapeRef at shape-emit)
**Hard gate**: CSS normalize ≥ 0.85× lightningcss single-thread NEON; ShapeRef drops bootstrap record count ≥ 30%; W2 parity still green.

## Scope

1. **TBL-4 kinded bitmap classifier** (Agent 4 novel): `vqtbl4q_u8` with 64-entry LUT produces per-byte kind code in one op. Emitted inline via `simd-scan::emit::tbl4_kinded_scan`. Eliminates walker's post-scan `bytes.get_unchecked(pos)` re-load.
2. **Kind-separated stage-1 position streams** (aw5-n2.3): `StructuralIndexKinds { delim_kinds: [Vec<u32>; K] }`. Per-shape walkers only query their relevant kind. Saves ~4 cyc per per-shape dispatch.
3. **SIMD-speculative Alt-branch prefix-match** (aw5-n2.4): parallel-compare N branch prefixes via `vceqq_u8 × N + OR-reduce + tzcnt` for CSS `compoundSelector` (5-way Unordered). 3-4 cyc vs 5-10 cyc linear try.
4. **Bloom+GADT dedup filter**: `BLOOM_SIGNATURES: &'static [u64; 4]` per grammar pre-filters `SHAPE_DICT.lookup` (~3 cyc vs 8 cyc hash+probe).
5. **L3 ShapeRef consumer at shape-emit** (Agent 5 relocation of #23): `shapes/{object,array}.rs` compute shape hash at compound-emit and on `SHAPE_DICT` match emit `TapeKind::ShapeRef { dict_idx }` instead of fresh compound. **Shape hash is CONST at codegen time — the prior runtime-hash failure mode does not apply.**

## Phase sub-items

### W5.1 TBL-4 kinded bitmap

`vqtbl4q_u8` 64-entry LUT. Firestorm L=6 rtp=1.0; 4 stripes = 6 cyc critical. Emitted inline via `simd-scan::emit::tbl4_kinded_scan`. Wire-contract: walker byte-load at post-scan `*bytes.get_unchecked(pos)` in compaction.rs:41 eliminates.

### W5.2 Kind-separated stage-1 streams

Replace unified `StructuralIndex` with per-kind `Vec<u32>` streams. IR mining in `stage1_kinds.rs` produces per-grammar `STAGE1_KIND_STREAMS` registry. Per-shape walker consumes only relevant kinds.

### W5.3 SIMD-speculative Alt for Unordered

CSS compoundSelector (5-way): parallel-compare via `vceqq_u8 × 5 + OR-reduce + tzcnt`. Replaces linear try. Applies to any Unordered rule where FIRST-sets admit SIMD compare (≤ 16-byte prefix overlap).

### W5.4 Bloom+GADT dedup

Bloom filter on compound fingerprint: `BLOOM_SIGNATURES: &'static [u64; 4]` emitted per grammar. `shapes/object.rs` + `shapes/array.rs` check bloom before `SHAPE_DICT.lookup` — hit rate ≥ 99% on non-dedup workloads (filter is miss).

### W5.5 ShapeRef at shape-emit (L3)

**Critical distinction from prior ShapeRef attempts**: shape hash is CONST at codegen (emitter knows the shape template). No runtime hashing. Mechanism:

```rust
// In shapes/object.rs compound-emit arm:
const SHAPE_HASH_OBJECT_RULE_N: u64 = <const-evaluated-at-codegen>;
if let Some(dict_idx) = SHAPE_DICT.lookup_const::<SHAPE_HASH_OBJECT_RULE_N>() {
    builder.push_shape_ref(dict_idx);  // ONE record
    return Ok(());
}
// else fallthrough to fresh compound
```

CSS bootstrap: `ws:ws` repeats 43×, `!important` 42×. Record count drops ≥ 30%.
