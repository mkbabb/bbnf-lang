# AZ.W2 — Snapshot + Resume

**Opens after**: W1 close
**Agents**: 2 parallel
**Hard gate**: `parse_resume_<grammar>` entrypoints reproduce cold-parse suffix results from stable shape boundaries on canonical fixtures.

## Scope

1. Capture resumable parser and substrate state at stable shape
   boundaries.
2. Emit resume entrypoints that re-enter the same parser and substrate
   contract.
3. Prove suffix identity between cold parse and resumed parse.

## File bounds

| File | Access |
|---|---|
| `crates/core/src/runtime/snapshot.rs` | create |
| `crates/core/src/runtime/parsed.rs` | modify |
| `crates/core/src/backend/rust/emitter/grammar.rs` | modify |
| `crates/core/tests/resume_suffix_identity.rs` | create |

**Do NOT touch**: incremental edit localization, recovery heuristics, build/profile tooling, any `.bbnf` grammar.

## Phase sub-items

### AZ.W2.1 Snapshot representation

Mechanism: define a snapshot format that captures stable parser and
substrate state only at admitted shape boundaries.

Files touched: `crates/core/src/runtime/snapshot.rs`,
`crates/core/src/runtime/parsed.rs`.

Sub-gate: snapshots can be created from cold parses on corpus fixtures.

### AZ.W2.2 Resume entrypoints

Mechanism: emit `parse_resume_<grammar>` entrypoints that resume from a
snapshot through the same grammar-derived parser path.

Files touched: `crates/core/src/backend/rust/emitter/grammar.rs`,
`crates/core/src/runtime/parsed.rs`.

Sub-gate: `cargo expand -p bbnf --bench json_monolithic` shows resume
entrypoints emitted from the grammar-derived path.

### AZ.W2.3 Suffix identity tests

Mechanism: compare resumed suffix results against cold parse suffixes on
canonical fixtures and admitted snapshot points.

Files touched: `crates/core/tests/resume_suffix_identity.rs`,
`crates/core/src/runtime/snapshot.rs`.

Sub-gate: suffix identity tests pass.

## Hard gate

1. `cargo expand -p bbnf --bench json_monolithic` shows
   `parse_resume_<grammar>` emission. Artefact:
   `docs/benchmarks/post-AZ-W2-expand.txt`.
2. `cargo test -p bbnf --test resume_suffix_identity --profile ax-iter`
   passes. Artefact: `docs/benchmarks/post-AZ-W2-resume.txt`.
3. Feature-off regression versus AY close remains `<= 4%` on the eager
   JSON 5-fixture geomean. Artefact:
   `docs/benchmarks/post-AZ-W2-mid.json`.
