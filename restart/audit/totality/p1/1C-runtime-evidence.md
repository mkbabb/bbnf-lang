# Executive Summary

The skinny runtime now contains real generated runtime modules under
`skinny/crates/runtime/src/grammars/<g>/`: JSON has an 8-file generated
runtime roster plus three hand-owned companions, and seven CSS L4 profiles
each have a 5-file generated fact-stream runtime. The runtime root wires those
profiles by grammar name (`skinny/crates/runtime/src/lib.rs:3`-`25`) and
reexports them through `grammars` aliases (`skinny/crates/runtime/src/lib.rs:35`-`43`),
so Lock 14 is only partially satisfied: generated output exists, but generic
runtime/codegen code still knows the concrete grammar roster. JSON has two
landed consumers: retained offset-tape parsing through `TapeBuilder` and
`JsonRoot::from_tape` (`skinny/crates/runtime/src/grammars/json/parser.rs:7`-`30`),
and generated `SinkOnly` direct parsing through `parse_direct` plus `JsonSink`
(`skinny/crates/runtime/src/grammars/json/generated.rs:746`-`764`,
`skinny/crates/runtime/src/grammars/json/sink.rs:1`-`4`). CSS L4 does not emit
`SinkOnly`/`OffsetTape`/`EventTape`; it emits admitted fact streams labelled
`admitted_fact_output` (`skinny/crates/runtime/src/grammars/css_l4_declaration_values/config.rs:2`-`9`).
`EventTape` remains design/selection state plus proof witnesses, not an emitted
runtime consumer. Pattern H remains explicitly 67 in the main workspace: 67
hand-written runtime files, zero generated headers, across nine per-grammar
dirs (`restart/ARCHITECTURE.md:1800`-`1824`, `restart/locks/LOCKS.md:402`-`420`).
