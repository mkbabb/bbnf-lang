# BA.W2 - Direct-Projection Codegen

**Name**: W2 - Direct-Projection Codegen
**Opens after**: W1 - Inverse-Layout-Audit IR Pass
**Agents**: 6 parallel (max under the orchestration ceiling)
**Hard gate**: per-grammar `<Grammar>Document` typed struct + `<Grammar>Value` typed enum emitted from `StructRegistry`; `arena_template` + `builder_template` retired from value-API hot path; AU floor 18/19 BELOW closes; `compound_kind_for_layout` runtime resolution removed
**Status**: planned

## Scope

This wave lands the direct-projection emitter. The emitter generates per-grammar `<Grammar>Document` typed struct + `<Grammar>Value` typed enum from `StructRegistry`; parse fns write directly to typed fields; `compound_kind_for_layout` runtime resolution is replaced by codegen-time const projection. The arena/builder templates retire from the value-API hot path. `JsonValue`, `CssTypedValue`, `SheetsValue`, `BbnfValue` become *generated* artefacts (the hand-curated facade type survives only as a re-export for back-compat at most one wave).

1. Define `crates/core/src/backend/rust/emitter/document.rs`: emits `<Grammar>Document<'p>` struct from `StructRegistry`. Each Named compound rule becomes a typed field/struct/enum branch. The emitter consumes the `StructRegistry` populated by `populate_struct_registry` and the W1 `inverse_layout_audit` pass's invariant (every compound-typed rule has a layout).
2. Define `crates/core/src/backend/rust/emitter/value_enum.rs`: emits `<Grammar>Value<'p>` enum. Each variant is a typed projection (`JsonValue::String(&'p str)`, `JsonValue::Object(JsonObject<'p>)`, etc.). The emitter is grammar-general; the same template handles JSON, CSS L4, Sheets, BBNF, and the smaller grammars.
3. Modify `crates/core/src/backend/rust/emitter/shapes/**` to consume the new emitter modules. Replace runtime `__layout: StructLayout { ... }` literals at parse-fn entry with codegen-emitted typed projections. Replace `OpenFrame::from_layout(layout, &registry)` with `OpenFrame::for_rule::<RULE_KIND>()` const dispatch.
4. Regenerate `crates/core/src/grammar/generated/{json,css_l4,sheets,bbnf,bnf,csv,ebnf,math,css_pretty}/**` using the new emitter. Verify per-grammar `<Grammar>Document` and `<Grammar>Value` are produced.
5. Delete `crates/core/src/runtime/{arena_template,builder_template}.rs` and the per-grammar `{arena,builder}.rs` files where direct-projection subsumes them. The hand-curated `JsonValue`, `CssTypedValue`, `SheetsValue`, `BbnfValue` survive as *facade re-exports* at the top of `runtime/{json,css_l4,sheets,bbnf}/value.rs` for one wave (W3 retires them once the rename is verified).
6. Update parity tests: `JsonValue::Object` (from generated) must equal `JsonValue::Object` (from facade) on the parity corpus. The migration is mechanical — the generated type IS the source of truth; the facade is the back-compat alias.
7. Close the AU floor 18/19 BELOW status: the row that was BELOW (specifically the JSON value-API rows that paid the runtime registry resolution per leaf) must reach AT-or-ABOVE on `docs/benchmarks/post-BA.json`. AF MASKED-DEFERRAL closes here.
8. Address the 14 substrates from W0.2 that "disappear by mechanism under direct-projection": verify each is gone after the regenerate; update `crates/ir/tests/substrate_audit.rs` whitelist.
9. F4 Tailwind regex_scan: profile under direct-projection. If the per-call layout-construction overhead is removed by mechanism, F4 closes here. If not, F4 routes to BB rule-discovery as a path-shape rewrite candidate (named decision in W2 close commit body).

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the emitter cannot produce a typed struct/enum for one of the 9 grammars (e.g., a `->`-less Alt produces an `HeterogeneousAltJoin` whose branches resist tagging — a sign the W1 audit pass missed a case);
- the regenerated generated outputs introduce more than three new compile errors across the workspace (scope reveal beyond W2's named bounds; the emitter design needs amendment);
- `arena_template` + `builder_template` deletion breaks an unwritten dependency in a smaller grammar (e.g., CSV or Math); the wave halts and dispatches a triumvirate to decide whether the smaller grammar gets its own direct-projection emit or routes to W3 separately;
- the AU floor row that should close stays BELOW after direct-projection lands — the perf miss is not local-edit-recoverable;
- F4 Tailwind regex_scan does not resolve under direct-projection AND the routing to BB rule-discovery cannot be made without changing BB.W1 file bounds (cross-letter scope reveal);
- three diagnostic-loop iterations fail to isolate why a generated `<Grammar>Document` does not compile;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.

## Agent Units

### BA.W2.1 Document Emitter

- Mechanism: emit `<Grammar>Document<'p>` struct. The emitter walks `StructRegistry` and produces a typed Rust struct per Named compound rule. Each field's type comes from the rule's `TypeDesc`: `Tuple([T1, T2, ...])` → `(T1, T2, ...)` or a generated struct; `Vec(inner)` → `Vec<inner>`; `Option(inner)` → `Option<inner>`; `HeterogeneousAltJoin([T1, T2, ...])` → a generated `enum`. The struct holds `'p` lifetime over input bytes for zero-copy leaf payloads. `compound_kind_for_layout` runtime resolution becomes `OpenFrame::for_rule::<RULE_KIND>()` const dispatch.
- Files: `crates/core/src/backend/rust/emitter/document.rs`, `crates/core/src/backend/rust/emitter/mod.rs` (register).
- Sub-gate: emitter compiles cleanly; running it against JSON produces a `JsonDocument<'p>` whose fields match the JSON grammar's Named compound rules; running against CSS L4 produces `CssL4Document<'p>` covering rules / declarations / values; named test in `crates/core/tests/document_emit_smoke.rs` verifies the emit on a synthetic grammar.

### BA.W2.2 Value-Enum Emitter

- Mechanism: emit `<Grammar>Value<'p>` enum. The emitter produces a typed enum whose variants project the grammar's `HeterogeneousAltJoin` shapes. JSON produces `JsonValue::{String, Number, Object, Array, Null, Bool}` with payloads typed via the rule's `TypeDesc`. CSS L4 produces `CssTypedValue::{Color, Length, Selector, ...}`. The emitter is grammar-general; smaller grammars (BNF, CSV, Math) get the same shape with their own variants.
- Files: `crates/core/src/backend/rust/emitter/value_enum.rs`, `crates/core/src/backend/rust/emitter/mod.rs` (register).
- Sub-gate: emitter compiles; named test verifies that `JsonValue` from the emitter is byte-equal to the hand-curated `JsonValue` (the W1.A/B revert-restored one) on the parity corpus; `cargo nextest run --test value_enum_emit_smoke` GREEN.

### BA.W2.3 Shapes Integration

- Mechanism: modify `crates/core/src/backend/rust/emitter/shapes/**` to consume W2.1 + W2.2's emitters. Replace runtime `__layout: StructLayout { ... }` literals at parse-fn entry. Replace `OpenFrame::from_layout(layout, &registry)` with `OpenFrame::for_rule::<RULE_KIND>()`. Update `compound_kind_for_layout` calls to const projections. Verify all 9 shape modules (struct, alt, repeat, optional, sum, etc.) consume the new emitters cleanly.
- Files: `crates/core/src/backend/rust/emitter/shapes/**`.
- Sub-gate: `cargo build` compiles cleanly; `cargo xtask regen --check` produces fresh outputs (the regen artefact is W2.4); the regenerated outputs do not contain `__layout: StructLayout {` literals at parse-fn entry.
