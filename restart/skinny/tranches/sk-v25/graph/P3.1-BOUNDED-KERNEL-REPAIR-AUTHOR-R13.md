## Implemented bounded repair

### T1 — one sealed measurement plan, no replay authority

`GraphJsonPreflight` now seals five private scalar facts from the existing
preflight traversal:

```text
S = exact checked serializer-callback traversal work
R = total raw serialized string/byte source length
P = total raw length of percent-bearing dynamic strings
M = maximum dynamic Identity string length
J = exact compact serialized JSON length
```

`S` deliberately differs from the existing weighted P/dry structural
admission. The weighted ledger pays conservative serializer construction and
output roles. `S` counts actual scalar, string, byte, container, compound
field/element, end, and newtype callbacks and is the term proved by the R12
comparison/privacy algebra. Keeping the two meanings distinct fixed the
initial diagnostic contradiction without weakening either bound.

`M` is likewise grammar-scoped, not graph-wide: an `Identity` has at most two
dynamic strings, so only node identities and edge endpoints contribute. The
preflight fails closed if that sealed type-shape premise changes. Payload
strings cannot inflate a comparator bound for a comparator that never reads
them.

The bounded canonical validator consumes the already-sealed `J`; it no longer
rescans the graph to rediscover serialized width. The privacy-only walker calls
its observer without `inspect_json_string`, eliminating its redundant width
scan while retaining the no-percent scan and portability DFA. Exact dry/hash
paths keep their required width inspection unchanged.

The admitted canonical/privacy charge is the checked R12 formula:

```text
C = 4S + 5R + 3J + D + 16T
```

where `T` is truth-row count and `D=percent_decode_work_bound(P)`. The charged
roles remain explicit: one graph writer; two stable edge writers over disjoint
graph subobjects; one privacy traversal with raw and decoded work; and fixed
semantic visits. The implementation enforces that the actual canonical writer
length equals sealed `J`.

No public token, cache, refund, replay representation, fallback, second
budget, or dual path was added. Public and test-only independent size limits
retain their own bounded measurement; only the private canonical path can
reuse its private sealed `J`.
