AZ-IV.W0.5 — Metadata Gate evidence
====================================

Scope
-----

1. Manifest metadata fail-closed: an unknown `features = [..]` entry on
   `[workspace.metadata.bbnf.grammars.<ident>]` aborts the manifest read
   with a structured error.
2. Staged regen trigger covers `Cargo.toml` metadata edits: the
   pre-commit hook (`cargo xtask regen --check --staged`) runs the
   unfiltered check loop when the `[workspace.metadata.bbnf]` subtree
   differs between staged and HEAD.
3. Full regen remains a CI blocker.
4. Focused test for the unknown-feature failure path.

Failure-path assertion (`unknown_feature_is_rejected_with_structured_error`):
  - synthetic manifest names `features = ["pretify"]` on grammar `json`;
  - `validate_grammar_features` returns Err;
  - error message contains `pretify`, `grammar `json``, the table

    `KNOWN_FEATURES` (structural, prettify, skip_recover, serialize,
    remove_left_recursion, debug).

Staged-trigger mechanism
------------------------

`xtask::regen::cargo_toml_diff_touches_grammar_metadata`:
  1. `git show :Cargo.toml`     — staged blob.
  2. `git show HEAD:Cargo.toml` — committed blob (empty on initial
     commit / orphan worktree).
  3. parse both as TOML, project the `workspace.metadata.bbnf` subtree.
  4. re-serialise each subtree; compare. Diverging subtree returns
     true and forces the unfiltered `regen_check_filtered` loop;
     equal subtrees fall through to the existing per-grammar staged
     filter so unrelated Cargo.toml edits (profile tweaks, dep bumps,
     workspace member churn) keep the cheap fast-path.

Pre-commit hook reads:
  `cargo xtask regen --check --staged`
which routes through this helper for every commit that stages
Cargo.toml.

CI runs `cargo xtask regen --check` (no `--staged`), so:
  - `load_manifest()` runs the eager `validate_grammar_features` over
    the entire workspace manifest;
  - any unknown feature anywhere in the manifest fails CI;
  - the regen drift loop runs against every grammar regardless of
    staged-file overlap.
