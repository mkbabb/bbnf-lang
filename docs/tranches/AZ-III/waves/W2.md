# AZ-III.W2 - Semantic Parity and Bootstrap Canonicalization

**Name**: W2 - Semantic Parity and Bootstrap Canonicalization
**Opens after**: W0p - Throughput Substrate, W1 - O5 Reclose.
**Agents**: up to 6 parallel.
**Hard gate**: JSON sonic-rs, CSS lightningcss, Sheets, and BBNF semantic parity are green on the struct-only path, and generated BBNF self-hosting is canonical or blocks close.
**Status**: planned

## Scope

1. Run and repair JSON parity against sonic-rs without tape adapters.
2. Run and repair CSS parity against lightningcss, including color,
   selector, bootstrap, and tailwind admission gaps.
3. Run and repair Sheets semantic parity and serializer/range gaps.
4. Prove BBNF generated self-hosting is the canonical parse path. If that
   cannot close inside W2 - Semantic Parity and Bootstrap Canonicalization,
   W2 closes blocked and opens a same-tranche redress wave; it does not
   retain a silent bootstrap fallback.
5. Convert ignored semantic tests into passing tests or named blockers.

## Agent Units

### AZ-III.W2.1 JSON Parity

- Mechanism: run sonic-rs and canonical/value parity suites; repair
  materialization defects at root.
- Files: JSON tests and shared materialization only if proven root.
- Sub-gate: focused JSON parity suites pass.

### AZ-III.W2.2 CSS Parity

- Mechanism: run lightningcss parity on normalize, colors, bootstrap,
  and tailwind; repair grammar/type/projection causes.
- Files: CSS tests, grammar, shared projection/type code as needed.
- Sub-gate: lightningcss parity passes or W2 - Semantic Parity and
  Bootstrap Canonicalization remains blocked with an exact source owner.

### AZ-III.W2.3 Sheets Parity

- Mechanism: run Sheets self/parity suites; repair mapped branch,
  range, and serializer defects at shared lowering/projection points.
- Files: Sheets tests and shared lowering/projection only as needed.
- Sub-gate: Sheets parity suites pass.

### AZ-III.W2.4 BBNF Bootstrap Canonical Path

- Mechanism: replace canonical `bootstrap_parser` routing with generated
  self-host parse. W2.4 closes ONLY when (a) the generated BBNF
  self-host parses canonically without `bootstrap_parser.rs` routing, OR
  (b) `bootstrap_parser.rs` is named in a same-tranche removal commit
  with a route to W5 close. There is no "deferred to BA" or "future
  tranche" close path.
- Files: BBNF grammar/parser/pipeline entry points,
  `crates/core/src/grammar/bootstrap_parser.rs`,
  `crates/core/src/grammar/mod.rs`.
- Sub-gate: either the generated self-host parse passes canonical
  fixtures with `bootstrap_parser.rs` removed, or the same-tranche
  removal commit lands with a routed close commit. Any retention of
  `bootstrap_parser.rs` as a closure path leaves W2.4 blocked.

## Triumvirate Dispatch

If a parity failure reveals unclear grammar/type/projection ownership,
external-library semantic mismatch, or a bootstrap routing choice, pause the
affected lane and dispatch research, plan augment/synthesis, and
redress/redeployment agents. Their synthesis either amends W2 - Semantic
Parity and Bootstrap Canonicalization with a same-wave implementation plan
or creates a same-tranche replacement wave before further implementation.
HARD CAP for any redress dispatch under W2 - Semantic Parity and Bootstrap
Canonicalization: 30 min. Research and plan augment dispatch defaults
follow `precepts/instructions/tranche/AGENT_DISPATCH_TEMPLATE.md`
(research=20, plan=15, audit=25).

## Hard Gate

1. `cargo test -p bbnf sonic_rs_parity --profile ax-iter` output is
   archived and exits green on the struct-only path.
2. `cargo test -p bbnf lightningcss_parity --profile ax-iter` plus the
   focused `css_l4_*` parity commands are archived and green.
3. Focused Sheets parity commands over `sheets_*` tests are archived and
   green.
4. `cargo test -p bbnf bbnf_ --profile ax-iter` or the narrower BBNF
   bootstrap proof command is archived and proves generated self-hosting
   is canonical.
5. `rg -n "return Ok\\(|#\\[ignore\\]|bootstrap_parser"` over parity
   tests and grammar routing is archived; any active masking or
   fallback keeps W2 - Semantic Parity and Bootstrap Canonicalization
   blocked.
6. W2.4 closes ONLY by canonical self-host (a) or same-tranche removal
   commit for `bootstrap_parser.rs` (b); deferral to BA, BB, or any
   future tranche letter is forbidden as a closure path.

## Format And Lint Cadence

`git diff --check` after each accepted integration batch. Run
`cargo xtask regen --check` whenever grammar, emitter, or generated parser
files change, and again before W2 - Semantic Parity and Bootstrap
Canonicalization closes. Before close, rerun `cargo fmt --all -- --check`
and `git diff --check`.
