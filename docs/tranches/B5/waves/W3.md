## Meta

## Scope

`feedback_no_god_modules` is non-negotiable: every level of the
hierarchy (crate, module, file) separates concerns. The post-B4
substrate carries six files exceeding natural responsibility
boundaries:

| File | LOC | Why a god module |
|------|----:|------------------|
| `crates/core/src/lower/expression.rs` | 2140 | Carries Alt lowering, Repeat lowering, Pratt operator-precedence climbing, wrap/closure handling — four families in one file. |
| `crates/core/src/backend/rust/emitter/shapes/dispatcher.rs` | 1969 | Cross-shape dispatch + symbol composition + support helpers — three orthogonal concerns. |
| `crates/core/src/backend/rust/emitter/shapes/inline.rs` | 1687 | Inline-shape emission across multiple inline-shape variants. |
| `crates/core/src/backend/rust/emitter/shapes/flat.rs` | 1342 | Flat-shape emission across multiple flat-shape variants. |
| `crates/tape/src/columns.rs` | 1287 | Substrate fields + reducer methods + SIMD module body, three concerns in one file. |
| `crates/core/src/backend/rust/emitter/grammar.rs` | 1286 | Audit candidate; split iff natural boundary < 800 LOC after. |

Per `feedback_directory_modules`, splits land as **directory
modules** (`expression/{...}.rs`), not flat siblings
(`expression_alt.rs`). Per `feedback_no_god_modules`, no
`helpers.rs` / `utils.rs` / `common.rs` kitchen sinks anywhere
in the resulting splits — those names indicate the split
re-encoded the smell.

### Part 1 — `lower/expression.rs` → `lower/expression/`

The 2140-line file partitions naturally into five sub-modules
plus a `mod.rs` that wires them:

```
crates/core/src/lower/expression/
├── mod.rs       — entry points, dispatch, shared types
├── alt.rs       — Alt lowering (lower_alt, lower_alt_branch, related)
├── repeat.rs    — Repeat lowering (lower_repeat, separator/min/max)
├── pratt.rs     — Pratt operator-precedence climbing
├── wrap.rs      — wrap, transparent, structural-wrapper handling
└── closures.rs  — closure / GrammarCall lowering
```

Each sub-module owns the construct family in its name. Shared
helpers (e.g. type-projection lookups used by more than one
family) live in `mod.rs`; if a helper is used by exactly one
family, it lives in that family's module.

LOC accounting: ~2140 redistributed; no file exceeds 800 LOC
after the split (target ~400-500 per family file).

### Part 2 — `shapes/dispatcher.rs` → `shapes/dispatcher/`

The 1969-line file splits along the audit's three concerns:

```
crates/core/src/backend/rust/emitter/shapes/dispatcher/
├── mod.rs                — entry points, dispatch
├── cross_shape.rs        — cross-shape dispatch logic
├── symbol_composition.rs — symbol composition for compounds
└── support.rs            — receivers, accessors, name-mapping
```

`support.rs` is the borderline case — it must not become a
kitchen sink. If during the split a function does not fit
naturally into `cross_shape` or `symbol_composition` and is not
trivially-shared infrastructure, it indicates a fourth concern;
add a fourth file rather than dumping it into `support.rs`.

### Part 3 — `shapes/inline.rs` and `shapes/flat.rs` directory splits

Each splits along its inline-shape / flat-shape variant
families. The exact partition depends on the variants present;
the audit indicates 3-4 natural sub-modules per file. Target
each sub-module ≤ 500 LOC.

```
crates/core/src/backend/rust/emitter/shapes/inline/
├── mod.rs
└── <one file per inline-shape family>

crates/core/src/backend/rust/emitter/shapes/flat/
├── mod.rs
└── <one file per flat-shape family>
```

The agent identifies the natural partition by reading the file's
internal structure: each sub-module owns one inline-shape (or
flat-shape) variant's emission logic.

### Part 4 — Hoist SIMD module out of `columns.rs`

`crates/tape/src/columns.rs` lines 1169+ hold an inline `simd`
module — substrate-orthogonal SIMD reducer/scanner code mixed
into the substrate definition. Move it to a directory module:

```
crates/tape/src/simd/
├── mod.rs
└── <files mirroring the existing module's internal structure>
```

Or, if the SIMD code is naturally one unit, `crates/tape/src/simd.rs`
as a flat sibling (still a separate file, not embedded in
`columns.rs`). The latter is acceptable iff the SIMD module
fits in one file ≤ 800 LOC.

### Part 5 — Audit `schema/emit/rust.rs` and `emitter/grammar.rs`

Both ~1286 LOC. The audit conditional: split iff a natural
partition produces sub-files all < 800 LOC. If the natural
partition has no sub-file < 800 LOC, the split is forced and
will introduce kitchen-sink modules; in that case, defer the
split to a future tranche and document the decision in
`PROGRESS.md`. The deferral applies only to these two files;
parts 1-4 are mandatory.

The bias is to split. Defer only if the agent can name the
natural partition and demonstrate every candidate sub-file
exceeds 800 LOC.

### Part 6 — Kitchen-sink rename / fold

Audit `crates/core/src/backend/{wasm,ts}/` and
`crates/ir/src/passes/{types,constraint}/` for any
`helpers.rs` / `utils.rs` / `common.rs` files. For each:

- If the file's contents form a coherent concern, rename to a
  concern-named file (`type_lookup.rs`, `name_mapping.rs`,
  etc.).
- If the file's contents are scattered helpers used by exactly
  one consumer, fold them into the consumer's file.
- If the file's contents are scattered helpers used by multiple
  consumers and don't form a coherent concern, the file's
  existence is the smell; re-distribute the helpers to the
  consumers that use them and delete the kitchen-sink file.

## Archaeology

The six god modules accreted across A* and B* tranches as
features added themselves to the natural locus without anyone
splitting the locus. `expression.rs` started as one file
because Alt lowering came first; Repeat / Pratt / wrap /
closures piled on. `dispatcher.rs` accumulated cross-shape
dispatch as new shape families were added without
ever-asking-for-a-new-file. The SIMD module embedded in
`columns.rs` because adding SIMD reducers to the substrate was
a one-line `mod simd { ... }` cheaper than a directory
restructure.

Each accretion was locally rational. The aggregate is the smell
W3 retires. The split is mechanical: identify the family
boundary, move the file, update imports, run nextest, confirm
no regression. The hard gate's bit-identical bench numbers
enforce the "pure refactor" contract.
