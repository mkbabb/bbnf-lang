# B1.W0 — Substrate Pin + Alias Surface + Nextest Config + Makefile

**Opens after**: tranche open
**Covers**: migration Steps 1-4
**Agents**: 3 parallel (W0.a, W0.b, W0.c) + 1 serial closer (W0.d)
**Total budget**: ~1 hour wall, 3 agent-hours
**Hard gate**: pinned substrate compiles the workspace clean; every cargo alias resolves and exits 0; `iter-check-full` cold wall recorded under the pin; ICE cluster cleared
**Status**: planned

## Scope

1. Pin the Rust nightly so every developer, CI runner, and sibling
   repo compiles against the same substrate — eliminating the 93-ICE
   cluster the meta-audit attributed to ambient nightly drift.
2. Rewrite `.cargo/config.toml` so the alias surface names routine,
   per-exclude fast-path, close-gate, and bench-json paths explicitly
   with one comment block describing the cost model.
3. Rewrite `.config/nextest.toml` so nextest becomes a required
   preflight with 4 profiles (`default`, `ax-iter`, `ci`, `close`)
   and junit emission gated on the `close` profile.
4. Rewrite `Makefile` so every target delegates to a cargo alias or
   a single script; collapse the ~470-line current file to ~150 by
   deleting the GNU-timeout fallback ladder and dead alias families.

## File bounds (disjoint per sub-agent)

Each file is owned by exactly one sub-agent. The shared artefact
`docs/benchmarks/post-B1-W0-proof.txt` is append-only with
per-sub-agent disjoint row prefixes (SPEC §N-agent shared-file
disjoint-hunk exception). No sub-agent writes a row prefix owned by
another.
