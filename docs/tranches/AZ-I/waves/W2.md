# AZ-I.W2 — Direct-to-struct emission (JSON + Sheets)

**Opens after**: AZ-I.W1 close
**Agents**: 2 parallel (JSON, Sheets)
**Hard gate**: JSON + Sheets emit into struct builders only; tape
path severed on these two grammars' hot paths; JSON twitter ≥ 1967
MB/s, canada ≥ 1231, citm ≥ 2438; Sheets parse_simple ≥ 95 MB/s;
sonic-rs + simdjson OnDemand + serde_json parity harnesses green.
**Status**: planned

## Scope

1. Rewire the JSON emission path to write directly into
   `StructRegistry`-backed struct builders. `push_leaf_with_f64`,
   `push_leaf_with_i64`, `push_leaf_with_bool`, `push_leaf_with_span`
   become field writes on the owning JSON struct (`JsonValue`,
   `JsonPair`, `JsonNumber`). `begin_compound` / `end_compound`
   allocate and close the child struct in the arena.
2. Rewire the Sheets emission path similarly: `Cell`, `CellValue`,
   `Formula`, `FormulaExpr`.
3. Sever the tape path on the JSON and Sheets runtime entry points.
   The tape builder is not instantiated for these two grammars'
   parse paths. (The tape crate itself continues to exist and link
   for BBNF's bootstrap.)
4. Rewire view-layer accessors for JSON and Sheets to read struct
   fields directly. `NodeView::<Number>::as_f64()` reads the
   `JsonNumber::Float` variant; Sheet cell accessors read
   `CellValue` directly.
5. Rewire sonic-rs, simdjson OnDemand, and serde_json parity
   harnesses to compare struct-vs-native.
6. Bench delta gate: JSON twitter ≥ 1967, canada ≥ 1231, citm ≥
   2438; Sheets parse_simple ≥ 95 — all on the struct-only path.
   Miss ≥ 20% reverts the wave's substrate.

## Phase sub-items

### AZ-I.W2.1 — JSON emitter rewire

Emission path for `grammar/json/` writes to `JsonValue` /
`JsonPair` / `JsonNumber` struct builders directly. No tape record
is pushed on JSON input. Confirm with grep on the dispatch path.

Sub-gate: `cargo bench -p bbnf-bench --bench json_twitter_cold`
≥ 1967 MB/s; sonic-rs + simdjson parity green.

### AZ-I.W2.2 — Sheets emitter rewire

Emission path for `grammar/sheets/` writes to `Cell` / `CellValue`
/ `Formula` struct builders directly.

Sub-gate: `cargo bench -p bbnf-bench --bench sheets_parse_simple`
≥ 95 MB/s; parity harness green.

### AZ-I.W2.3 — View-layer rewire

`NodeView` accessors for JSON and Sheets read struct fields
directly. Any path that consulted tape offsets is rewritten to
consult struct field indices.

Sub-gate: `rg '\bTapeCursor\b|\bTapeRec\b'
crates/core/src/runtime/{json,sheets}/` → zero matches.

### AZ-I.W2.4 — Parity harness recode

Rewire the sonic-rs, simdjson OnDemand, and serde_json parity
harnesses on the JSON side. Sheets parity rewires its internal
harness.

Sub-gate: all parity harnesses green on the full fixture corpus.
