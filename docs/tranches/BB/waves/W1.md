# BB.W1 - Ruler CVC Enumerator

**Name**: W1 - Ruler CVC Enumerator
**Opens after**: W0 - Substrate Preflight
**Agents**: 5 parallel
**Hard gate**: `crates/egraph/src/ruler/enumerate.rs` produces candidate pairs over `IrNode` alphabet up to bounded size; e-graph residue wrapper begins; Tranche H rediscovery starts (≥ 50% by W1 close, ≥ 80% by W2 close); enumeration ≤ N=50 candidates per pass; node-count ceiling enforced
**Status**: planned

## Scope

1. Implement `crates/egraph/src/ruler/enumerate.rs`: Ruler-style CVC enumeration over `IrNode`. Generate candidate terms over the grammar's alphabet up to bounded size; group them by equivalence under the e-graph (with the W0 base RON rules + cost extractor); extract candidate pairs `(L, R)` as cross-class equivalences.
2. Implement `crates/egraph/src/ruler/residue.rs`: e-graph-first equivalence check. If `L` and `R` are already in the same class under the current rewrite set, the pair is captured and skipped (no oracle call). Otherwise, the residue routes to W2's VM oracle.
3. Begin Tranche H rediscovery: enumerate the alphabet that produces `factor`, `merge_regex_alts`, `inline_acyclic`. Verify the enumerator surfaces these as candidate pairs; the e-graph captures them when the corresponding base RON rules are present.
4. Enforce enumeration discipline: the per-pass candidate budget is N=50. The e-graph node-count ceiling is per-wave (W1 budget: 100k nodes); crossing the ceiling reverts the alphabet at wave close.
5. Per-wave declared candidates: W1 = 20 JSON.
6. The enumerator consumes the W0 cost extractor's path-aware dimension; rules with negative cost delta cannot promote to oracle validation.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the enumerator's candidate budget overflows (more than N=50 candidates per pass; the alphabet narrows before the next pass; if narrowing requires changing W0's `IrNode` alphabet definition, route to triumvirate);
- the e-graph node-count ceiling crosses (100k nodes; the wave halts and reverts the alphabet);
- Tranche H rediscovery shows < 50% match at W1 close (a soundness or coverage gap; root cause must be found before W2 opens);
- a candidate `L=R` is rejected by the e-graph residue check but accepted by a separate hand-trace (the e-graph saturation is incomplete; substrate bug);
- three diagnostic-loop iterations fail to isolate why a known Tranche H rule is not rediscovered;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).
