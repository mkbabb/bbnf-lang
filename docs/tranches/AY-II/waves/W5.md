## Phase sub-items

### AY-II.W1.a — close evidence capture

Mechanism:

1. `make ay-prepare-profile-wave WAVE=II` produces prebuilt
   bench binaries under `profiling-prep` for all 5 bench
   binaries (json_monolithic, css_l4,
   google_sheets_monolithic, bbnf_monolithic,
   compile_pipeline).
2. `make ay-bench-close WAVE=close` runs the full fat-LTO
   matrix. Aggregate into `docs/benchmarks/post-AY-II.json`.
3. `cargo bench --profile bench -p bbnf --bench json_monolithic_value`
   runs the eager-JSON value-bench matrix. Write
   `docs/benchmarks/post-AY-II-eager.json` with the
   bbnf / sonic ratios per fixture.
4. Competitor benches:
   - `cargo bench --profile bench -p bbnf --bench competitors`
     if a unified competitors bench exists, OR
   - separate `json/competitors.rs` + `css/competitors.rs`
     entries. Capture to `post-AY-II-competitors-json.txt` and
     `post-AY-II-competitors-css.txt`. Extract ratios vs each
     competitor per fixture.
5. Samply per grammar under
   `.profiles/samply/AY-II/<grammar_fixture>/`:
   - `json_twitter` (eager value)
   - `css_tailwind`
   - `sheets_stress`
   - `bbnf_self`
   Summary to `post-AY-II-samply-summary.txt` (top-5 self-time
   per profile).
6. `cargo asm -p bbnf <unified-compound-close-symbol>` + any
   other critical fused-pipeline symbol. Capture to
   `post-AY-II-close-bench.txt`'s asm appendix.
7. Compute cycles/byte per fixture under the host clock rate
   assumption documented in AUDIT-D. Write
   `post-AY-II-cycles-per-byte.txt` comparing AY-I / AY-II /
   competitor / AU-era trajectory.

Sub-gate:
- Every artefact above exists with non-empty content.

- Competitor bench files cite at least 2 external references
  per grammar family (sonic + simd-json for JSON;
  lightningcss + cssparser for CSS).

## Archaeology

- AY-I.W8 was the planned close wave (superseded by AY-II.W1).
  Its gate targets carry forward on the JSON eager lane; AY-II
  extends them with CSS typed-semantic-parity + peer competitor
  gates + per-grammar samply coverage.
- AUDIT-D §2 measured `bbnf_visitor_*` geomean at 0.99× sonic
  on a standalone visitor-lane entry point. AY-II.W0' (per
  AUDIT-C Path B) collapses TapeBuilder + ValueBuilder into
  `FusedBuilder<R>`, so the fused parse IS the visitor lane —
  the standalone `parse_with_visitor` emission retires in
  W0'.a. W1 verifies `Parsed::to_value()` delivers the same
  ceiling on the `_value_` lane that the visitor lane measured
  pre-collapse.
- The W5.a / W5.b / W6.b / W6.c experiments were retired
  architecturally at W0. W1's close matrix is the truth-check
  against external peers that AY-I did not capture.
