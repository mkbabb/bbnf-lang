## §1 Deliverable

W5 lands two complementary surfaces: the path-API (sonic-rs isomorphic) and the visitor-API (lightning-css isomorphic). Both are user-facing surfaces that consume the typed values from BB.W4's three parse surfaces.

The path-API at `crates/path/`: per Lock 7 (`docs/HARDENING-PLAN-PROMPT.md:46`), `crates/path/` is the consolidated path crate (renamed from `crates/bbnf-path/` at BA.W3 per `docs/tranches/BA/BA.md:33`). The `pointer!["a","b",1]` proc-macro takes a heterogeneous sequence of `&str` keys + `usize` indices and lifts to a `TypedPath<G, T>` at Rust compile time. The macro emits `compile_path` resolving against the per-grammar `pub const REGISTRY: StructRegistry` (per the BA.W3 T4 closure per `audit/CENSUS-2026-05-03.md:147-148`); the lex/lower/validate body lives in `crates/path-core/` (BA→BB.C4 carry).

Runtime evaluation produces `LazyValue<'a>` (sonic-rs surface per `audit/SOTA-2026-05-03.md:33-42`):

```rust
let path = pointer!["a", "b", 1];
let v: LazyValue<'_> = JsonValue::pointer(input, &path)?;
let s: &str = v.as_str()?;
let i: i64 = v.as_i64()?;
```

`LazyValue` is "a wrapper of a raw valid JSON slice" per `audit/SOTA-2026-05-03.md:40`; conversion happens at `.as_str()` / `.as_i64()` / `.as_<T>()` time. The borrow lifetime ties to input; `LazyValue::owned()` clones for owned scope.

The visitor-API: per Lock 9 + sonic-class API anchor + lightning-css `Visitor` trait (`audit/SOTA-2026-05-03.md:104-118`), each grammar exposes a `Visitor<'i, T>` trait + `VisitTypes` bitflag bitmask. CSS L4 exposes `visit_color`, `visit_length`, `visit_url`, `visit_property`; JSON exposes `visit_string`, `visit_number`, `visit_object`, `visit_array`. The `VisitTypes` bitflag prunes subtree traversal whose `CHILD_TYPES` does not intersect the visitor's interests — depth-first, conditional traversal — name-driven, mechanical.

The visitor signature shape:

```rust
pub trait Visitor<'i, T: Visit<'i>> {
    type Error;
    fn visit_types(&self) -> VisitTypes;
    fn visit_color(&mut self, _: &mut CssColor<'i>) -> Result<(), Self::Error> { Ok(()) }
    fn visit_length(&mut self, _: &mut Length<'i>) -> Result<(), Self::Error> { Ok(()) }
    // ... per-grammar
}

bitflags! {
    pub struct VisitTypes: u32 {
        const COLORS = 1 << 0;
        const LENGTHS = 1 << 1;
        const URLS = 1 << 2;
        const PROPERTIES = 1 << 3;
        // ... per-grammar
    }
}
```

The lightning-css derive macro from `lightningcss-derive::Visit` (`audit/SOTA-2026-05-03.md:101`) auto-implements `Visit` trait + `CHILD_TYPES` bitmask. BBNF's analogue lives in the codegen at `crates/core/src/codegen/visitor.rs`; the per-grammar emit lands at xtask regen time per Lock 6.

The `pointer!` macro friction: per Lane 7 friction-forecast (`docs/HARDENING-PLAN-PROMPT.md:133-139`), the friction at `pointer!["a", "b", 1]` syntax is the heterogeneous parameter list; the cookbook entry at `docs/cookbook/path-macro.md` shows the mental model and example error messages. Verbatim error message: `error: pointer![] segment 2 of type 'usize' indexes into a JSON object whose values are 'JsonObject' — did you mean a string key?`.

Estimated edit surface: `crates/path/src/path_macro.rs` extends to emit the `compile_path` runtime evaluator (~+200 LOC); the per-grammar visitor module emits at xtask regen time (~+150 LOC per grammar, total ~+1,350 LOC across 9 grammars); the cookbook + error messages ~+150 LOC. Per BB.md generated-LOC budget table, the W5 specialised-grammar delta is +5% on CSS L4 (heavy-record visitor); +1-2% on others.

|---|---|---|

The `VisitTypes` bitflag enumeration:

| Bit | Name | Description |
|---|---|---|
| 1 << 0 | RULES | At-rules + style rules |
| 1 << 1 | DECLARATIONS | Property declarations |
| 1 << 2 | SELECTORS | Selector lists |
| 1 << 3 | URLS | URL tokens |
| 1 << 4 | COLORS | Colour values |
| 1 << 5 | LENGTHS | Length values |
| 1 << 6 | ANGLES | Angle values |
| 1 << 7 | RATIOS | Ratio values |
| 1 << 8 | RESOLUTIONS | Resolution values |
| 1 << 9 | TIMES | Time values |
| 1 << 10 | CUSTOM_IDENTS | Custom identifiers |
| 1 << 11 | DASHED_IDENTS | Dashed identifiers (CSS variables) |
| 1 << 12 | VARIABLES | CSS variables |
| 1 << 13 | MEDIA_QUERIES | Media query lists |
| 1 << 14 | SUPPORTS | Supports query lists |
| 1 << 15 | TOKENS | Raw tokens (fallback) |

Per `audit/SOTA-2026-05-03.md:118`, the bitflag pruning is depth-first conditional traversal: name-driven, mechanical, layout-flavoured. The auto-derived `CHILD_TYPES` bitmask per record type lets the framework prune subtree traversal whose intersection with the visitor's interests is empty — e.g., a visitor with only `VisitTypes::COLORS` set skips entire selector subtrees.

| `visit_object` | `&mut JsonObject<'i>` | Object-level transforms |

```rust
// crates/path/src/path_macro.rs (extended at W5)
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, LitInt, LitStr, Token};

#[proc_macro]
pub fn pointer(input: TokenStream) -> TokenStream {
    let segments = parse_macro_input!(input as PathSegments);
    let validated = path_core::validate_against_registry(&segments)?;
    let lowered = path_core::lower(&validated);
    
    let expanded = quote! {
        ::bbnf::path::TypedPath::<G, T>::from_segments(#lowered)
    };
    
    expanded.into()
}
```

```rust
// crates/core/src/runtime/<g>/lazy_value.rs (templated)
pub struct LazyValue<'a> {
    slice: &'a [u8],
    type_tag: ValueType,
}

impl<'a> LazyValue<'a> {
    pub fn as_str(&self) -> Result<&'a str, ParseErr> {
        if self.type_tag != ValueType::String {
            return Err(ParseErr::type_mismatch(self.type_tag, ValueType::String));
        }
        // re-parse the slice (bounded by slice length, not document length)
        std::str::from_utf8(self.slice).map_err(ParseErr::utf8)
    }
    
    pub fn as_i64(&self) -> Result<i64, ParseErr> {
        if self.type_tag != ValueType::Number {
            return Err(ParseErr::type_mismatch(self.type_tag, ValueType::Number));
        }
        // ... lexical-core parse
    }
    
    pub fn as_<T: FromLazyValue<'a>>(&self) -> Result<T, ParseErr> {
        T::from_lazy(self)
    }
}
```
