# AZ-III.W3 - Fact, Type, CSP, and Projection Authority

**Name**: W3 - Fact, Type, CSP, and Projection Authority
**Opens after**: W1, and may run in parallel with W2 after W0 if file bounds are disjoint.
**Agents**: up to 10 parallel.
**Hard gate**: grammar-general semantic facts, type obligations, CSP decisions, and projection emission are durable, consumed by production emitters, and tested against EBNF/CSS/Sheets/BBNF failures.
**Status**: planned

## Scope

1. Persist egraph/node/projection facts as an authority consumed by
   layout, dispatch, type inference, and projection.
2. Replace silent cyclic or heterogeneous `BoxedEnum` fallbacks with
   obligations, explicit ambiguity states, or grammar-general layouts.
3. Install CSP shape/layout/dispatch constraints so `shape_dict` and
   related decisions are not no-ops.
4. Wire authority facts into StructDirect projection/emission, including
   unsupported variants that currently route through dispatcher fallback.
5. Add production consumers and failing-before tests for each substrate.

## Agent Units

### AZ-III.W3.1 Durable Fact Authority

- Mechanism: make recognizer/egraph/projection facts durable enough for
  downstream consumers.
- Files: egraph analysis, grammar facts, recognizer fact producers.
- Sub-gate: one production emitter/layout consumer fails without the fact.

### AZ-III.W3.2 Type Obligation Solver

- Mechanism: replace silent `BoxedEnum` fallback for cycles and
  heterogeneous alternations with obligations and explicit diagnostics.
- Files: type constraint solver and tests.
- Sub-gate: tests cover EBNF/CSS-like heterogeneous alternations and
  recursive rules without silent fallback.

### AZ-III.W3.3 CSP Strategy Globalization

- Mechanism: install and consume shape/layout/dispatch constraints.
- Files: `csp_strategy`, `constraints/shape_dict`, recognizer strategy.
- Sub-gate: emitted decisions cite CSP facts; `shape_dict::install` is
  no longer a no-op.

### AZ-III.W3.4 Projection Consumption

- Mechanism: wire authority into StructDirect projection/emission and
  delete dispatcher fallbacks that mask unsupported variants.
- Files: core Rust emitter and focused generated outputs.
- Sub-gate: EBNF/CSS/Sheets/BBNF projection tests fail without the new
  authority and pass with it.

## Hard Gate

1. Every new authority substrate has a production consumer.
2. Tests fail if facts/CSP/type obligations are disconnected.
3. No silent `BoxedEnum` fallback remains on production close paths.
4. Unsupported StructDirect variants are implemented or named blockers;
   no compatibility shim closes the wave.
