Methodology
-----------

bytes_per_ns derived from data file size / ns_per_iter (cargo bench).
bytes_per_cyc = bytes_per_ns / 3.2 GHz (Apple M-series P-core).
MB/s figures use base-10 (1 MB = 1,000,000 bytes), matching cargo bench convention.

AU reference: post-AU.json (commit 3b8b757d, 2026-04-15).
post-AX-W1 reference: post-AX-W1-close.json (commit 6516086f, 2026-04-20).
Sonic reference (twitter): 2587 MB/s = 0.808 bytes/cyc, derived per AY.md AU
archaeology (post-AU twitter at 0.615 bytes/cyc = 76% of sonic, hence sonic =
0.615 / 0.76 = 0.808 bytes/cyc).

the AU revert was projected to deliver did not materialise on twitter.
