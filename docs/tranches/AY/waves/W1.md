## Scope

1. **Inline `Columns::push_structural`** into per-rule emit call sites (A1/A2/A3 L1). Currently declared `#[inline]` at `crates/tape/src/columns.rs:321` but emitted as cross-crate call boundary in every bench binary. Change to `#[inline(always)]` + verify LLVM inlines at every call site OR refactor into a macro + grammar-emit the expansion.
2. **Fuse `finalise` post-pass into emit path** (A3 L2). `tape::finaliser::finalise` runs a post-parse linear sweep populating `sib_skip` / `child_off` / `span_hi` backlinks. Replace three per-parse `Vec<Option<u32>>` allocations with `[Option<u32>; 32]` stack buffers + fold each of the three post-passes into `close_compound` as back-patch calls. `finalise` becomes no-op (or debug-assertion-only verification pass).
3. **Activate structural-alphabet pre-pass** (A9 Part 1). `GrammarProfile::structural_alphabet` + `structural_digraphs` + `structural_digraph_mask` + `structural_quote_classes` are emitted per grammar but have zero runtime consumers. Emit `scan_structural(input, &alphabet)` at every `<Parser>::parse` entry; feed result into `ScanState` so (a) CTNS-admitted regex patterns jump via `idx.positions[slot]` instead of byte-by-byte DFA walks, (b) `skip_space` reads from the index when whitespace is in the alphabet. Index allocation reuses the tape's arena pages. Must land AFTER push_structural inline for mi_heap sharing (per A9 §b).
4. **Pratt Option C incremental** (A9 Part 2). Preserve reducer-compound tape (Option B flat-tape regressed CSS+Sheets per W0a.2.k). Inline `push_leaf_with_arena_payload` per call site; hoist op_stack capacity from the mined per-rule chain-depth (`operator_chain.rs` miner data); write op_discriminant directly to payload column, drop the `arena_mut().push` round-trip. Zero consumer changes, zero invariant exposure. Folds under push_structural inline umbrella.
5. **Verify universal hot-path collapse via `nm` + samply** post-wave. Symbols must shift from `tape` crate cross-crate exports into per-rule `parse_<shape>_<grammar>_<rule>` frames (invariant 22).

### AY.W1.2 finalise fusion (agent B)

Mechanism:
- Identify three data dependencies `finalise` resolves: `sib_skip` (parent→first-sibling-of-next-open), `child_off` (parent→first-child-offset), `span_hi` (parent→last-child-end-span).
- Add back-patch helpers on `TapeBuilder` + `Columns` that stamp these at `close_compound(open_idx, close_idx)` time rather than post-parse sweep.
- Delete `finaliser::finalise` body OR retain as debug-only invariant verifier.
- Replace three `Vec<Option<u32>>` allocations with `[Option<u32>; 32]` stack buffers (matches AW-V FrameStack depth cap).

**Sub-gate**: bootstrap regen cycle-1 = cycle-2 byte-identical; all 13 parity harnesses green; `nm` shows no `finalise::finalise` symbol export OR samply self-time < 1% on `finalise`.

### AY.W1.3 Structural-alphabet activation (agent C)

Per A9 §Part 1. Mechanism:
- Create `crates/tape/src/structural_scan.rs` with:
  ```rust
  pub struct ScanState {
      pub positions: Vec<u32>,  // sorted byte-offsets of structural bytes
      pub kinds: Vec<u8>,       // structural-kind per offset (brace-open/brace-close/semi/etc.)
  }
  pub fn scan_structural(input: &[u8], alphabet: &StructuralAlphabet) -> ScanState { ... }
  ```
- `scan_structural` uses SIMD byte-class comparison (vpcmpeqb on x86; NEON equivalent on aarch64) against alphabet bytes; emits sorted position + kind arrays.
- Consumer integration: `<Parser>::parse` entry emits `let _scan = scan_structural(input.as_bytes(), &GRAMMAR_PROFILE.structural_alphabet);`. CTNS emissions in shape emitters query `_scan.positions` for next-structural-byte lookup instead of byte-by-byte DFA.
- `skip_space` consumer: if whitespace byte `\x20` is in alphabet, reads from scan index; else falls through to existing per-byte trim.

Files: `crates/tape/src/structural_scan.rs` (new), `crates/tape/src/lib.rs`, `crates/core/src/backend/rust/emitter/grammar.rs`, `crates/core/src/backend/rust/emitter/shapes/*.rs` (CTNS + skip_space consumers).

**Sub-gate**: `nm target/release/deps/css_l4-<hash> | grep scan_structural` returns ≥ 1; fresh samply on CSS L4 tailwind shows `__regex_scan_CssL4Parser` self-time ≤ 16% (from 26% baseline; A9 projects -10 to -13pp).
