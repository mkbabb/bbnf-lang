`xtask/src/regen_css.rs` does the same for the CSS L4 runtime projection.

The existing `xtask regen --check` path checks only
`crates/core/src/grammar/generated`; it does not check root runtime projection
outputs.

## W4 Implication

W4 cannot close by adding headers manually. Redress must add a non-writing
root runtime check that compares the generated bytes from projection inputs and
registry sidecars against checked-in files.

Header emission must be generator-owned. The generated header cannot be added
after the fact by a one-off script or manual edit.
