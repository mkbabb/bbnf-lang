- the AUDIT-B target file LOC has grown past the AUDIT-B baseline (the split is more urgent; W1 file bounds expand);
- the Audit-A inventory surfaces an item that requires changing BA's or BB's thesis (route to thesis triumvirate, not BC scope);
- the substrate-audit denominator surfaces a post-BB substrate with no production caller (the BB close was incomplete; route back to BB);
- regen drift requires changes outside the W0 file bounds;
- three diagnostic-loop iterations fail to isolate why a substrate-audit row regressed;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).
