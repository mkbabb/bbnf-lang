## 3. ToolBinding and BuildReceipt truthfulness

### Current runtime ToolBinding semantics

Current `tool_binding_at` means:

| Field | Current fact |
| --- | --- |
| `tool`, `argv` | logical capability request, such as `cc`, `--version` |
| `invocation_name`, `invocation_path_hash`, `proxy_hash` | path passed by runtime `tool_binding_at`; currently the selected payload for Apple tools |
| `effective_path_hash`, `executable_hash` | effective selected payload path and bytes |
| `capability`, `capability_hash` | output of the runtime capability child |
| `execution_contract` | runtime child policy (`env_clear`, `LC_ALL=C`, `TZ=UTC`); no physical argv today |
| `toolchain_selection_hash` | runtime selection transcript/hash |
| `dynamic_runtime_hash` | runtime OS/payload/dependency transcript |

R14's proposed mapping could be truthful for **capability recapture** if the
actual runtime child is exactly `/usr/bin/arch -arm64 <selected> <args>` and
the fields/contracts bind that physical invocation. It would not thereby
describe the earlier Cargo link.

### Current BuildReceipt is not a link-spawn receipt

`BuildReceipt` is constructed by code running in the exporter/test process,
after link. At `binding.rs:2165-2171` it selects the runtime-captured `cc` and
`ld` bindings. At `binding.rs:2287-2292` it copies their payload hashes into
`linker_driver_payload_hash`, `linker_payload_hash`, and related fields.

For integration tests:

- `build_argv` is a hard-coded identity describing a generic Cargo no-run
  command, not an observed child-process transcript;
- `build_environment_hash` is literally derived from
  `integration-test-unbound`;
- `embedded_build_tool_ledger_hash` defaults to the newly recaptured runtime
  ledger; and
- no current field contains the retained rustc physical link program, complete
  link argv, resolved physical path, or exit/signal transcript.

Release compile-time path/ledger values can bind intended tool inputs, but the
current code still does not prove the physical program/argv that rustc spawned
for a particular link.
