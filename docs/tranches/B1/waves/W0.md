# B1.W0 — Command-Surface Truth + Proof-Surface Hardening

**Opens after**: tranche open
**Agents**: 3 parallel
**Hard gate**: routine commands, bootstrap, profiling-prep, samply, and bench-close all run on the documented public surface; stale workflow comments/docs deleted in the same wave
**Status**: planned

## Scope

1. Normalize the routine command surface so `.cargo/config.toml`,
   `Makefile`, `scripts/test-tier.sh`, and `docs/instructions/PROFILING.md`
   describe the same live behavior.
2. Harden the bootstrap/profile/expand surface so `bootstrap-bbnf`,
   `ay-prepare-profile-wave`, and at least one `ay-samply-*` path are
   truthful and measured.
3. Harden the final-proof surface so `iter-check-full` and
   `ay-bench-close WAVE=close` are explicit, reproducible, and documented.

## File bounds (disjoint per sub-agent)

Each file is owned by exactly one sub-agent except
`docs/benchmarks/post-B1-W0-proof.txt`, which is append-only with
per-sub-agent disjoint row prefixes (the SPEC §N-agent shared-file
disjoint-hunk exception). No sub-agent writes a row prefix owned by
another.

| File | Owner | Access |
|---|---|---|
| `.cargo/config.toml` | W0.a | modify |
| `Makefile` | W0.a | modify |
| `docs/instructions/PROFILING.md` | W0.a | modify (consolidator) |
| `scripts/test-tier.sh` | W0.a | modify |
| `docs/benchmarks/post-B1-W0-routine.txt` | W0.a | create |
| `scripts/bootstrap-bbnf.sh` | W0.b | modify |

| `scripts/profile-bench-headless.sh` | W0.b | modify |
| `.github/workflows/ci.yml` | W0.c | modify (only if present) |
| `docs/tranches/B1/PROGRESS.md` | W0.c | modify (close-entry) |
| `docs/benchmarks/post-B1-W0-proof.txt` | W0.a rows `ay-prime-fresh`; W0.b rows `bootstrap-*`, `ay-samply-*`; W0.c rows `iter-check-full-*`, `ay-bench-close-*` | append-only, disjoint rows |

PROFILING.md doc updates consolidate under W0.a. W0.b + W0.c
produce raw evidence rows in `post-B1-W0-proof.txt`; W0.a references
those rows from PROFILING.md prose at its own commit time. This
matches the SPEC §N-agent shared-file consolidation pattern (W0.a
is the named consolidator for PROFILING.md).

**Do NOT touch**: `crates/**`; `grammar/**`; `docs/tranches/AY-II/**`
except by explicit W1 handoff; any runtime or emitter source; any
bench/test fixture corpus unrelated to the command surface.

## Phase sub-items

### B1.W0.a — Routine surface normalization + cache-alias separation (PROFILING.md consolidator)

Mechanism:
- Align `.cargo/config.toml`, `Makefile`, `scripts/test-tier.sh`, and
  `docs/instructions/PROFILING.md` to the actual routine surface:
  `cargo iter-check`, `cargo iter-test-leaf`, `scripts/test-tier.sh`
  tiers, and the documented meaning of `iter-check-full`.
- Delete stale comments and stale prose that still describe
  pre-`700501f5` or pre-`ac7bc754` behavior.
- Record routine-surface timing and pass/fail output in
  `docs/benchmarks/post-B1-W0-routine.txt`.
- Downgrade `iter-check-full` from the routine-alias comment block
  to an explicit close-ceremony alias (it still routes through
  `--workspace`, but the prose names it as heavy close-proof).
- Add one named fast-path alias per crate currently excluded from
  `iter-check` — satisfies B1 invariant §10 end-to-end:
  - `iter-check-lsp` = `check --profile ax-iter -p bbnf-analysis -p bbnf-lsp`
  - `iter-check-prettify` = `check --profile ax-iter -p gorgeous --lib`
  - `iter-check-bootstrap` = `check --profile ax-iter -p bbnf-bootstrap --lib`
- Add a new `make ay-prime` Makefile target that seeds
  `target/.bbnf-cache/` by running `cargo check -p bbnf-bootstrap
  --lib` (+ optionally `-p gorgeous --lib`) once. Reports the
  resulting cache-entry count.
- `.cargo/config.toml` carries a comment-block naming the full
  alias cost model: routine (`iter-check`), per-exclude fast-paths
  (`iter-check-lsp` / `iter-check-prettify` / `iter-check-bootstrap`),
  close-gate (`iter-check-full`).
- **Consolidator role**: PROFILING.md prose references
  `docs/benchmarks/post-B1-W0-proof.txt` rows produced by W0.b
  (bootstrap / samply) and W0.c (iter-check-full / bench-close).
  W0.a commits PROFILING.md after the referenced rows are visible
  in the shared artefact file — per SPEC §N-agent shared-file
  consolidation.

Files touched: `.cargo/config.toml`, `Makefile`,
`docs/instructions/PROFILING.md`, `scripts/test-tier.sh`,
`docs/benchmarks/post-B1-W0-routine.txt`.

Sub-gate:

- `cargo iter-test-leaf` exits 0.
