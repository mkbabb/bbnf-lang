# AZ-III.W1 - O5 Reclose

**Name**: W1 - O5 Reclose
**Opens after**: W0 - Quarantine and Dispatch Repair clean-dispatch gate
and W0p - Throughput Substrate.
**Agents**: up to 6 parallel.
**Hard gate**: the AZ-II.O5 close packet is refreshed and green: regen, no-default build, metadata, deletion scans, and A1 residue disposition.
**Status**: planned

## Scope

1. Refresh `cargo xtask regen --check` and repair grammar-general drift.
2. Re-run `cargo build -p bbnf --no-default-features --profile ax-iter`.
3. Prove metadata has no `tape` or `json-prototype` package.
4. Refresh deletion scans for `crates/tape`, public tape runtime,
   `json-prototype`, Gorgeous JIT, and A1 provenance residue.
5. Commit or delete stale O5 evidence; no stale blocked artifact may
   masquerade as current truth.

## Triumvirate Dispatch

If regen drift has an unclear generator root, a deletion scan exposes live
consumer ownership, or no-default repair requires work outside W1 - O5
Reclose file bounds, pause the implementation lane and dispatch research,
plan augment/synthesis, and redress/redeployment agents. The result must be
folded into W1 - O5 Reclose or a same-tranche replacement wave before code
continues. HARD CAP for any redress dispatch under W1 - O5 Reclose: 30 min.
Research and plan augment dispatch defaults follow
`precepts/instructions/tranche/AGENT_DISPATCH_TEMPLATE.md` (research=20,
plan=15, audit=25).
