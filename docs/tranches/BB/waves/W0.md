# BB.W0 — Fast-Path Defaults + Command-Surface Repair

**Opens after**: tranche open
**Agents**: 3 parallel
**Hard gate**: The default command surface exposes a fast iteration path and no longer defaults routine work into heavyweight build, bench, or profiling loops.

## Scope

1. Promote the intended fast iteration path into the public command
   surface.
2. Repair default command entrypoints so they encode the intended
   workflow rather than only documenting it.
3. Prove lower routine wall-clock cost on representative commands.

## File bounds

| File | Access |
|---|---|
| `Makefile` | modify |
| `.cargo/config.toml` | modify |
| `docs/instructions/PROFILING.md` | modify |
| `docs/instructions/tranche/SPEC.md` | modify |

**Do NOT touch**: parser runtime code, replay/recovery/debug tooling,
any `.bbnf` grammar.

## Phase sub-items

### BB.W0.1 Public fast-path commands

Mechanism: promote scoped `ax-iter` and equivalent fast-path commands
into the public command surface.

Files touched: `Makefile`, `.cargo/config.toml`.

Sub-gate: routine commands invoke the intended fast path by default.

### BB.W0.2 Workflow-doc sync

Mechanism: align profiling and tranche instructions with the repaired
command surface so the docs describe the actual defaults.

Files touched: `docs/instructions/PROFILING.md`,
`docs/instructions/tranche/SPEC.md`.

Sub-gate: docs and commands agree on the default workflow.

### BB.W0.3 Routine timing proof

Mechanism: measure representative routine commands before and after the
command-surface repair.

Files touched: `Makefile`, `.cargo/config.toml`.

Sub-gate: representative routine commands are measurably faster.

## Hard gate

1. The default command surface exposes fast-path commands directly.
   Artefact: `docs/benchmarks/post-BB-W0-commands.txt`.

   Artefact: `docs/benchmarks/post-BB-W0-mid.json`.
3. Docs and command defaults agree. Artefact:
   `docs/benchmarks/post-BB-W0-commands.txt`.
