## Scope

Sheets is a spreadsheet-formula language — not a data language
like JSON, not a declarative language like CSS. Its typed surface
is an expression tree over references, literals, operators, and
variadic function calls. W3 proves the AY-II thesis on that
surface end-to-end: every declared `->` annotation lands in the
fused tape + value, every admission has a materializer and a
consumer, every fixture parses at fat-LTO without panicking, and
the hot path runs through the W0 fused pipeline.

Sheets's declared typed surface
(`grammar/google-sheets/google-sheets.bbnf`):

- `number = /regex/ -> f64` (line 6).
- `string = /"([^"]|"")*"/ -> input : Span` (line 12) with
  `TODO AU.6.7` decode kernel deferral.
- `boolean -> true | false` (lines 17–18) — bool-valued alt.
- `error_literal` (lines 34–42) — nine-branch Nu8 alt covering
  `#N/A` → `#SPILL!`.
- `sheet_prefix` (lines 48–49) — two-branch Nu8 alt.
- `cell_ref = /regex/ -> input : Span` (line 60); grammar comment
  names the aggregate `(row, col, abs_row, abs_col)` target that
  the current `type_annotation` grammar cannot express.
- `range_end` (line 72) — three-branch alt, no typed annotation;
  comment declares intended variant-tagged `(Cell | Column |
  Row)` enum blocked on AU.6.7.
- `identifier = /regex/ -> input : Span` (line 87).
- Operator families — `compare_op` (6), `add_op` (2), `mul_op`
  (2), `unary_prefix` (2) — all Nu8.
- Composite surfaces (`cell`, `range_ref`, `cell_or_range`,
  `paren_expr`, `func_open`, `arg`, `func_args`, `func_call`,
  `let_binding`, `let_args`, `let_call`, `lambda_params`,
  `lambda_call`, `array_row`, `array_rows`, `array_literal`,
  `formula`) — structural compounds whose fused-pipeline value
  is a child-vec over `SheetsGValue<'p>`.

AUDIT-B §4 measured the Sheets projection landscape at HEAD
`b346ebca` (`target/expand/ay-named-type.rs:224560-224582`): 10
`PROJECTION_DIRECT_TO_STRUCT` entries (`string`, `boolean`,
`error_literal`, `sheet_prefix`, `cell_ref`, `compare_op`,
`add_op`, `mul_op`, `unary_prefix`, `func_open`), 10
`__grammar_projection_*` markers (`224587-224700`), 10
`materialize_projection_*_SheetsG` fns (`225468-225705`). The
`SheetsGValue<'p>` enum at `224700-224770` exposes 29 rule
variants plus the `Unknown` fallback.
