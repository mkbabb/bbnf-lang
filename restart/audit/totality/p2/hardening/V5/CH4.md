## Verdict

ACCEPT.

V5 confirms the unchanged V4 packet for CH4. PASS-2 requires every grounded
primitive to carry scalar reference, checkasm parity, same-wave consumer,
realistic LOC/risk, and no orphan-kernel research
(`restart/prompts/totality/PASS-2-RESEARCH.md:117-119`). The V4 packet now
meets that bar by making executable rows copyable when complete and by marking
incomplete rows non-shortlist until their missing strict command, first
consumer, or caller-specific harness exists. I find no CH4 reason to reopen V4.

   source-present, string/digit, and parse-that families

2. Exact commands or explicit non-shortlist blockers are present.

   scalar references, command cells, same-wave consumers, expected gates,
   LOC/risk, rollback paths, abrogate thresholds, state, blockers, substrate

   `pmull_cssc_structural_union_emit64` names the existing strict prefix/next

   first consumer (`restart/audit/totality/p2/T-P2-V4-FOLD-ADDENDUM.md:52`).

3. REDRESS-slice coverage is concrete enough for CH4.

   V4 supplies the table V3 CH4 requested: each slice maps prior REDRESS rows
   to candidate id, owner, first consumer or blocker, expected row gate, LOC

   REDRESS-119 direct rows for `twitter`, `canada`, `github_events`,
   `update_center`, string/unicode, and numbers
   (`restart/audit/totality/p2/T-P2-V4-FOLD-ADDENDUM.md:68-73`). It also covers
   PMULL/CSSC/union, source-present prefix/next/bulk, byte-context, cache
   hints, CSS ASCII run-skip, and parse-that HIR/import slices
   (`restart/audit/totality/p2/T-P2-V4-FOLD-ADDENDUM.md:74-79`).

4. LOC, rollback, and abrogate fields are not aspirational.

   The V4 REDRESS table gives numeric LOC ranges, named rollback actions, and
   fail-closed triggers row-by-row: direct digest rows use 80-180 LOC with
   scalar-mix rollback and digest/admitted-row aborts; number routes use
   120-240 LOC with DOTPROD-disable rollback and parity/overflow/row aborts;
   PMULL/CSSC/union uses 280-520 LOC with PMULL/CSSC removal or scalar-scan
   rollback and prior-regression/no-consumer/parity/guard aborts
   (`restart/audit/totality/p2/T-P2-V4-FOLD-ADDENDUM.md:68-75`). Byte-context,
   cache hints, CSS run-skip, and parse-that import rows carry the same
   concrete budget/rollback/abrogate shape
   (`restart/audit/totality/p2/T-P2-V4-FOLD-ADDENDUM.md:76-79`). The V3 numeric
   caps still bind e-graph saturation, CSP solve time, stale/static fallback,
   generated LOC growth, row regression, and parity/equality failures
   (`restart/audit/totality/p2/T-P2-V3-FOLD-ADDENDUM.md:103-115`).
