# BB.W4a — `parse / parse_in / parse_owned` Trait + Surface

**Thesis** Hereupon each grammar emits the three signatures (`parse`, `parse_in`, `parse_owned`); the inner per-rule parse fn is generic over `'i`; the three surfaces specialise the lifetime parameter differently per Lock 9. **Closer-gate** BB-G8 met; `cargo doc -p bbnf` shows the three surfaces × 9 grammars = 27 signatures with consistent docstring shape; `cargo bench -p bbnf -- json_twitter_parse_in` ≤ 420 µs (≤ +5% vs `parse`); `cargo bench -p bbnf -- json_twitter_parse_owned` ≤ 600 µs.

## §1 Deliverable

W4a is the first of two W4 sub-waves. The three-surface API lands at W4a; the cookbook + trybuild fixtures land at W4b.

The three surfaces share one parse implementation. The lifetime parameter is the discriminant: the inner per-rule parse fn (per-rule, generated by BB.W1's direct-to-struct codegen) is generic over the lifetime; each surface specialises differently.

```rust
// Default — slice-borrow primary, lifetime tied to input
pub fn parse<'i>(input: &'i str) -> Result<<G>Value<'i>, ParseErr>;

// Bumpalo opt-in — lifetime tied to caller-provided bump arena
pub fn parse_in<'i>(input: &'i str, bump: &'i bumpalo::Bump) -> Result<<G>Value<'i>, ParseErr>;

// Owned opt-in — no borrow; all slices interned
pub fn parse_owned(input: &str) -> Result<<G>OwnedValue, ParseErr>;
```

Per surgery 21 wrapper-delta window: ≤ +2% from W3c. The inner per-rule parse fn is shared; the three surfaces are thin wrappers; the wrapper LOC scales with surface count (3 per grammar) not with rule count.

The `<G>OwnedValue` type per grammar emits at xtask regen time. Every `&'i str` becomes `String`; every borrowed slice becomes owned. The codegen produces the owned type alongside the borrowed type.

## §5 Risks

Per BB.md `## Risks + mitigations` row "BB.W4a three-surface API confuses authors". The mitigation is W4b's cookbook + trybuild fixtures.

| Risk | Likelihood | Mitigation |
|---|---|---|
| `parse_in` lifetime variance breaks CSS L4 multi-lifetime types | Medium | Inner per-rule parse fn is generic over single lifetime; CSS L4's `CssTypedValue<'p>` collapses lifetime via layout-lowering at codegen. |
| `parse_owned` interning cost regresses serde_json comparison | Low | `parse_owned` target ≤ 600 µs; serde_json baseline 831 µs on twitter; `parse_owned` is competitive. |
