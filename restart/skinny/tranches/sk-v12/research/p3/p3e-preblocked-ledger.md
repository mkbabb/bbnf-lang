## §1 — Synthesis

The 2026-05-20 user pin changes the ledger. It does not erase REDRESS history,
but it rescinds two category-level blocks:

- Rust union substrate routes are unblocked at architectural-category level.
  REDRESS 96/97/98 remain measured-rejected implementation evidence, so a new
  attempt must cite them, name the material differential, pass CHALLENGE, keep
  one substrate, and land a same-wave consumer.
- ASM-gen routes are unblocked at architectural-category level. REDRESS
  88/89/90 remain measured-rejected or limited implementation evidence, so a
  new PMULL/CSSC/ASM route must cite them when adjacent, use scalar reference,
  checkasm/parity, micro-proof, feature-gated fallback, and a same-wave
  consumer.

Everything else tightens around CSS L4. CSS is authoritative; Sheets and
BBNF-self cannot dispatch as preflight-equivalent baselines before measured CSS
redress. The CSS close floor is `Track 1 Mbps > lightningcss_mbps + 1`, not
`ceil(baseline_mbps * 1.01)`. JSON `parse_only` remains diagnostic-only. The
seven Lock-14 leaks in the JSON templates must be resolved through
`GrammarConfig` or equivalent generated metadata before CSS L4 emission is
legal. The `escape_mask_64` NEON falsifier
`0xCAFEF00DBAADF00D` must be verified and fixed before any new SIMD admission.
Close still requires zero production aarch64 orphans by admission, removal, or
inventory demotion.

The accepted S-P2 surface is correspondingly narrow. P2-C shortlist-ready
aarch64 candidates are C1 `a64_tbl_tbx_byte_class_mask64`, C3
`a64_udot_digit_run_span`, C4 `a64_wide_string_special_scan64`, C5
`a64_hex_quartet_decode_x4`, and C6 `a64_ascii_set_run_skip`. P2-D contributes
no current shortlist-ready union primitive; a same-tape CSS-local union route is
conditional after generated CSS Track 1, same-plane lightningcss comparator,
strict equality, CSS hot-leaf attribution, REDRESS 96/97/98 material
differential, and CHALLENGE. P2-F makes `GrammarConfig` the legality
precondition for CSS emission, not an optimization.

## §3 — Falsifiability Binding

P3-E is a negative gate: it falsifies illegal routes before redress. The
binding measurable surfaces are:

| Surface | Binding facts | Ledger effect |
|---|---|---|
| CSS L4 admission | Generated Track 1 must be strictly greater than `lightningcss_mbps + 1`; same corpus/output plane/host; strict equality; independent oracle/Track 2; gate-consumed provenance. | Missing lightningcss Mbps, equality, oracle independence, generated source/runtime provenance, or strict `>` fails the route. |
| CSS fallback ordering | Sheets/BBNF-self are fallback-only after measured CSS redress. | Any W1 plan that skips CSS for preflight convenience is pre-blocked. |
| JSON guards | Direct guard floors and typed guard floors from `SYNTHESIS.md` §0.4 remain active until refreshed by P3-C/SPEC. | Runtime/codegen/gate/report changes that can affect JSON require refreshed guard run or measured REDRESS demotion. |
| SIMD admission | `escape_mask_64` fix first; scalar reference; strict checkasm/parity; micro-proof; same-wave consumer; zero orphan at close. | SIMD proof-only or orphan production code fails closed. |
| Union attempt | CSS baseline + hot-leaf evidence first; REDRESS 96/97/98 citation; material differential; same tape; strict CSS equality; CHALLENGE. | Parallel retained substrate, parser-owned projection, or source-free proof-only class lane fails closed. |
| ASM-gen attempt | REDRESS 88/89/90 citation when adjacent; narrow consumer; scalar/checkasm; micro-proof; feature-gated fallback; same-wave row measurement. | Default-body PMULL/CTZ replay or canary-as-row-movement fails closed. |

Producer-only telemetry is rejected. Any field emitted into `RESULTS.md`,
non-JSON reports, gate manifests, SIMD reports, or REDRESS evidence must be
consumed by the same-wave gate/report path. Stale run ids, oracle coupling,
hand-only witness modules, grammar-name branches in generic crates, parse-only
SOTA claims, or direct digest as typed/CSS proof fail closed.

## §4 — Pre-Blocked Routes

Hard pre-blocks no SK-V12 PIN-V1 wave may reopen under current authority:

1. CSS admission using `ceil(baseline_mbps * 1.01)` or any bar weaker than
   strict `Track 1 > lightningcss_mbps + 1`.
2. Sheets or BBNF-self dispatch before a measured CSS L4 redress attempt.
3. JSON `parse_only` SOTA admission or parse-only evidence as CSS/direct/typed
   product proof.
4. REDRESS 111 report fixture as generated Track 1 baseline.
5. Hand-only non-JSON witness modules, stale report lanes, or prose Lock-14
   claims as grammar-generalization proof.
6. Generic JSON policy leaks in shared/generic crates: structural alphabet,
   value dispatch, string/escape policy, number policy, key/pair model,
   `OffsetFlags` meaning, or JSON sink methods outside generated metadata.
7. New directive, BIR variant, `BackendShape` expansion, public substrate API,
   parser-owned sidecar/fact slot, or second retained substrate beyond the
   category-level D3/D4 rescissions.
8. Parser-owned structural projection, retained cursor/cursor list, class lane,
   whitespace bitmap, aux density/projection column, event side vector,
   decoded-byte sidecar, `UnionTape`, or retained scanner that can be traversed
   independently of the tape.
9. Replays of REDRESS 96 class-column, REDRESS 97 streaming-cursor, or
   REDRESS 98 class-lane-only implementations without CSS-local same-tape
   material differential and CHALLENGE.
10. Replays of REDRESS 88 PMULL default prefix-XOR body, REDRESS 89 CTZ bulk
    consumer, or REDRESS 90 canary-as-row-movement without narrow consumer
    material differential.
11. New SIMD admission before the `escape_mask_64` NEON bug is verified and
    resolved.
12. Orphan production SIMD at close, including the five carried aarch64 orphans
    unless consumed, removed, or inventory-demoted with evidence.
13. Primitive-only checkasm, PMU, cycles, structural-scan, masking probes,
    Criterion slope, sidecar freshness, or inventory presence as behavior
    producers.
14. Direct digest evidence as typed product proof, CSS fact proof substitute, or
    parser primitive absent a legal row-owned output plane.
15. JSON direct residual row movement as the SK-V12 close target, or any
    docs-only/W0-clamped direct admission.
16. x86 implementation work.

Routes that may admit only under different framing with fresh evidence:

- Same-tape CSS-local union may admit only after W1b produces CSS generated
  Track 1/comparator/equality and a fresh CSS hot leaf, and only if it remains
  one substrate and cites REDRESS 96/97/98.
- PMULL/CSSC/ASM-gen may admit only as a narrow same-wave CSS or guard-row
  consumer after `escape_mask_64` is green, and only if it cites REDRESS
  88/89/90 where adjacent.
- LD4, SHA3 EOR3/BCAX, PRFM/STNP, cache hints, byte-context, and other
  support/inventory ideas may enter only after a profile names a real stream,
  formula, writer, or boundary consumer and the wave supplies scalar/checkasm
  and same-wave measurement.
- JSON direct residual companions may enter only after CSS priority resolves
  and the candidate exceeds REDRESS 114-119 with a fresh material source delta,
  independent Track 2, strict comparator floor, and gate-consumed provenance.
