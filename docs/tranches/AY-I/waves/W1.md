## Scope

Per the AU archaeology: post-AU twitter was 0.615 bytes/cyc (76% of sonic); current is 0.137 bytes/cyc (17% of sonic). The 4.5× regression is dominated by write-path layer changes since AU. W1 restores AU's flat-AoS write path + folds the finalise post-pass + activates the long-orphaned structural-alphabet + inlines Pratt's within-compound write.

1. **Revert write-path from SoA 7-column to AU-era flat AoS `Vec<TapeRec>`** (A7 absorbed + AU.6.7 restoration). Current `Columns` struct carries 7 independent `Vec` fields (`kinds`, `flags`, `extra`, `span_lo`, `span_hi`, `sib_skip`, `child_off`). Per push: 7 bounds-checks + 7 potential reallocations + 7 stores across heterogeneous Vec types. AU shipped `Tape { records: Vec<TapeRec>, arena: Vec<u8> }` — one 16-byte store per record, one `with_capacity` per parse. Restore as primary; retain AoS `PackedRecord` sidecar (W1.D) as read-side optional.
2. **Restore unified `push_leaf_with(kind, PayloadData)` as sole payload-bearing leaf entry** (AU.6.7). Already exists at `crates/tape/src/builder.rs:275`; verify every emission site uses it rather than specialized helpers that leak cross-crate boundaries.
3. **Fuse `finalise` post-pass into emit path** (A3 L2 + A1 finalise-23-27%). Replace per-parse `Vec<Option<u32>>` allocations with `[Option<u32>; 32]` stack buffers; fold sib_skip / child_off / span_hi back-patches into `close_compound` as stamp-at-close rather than post-parse sweep.
4. **Activate structural-alphabet pre-pass** (A9 Part 1). `GrammarProfile::structural_alphabet` + `_digraphs` + `_digraph_mask` + `_quote_classes` mined per grammar but zero consumers since W0b. Emit `scan_structural(input, &alphabet)` at every `<Parser>::parse` entry; feed into `ScanState` so CTNS regex patterns jump via `idx.positions[slot]` + `skip_space` reads from the index.
5. **Pratt Option C incremental** (A9 Part 2). Inline `push_leaf_with_arena_payload` per call site; hoist op_stack capacity from mined per-rule chain-depth (`operator_chain.rs`); write op_discriminant directly to a scalar column, skip `arena_mut().push` round-trip. Preserve reducer-compound tree (W0a.2.k flat-tape regression archaeology dispositive).
6. **Restore per-grammar push_fingerprint capacity** (AU.6.2). `GrammarProfile::compounds_per_input_byte` + `leaves_per_input_byte` fields exist; verify `Tape::with_capacity(input.len())` threads through the fingerprint to presize the AoS Vec.
7. **Verify universal hot-path collapse via `nm` + samply** post-wave. Symbols must shift from `tape` crate cross-crate exports into per-rule `parse_<shape>_<grammar>_<rule>` frames (invariant 22).

## Phase sub-items

### AY.W1.1 AU AoS substrate revert (agent A — load-bearing)

Mechanism per AU archaeology:

- `Columns` struct: collapse the 7 `Vec`s into a single `records: Vec<TapeRec>` where `TapeRec { kind_meta: u8, flags: u8, extra: u16, span_lo: u32, span_hi: u32, child_off: TapeOffset }` is 16 bytes. `sib_skip` moves to a parallel `Vec<u32>` (fused-pair write: one `(TapeRec, u32)` = 20 bytes). Alternative: widen `TapeRec` to 20 bytes with sib_skip inline — evaluate cost-benefit.
- `push_structural` reduces to `self.records.push(TapeRec { kind_meta, flags, extra, span_lo, span_hi, child_off }); self.sib_skip.push(0)`. LLVM sees 1-2 stores per push.
- All column accessors (`materialize`, `materialize_unchecked`, `kind_at`, `has_children_at`, etc.) rewrite to read from the `Vec<TapeRec>` directly.
- AoS `PackedRecord` sidecar (W1.D): its transpose source changes from SoA columns to already-AoS `Vec<TapeRec>` + `Vec<u32>` — transpose is now nearly identity (just copy + align to 32-byte boundary).
- `invalidate_packed()` still fires per push to keep the sidecar contract; but the sidecar is a read-side-only cache. No write cost beyond one `OnceLock::take()`.

Files: `crates/tape/src/{columns,tape,builder,packed}.rs`, `generated.rs` (regen).

**Sub-gate**: `nm target/release/deps/json_monolithic-<hash> | grep push_structural` returns zero (inlined); `wc -l crates/tape/src/columns.rs` reduced ≥ 40% (SoA accessor sprawl gone); bootstrap regen cycle-1 = cycle-2.
