## Scope

The structural-scan working approach per `docs/tranches/AW/audit/structural-scan-working-approach.md`. Per-rule `BoundedRegex` using mined `last_byte_set` from `pattern_alphabet.rs`. NOT a universal grammar-wide pre-pass (six prior failures); per-rule inline bounded-scan at shape-emit sites.

1. **`BoundedRegex` state + IR lifter**: new `DtaState::BoundedRegex { pattern, termination_bitmap: [u64; 4] }`. IR pass in `pattern_alphabet.rs` already mines `last_byte_set` per regex pattern; this wave emits the state + consumer. CSS `declaration-value = [^;}]*`: complement yields `S' = {';', '}'}` — 2-byte termination set.
2. **Per-rule `prefer_inline_in_loop` bitmap**: `GrammarProfile.prefer_inline_in_loop: &'static [RuleId]` per R1 §5.2. Per-rule opt-in for inline-SIMD vs indexed stage-1.
3. **Shape emitter CTNS consumer**: `shapes/{string,number,scalar,hregex}.rs` emit a 2-byte `nibble_lut_scan` splice when `rule_id ∈ prefer_inline_in_loop` AND has `BoundedRegex` witness. Uses W5.2 kind-separated streams for fast-jump to termination position.

## Phase sub-items

### W6.1 IR pass: per-pattern alphabet narrowing

Extend `pattern_alphabet.rs` to emit:
- `last_byte_set: [u64; 4]` per `IrNode::Regex` (256-bit bitmap of bytes in NFA accept-state predecessors).
- `first_byte_set: [u64; 4]` per pattern (initial-set bitmap).

Mined per-rule via existing `PatternAlphabetMiner` (already ships `matchable_bytes`, `is_tight`, `is_last_byte_tight`). Extension is straightforward mining-pass continuation.

### W6.2 `kernel_strategy.rs` IR pass

Computes per-rule `prefer_inline_in_loop: bool` per R1 §4 criterion:
> Rule requires bounded-regex-via-stage-1 iff its hot-path body is `Regex("[^S]*")` where `S` is a strict subset of `single_bytes` AND `S` is a strict subset of the mined structural alphabet.

Complement: rule benefits from inline-SIMD-in-loop when criterion fails (JSON-class grammar + narrow-pattern rules).

### W6.3 Shape emitter CTNS consumer

Per Agent 1's concrete design:

```rust
// shapes/hregex.rs emit body:
if rule.prefer_inline_in_loop {
    // inline SIMD: splice 2-byte nibble_lut_scan with terminator_set
    #nibble_lut_scan_fragment_for_terminators(...)
} else {
    // indexed: ConsumeToNextStructural jump via kind-separated stream from W5.2
    #ctns_jump_via_kind_stream(...)
}
```

Per-rule decision at codegen; no runtime selection.

### W6.4 Wire-contract + bench

Wire-contract: fixture grammar `root = [0-9]+ ","`; assert `pattern_last_bytes = {0-9}`; assert emitted `BoundedRegex` consumer dispatches to `idx.positions[slot]` jump; samply shows zero byte-stepping inside the number scan.

## Archaeology

Six prior attempts at structural pre-pass — all failed per `structural-scan-working-approach.md` §2. Key distinction: prior attempts shipped grammar-wide universal index; this wave ships per-rule narrow termination bitmap. Pitfalls addressed per §7 of that audit:
- Per-invocation LUT setup: const LUT at codegen (no runtime alloc).
- Gate-off: per-rule opt-in via `prefer_inline_in_loop` bitmap; absent entry = no emission.
- Dense-alphabet collapse: mined `last_byte_set`-complement is invariant-proof non-empty.
- Pattern widening: per-pattern (not per-grammar) alphabet; no silent widening.
