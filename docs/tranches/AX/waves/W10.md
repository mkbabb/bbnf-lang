## Scope

Per `docs/tranches/AW/research/aw5-r6-depart-egraph-compile.md` + `docs/tranches/AW/audit/egraph-substrate-audit.md`: e-graph substrate already consumer-activated via `write_back_optimized`. This wave adds four grammar-universal algebraic rewrites + two new `GrammarENode` variants + one cost-fn extension.

Rewrites:

1. **G1 Alt-flatten**: `Alt([Alt(…), x]) ≡ Alt([…, x])`. No preconds; enables N-way dispatch over flattened set.
2. **G2 Seq-flatten**: `Seq([Seq(…), x]) ≡ Seq([…, x])`. Mirror of G1; enables tail-inline.
3. **G3 KwWs fusion**: `Seq([Literal(sid), OW(Epsilon)]) ≡ KwWs(sid)` when `facts.literal(sid).width.max ≤ 16`. New `GrammarENode::KwWs(StringId)` variant. Emitter renders as fused `cmp_literal + skip_ws`.
4. **G4 PHF dispatch inference**: `Alt([Literal(s_1), …, Literal(s_N)]) ≡ PhfDispatch(…)` when `N ≥ 3 ∧ all widths ≤ 16`. New `GrammarENode::PhfDispatch(Box<[StringId]>)` variant. Cost model decides via `dispatch_branch × N` vs `dispatch_table + phf_cost`.

Plus Agent 5 L5:

5. **`is_fixed_shape` cost bias**: `GrammarCostModel::cost` adds a penalty term for classes whose extracted node is NOT `is_fixed_shape`. Extraction prefers ShapeRef-friendly forms. One arm; reads `EClassFacts` fields that already exist.

## Phase sub-items

### W10.1 G1 + G2 (universal flatten)

Pure shape-match rewrites on existing `Alt` / `Seq` variants. No new e-node. ~50 LOC per rule. Register in `default_rules()`.

### W10.2 G3 KwWs fusion

Add `GrammarENode::KwWs(StringId)` variant + `GrammarCostModel::cost` arm (negative delta vs `Seq([Literal, OW(Epsilon)])`). Rewrite fires per precondition. Emitter in `shapes/keyword.rs` handles extracted `KwWs` by emitting fused scan.

### W10.3 G4 PHF dispatch

Add `GrammarENode::PhfDispatch(Box<[StringId]>)` variant + cost arm (`dispatch_table + dispatch_branch × log2(N)` vs linear). Rewrite fires per `N ≥ 3 ∧ widths ≤ 16`. Shape-emitter's Keyword shape consumes `PhfDispatch` variant extraction.

### W10.4 L5 fixed-shape cost bias

```rust
// GrammarCostModel::cost(node: &GrammarENode, children_cost) -> Cost
fn cost(&self, node: &GrammarENode, children_cost: impl Iterator<Item=Cost>, facts: &EClassFacts) -> Cost {
    let mut base = /* existing cost */;
    if !facts.is_fixed_shape {
        base += self.weights.non_fixed_shape_penalty;
    }
    base
}
```

Reads `facts.is_fixed_shape` + `facts.all_descendants_elidable` (both already populated; extractor ignores today). Biases extraction toward ShapeRef-friendly forms. Composes with W5 ShapeRef consumer.

### W10.5 Wire-contract tests

Per rewrite: fixture grammar → assert `classify_shape(egraph, root)` returns expected extracted canonical form. For G3: `Seq([Literal("foo"), OW(Epsilon)])` extracts to `KwWs("foo")`. For G4: `Alt([Literal("a"), Literal("b"), Literal("c")])` extracts to `PhfDispatch(["a","b","c"])`. For L5: fixture with two equivalent classes (one fixed-shape, one not) extracts fixed-shape form.
