## Phase sub-items

### W13.1 Five-variant codegen

Emitter generates five variants per primary entry:

```rust
pub fn parse<V: JsonVisitor>(input: &[u8], visitor: &mut V, options: &ParseOptions) -> Result<(), ParseError> {
    match options.cpu_variant.resolve() {
        CpuVariant::Baseline        => parse_json_baseline(input, visitor),
        CpuVariant::NeonPmull       => parse_json_neon_pmull(input, visitor),
        CpuVariant::Avx2            => parse_json_avx2(input, visitor),
        CpuVariant::Avx512Vbmi2     => parse_json_avx512(input, visitor),
        CpuVariant::Sme             => parse_json_sme(input, visitor),  // placeholder until SME intrinsics stable
    }
}
```

Binary size cost: ~1.5–2× per grammar (kernel-bearing fns only, not every emitted fn).

### W13.2 PMC substrate

Apple M: `mach_thread_policy` + `PL_HW_PMC_*` counter sampling. Linux: `perf_event_open`. Runtime: first N=3 parses sample IPC/branch-miss/L1-miss; select variant with best IPC for subsequent parses. Gate: `ParseOptions::tune_online = true`.

### W13.3 `cpu_variant::Auto` resolve

```rust
impl CpuVariant {
    pub fn resolve(&self) -> Self {
        if *self != CpuVariant::Auto { return *self; }
        if is_x86_feature_detected!("avx512vbmi2") { return CpuVariant::Avx512Vbmi2; }
        if is_x86_feature_detected!("avx2") { return CpuVariant::Avx2; }
        if is_aarch64_feature_detected!("pmull") { return CpuVariant::NeonPmull; }
        CpuVariant::Baseline
    }
}
```

### W13.4 Cost-grid sweep

Leverages existing `crates/bootstrap/src/bin/cost_grid_sweep.rs` binary. Extend with W10/W11 cost weights. Pareto-filter: optimum = max-geomean across 17 bench entries s.t. no single entry regresses >1% from W12 baseline.

Output: per-grammar optimal weight vector emitted into `CostWeights::CALIBRATED` const. Wire-contract test asserts emitted const matches sweep output.

### W13.5 `BBNF_COST_TRACE` attribution

Env-flag gated: `BBNF_COST_TRACE=1` prints per-extraction cost breakdown during bootstrap. Used by the grid-sweep binary to attribute bench wins to specific cost axes.
