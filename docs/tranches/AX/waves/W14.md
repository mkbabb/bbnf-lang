## Phase sub-items

### W14.1 `#[derive(Visitor)] #[emit_paired_with]` macro

```rust
#[derive(Visitor)]
#[emit_paired_with(SchemaValidator)]
struct AppVisitor { ... }
```

Macro expansion generates a per-visitor paired-emit request; emitter monomorphises shape emitters for the `(AppVisitor, SchemaValidator)` pair at use-site.

### W14.2 L1-budget guard

Per aw5-h2 §2.2: `total_bytes = sum_of_emitted_fns_x_visitor_pair_size`. Emitter projects L1 footprint:

```
error: visitor pair (AppVisitor, SchemaValidator, CustomLogger) exceeds L1 i-cache budget for grammar 'css_l4':
         projected 647 KB, budget 128 KB.
       reduce visitor pair size or remove the third visitor.
```

Compile-time diagnostic with actionable message.

### W14.3 Multi-key SIMD compare

When `#[derive(Visitor)]` carries `#[keys("a", "b", ..., "n")]`, emitter:
- Generates `static KEYS: [[u8; 16]; N]` packed prefix array.
- Emits `vceqq_u8 × N + OR + movemask + tzcnt` for key dispatch at Object-shape key-match sites.
- N ≤ 16 fits in one SIMD op (NEON `uint8x16_t`); N ≤ 32 on AVX-512.

W5.3's `multi_compare.rs` kernel is the substrate; W14 is the codegen consumer. Gate: twitter with ≥ 16 known keys ≥ 1.1× linear-compare.
