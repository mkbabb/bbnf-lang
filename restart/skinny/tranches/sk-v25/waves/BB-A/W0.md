# BB-A.W0 — immutable constellation baseline and born-RED oracles

## Authority

Opens BB-A. May run beside parse-that T/U prototypes, but it cannot bless a
cross-repository edge until parse-that publishes the relevant package manifest.

## Inputs

- bbnf-lang root, `restart/skinny`, and `wasm` at their recorded commits;
- parse-that, value.js, keyframes.js, and glass-ui at the census commits;
- owner-dirty and worktree ledger; no cleanup authority;

## Implementation

1. Add a baseline command manifest with cwd, toolchain, environment dimensions,
   inputs, declared outputs, mutation policy, and expected exit class for every
   root/skinny/WASM/playground/parse-that gate.
2. Reproduce the unlawful type right-overwrite, contradictory-ground termination,
   ignored type error, default-Span obligation, G3 nullable alternation rewrite,
   partial saturation/writeback, independent-minimum CSP fallback, stale/different
   WASM copies, entry-rule disagreement, and x86/false-NEON routes as focused tests.
3. Hash all tracked source/config/grammar/generated/package-lock inputs relevant to
   later graph comparisons. Keep owner changes as an explicit overlay.
4. Define semantic observations for acceptance, value, span, diagnostic, type,
   lowering decision, generated bytes, package resolution, and browser behavior.
5. Run every oracle twice; quarantine flaky or environment-dependent evidence
   rather than normalizing it into a baseline.

## Evidence gates

- Every named incumbent defect is RED for its named reason.
- No command mutates a tracked manifest/lock/generated output unexpectedly.
- Repeated fixture and failure payloads are byte-identical after normalized temp
  roots; normalization never erases semantic paths or identities.
- All unsupported platform/tool conditions are explicit RED obligations.
- Two hostile critics and a fresh adjudicator rule witness completeness.

## Outputs

- command and artifact manifest;
- counterexample bank with exact expected/actual values;
- immutable source/config/grammar/package census;
- supersession table linking every old green claim to its stronger oracle.

## Reopen rule

Any new compiler operator, backend, package face, generated artifact, worktree
scope, or frontend route reopens this wave before it can enter later graph truth.
