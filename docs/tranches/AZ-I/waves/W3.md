# AZ-I.W3 — Direct-to-struct emission (CSS L4 aggregate + typed values)

**Opens after**: AZ-I.W2 close
**Agents**: 2 parallel (typed-value enums; aggregate/Named)
**Hard gate**: CSS L4 emits into struct builders only; tape path
severed on CSS L4 hot path; CSS normalize ≥ 735 MB/s, bootstrap ≥
600 MB/s, tailwind ≥ 500 MB/s; lightningcss + cssparser parity
harnesses green node-for-node across the full CSS L4 corpus.
**Status**: superseded (2026-04-28). The CSS L4 struct-direct activation collapses into the merged **W2-act (GESTALT-ACTIVATE)** wave per `docs/tranches/AZ-I/audit/W2-CLOSE-AUDIT.md` §2 + Audit-5 Proposal A — the W2 substrate is grammar-general, so the per-grammar resolver-arm flip handles JSON / Sheets / CSS L4 simultaneously rather than as three sequential waves. Hard gates (CSS normalize ≥ 735, bootstrap ≥ 600, tailwind ≥ 500; lightningcss + cssparser parity) carry forward to W2-act.B3.

## Scope

1. Rewire the CSS L4 emission path to write directly into
   `StructRegistry`-backed struct builders. Materialise
   `StyleSheet`, `CssRule`, `StyleRule`, `MediaRule`,
   `KeyframesRule`, `Selector`, `Declaration`.
2. Materialise typed values as Rust enums: `Length`, `Color`,
   `Dimension`, `Time`, `Resolution`, `Percentage`, `Angle`.
   Variant sets match the grammar's alternation structure.
3. Materialise compound typed values: `CalcExpr`, gradient shapes,
   function calls, lists.
4. Sever the tape path on the CSS L4 runtime entry point.
5. Rewire view-layer accessors: `css::StyleSheet::rules()` returns
   `CssDeclaration` from the struct graph directly. Every
   `<length>` returns a `Length` convertible to
   `lightningcss::values::length::Length` without loss.
6. Rewire lightningcss and cssparser parity harnesses to compare
   struct-vs-native node-for-node.
7. Bench delta gate: normalize ≥ 735, bootstrap ≥ 600, tailwind ≥
   500 on the struct-only path. Lightningcss parity green on the
   full CSS L4 corpus.

## Phase sub-items

### AZ-I.W3.1 — Typed-value enums

Materialise `Length`, `Color`, `Dimension`, `Time`, `Resolution`,
`Percentage`, `Angle`. Each enum's variants match the grammar's
alternation structure; each enum is convertible to lightningcss's
equivalent through a parity-harness conversion impl.

Sub-gate: conversion impl exists for each typed-value enum;
round-trip test on every variant green.

### AZ-I.W3.2 — Aggregate + Named emitter rewire

Emission path for `grammar/css-l4/` writes to `StyleSheet` /
`CssRule` / `StyleRule` / `Declaration` / etc. builders directly.
No tape record is pushed on CSS L4 input.

Sub-gate: `rg '\bTapeBuilder\b|\bpush_rec\b'
crates/core/src/runtime/css_l4/` → zero matches.

### AZ-I.W3.3 — Compound typed values (calc, gradient, function, list)

Materialise `CalcExpr`, gradient shapes, `FunctionCall`,
`TypedValue::List`. Calc recursion handled by arena allocation of
nested `&'a CalcExpr`.

Sub-gate: parity harness covers calc/gradient/function/list
fixtures; green on the CSS L4 corpus.

### AZ-I.W3.4 — View-layer + parity harness rewire

`css::StyleSheet::rules()` returns struct-graph nodes. Lightningcss
parity compares node-for-node; cssparser parity compares
struct-vs-cssparser accessor output.

Sub-gate: both parity harnesses green on full CSS L4 corpus.

## Hard gate

1. CSS L4 emits into struct builders only; grep confirms.
2. Throughput gates met: normalize ≥ 735, bootstrap ≥ 600,
   tailwind ≥ 500.
3. Lightningcss + cssparser parity harnesses green node-for-node
   across the full CSS L4 corpus.
4. Every `<length>`, `<color>`, `<angle>`, `<time>`, `<resolution>`,
   `<percentage>` typed value round-trips against lightningcss.
5. No AU-baseline regression on JSON, Sheets, or BBNF entries.
6. `cargo nextest run --workspace --profile ax-iter` ≥ 1480 pass
   (post-B4 baseline per `docs/tranches/B4/FINAL.md` test summary).

## Reversal criteria

Miss ≥ 20% on normalize / bootstrap / tailwind, or parity harness
red on any typed-value kind → revert the substrate for the failed
component. Partial-close escape (see AZ-I.md §Defensible floor):
keep CSS L4 on struct-only output with named semantic gaps (for
example selectors, calc, gradients, or color edge cases) and route
the missed semantic surface to AZ-I'. A CSS tape bridge is not a
valid W3 floor; any attempt to retain aggregate CSS tape is a wave
revert + re-plan trigger.
