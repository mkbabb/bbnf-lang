## Finding 1 — M01 conflates a redundant assertion with exact RHS ownership

The unmutated lowerer already receives one structural `Factor`, one structural
value-expression child, and optional structural type annotation. Map ownership
comes from those children. It validates that the textual gap between factor and
value trims to `->`, then slices the RHS from the exact value-expression range.

M01 deletes the gap assertion *and* changes the RHS start from `value_lo` to
`factor_hi`. The failing fixture reaches `direct_numeric_suffix` with text that
begins `-> 1u8`, so the suffix is correctly rejected. The failure proves the
exact RHS slice; it does not prove the gap assertion. Deleting only the
assertion leaves canonical parser-produced output unchanged and survives the
frozen tests.

The KISS disposition is therefore not to invent a malformed parser view or
retain an unproved duplicate syntax check. Delete the redundant textual arrow
assertion, retain the exact structural RHS range, and mutate only that range.
Run the division killer and block-comment control in the same mutant epoch.

## Finding 2 — cancellation should use the one monotone authority

`CancelToken` is one shared `Arc<AtomicBool>`. It exposes cancellation and
observation, not reset. The CSP search writes `stats.cancelled = true` only
after observing that configured token as true. The caller then observes its
clone of the same token. Consequently:

```text
solver_stats_cancelled == true  =>  current_token_cancelled == true
```

M06's `(true, false)` cell cannot occur in production. It is a truth-table test
of an abstraction introduced solely to split an earlier coupled mutation. The
smallest implementation has one post-solve authority: check the current token.
Delete `cancellation_observed`, its stats-only test, and M06.

The inverse `(false, true)` is reachable. In the solver, complete assignment is
accepted before the cancellation cadence guard. A constraint can cancel the
