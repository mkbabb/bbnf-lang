## Phase sub-items

### AY.W6.1 parse_that de-generic (parallel agent A)

Mechanism:
- Run `cargo llvm-lines -p parse_that --profile ax-iter > /tmp/parse_that-llvm-lines.txt`.
- Identify top-10 monomorphisation explosions. Typical culprits: `Parser<'_>::map<F>` with F unbounded; `Parser<'_>::chain` with nested generic chains; `Combinator` trait's generic associated types.
- Replace with enum-based dispatch OR `impl Trait` where possible. Preserve public API shape — no breaking changes.
- Run workspace rebuild; verify parse_that combined rustc time decreases.

Files: `.cargo/patches/parse_that/src/*.rs` (may be a few files).

**Sub-gate**: `cargo build --workspace --profile ax-iter --timings` reports parse_that combined ≤ 70s.

### AY.W6.2 ax-iter profile tuning (parallel agent B)

Mechanism:
- Audit workspace `Cargo.toml` `[profile.ax-iter]` definition. Current state: inherits dev, debug=0, opt-level=1 per-package on bbnf-ir + csp-solver + parse_that.
- Add: `incremental = true` (or verify inherited from dev), `codegen-units = 256` (max parallelism), `split-debuginfo = "unpacked"`.
- Verify incremental rebuild on a trivial single-test edit runs in ≤ 10s.

Files: workspace `Cargo.toml` only.

**Sub-gate**: trivial test-file edit + rebuild via `cargo test --no-run -p bbnf --test bbnf_parity --profile ax-iter` wall ≤ 10s.
