# BC.W1 — Decision Log + Replay

**Opens after**: W0 close
**Agents**: 3 parallel
**Hard gate**: Feature-gated decision logging and replay reproduce substrate-identical output on corpus fixtures with no alternate parser path.
**Status**: planned

## Scope

1. Record emitted parser decisions as a feature-gated log on the
   canonical
   runtime path.
2. Re-enter the same parser against that log for replay.
3. Prove substrate identity and bounded feature-off cost with tests and
   benchmarks.

## File bounds

| File | Access |

| `crates/core/src/runtime/replay.rs` | create |
| `crates/core/src/runtime/parsed.rs` | modify |
| `crates/core/src/backend/rust/emitter/grammar.rs` | modify |
| `crates/core/tests/replay_substrate_identity.rs` | create |

**Do NOT touch**: incremental splice logic, recovery semantics, build/profile tooling, any `.bbnf` grammar.

## Phase sub-items

### BC.W1.1 Decision logging

Mechanism: define a compact decision-log representation keyed to the
canonical
provenance and populate it behind a feature gate on the production
parser path.

Files touched: `crates/core/src/runtime/replay.rs`,
`crates/core/src/backend/rust/emitter/grammar.rs`.

Sub-gate: emitted parsers can produce decision logs without leaving the
canonical runtime path.

### BC.W1.2 Replay path

Mechanism: implement replay by feeding the log back through the same
shape-emitted parser control path rather than a replay-only executor.

Files touched: `crates/core/src/runtime/replay.rs`,
`crates/core/src/runtime/parsed.rs`.

Sub-gate: replay returns the same substrate shape on canonical inputs.

### BC.W1.3 Identity tests and cost check

Mechanism: add substrate-identity tests and compare feature-on/off
costs on the eager JSON matrix.

Files touched: `crates/core/tests/replay_substrate_identity.rs`,
`crates/core/src/runtime/replay.rs`.

Sub-gate: replay identity tests pass on corpus fixtures.

## Hard gate

1. `cargo test -p bbnf --test replay_substrate_identity --profile ax-iter`
   passes on the replay corpus. Artefact:
   `docs/benchmarks/post-BC-W1-replay.txt`.
2. Replay output is substrate-identical to cold parse on the corpus.
   Artefact: `docs/benchmarks/post-BC-W1-replay.txt`.
3. Feature-off regression versus BA close remains `<= 3%` on the eager
   JSON 5-fixture geomean. Artefact:
   `docs/benchmarks/post-BC-W1-mid.json`.
