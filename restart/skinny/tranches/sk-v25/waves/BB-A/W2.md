## Authority

Consumes a GREEN BB-A.W1 graph. This wave decides ownership; it does not migrate
semantics before destination tests exist.

## Implementation

1. Treat bbnf-lang root as the sole product workspace. Make WASM a normal locked
   member with local canonical package identities and one declared output route.
2. Freeze skinny as a read-only lab. For every package/module/fixture/benchmark,
   record semantic uniqueness, measured advantage, provenance, destination, and
   `KEEP`, `TRANSPOSE`, or `DELETE-AFTER` disposition. Consumer count is context,
   never proof of value.
3. Map retained root shells—grammar/spec, formatter, analysis/LSP contracts,
   backends, WASM source, public packages, playground consumers—to the staged
   `Program -> DependencyGraph -> TypeSolution -> AnalysisFacts -> LoweringPlan`
   product.
4. Identify collisions where root and skinny claim the same regex/scanner/type/
   egraph/CSP/runtime/generator authority. Select one eventual home or a bounded
   island; no shared ambient service is grandfathered.
5. Build a deletion order whose prerequisite is destination differential proof and
   whose atomic change removes the old route. No adapter tranche or dual plane.

## Evidence gates

- Every shipping and lab node has one disposition, proof, owner, destination, and
  deletion prerequisite.
- Root product manifests do not depend on skinny shipping packages.
- WASM resolves real root packages and has one artifact producer/consumer lineage.
- No semantic organ has two production owners in the target quotient graph.
- Two hostile carrier reviews and adjudication close every ambiguous disposition.
