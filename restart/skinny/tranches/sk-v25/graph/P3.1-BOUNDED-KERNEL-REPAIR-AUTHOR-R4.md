## R4 mechanism

### Strict schema identity

`Sha256Digest` and `EdgeIdentity` now have manual `Deserialize`
implementations. Wire input must be canonical lowercase hexadecimal and edge
identity must be exactly `edge:sha256:<64 lowercase hex>`; deserialization no
longer admits unchecked or silently normalized wrapper strings.

`NodeFact::validate_identity_kind` is exhaustive over every `Identity`
variant. `exact_node` applies it at construction and graph canonicalization
reapplies it to decoded or manually assembled facts. Physical identity kind is
bound to file/directory/symlink; semantic backend/IR/cost/constraint/type/ASM
kinds remain confined to the virtual identity domain.

Graph truth count and allocation-free serialized-byte admission now run before
canonical clone, sort, or identity index construction.

### One sealed graph domain

`Decomposition` now seals the projection, canonical components, ownership,
all checked selected edges, and exact internal-edge buckets. Cluster and
quotient construction consume that sealed object; callers can no longer
splice arbitrary components and edges at those boundaries.

Every public cycle operation reaches the same checked `EdgeDomain`
constructor. It enforces node/edge counts, aggregate serialized bytes,
projection byte reservation, edge-record identity, endpoint containment,
canonical edge order, and uniqueness before algebra indexes or vectors are
allocated.

The public weak undirected `cycle_rank` route was removed. The sole public rank
API is `directed_cycle_rank`; it sums only cyclic SCC-internal domains and is
therefore exactly consistent with `basis_for_subgraph`. Empty graphs and empty
selected-edge projections remain rank zero and retain R3 F19 truth.

### Honest byte and cluster work

`ProjectionBudget` now owns both checked work and aggregate byte reservations.
SCC cardinality and allocation-free aggregate-byte gates run before the owned
API constructs its edge-reference vector and before either SCC API constructs
maps, traversal vectors, component clones, ownership, or buckets. Cycle
domain/index and GF(2) row/witness reservations share that same projection
budget. Cluster index admission is charged before its derived indexes.

Cluster indexing now retains per-node incident edge indexes. Partition groups
carry their internal-edge counts; adding a node updates that count only from
the candidate's incident edges. Connectivity splits calculate their own local
count from incident indexes. The former whole-edge `count_internal` rescans and
proposal-set clones are absent.

The three pre-existing `evidence/binding.rs` `needless_borrow` findings named
by R3 were corrected without changing binding behavior.
