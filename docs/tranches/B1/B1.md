# Tranche B1 — Dev-Loop Truth + Proof-Surface Hardening

B1 is the bounded prelude annex that restores truthful development
infrastructure before AY-II resumes. It owns no runtime architecture.
It closes only when the public command surface, bootstrap/expand/bench/
profile surfaces, and their documentation agree on measured reality.
AY-II.W0' stays paused until B1 closes; AY-II resumes immediately
afterward on the refreshed proof surface.

## Research artefacts / waiver

B1 waives a separate research wave. The design space is already tight
and sufficiently illuminated by:

- `docs/tranches/AY-II/audit/W0p-infra-root-cause.md`
- `docs/tranches/AY-II/audit/W0p-infra-fix-plan.md`
- `docs/tranches/AY-II/audit/W0-iter-surface-verification.md`
- `docs/tranches/AY-II/PATH-FORWARD.md`

These artefacts already provide the required research-phase inputs:
root-cause attribution, proposed remediations, and measured surface
verification. B1 therefore opens directly as an implementation annex.

## Architectural thesis

1. **B1 precedes AY-II's next runtime step.** As a prelude annex,
   B1 closes before AY-II.W0' close ceremony and W1 dispatch resume.
   There is no parallel annex execution.
2. **B1 owns infrastructure only.** Command surfaces, build/expand
   behavior, profiling preparation, bench orchestration, CI/defaults,
   and documentation are in scope. Parity-critical runtime architecture
   remains in AY-II.
3. **One public workflow surface.** Cargo aliases, Make targets,
   scripts, CI, and docs must describe the same workflow. Stale comments,
   stale docs, and superseded command claims are infrastructure debt and
   must be deleted.
4. **Proof surfaces must be real.** `iter-*`, `bootstrap-bbnf`,
   `cargo expand`, `ay-prepare-profile-wave`, `ay-samply-*`, and
   `ay-bench-close` close on present-day measurements and artefacts,
   not inherited tranche prose.
5. **Delete legacy workflow cruft.** B1 does not layer new guidance on
   top of obsolete surfaces. It retires stale comments, stale aliases,
   and dead workflow branches in the same change that supersedes them.

## Invariants

1. No B1 commit touches parity-critical runtime architecture.
2. B1 blocks AY-II.W0' close ceremony and AY-II.W1 open until B1 closes.
3. Every public routine command remains seconds-scale on the declared
   routine surface or is removed from that surface.
4. Every public proof command (`bootstrap`, `expand`, `samply`,
   `ay-bench-close`) is runnable and documented on the exact command path
   users and agents will invoke.
5. Every documentation claim about the public command surface is
   re-verified against the live repo state during B1.
6. No stale `#[allow(dead_code)]`, `#[ignore]`, `#[cfg(false)]`, or
   dead workflow prose is introduced to hide incomplete work.
7. Samply closes on symbol-resolved captures, not `nm`-only salvage.
8. B1 closes with a benchmark/timing artefact trail of its own.
9. B1 carries no successor debt tree; anything runtime-facing routes
   back to AY-II immediately.

## Operational posture

1. B1 executes in two waves only: one repair wave, one close wave.
2. W0 is allowed to edit command/config/script/docs surfaces together
   when that is the smallest truthful change set.
3. Every B1 claim about command behavior cites a measured artefact.
4. Any runtime defect surfaced during B1 is recorded and routed to
   AY-II rather than fixed in-annex.
5. B1 closes before any further AY-II runtime or semantic dispatch.

## Hard gates summary

### W0

1. `cargo iter-check` and `cargo iter-test-leaf` run clean on the
   documented routine surface.
2. `scripts/test-tier.sh` and the documented make/cargo aliases agree
   on crate names and tier semantics.
3. `bash scripts/bootstrap-bbnf.sh` completes on the declared close
   surface with a measured wall-clock artefact.
4. `make ay-prepare-profile-wave` and at least one `make ay-samply-*`
   target produce a symbol-resolved profile on the declared path.
5. `make ay-bench-close WAVE=close` is runnable on the declared proof
   surface and records non-empty output.
6. Stale comments/docs that contradict the live command surface are
   removed in the same wave.

### W1

1. `docs/benchmarks/post-B1.json` captures the refreshed timing/proof
   matrix.
2. `docs/tranches/B1/FINAL.md` records every invariant with artefact
   citations.
3. `docs/tranches/AY-II/PATH-FORWARD.md`, `AY-II/PROGRESS.md`,
   `AY-II/AY-II.md`, and the active AY-II wave specs reflect the
   post-B1 execution order: B1 close, AY-II.W0' close, then AY-II W1-W5.

## AY-II handoff contract

B1 does not close until all of the following are true:

1. The public command surface and its docs are internally consistent.
2. The bootstrap, expand, profile-prep, samply, and bench-close paths
   are proven on current repo state.
3. AY-II.W0' is explicitly unblocked in AY-II's planning/status docs.
4. No B1 change introduced runtime drift into AY-II.

## Defensible floor

B1's defensible floor is:

1. Truthful routine command docs and comments.
2. Measured bootstrap/expand/profile/bench proof surfaces.
3. An AY-II handoff that no longer depends on ambiguous or stale infra
   claims.

Anything less leaves AY-II blocked on documentation debt rather than
engineering truth.

## Cross-tranche debt

- Runtime parity, fused-substrate closure, projection/materializer
  totality, and all semantic-wave work remain in AY-II.
- If B1 surfaces runtime regressions while proving bench/bootstrap/
  profile surfaces, those regressions route to AY-II immediately with
  artefact citations.

## Escape clause

None. If B1 discovers a broader runtime blocker, it records the evidence
and stops; it does not absorb AY-II work.

## Indefatigability

When B1 closes correctly, the repo has one truthful workflow surface,
one truthful proof surface, no stale infra prose, and one immediate
next step: AY-II.W0' close, then AY-II W1-W5 on the refreshed surface.
