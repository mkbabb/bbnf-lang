## Scope

BBNF is the meta-grammar. Its typed surface IS grammar structure — Rule shapes, Body shapes (Alt / Seq / Repeat / Optional / Group / Ref / Literal / Regex / TypeAnnotation / Negate / Minus), Directive shapes (`@pretty`, `@token`, `@ws`, `@import`, `@host`, `@debug`, `@recover`). Its bootstrap cycle is the canonical self-hosting identity check for the whole language. W0 landed the fused substrate + grammar-derived typed emission in a grammar-agnostic way; W1 / W2 / W3 proved it on JSON / CSS L4 / Sheets; W4 proves it on BBNF, the only grammar where a fused-substrate correctness failure manifests as an outright inability to regenerate the parser.

No external peer bench exists for BBNF. Unlike JSON (sonic-rs, simd-json), CSS (lightningcss, cssparser), or Sheets, BBNF is a unique language with no third-party reference implementation. W4's close criteria key against three internal-truth anchors instead: (a) bootstrap double-regen byte-identity — the canonical BBNF identity check, (b) grammar-meta projection totality under the W0.d standard, (c) samply-verified fused-pipeline attribution on `bbnf_self`. All three are falsifiable runtime facts, not internal ratios. This satisfies AY-II invariant §9 ("BBNF first-class peer: benched, profiled, expanded, gate-verified"); the peer-ratio axis of the other waves has no BBNF equivalent because no BBNF peer exists.
