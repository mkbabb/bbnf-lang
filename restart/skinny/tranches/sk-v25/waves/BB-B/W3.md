# BB-B.W3 — adjudicated semantic type kernel v3

## Goal

Infer and solve grammar value types without conflating them with storage layout or
finite shape propagation.

## Core contract

- immutable store/revision-qualified opaque IDs;
- separate flexible metavariables and recursive bound variables;
- primitives, tuples, lists, options, functions, records, variants, spans,
  transforms, parse results/diagnostics, and explicit `mu` binders;
- equality constraints, open row equations, explicit lacks constraints, named
  reuse-boundary schemes, fully zonked immutable `TypeSolution`;
- complete provenance and deterministic typed failures;
- checked downstream layout lowering only.

## Implementation

1. Validate/intern terms through builders that reject cross-store/dangling/cyclic/
   capture/duplicate-label constructions. IDs and raw insertion remain private.
   Recursive binders use explicit store-scoped `RecVar` identities and exact free
   variable closure; there is no mutable active-binder depth stack.
2. Solve without mutating the term store. Orient metavariable equations
   canonically; perform complete type/row occurs checks and preserve every
   contributing origin through decomposition and substitution.
3. Solve record/variant row equality with disjoint residual fields, fresh shared
   tails where required, lacks propagation, canonical residuals, and deterministic
   closed-row errors.
4. Represent explicit recursion alpha-stably and compare/unify bodies with bound
   variables distinct from free metavariables.
5. Materialize a fully zonked solution and residual constraint set with path-local
   memoization. Generalize qualified type/row variables only after solving against
   an owned rigid environment; preserve lacks predicates, levels, and the named
   value restriction through every instantiation.
6. Charge ingestion, validation, ordering, solving, occurs, zonk, fingerprint,
   layout, and projection to one total operation context. Failures expose a minimal
   deterministic proof-DAG slice, not the flat set of all input origins.
7. Lower semantics to layouts through validated target rules. Physical Apple ARM64
   claims apply only to explicit kernel-owned representations and carry size,
   alignment, offsets, padding, tags, target, and toolchain. Unknown/free types,
   opaque Rust containers, arbitrary byte/align values, or mismatched revisions are
   typed failures.
8. Project with target-specific Rust/TypeScript identifier allocators, keyword and
   literal escaping, post-normalization collision tables, and correct singleton
   tuples. Every artifact carries semantic/source/toolchain reproduction identity.
9. Compare this equality+rows kernel with a small grammar-shape algebra. Admit
   algebraic subtyping or effect rows only if a real consumer fixture cannot be
   expressed and the richer prototype wins its correctness/complexity comparison.

## Gates

- BB-B.W0 property/corpus bank passes, including 1,000+ permutations and repeat
  byte identity.
- Deep terms hit explicit budgets without panic/overflow; public arbitrary-input
  corpora do not panic; both 20,000-deep success/exhaustion witnesses are iterative
  or explicitly heap-stacked.
- Alpha-equivalent recursion, row lacks/duplicates/occurs, generalization, and
  complete provenance are directly asserted.
- Every actual `IrNode` variant and real `FnDescriptor` boundary produces
  non-empty constraints or a named diagnostic; adding a node variant breaks the
  exhaustive match.
- Generated Rust and TypeScript projections compile and consume solved fixtures,
  including hostile keywords, punctuation, normalized collisions, string escapes,
  nested rows/variants/functions, and empty/singleton tuples.
- `cargo fmt --check`, strict clippy, tests twice, and allocation/runtime evidence
  pass before integration.

## Completion

The kernel is a proved standalone carrier; production authority waits for W4–W6
grammar generation and consumer cutover.
