Cost / extraction fix
---------------------
crates/ir/src/egraph/cost.rs:130-152
  GrammarENode::Map { inner, fn_id: _ } => {
      const MAP_PRESERVE_BONUS: f64 = 1.0e6;
      (child_cost(*inner) - MAP_PRESERVE_BONUS).max(f64::MIN / 2.0)
  }

Mechanism: Map's cost subtracts a preservation bonus so the wrapper
always undercuts any non-Map sibling sharing its e-class. Every non-Map
e-node carries at least Epsilon's 0.5 of structural mass; a 1e6 bonus
keeps the wrapper safely below that floor while child_cost(*inner)
keeps distinct Maps (different fn_ids, different inners) ranked
against one another. The f64::MIN/2 floor caps deeply-nested Map cost
at a finite negative value.
