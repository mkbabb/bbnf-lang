# BB-B.W4 — complete grammar constraint generation

## Goal

Generate load-bearing semantic constraints for every Program operator and host
boundary, with no default type or unconsumed obligation.

## Implementation

1. Define the value transformation for literals, regex/scanners, sequence,
   alternative, repeat, option, reference, capture/field, skip/projection, map/
   transform, recovery, Pratt/precedence, directives, host functions, and public
   rules.
2. Assign a qualified type metavariable to every value-bearing node and named rule
   boundary. Generate equality/row constraints with node/operator/source origins.
3. Keep semantic type equations, grammar validity obligations, capabilities/
   effects, and storage/layout requirements as separate products and solvers.
4. Require host maps/functions to declare checked signatures or generated schemas;
   an unannotated host boundary is a diagnostic, never `Span`, unknown, or scalar.
5. Generalize only named reusable rules after their SCC is solved and subject to
   the chosen value restriction. Instantiate per reference with provenance.
6. Produce a total node-to-solved-type mapping plus rule schemes and diagnostic
   report. Connect at least one generated Rust and TypeScript value consumer.

## Coverage gates

- A generated operator-coverage mutation removing any constraint arm fails.
- Every Program node is classified value-bearing/non-value-bearing with proof and
  has a solution or named diagnostic.
- Recursive, generic host-map, parse-result/diagnostic, CssValue, heterogeneous-alt,
  and all manifest grammar fixtures solve deterministically.
- Constraint order/hash/worker permutations yield byte-identical solutions and
  diagnostic sets.
- Disconnecting TypeSolution from a consumer fails compilation or behavior.

## Completion

TypeSolution becomes semantic truth for real grammar values rather than a detached
prototype.
