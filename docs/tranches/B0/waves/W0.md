# B0.W0 — Public Fast-Path Defaults + Scoped AY Command Repair

**Opens after**: tranche open
**Agents**: 3 parallel
**Hard gate**: The public command surface exposes the fast routine path AY actually needs and no longer defaults routine work into full-workspace or final-proof loops.
**Status**: planned

## Scope

1. Promote the intended fast routine path into the public command
   surface.
2. Repair default entrypoints so AY work stops paying for heavyweight
   loops by default.
3. Prove lower wall-clock cost on representative AY routine commands.

## Phase sub-items

### B0.W0.1 Public fast-path commands

Mechanism: promote scoped `ax-iter` and equivalent routine commands
into the public command surface the AY executor will actually call.

### B0.W0.2 Default-loop repair

Mechanism: remove command defaults that silently route routine work into
full-workspace or final-proof profiles.

Files touched: `Makefile`, `.cargo/config.toml`.

Sub-gate: routine defaults and heavy defaults are distinct.

### B0.W0.3 Timing proof

Mechanism: measure representative AY routine commands before and after
the command-surface repair.

Files touched: `docs/instructions/PROFILING.md`.

Sub-gate: representative routine commands are measurably faster.
