## Scope

W2 merges three historically-separate concerns that all live in `crates/ir/src/` + `crates/ir/src/egraph/`:

1. **Named preservation** (A6 + W1r.1 diag) — `TypeDesc::Named(_)` collapses before Rust emit. Fix at the hypothesized site(s): egraph cost-guided extraction OR alias/transparent stamping pre-normalizer-loop.

2. **E-Graph G1-G9 canonicalisation** (absorbed from AX.W10+W11 per user directive — not deferred). Universal rewrites:
   - G1: Alt-of-single-branch elision (`Alt([x]) ≡ x`).
   - G2: Repeat-of-single elision (`Repeat { inner, lo: 1, hi: 1 } ≡ inner`).
   - **G3: Wrap-of-epsilon elision** (`Wrap { body: Alt([leaf, ε]) } ≡ leaf`). **PRIMARY LEVER** — cuts JSON value-wrap tax 50%.
   - G4: adjacent-literal concatenation (`Concat(Literal(a), Literal(b)) ≡ Literal(ab)`).
   - G5-G9: per-shape (Pratt/Wrap/Flat/HRegex/AltDispatch) rewrites. E.g. G5 `Pratt + single-rung ≡ Flat`; G6 `Wrap + epsilon-only-tail ≡ leaf`.

3. **Shape-dispatch detector retirement** (AX.W12 absorbed) — once e-graph G5-G9 subsume the hand-coded shape detectors, retire the classifier (~1,676 → ~150 LOC). The detector logic moves into cost-model extraction biases.

4. **Wrap-compound elision consumer activation** — the shape emitter's wrap-rule path reads the post-canonicalisation IR and skips compound emission for rules whose body canonicalizes to scalar/leaf form. Per A1 attribution: JSON twitter record count 158K → ~80K (matching sonic-rs node count) post-G3.

5. **Wire-contract tests** — two new tests: `named_type_preservation.rs` (every `-> input : <Name>` reaches emit as Named) + `wrap_compound_elision.rs` (JSON value rule emits leaf, not wrap, for scalar branches).

6. **EBNF Minus-in-Keyword-Seq codegen extension** (absorbed from AY.W0.2 deferral per `docs/tranches/AY/audit/AYW0-ebnf-diag.md`). The catch-all stub at `crates/core/src/backend/rust/emitter/shapes/inline.rs:633-639` (`emit_branch_position_core`) emits `quote! { return Err(()); }` for Negate/Minus/Alt/TokenDispatch positions inside Keyword Seq branches. EBNF's `terminal` (`character - '"'`) violates the assumption. Lift `emit_minus_tape` / `emit_negate_tape` / Alt + TokenDispatch dispatch into per-position context inside `emit_branch_position_core` (~80–150 LOC). Re-activate `parse_single_rule` + `parse_multi_rule` in `crates/core/tests/ebnf_prettify.rs` and `serialize_roundtrip::ebnf_rule` (remove `#[ignore]` annotations).

### AY.W2.3 E-graph G1-G4 universal rewrites (parallel agent A, after W2.2)

Per AX.W10 absorbed scope. Add to `egraph/rewrites.rs` (or `egraph/rules/*.rs` if modularised):

- **G1** `alt_of_single`: `Alt([x]) → x`.
- **G2** `repeat_of_single`: `Repeat { inner: x, lo: 1, hi: 1 } → x`.
- **G3** `wrap_of_epsilon_scalar`: `Wrap { body: Alt([leaf_rule, ε]) } → leaf_rule` when leaf_rule's projection is scalar. **Critical for JSON value wrap elision.**
- **G4** `concat_literals`: `Concat(Literal(a), Literal(b)) → Literal(concat(a, b))`.

Each rewrite carries:
- `check()` — preconditions guarding the rewrite (e.g. G3 requires leaf_rule to have scalar TypeDesc + the epsilon branch to be provably-unreachable-on-nonempty-input).
- `apply()` — constructs the rewritten IR.
- Per-rule unit test in `crates/ir/tests/egraph/rewrite_*.rs`.

**Sub-gate**: fresh JSON tape record count on twitter reduced ≥ 40% post-G3 vs W1 baseline; 13 parity + canonical harnesses green (rewrites preserve semantics).
