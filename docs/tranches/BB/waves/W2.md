# BB.W2 — Bench/Test Surface Separation

**Opens after**: W1 close
**Agents**: 2 parallel
**Hard gate**: Routine correctness runs no longer pay heavy bench or profiling costs by default, and the separated surfaces remain green.

## Scope

1. Separate routine correctness loops from heavy bench and profiling
   loops.
2. Move or gate heavyweight surfaces so default `test` commands stay
   focused.
3. Prove lower routine cost without losing the heavyweight surfaces.

## Phase sub-items

### BB.W2.1 Routine/heavy split

Mechanism: separate routine test commands from heavy bench/profiling
commands in the public workflow and CI surface.

Files touched: `Makefile`, `.github/workflows/ci.yml`.

Sub-gate: routine and heavy surfaces are distinct command paths.

### BB.W2.2 Instruction sync

Mechanism: update tranche and profiling instructions so the new split is
the documented default.

Files touched: `docs/instructions/tranche/SPEC.md`,
`docs/instructions/PROFILING.md`.

Sub-gate: instructions match the separated command surface.

## Hard gate

1. Routine correctness commands no longer invoke heavy benches or
   profiling prep by default. Artefact:
   `docs/benchmarks/post-BB-W2-commands.txt`.
2. Routine command timings improve versus post-W1. Artefact:
   `docs/benchmarks/post-BB-W2-mid.json`.
3. The heavy surfaces remain reachable and documented. Artefact:
   `docs/benchmarks/post-BB-W2-commands.txt`.
