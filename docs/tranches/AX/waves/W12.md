## Phase sub-items

### W12.1 `classify_shape(egraph, root) -> ShapeTag` reader

```rust
pub fn classify_shape(egraph: &EGraph, root: EClassId) -> ShapeTag {
    match egraph.extract_canonical(root) {
        GrammarENode::KwWs(_) => ShapeTag::KwWs /* or Keyword */,
        GrammarENode::PhfDispatch(_) => ShapeTag::Keyword,
        GrammarENode::PhfLoop(..) => ShapeTag::Keyword /* or sub-variant */,
        GrammarENode::OperatorChain(..) => ShapeTag::Pratt,
        GrammarENode::ClassifyByteLoop(..) => ShapeTag::Unordered,
        GrammarENode::Seq(children) if is_object_pattern(egraph, children) => ShapeTag::Object,
        GrammarENode::Seq(children) if is_array_pattern(egraph, children) => ShapeTag::Array,
        GrammarENode::Regex(sid) if is_quoted_string(sid) => ShapeTag::String,
        GrammarENode::Regex(sid) if is_numeric(sid) => ShapeTag::Number,
        GrammarENode::Literal(sid) => ShapeTag::Scalar,
        GrammarENode::Alt(branches, _) if all_refs(branches) => ShapeTag::Wrap,
        GrammarENode::Seq(children) if is_arglist_pattern(children) => ShapeTag::ArgList,
        GrammarENode::Seq(children) if is_flat_pattern(children) => ShapeTag::Flat,
        GrammarENode::Map { fn_id, .. } if is_hregex_pattern(fn_id) => ShapeTag::HRegex,
        _ => ShapeTag::None,
    }
}
```

~150 LOC total. Pattern helpers (`is_object_pattern`, `is_array_pattern`, etc.) are 3-5 LOC each inspecting e-class children via `egraph.class(cid)`.

### W12.2 Regression harness

Pre-retirement oracle: capture every rule's `ShapeTag` output from the hand-coded detectors (snapshot into a JSON file per grammar). Post-retirement: run extraction-based classifier; assert tag matches snapshot for every rule. Wave fails on any mismatch.

```rust
#[test] fn shape_retirement_parity_<grammar>() {
    let ir = load_ir("<grammar>");
    let snapshot = load_snapshot("shape_tags_<grammar>.json");
    let egraph = build_and_saturate(&ir);
    for (rule_id, expected_tag) in snapshot {
        let actual_tag = classify_shape(&egraph, egraph.lookup_rule(rule_id));
        assert_eq!(actual_tag, expected_tag, "rule {} tag mismatch", rule_id);
    }
}
```
