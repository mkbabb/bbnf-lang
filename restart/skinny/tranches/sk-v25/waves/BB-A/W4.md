# BB-A.W4 — test isomorphism and artifact provenance

## Authority

Consumes BB-A.W1 graph identities and BB-A.W2 ownership. This wave changes test and
artifact topology without changing approved semantics.

## Implementation

1. Move every inline production test into an external tree isomorphic to its source
   package/module. Rehouse flat test piles under the production feature they prove.
2. Preserve private-invariant testing through narrow test-support APIs or black-box
   behavior; do not expose production internals merely to relocate a test.
3. Create a placement checker mapping source modules to allowed test paths and
   rejecting inline `cfg(test)`, orphan tests, ambiguous targets, and stuttering
   names.
4. Give every generated artifact a manifest/header with source, semantic inputs,
   generator, toolchain, command, configuration, and output digests. Verify before
   compile, package, copy, WASM load, or browser consumption.
5. Replace manual artifact copies with one producer and declared load paths. Large
   generated files remain cohesive if splitting would obscure provenance.
6. Add mutation probes for moved/missing/stale/tampered artifacts, wrong toolchain,
   omitted semantic input, misplaced tests, and undeclared generated files.

## Evidence gates

- Zero production inline test modules; the external tree has total source mapping
  and no flat catch-all pile.
- Clean regeneration twice yields identical bytes and manifests.
- Every generated/copy/load edge has one producer and verified consumer.
- Ordinary build/test/package/browser gates fail on each provenance mutation.
- Baseline behavior remains equal or an intentional break has an adjudicated new
  oracle.

## Completion

Tests and artifacts become first-class, directed graph planes with no hidden
authority inside production files or manual outputs.
