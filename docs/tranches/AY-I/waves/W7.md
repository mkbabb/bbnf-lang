# AY.W7 — Shared-Fact Optimizer Integration

**Opens after**: W6 close
**Agents**: 3 parallel
**Hard gate**: Packed-layout, direct-to-struct, Pratt lowering, and structural-side decisions are driven by shared facts and objective data; duplicated dead surfaces are retired or consumed; eager JSON improves again versus post-W6.
**Status**: superseded — AY-II/W0 consolidates (substrate collapse + emitter unification + navigate_tape retirement). The W7 execution agent stalled on a rollback-invariant violation in `TapeBuilder::note_push`; the audit triumvirate (`../../AY-II/audit/AUDIT-{A,B,C,D}-*.md`) diagnosed the draft fix as a band-aid and prescribed architectural consolidation in AY-II. This wave's scope routes forward in full.

## Scope

1. Introduce a shared fact and cost surface for the parity-critical
   layout and emission decisions that AY owns.
2. Wire materialization, recognizers, CSP, and e-graph consumers to
   that same fact surface for packed-layout, projection, and lowering
   decisions.
3. Retire or activate any dead optimization surfaces that still fail
   the substrate-with-consumer rule, preferring fold into the canonical
   normalizer/transform pipeline over raw deletion when a surface still
   preserves live canonicalization value.
4. Make the structural scan/index a real shared same-path consumer
   surface for the canonical runtime with explicit no-regression proof.

## Phase sub-items

### AY.W7.1 Shared fact substrate

Mechanism: define one parity-critical fact bundle and cost objective at
compile/pipeline time, covering packed layout, projection admission,
Pratt lowering, and structural-side use so downstream passes stop
recomputing incompatible summaries. This explicitly includes wiring
`egraph::CostWeights` into the still-isolated consumers in
`byte_class.rs` and `payload/layout.rs`, so AY stops paying for a
shared cost model that only some production consumers read. It also
includes a first-class structural-scan policy: the shared plan chooses
when the canonical path pays scan cost (eager, lazy, or bounded-region)
and every admitted mode must prove consumer benefit with no declared
regression.

Files touched: `crates/core/src/pipeline/compile.rs`,
`crates/ir/src/passes/recognizers/mod.rs`,
`crates/ir/src/passes/payload/layout.rs`,
`crates/core/src/generate/regex/byte_class.rs`,
`crates/core/src/backend/rust/emitter/shapes/dispatcher.rs`,
`crates/tape/src/structural_scan.rs`.

Sub-gate: a compile-time wire-contract test proves the fact bundle is
materialized and handed to downstream consumers.

### AY.W7.2 Consumer wiring

Mechanism: route e-graph, materialization, CSP, and inline-analysis
consumers through the shared fact surface for parity-critical emission
decisions, then emit the chosen decisions into generated runtime code.
This sub-phase explicitly owns `NogoodStore` wiring into production CSP
search if it survives the parity-critical threshold.

Files touched: `crates/ir/src/egraph/mod.rs`,
`crates/ir/src/passes/materialization/mod.rs`,
`crates/ir/src/passes/csp_strategy/mod.rs`,
`crates/csp-solver/src/solver/nogoods.rs`,
`crates/core/src/backend/rust/analysis/inline.rs`,
`crates/core/src/backend/rust/emitter/grammar.rs`.

Sub-gate: `cargo expand -p bbnf --bench json_monolithic` shows emitted
decision surfaces sourced from the shared optimization plan.

### AY.W7.3 Dead-surface retirement or activation

Mechanism: delete duplicated or consumerless optimization surfaces, or
wire them to production consumers in the same wave if they survive the
parity-critical threshold. For canonicalization-bearing e-graph rules
and transform surfaces, the default action is fold into
`crates/ir/src/passes/transform/*` or the normalizer pipeline rather
than raw deletion; delete only when the surface is truly dead after the
fold audit. Structural scan does not get sidecar status here: W7 must
integrate it as a real shared consumer on the one canonical path and
close with non-regression proof.

Files touched: `crates/core/src/pipeline/compile.rs`,
`crates/ir/src/passes/transform/mod.rs`,
`crates/core/src/backend/rust/emitter/grammar.rs`,
`crates/core/src/backend/rust/emitter/shapes/dispatcher.rs`,
`crates/tape/src/structural_scan.rs`,
`crates/core/tests/gate_predicate_wire_contract.rs`.

Sub-gate: every surviving optimization surface has a wire-contract test
and at least one production consumer.
