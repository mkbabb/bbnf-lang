# AZ-II.W1 — Stage A (tape-compiler builds struct-compiler candidate)

**Opens after**: AZ-II.W0 close
**Agents**: 2 parallel (`project_types` closure on BBNF; xtask regen struct-emission mode)
**Hard gate**: `project_types` closes on `grammar/bbnf/bbnf.bbnf`;
`StructRegistry` populated with `BbnfAst`, `Rule`, `Expr`, etc.;
`cargo xtask regen --emit-mode struct` lands; Stage A
produces struct-writing parsers; Stage A output archive captured
on the full BBNF fixture corpus; no regression on AZ-I close
matrix.
**Status**: planned

## Scope

1. Run `project_types` to fixed point on BBNF's grammar. Resolve
   every named-rule type, every `->` field, every compound closure.
   Hard-fail-and-block on any unclosed edge.
2. Populate `StructRegistry` with BBNF's full layout set: `BbnfAst`,
   `Rule`, `Expr`, `Ident`, `Param`, `TypeExpr`, `Import`,
   `Directive`, `Comment`, `RegexPattern`, `RegexHir`, and per-
   variant sub-shapes.
3. Add a struct-writing emission mode to the rust emitter under
   `crates/core/src/backend/rust/emitter/`, exposed via
   `cargo xtask regen --emit-mode <tape|struct>`. Both modes
   (tape-writing and struct-writing) are present in W1.
4. Wire the BBNF runtime loader to read `BbnfAst` via the struct
   path when the flag is enabled.
5. Run Stage A: pre-AZ-II compiler (tape-based, from AZ-I close)
   builds the AZ-II-candidate compiler with struct-writing mode
   enabled. The resulting xtask regen pipeline emits struct-writing
   parsers.
6. Capture Stage A output: run `cargo xtask regen --emit-mode
   struct` against every `.bbnf` fixture (`grammar/*/*.bbnf`,
   `tests/fixtures/*.bbnf`, `grammar/bbnf/bbnf.bbnf` itself) and
   archive the parsed output to
   `docs/benchmarks/AZ-II/W1/stage-a-output/<fixture>/`.
7. Land `tests/bbnf_self_parity.rs`: compares `BbnfAst` parsed via
   struct path against the hand-maintained in-memory IR surface.

## Phase sub-items

### AZ-II.W1.1 — `project_types` closure on BBNF

Fix-point `project_types` over `grammar/bbnf/bbnf.bbnf`. Register
every Named rule; verify with the audit pass.

Sub-gate: `cargo test -p bbnf-ir --test project_types_bbnf` green;
audit pass reports 100% on BBNF.

### AZ-II.W1.2 — xtask regen struct-emission mode

Add the struct-writing code generator alongside the tape-writing
generator under `crates/core/src/backend/rust/emitter/`. CLI flag
on `cargo xtask regen --emit-mode <tape|struct>` selects between
the two. Struct-writing mode reads `StructRegistry` and emits
field-write calls per rule.

Sub-gate: `cargo xtask regen --emit-mode struct --check` green;
generated parser compiles and runs.

### AZ-II.W1.3 — Stage A build + output capture

Stage A sequence: checkout AZ-II W1 branch, `cargo clean`,
`cargo build -p bbnf` with AZ-I close toolchain. Run
`cargo xtask regen --emit-mode struct` on the full fixture corpus;
capture output.

Sub-gate: `docs/benchmarks/AZ-II/W1/stage-a-output/` populated
for every fixture; every fixture parses without error.

### AZ-II.W1.4 — Self-parity harness

`tests/bbnf_self_parity.rs` compares `BbnfAst` (struct path)
against the hand-maintained IR surface. Covers every fixture.

Sub-gate: `cargo test --test bbnf_self_parity` green on every
fixture.

## Hard gate

1. `project_types` closes on BBNF without build-stop diagnostic.
2. `StructRegistry` populated for every Named rule in BBNF.
3. IR audit pass: 100% `->` coverage on BBNF.
4. `cargo xtask regen --emit-mode struct` produces parsing parsers
   for every `.bbnf` fixture.
5. Stage A output archive complete under
   `docs/benchmarks/AZ-II/W1/stage-a-output/`.
6. `bbnf_self_parity` test green on every fixture.
7. No regression on AZ-I close matrix (JSON, CSS L4, Sheets,
   BBNF tape-path entries all at AU parity).
8. `cargo nextest run --workspace --profile ax-iter` ≥ 1480 pass
   (post-B4 baseline per `docs/tranches/B4/FINAL.md` test summary).

## Reversal criteria

`project_types` fails to close on BBNF → build-stop diagnostic
identifies the unclosed edge; W1 re-plans to resolve (likely via
grammar edit or `project_types` pass fix).

`bbnf_self_parity` fails on any fixture → revert the struct-
emission path for that fixture class; investigate drift source;
re-attempt within the wave or escalate to W0 re-plan.
