# BC.W1 — Rust Emitter Refactor to IR Contract

**Name**: W1 — Rust Emitter Refactor to IR Contract
**Opens after**: BC.W0 close (IR contract spec landed; `crates/ir/src/typed_ir/` module exists; Rust emitter begins consuming typed IR)
**Hard gate**: `cargo xtask regen --check` produces byte-identical output to BB close artefact for all nine grammars; per-grammar parity tests against sonic-rs / lightningcss / simdjson / cssparser remain green
**Status**: superseded — split into BC.W1a (full Rust emitter refactor across nine grammars) + BC.W1b (regen-equality byte-verification) per `audit/HARDENING-PLAN-2026-05-03-02-sequencing-discipline.md:59` (BC02-1). See `waves/W1a.md`, `waves/W1b.md`.

## §1 Deliverable

Hereupon `crates/core/src/codegen/rust/emitter.rs` becomes `crates/core/src/codegen/rust/lower.rs` consuming `TypedIRNode`; existing emitter shapes — struct_direct, dispatcher, alt_dispatch — refactor to consume typed IR; codegen surface preserves Lock 1 (direct-to-struct visible-and-internal across all nine grammars per BB.W1 generalisation) and Lock 9 (slice-borrow primary). The refactor is a rename + interface narrowing, not a behaviour change; regen-equality between pre- and post-refactor xtask output is the gate.

The wave completes BC.W0's closure; W0 lands the contract spec + the lowerer skeleton consuming `TypedIRNode`; W1 lands the per-shape consumer refactor + the regen-equality gate. The two waves are sequenced because the spec must precede the consumer refactor: Era V's failure mode — substrate-first/consumer-later — is structurally precluded only when the consumer arrives in the same or next wave (per `audit/HARDENING-PLAN-PROMPT.md` Lane 2).

The behavioural invariant: every Rust source byte the emitter produces in BC.W1 close must match BB close artefact byte-for-byte. The performance invariant: per-grammar parity tests against sonic-rs / lightningcss / simdjson / cssparser remain green (no regression on `JsonParser::parse(twitter.json)` ≤ 400 µs, `parse(bootstrap.css)` ≤ 3.5 ms, `parse(canada.json)` ≤ 3.0 ms, etc.).

## §4 Invariants

§I1. **Lock 5 (IR + per-backend lower)**: the Rust emitter consumes typed IR exclusively at W1 close; this completes BC.W0's contract codification.

§I2. **Lock 1 (direct-to-struct visible-and-internal)**: the refactor preserves direct-to-struct emit; no `OpenFrame` resurrection; no tape rebranded as fast-path.

§I3. **Lock 9 (slice-borrow primary)**: the refactor preserves `&'i str` slice-borrow primary surface; the three-surface API (parse / parse_in / parse_owned) from BB.W4 remains intact.

§I4. **Regen-equality**: byte-for-byte equality between pre- and post-refactor xtask output is the W1-G3 gate; behavioural drift forbidden.

§I5. **Same-wave consumer**: the typed IR alphabet from BC.W0 is the input; the four shape consumers are the W1 wave's same-wave consumers.

§I6. **Lock 13 (cohesive encapsulation)**: each shape consumer (struct_direct, dispatcher, alt_dispatch, pratt) is a sibling under `crates/core/src/codegen/rust/shapes/`; each < 500 LOC after BA.W2 splits; each exports a uniform sub-API (`fn lower(&typed_ir, &mut ctx) -> TokenStream`).

## §5 Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| Regen-equality fails because the typed IR lowering at `crates/ir/src/typed_ir/lower.rs` introduces structural drift | Medium | The lowering is one-to-one for most variants; round-trip test in BC.W0 §2.3 asserts no information loss; CSS L4's 14-variant Alt is the worst case and is round-trip-tested. |
| Per-grammar parity tests fail because shape consumers re-derive a structural decision the typed IR pre-resolved | Medium | The lowerer reads `Layout` + `TypeDesc` from the typed IR node directly; the shape consumers must not re-derive these; W1-G2 gate catches direct grammar-IR access. |
| Performance regresses because the typed-IR consume adds an indirection | Low | The lowerer reads pre-resolved fields; the indirection is a single struct field access, not a re-derivation; samply trace at W1 close compares to BB close samply. |
| The rename from `emitter.rs` to `lower.rs` breaks an external doc reference or import path | Low | `rg -n 'use bbnf::codegen::rust::emitter\|bbnf::backend::rust::emitter' crates/ tests/ docs/` enumerates all references; rename pass updates each. |
| The four shape consumers (struct_direct, dispatcher, alt_dispatch, pratt) refactor in different sub-commits and the regen-equality gate fails partway | Medium | Each sub-milestone (§2.1-§2.4) lands a regen-equality sub-check on the affected grammar slice; the W1-G3 gate is the union closer. |
| The CSS L4 14-variant Alt (the most complex Alt-dispatch in any grammar) regresses behaviour due to a subtle typed-IR lowering bug | Medium | The CSS L4 14-variant Alt is the worst-case test; the round-trip fixture from BC.W0 §2.8 exercises it; W1-G4 (parity tests) catches behaviour drift. |
| The Pratt emit (BBNF's `binary_factor`) regresses because the typed-IR `dispatch: AltDispatch::Pratt` annotation is incorrectly resolved | Low | BB.W3 lands the Pratt auto-detection per `audit/HARDENING-SYNTHESIS-2026-05-03.md:107-127`; the typed IR's dispatch annotation is grammar-derived; W1's regen-equality test asserts byte-identical Pratt output. |

## §10 Mechanical posture

The wave is mechanical: rename, narrow, verify. No new behaviour; no new shapes; no new emitters. The risk surface is the renames + interface narrowing breaking regen-equality; the gate is `cargo xtask regen --check` returning byte-identical output to BB close. Per-shape consumers refactor disjointly so a regression in one does not block the others; sub-milestone gates catch per-shape drift; the W1-G3 gate is the union closer.
