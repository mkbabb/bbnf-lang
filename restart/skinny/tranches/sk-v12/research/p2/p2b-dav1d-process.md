## §2 — Candidate primitives (each: shape + scalar-ref status + arch + P1 antecedent)

Admission process common to every candidate:

1. Scalar oracle first. The scalar function is the executable spec for output, invalid input, tail behavior, carry state, and fallback. If the scalar reference does not exist, S-P3 may only schedule a scalar-reference wavelet, not native wiring.
2. Differential checkasm second. Candidate and scalar run on cloned inputs, alignment windows, random/adversarial seeds, corpus windows when available, source-immutability checks where the function accepts mutable input, stack canary, signal guard, and strict failure mode. Bug-injection proof is required for new harness infrastructure.
3. Feature/fallback third. Every native body is feature-gated and has the scalar oracle as fallback. Hand-written `asm!` is allowed only when the equivalent intrinsic is absent or when Lock 16 already allows the exact instruction family.
4. Caller micro-proof fourth. A primitive can pass checkasm and still stay proof-only. The same packet must show a caller-local movement on representative slices for the selected generated non-JSON baseline or guard surface, with strict output equality.
5. Same-wave consumer last. No orphan primitive. The same wave must consume it in a generated/runtime/parser path, report/gate lane, or explicit oracle. Otherwise S-P3 marks it support-only/proof-only and cannot shortlist it as a row mover.
6. REDRESS pre-block check. If the candidate touches a rejected family, the packet must show fresh P1 antecedent, materially different framing, and a non-JSON priority-compatible consumer before any implementation work.

## §4 — Risks (REDRESS entries any candidate must NOT re-open)

1. Generated non-JSON priority is binding. W1a admitted only a report lane, W1b rejected the generated non-JSON baseline, and W2 blocked before implementation (`skinny/REDRESS.md:3282`-`skinny/REDRESS.md:3344`). S-P3 must not use this P2-B candidate list to schedule JSON-direct work before the baseline priority.
2. Direct residual rows are a measured fixpoint, not a live candidate pool. REDRESS 119 closes 13 residual direct rows and REDRESS 120 routes SK-V12 to the generated non-JSON baseline (`skinny/REDRESS.md:3495`-`skinny/REDRESS.md:3553`). Candidate caller proofs may use JSON guards only as preservation checks.
3. Retained structural or sidecar routes stay blocked. PASS-2 rejects second scans, retained cursors, aux density tables, and parser-owned structural projections (`restart/prompts/skinny/PASS-2-RESEARCH.md:126`-`restart/prompts/skinny/PASS-2-RESEARCH.md:131`); Lock 1 has the same constraint (`restart/locks/LOCKS.md:52`).
4. String and Unicode proof-only routes stay constrained. REDRESS 106 rejected the full string primitive micro-proof as a production route (`skinny/REDRESS.md:3150`-`skinny/REDRESS.md:3170`), REDRESS 117 blocks escaped segment entry, and REDRESS 82 rejects the single-quartet Unicode classifier route (`skinny/REDRESS.md:2285`-`skinny/REDRESS.md:2313`; `skinny/REDRESS.md:3434`-`skinny/REDRESS.md:3460`).
5. Numeric shortcuts stay constrained. REDRESS 80 rejects mantissa-widen on the then-current baseline (`skinny/REDRESS.md:2215`-`skinny/REDRESS.md:2250`), and REDRESS 114 rejects numeric direct closure (`skinny/REDRESS.md:3357`-`skinny/REDRESS.md:3380`). A digit-span candidate must be grammar-neutral and attached to the selected baseline.
6. Bitmap helper proof does not imply parser admission. REDRESS 88 rejects PMULL prefix-XOR as a default hot body (`skinny/REDRESS.md:2508`-`skinny/REDRESS.md:2540`), and REDRESS 89 rejects the CTZ bulk consumer despite correctness/checkasm proof (`skinny/REDRESS.md:2542`-`skinny/REDRESS.md:2580`).
7. Output digest is not a parser primitive by default. REDRESS 118 blocks the output digest/hash host-sink entry route (`skinny/REDRESS.md:3462`-`skinny/REDRESS.md:3494`). Treat digest as an oracle/report gate unless S-P3 names a real selected-baseline consumer.
8. Parse-only and Mode III remain nonproducer evidence. P1 converged with Mode III absent and PMU/cycles profile-only (`restart/skinny/tranches/sk-v12/research/p1/hardening/HARDENING-S-P1-CONVERGED.md:56`-`restart/skinny/tranches/sk-v12/research/p1/hardening/HARDENING-S-P1-CONVERGED.md:59`), and P1-E carries nonproducer pre-blocks (`restart/skinny/tranches/sk-v12/research/p1/p1e-hot-leaf-attribution.md:324`-`restart/skinny/tranches/sk-v12/research/p1/p1e-hot-leaf-attribution.md:336`).
