# AZ.W1 — Tape Substrate Inline + Finalise Fusion

**Opens after**: W0 close
**Agents**: 2 parallel (inline + finalise-fuse)
**Hard gate**: `push_structural` + `finalise` symbols absent from `nm` on all 4 prebuilt bench binaries; samply self-time on those symbols < 5% total; JSON twitter bench ratio bbnf/sonic ≤ 5× (from current 7.93×); all 13 parity + canonical harnesses remain green (247/1 ignored); bootstrap regen cycle-1 = cycle-2 byte-identical.

## Scope

1. **Inline `Columns::push_structural`** into per-rule emit call sites. Currently declared `#[inline]` at `crates/tape/src/columns.rs:321` but emitted as cross-crate call boundary (A1 §3, A2 §3, A3 §3). Change to `#[inline(always)]` + verify LLVM inlines at every call site OR refactor push_structural into a macro + grammar-emit the expansion.
2. **Fuse `finalise` post-pass into emit path**. `tape::finaliser::finalise` runs a post-parse linear sweep populating `sib_skip` / `child_off` / `span_hi` backlinks. Per A3 L2: replace three per-parse `Vec<Option<u32>>` allocations with `[Option<u32>; 32]` stack buffers + fold each of the three post-passes into `close_compound` as back-patch calls. Finalise becomes no-op (or debug-assertion-only verification pass).
3. **Verify inlining via `nm` + samply**. Post-wave, the symbols must not export from the bench binary; self-time must shift into per-rule `parse_<shape>_<grammar>_<rule>` frames (invariant 22).

## Phase sub-items

### AZ.W1.1 push_structural inline (parallel agent A)

Mechanism:
- Change `#[inline]` → `#[inline(always)]` on `push_structural` + any adjacent hot-path helpers (`push_leaf_with`, `close_compound`).
- Run `cargo build --release` + `nm` verification on `json_monolithic-<hash>` bench binary. Expected: zero `push_structural` symbol exports.
- If `#[inline(always)]` alone fails (LLVM declines for size reasons), investigate per-call-site monomorphisation OR macro-ify and have shape emitters splice the expansion.

Files: `crates/tape/src/columns.rs`, possibly `crates/core/src/backend/rust/emitter/shapes/*.rs`.

**Sub-gate**: `nm target/release/deps/json_monolithic-<hash> | grep push_structural` returns zero.

### AZ.W1.2 finalise fusion (parallel agent B)

Mechanism:
- Identify the three data dependencies `finalise` resolves: `sib_skip` (parent→first-sibling-of-next-open), `child_off` (parent→first-child-offset), `span_hi` (parent→last-child-end-span).
- Add back-patch helpers on `TapeBuilder` + `Columns` that stamp these fields at `close_compound(open_idx, close_idx)` time rather than post-parse sweep.
- Delete `finaliser::finalise` body OR retain as debug-only invariant verifier.
- Replace three `Vec<Option<u32>>` allocations with `[Option<u32>; 32]` stack buffers (A3 L2 — matches AW-V FrameStack depth cap).

Files: `crates/tape/src/finaliser.rs`, `crates/tape/src/columns.rs`, `crates/tape/src/builder.rs`.

**Sub-gate**: bootstrap regen cycle-1 = cycle-2 byte-identical (tape semantics preserved); all 13 parity harnesses green; `nm` shows no `finalise` symbol export OR samply self-time < 1% on `finalise`.
