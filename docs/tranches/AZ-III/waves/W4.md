# AZ-III.W4 - Benchmark, Profile, and Workspace Truth

**Name**: W4 - Benchmark, Profile, and Workspace Truth
**Opens after**: W0p - Throughput Substrate, W1 - O5 Reclose, W2 -
Semantic Parity and Bootstrap Canonicalization, W3a - Fact and Type
Authority, W3b - CSP Strategy Globalization, and W3c - Projection
Consumption and Registry Authority close.
**Agents**: up to 10 parallel for preparation; measurements are orchestrator-serialized.
**Hard gate**: workspace health, structural audits, profiles, and the 17-entry benchmark matrix are refreshed on the final AZ-III struct-only path.
**Status**: planned

## Scope

1. Run workspace test health with the tranche profile.
2. Run payload coverage, StructRegistry, IR coverage, regen, and static
   no-legacy audits.
3. Compile and run the 17-entry matrix sequentially.
4. Capture profile evidence for hot-path regressions without beginning BB
   optimization.
5. Publish `docs/benchmarks/post-AZ-III.json` with no placeholders.

## Agent Units

### AZ-III.W4.1 Workspace and Structural Audits

- Mechanism: run nextest/build/regen/static scans.
- Files: evidence docs; source only if a gate command surface is broken.
- Sub-gate: archived outputs with exact pass/fail counts.

### AZ-III.W4.2 Bench Harness Preflight

- Mechanism: compile bench targets and repair harness-only blockers.
- Files: bench harnesses and scripts.
- Sub-gate: all matrix binaries compile before measurement.

### AZ-III.W4.3 Serialized Measurement

- Mechanism: orchestrator runs matrix sequentially, records commands and
  units.
- Files: benchmark artifacts.
- Sub-gate: `post-AZ-III.json` contains no `NOT_MEASURED`, placeholder,
  stale AZ-II, or narrative-only rows.

### AZ-III.W4.4 Profile Truth

- Mechanism: capture profiles for regressions and hot paths; do not tune.
- Files: profile artifacts.
- Sub-gate: profile files are archived and referenced by W5.

## Triumvirate Dispatch

If workspace health, structural audits, benchmark harness preflight, or
profile capture reveals an unclear source-vs-harness root cause, pause
measurement and dispatch research, plan augment/synthesis, and
redress/redeployment agents. W4 - Benchmark, Profile, and Workspace Truth
may resume only after the synthesis updates this wave or opens a
same-tranche redress wave.

## Hard Gate

1. Workspace health command output, including `cargo fmt --all -- --check`,
   `cargo clippy --workspace --all-targets --profile ax-iter`, and the
   chosen workspace test command, is archived.
2. Structural audits, including payload coverage, StructRegistry, IR
   coverage, regen, and no-legacy scans, are archived with pass/fail
   counts.
3. Every 17-entry benchmark matrix row is compiled, measured, and written
   to `docs/benchmarks/post-AZ-III.json` with command, unit, and commit.
4. `rg -n "NOT_MEASURED|placeholder|post-AZ-II|TBD"` over
   `post-AZ-III.json` and W4 artefacts is archived with no active hits.
5. Profiles exist for any regression consumed by the close report and are
   referenced from W5 - Terminal Close and Handoff.

## Format And Lint Cadence

Run `cargo fmt --all -- --check`, bench-target compile checks, and
`git diff --check` after each harness integration batch. Measurement
commands are serialized by the orchestrator; no parallel benchmark run
may close a W4 gate. Run generated checks only if harness work changes
grammar generation. Before W4 - Benchmark, Profile, and Workspace Truth
closes, rerun `cargo fmt --all -- --check` and `git diff --check`.
