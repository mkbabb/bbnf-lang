# AY-II.W0 — Architectural Consolidation

**Opens after**: tranche open
**Agents**: 3 parallel (W0.a / W0.b / W0.c on disjoint file bounds)
**Hard gate**: `push_compound` retired; `note_push` + `SIB_SKIP_STAMPED_BIT` retired; `Columns::rollback_to` is the sole retry-path truncation primitive; `navigate_tape` retired; `Parsed::to_value()` routes through visitor-lane codegen; full fat-LTO bench matrix runs clean on all 5 bench binaries with no panic.
**Status**: planned

## Scope

AY-I's pass-I audit triumvirate (`../audit/AUDIT-{A,B,C,D}-*.md`)
prescribes three convergent architectural transpositions plus one
dead-surface retirement. W0 lands them atomically in a single wave
with three parallel sub-agents on disjoint file bounds. No part of
the W5.a/b/c + W6.a/b/c experiment survives unchanged — the
substrate collapses back to the pre-W5 post-pass stamping
discipline plus a first-class rollback primitive.

1. Retire `TapeBuilder::{open_compound, close_compound, open_stack,
   note_push}` + `TapeRec::SIB_SKIP_STAMPED_BIT`.
2. Restore `finaliser::finalise` as the sole `sib_skip` stamp
   source (pre-W5 / AU-era discipline).
3. Add `Columns::rollback_to(open_offset)` as the rollback
   primitive. Replace every `columns_mut().truncate(...)` site in
   the emitter with `rollback_to`.
4. Full abrogation of `push_compound`: every shape emitter
   (`object.rs`, `array.rs`, `wrap.rs`, `keyword.rs`, `inline.rs`,
   `alt_dispatch.rs`, `flat.rs`, `pratt.rs`, `compound.rs` if
   present, `dispatcher.rs`) emits compounds via a unified API.
   AUDIT-C's wording "one emission API" is satisfied by either
   (a) a single renamed API that is morally `push_compound`
   extended with an open/close contract that is rollback-aware, or
   (b) keeping the open_compound/close_compound names and
   rebuilding them against `Columns::rollback_to`. W0.a chooses
   the name; W0.b + W0.c adopt it.
5. Retire `runtime/path.rs::navigate_tape` + its 4 test assertions.
   Simplify `__path_walk` to classic `TapeCursor` descent.
6. Move `Parsed::to_value()` onto the visitor-lane emission
   discipline: the grammar-emitted `<Grammar>::parse_with_visitor<V>`
   codegen already hits 0.99× sonic geomean (AUDIT-D §2); default
   `to_value()` instantiates a `ValueVisitor` against that path
   and retires the tape-reconstruction route.
7. Fix the CSS + Sheets fat-LTO panic (`columns.rs:409 index out
   of bounds`) — transitively resolved by landing `rollback_to` in
   the retry-IIFE sites.
8. Regen bootstrap at W0 close; `cycle-1 == cycle-2` byte-identical.

## Phase sub-items

### AY-II.W0.a — substrate rollup

Owner: tape crate.

Mechanism:
1. Delete `TapeBuilder::open_compound`, `close_compound`,
   `open_stack`, `OpenFrame`, `note_push`.
2. Delete `TapeRec::SIB_SKIP_STAMPED_BIT` and its associated
   `extra`-bit accessor; reclaim the bit for future use OR leave
   reserved with a `// reserved` doc comment.
3. Restore `finaliser::finalise` as the sole stamp source for
   `sib_skip` (strip the skip-pre-stamped branch added at W5.a.1).
4. Add `Columns::rollback_to(open_offset)` — truncates `kinds`,
   `flags`, `extra`, `span_lo`, `span_hi`, `child_off`, `sib_skip`,
   `pay_narrow`, `pay_wide`, `pay_agg`, `frame_depth` back to the
   slot count corresponding to `open_offset`. Idempotent.
   Documented against the "single source of liveness" invariant.
5. Unified compound emission API — `W0.a` picks the name (either
   rehabilitated `open_compound/close_compound` against rollback-
   aware semantics, OR a single `push_compound_open(kind, span_lo)
   -> TapeOffset` + `close_compound(offset, span_hi)` pair — pick
   the idiomatic variant in W0.a's worktree and publish the
   signature for W0.b + W0.c to adopt).
6. Update `close_compound` tests in `crates/tape/tests/close_compound.rs`
   to assert finaliser-only stamping semantics. Retire
   `w5_close_stamp_activation.rs` (tests a retired substrate).
7. `crates/tape/src/cursor.rs` — any `SIB_SKIP_STAMPED_BIT`
   reference removed; cursor reads the post-finaliser authoritative
   `sib_skip`.

Sub-gate: `cargo iter-check` exit 0; `make iter-test-leaf` exit 0;
`nm` of any bench binary shows `note_push` absent;
`Columns::rollback_to` symbol present.

### AY-II.W0.b — emitter unification

Owner: emitter shapes.

Mechanism:
1. Every `quote! { ... builder.push_compound(...) ... }` emitter
   site converts to the unified API chosen by W0.a. Every
   `builder.mark_children()` + paired `push_compound` pattern
   folds into the unified API.
2. Every retry-IIFE site (`wrap.rs`, `keyword.rs`, `inline.rs`,
   `alt_dispatch.rs`, `flat.rs`, `array.rs` Shape-2, `pratt.rs`
   reducer) replaces its `columns_mut().truncate(save)` with
   `columns_mut().rollback_to(open_off)`.
3. `shapes/dispatcher.rs` + `shapes/mod.rs` auditing for
   dispatch-table hygiene under the unified API.
4. Bench-critical shapes (object, array) produce `cargo expand`
   evidence showing zero `push_compound` calls in
   `target/expand/ay-json.rs`.

Sub-gate: `cargo iter-check` exit 0; `target/expand/ay-json.rs`
shows zero `push_compound` references and rollback_to at every
retry site.

### AY-II.W0.c — runtime consolidation

Owner: runtime + view + value-materialize.

Mechanism:
1. `runtime/path.rs::navigate_tape` + associated helpers delete
   (AUDIT-B classified as DEAD). `__path_walk` simplifies to
   classic `TapeCursor` descent; the 4 substrate-nav test
   assertions in `value_api_apples_to_apples.rs` retire or migrate
   to cursor-API assertions.
2. `Parsed::to_value()` retargets onto the visitor-lane emission
   path: instantiate a `ValueVisitor` that implements the
   grammar-emitted `ObjectVisitor`, `ArrayVisitor`, `StringVisitor`,
   `NumberVisitor`, `KeywordVisitor` sub-traits; dispatch via
   `<Grammar>::parse_with_visitor` on the source span; return the
   constructed `<Grammar>Value`.
3. `view/mod.rs` + `view/value.rs` audit for any residual
   tape-reconstruction fallback path; retire it.
4. `shapes/value_materialize.rs` adjusts for the new default:
   `materialize_projection_*` helpers continue to serve the
   admitted direct-to-struct projections; the overall value-API
   routing changes to visitor-lane-first.

Sub-gate: `cargo iter-check` exit 0; `make ay-test-value-api`
exit 0; `bbnf_value_twitter / sonic_value_twitter <= 1.20` on a
spot bench (full matrix at W1).
