## Phase sub-items

### W9.1 IR mining: `fork_cut_byte`

In `list_rules.rs::mine_list_rules`:
1. When an entry rule admits as list-shaped (existing), recurse into `Repeat.inner`.
2. Find first `single_byte_literal` whose byte ∈ `structural_alphabet` AND whose pairing is balanced (open/close both present).
3. Emit close byte as `fork_cut_byte`. Else `None`.

### W9.3 `parallel.rs` module

```rust
pub fn fork_shape_parse<G: ShapeGrammar>(
    input: &[u8],
    idx: &StructuralIndex,
    cut_byte: u8,
    break_even: usize,
    worker_fn: fn(&[u8], &StructuralIndex, &mut TapeBuilder) -> Result<u32, ParseErr>,
    master: &mut TapeBuilder,
) -> Result<u32, ParseErr> {
    // 1. Scan idx.positions + idx.kinds for depth-0 occurrences of cut_byte
    //    using structural_digraph_mask for paired-open tracking
    // 2. Byte-balanced shard selection (target_byte = w × input.len() / n_workers;
    //    pick nearest depth-0 close)
    // 3. rayon par_iter over chunks; each worker calls worker_fn with chunk + sub-index
    // 4. Merge per-chunk builders via TapeBuilder::merge_from(...)
}
```

Per AW-IV.W4.4 learnings (doc-parallel-heuristic §7): shards must start at structural boundaries; byte-balance not item-count-balance; sub-index materialisation inside `par_iter`; worker count clamped.

### W9.4 Dispatcher consumer

`shapes/dispatcher.rs` emits `parse()` with fork branch:

```rust
pub fn parse(input: &str) -> Result<Parsed<'_, Self>, ParseErr> {
    let mut builder = TapeBuilder::with_capacity(GRAMMAR_PROFILE.capacity_for(input.len()));
    const STRUCTURAL: StructuralAlphabet = StructuralAlphabet::from_profile(&GRAMMAR_PROFILE);
    let idx = scan_structural(input.as_bytes(), &STRUCTURAL);

    let root_off = if let Some(cut_byte) = GRAMMAR_PROFILE.fork_cut_byte
        && input.len() > fork_break_even(&GRAMMAR_PROFILE, rayon_num_threads())
    {
        fork_shape_parse::<Self>(input.as_bytes(), &idx, cut_byte,
                                  parse_<grammar>_<root>, &mut builder)?
    } else {
        parse_<grammar>_<root>(input.as_bytes(), &mut 0, &mut state, &mut builder)?
    };
    Parsed::new(builder.finish(), input, root_off)
}
```
