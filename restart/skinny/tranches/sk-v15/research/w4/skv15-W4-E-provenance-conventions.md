# SK-V15 W4-E Provenance Conventions

Existing generated headers in the repository:

- Skinny generated Rust files:
  `// @generated by skinny bbnf-codegen; do not edit by hand.`
- Root grammar-generated files:
  `//! AUTO-GENERATED from \`[workspace.metadata.bbnf.grammars]\` — do not edit manually.`
  plus a regenerate command line.

For W4, line-1 provenance must be emitted by the root runtime generator and
then reproduced by the non-writing root runtime check. The marker is not proof
unless the generated bytes match the checked-in files.

## W4 Header Choice

Use root-runtime-specific line-1 provenance:

```text
// @generated by xtask regen-<grammar>; do not edit by hand.
```

This keeps W4 compatible with the provenance scan expected by the W4
verification scout and distinguishes root runtime projections from skinny
runtime generation and root grammar generation.

The header must be attached after Rust pretty-printing so ordinary comments are
not discarded by `syn` parsing and `prettyplease` rendering. The check path must
compare the header-bearing final bytes.

## Paper-Close Guard

Do not present JSON headers, CSS config facts, or existing grammar-generated
headers as proof for root Pattern H. Root runtime files currently reference
generated grammar modules, but those references are not provenance for the
runtime projection files themselves.
