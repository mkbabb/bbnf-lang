## §3 — Falsifiability binding (named corpus rows + Mbps thresholds)

Universal threshold rule:

- JSON admission uses strict same-plane sonic-rs only:
  `Track 1 Mbps > sonic-rs strict Mbps + 1`, strict equality, same corpus,
  same output plane, measured-row validation, no lossy/permissive anchor.
- CSS admission uses strict same-plane lightningcss only:
  `Track 1 Mbps > lightningcss_mbps + 1`, strict equality, feature-coverage
  parity, and cssparser/golden independent oracle.
- Every behavior wave must also keep no silent demotion: all previously
  admitted A/GO rows and the admitted CSS row either maintain or record
  measured REDRESS.

  batched/policy-level and row-moving.
