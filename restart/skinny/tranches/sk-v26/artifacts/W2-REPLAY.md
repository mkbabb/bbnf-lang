## What replay means

The complete packet is the inverse boundary. A serialized
`bbnf.compiled-module.v5` carries compile options, source map, program,
node remap, dependency solution, type solution, analysis facts, lowering plan,
event plan, and exact generated source and manifest strings.
`replay_compilation` and `CompiledModule::from_replay_json` parse that
envelope, extract only the logical path and source bytes, recompile them with
the caller-supplied options, compare every component and generated byte, and
require canonical bytes to equal the input packet. Packet options must equal
the caller options, including the required `analysis_work` bound.

Individual stage packets are deterministic serialization receipts only.
Although each has a versioned envelope, W2 supplies no public standalone
inverse that can deserialize one isolated stage into a trusted compiler
carrier. A caller also cannot substitute compile options: a mismatch against
the packet options is a typed `ValueMismatch` rejection.

The edit law uses the public stateful `CompilationSession`.
`apply_edit` updates owned source bytes and fully recompiles the immutable
carrier; the four-state edit test compares every resulting stage packet with a
separate fresh compile of the same current bytes. Reversed or out-of-bounds
ranges are atomic errors, while a valid edit that creates rejected source
remains the session's current source. This is deterministic full invalidation,
not an incremental compiler, incremental type solver, or edit-preserving
cache.

`ScalarEventPlan` does not embed or clone `LoweringPlan` in v4. The complete
packet carries them separately, and emission receives both revision-equal
sealed inputs.

Public compiler IDs are exact capabilities containing the full source
`Revision` plus a private local `u32` ordinal. Same-index IDs from a foreign
revision are rejected before lookup; IDs from identical deterministic rebuilds
interoperate; an edit invalidates old IDs and restoring identical bytes
restores the revision. Persistent arenas store only the four-byte private
ordinals, not repeated capabilities. Public capability types and sealed
carriers are deliberately opaque to serde: five compile-fail cases prove that
local index types cannot be imported, capability fields and local accessors
cannot be used, and neither a naked capability nor a sealed `Program` can be
serialized. Private replay adapters intentionally emit only compact local
ordinals under revision-bearing carriers—wire ordinals are not public
capabilities.

Thirteen compiler-colocated unit laws include the prior eleven
representation/remap/order/occurs laws plus minimum-lattice and overflow-
diagnostic permutation laws. The compactness subset enforces: source
rows are capped at 48/40/48 bytes; syntax rows at 56/40/48/40/12; type rows at
32/40/40/12/48; analysis rows at 24/24; lowering rows at
12/48/40/48/40; and event rows at 32/32. All local index types are four bytes;
`Option<PlanNodeIx>` is at most eight bytes; the audited public `NodeId` is 36
bytes and appears only at API boundaries.

The type claim is first-order structural principality for one admitted
`Program`; it is not Hindley-Milner inference, polymorphic generalization, row
typing, or a claim that arbitrary parallel sealing orders converge.

## Analysis repair laws

`bbnf.analysis-facts.v3` is a new semantic carrier, not a renamed v1 packet.
It uses a three-state minimum-consumption lattice—finite, empty language, and
overflow—and rejects any surviving overflow with typed
`MinimumConsumptionOverflow`. Sequence, record, and non-entry descendant
witnesses are covered; 16 discovery permutations produce identical accepted
facts or identical overflow diagnostics.

Analysis visits SCCs in deterministic dependency-first order, with stable
local-ordinal tie breaking. Acyclic components take one pass. The recursive
budget fixture rejects at one pass and converges in exactly two. The required
`analysis_work` budget is charged before terminal and regex initialization,
during range/component scheduling, and before component node/rule evaluation.
Singleton acyclic reference chains of 8, 64, and 256 rules consume exactly
seven `work_units` per rule; the exact cap passes and one less returns typed
`ResourceLimit`.

## Interpretation

Passing replay establishes internal coherence of this frozen, first-order W2
vertical and its generated correctness controls. It does not establish SOTA
performance, a totality cutover, a Rust/ASM backend, universal grammar
coverage, standalone inversion of individual stage packets, or incremental
compilation. The checked-in scalar profile supplies affirmative evidence
against promotion.
