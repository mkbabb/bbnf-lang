# BA.W2 — Host-Binding Isomorphism (TS + Python) + E2E Integration

**Opens after**: W1 close (Rust `path!` + executor landed; per-grammar
bench green).
**Agents**: 2 parallel, disjoint file bounds.
**Hard gate**: TS template-literal tag and Python callable surface
the same path IR, type checker, and executor as the Rust frontend —
identical signatures (modulo host-language syntax), identical error
taxonomy, identical response shapes on a round-trip fixture.
**Status**: planned.

## Scope

1. Land the WASM sub-crate `crates/bbnf-path-ts/` exporting the
   shared path IR + type checker + executor to TypeScript.
2. Land the PyO3 sub-crate `crates/bbnf-path-py/` exposing the same
   surface to Python.
3. Land the e2e round-trip test exercising identical fixtures across
   Rust / TS / Python and asserting identical response shapes.

`feedback_isomorphic-api` is the binding rule: same argument
shape, same return shape, same error taxonomy. `feedback_wasm-subcrate-pattern`
places the WASM binding as a workspace sub-crate, isomorphic to the
Python binding location.

## Phase sub-items

### BA.W2.1 — TS template-literal tag

`crates/bbnf-path-ts/` is a `cdylib` workspace member exposing
`compile_path(path: &str, grammar: &str) -> JsValue` via
`wasm-bindgen`. The TS frontend is a template-literal tag
`` path`$.users[0].name` `` that invokes the WASM-exported
validator at load time (build-time for bundlers with constant
folding) and produces a typed accessor closure over the shared
struct-tree view.

Sub-gate: TS tag compiles against the JSON grammar; a malformed
path surfaces the same grammar-aware error as the Rust frontend.

### BA.W2.2 — Python callable

`crates/bbnf-path-py/` is a PyO3 sub-crate exposing
`path(path_str: str, grammar: str) -> TypedPath`. Python is
runtime-typed per language idioms, but validation and execution
dispatch through the same Rust path IR.

Sub-gate: Python `path()` compiles against the JSON grammar; a
malformed path raises `PathError` carrying the same diagnostic
fields as the Rust frontend.

### BA.W2.3 — E2E round-trip

`tests/path_isomorphic.rs` drives citm.json / sample tailwind CSS
fixtures through Rust / TS (via `wasm-bindgen-test`) / Python
(via PyO3 test harness) and asserts identical response shapes.

Sub-gate: round-trip test green for JSON + CSS L4 across all
three host bindings.
