# Tranche B4 — Codegen-Emission Correctness + W0' Re-land Hardening

B4 is a focused tranche covering two scopes: the bbnf self-host xtask
regen codegen-emission correctness fix (W0), and consumer-fixture polish
for the runtime parser substrate produced after the parser-baseline
restoration era (W1). The bbnf grammar regen reaches the codegen
TokenStream emission stage cleanly and then fails downstream at
`syn::parse2` with "expected loop or block expression". The TokenStream
that `generate_all` produces contains a position-context defect: an
expression slot receives a syntactic form that Rust's grammar admits
only as a statement or block. W0 traces the emitter responsible, fixes
the wrapping at source, and verifies end-to-end that
`cargo xtask regen --grammar bbnf` writes a populated, valid
`crates/core/src/grammar/generated/bbnf.rs`.

## Architectural thesis

The `generate_all` pipeline composes per-rule TokenStream fragments
under a single outer `mod` block. Every fragment must either be a
self-contained item or, where it lands inside an expression context,
emit a parenthesised or braced expression form that Rust's grammar
admits in that slot. A defect in any one shape's emitter that produces
an item-shaped fragment in expression context, or an unbraced
control-flow form where a block expression is required, surfaces only
when the offending grammar exercises that emitter shape — which is why
the json grammar (smaller, narrower shape coverage) regenerates
cleanly while the bbnf self-host grammar (which exercises every shape
the emitter family supports, including Pratt operator chains, deep
alternation, recursion-elimination dispatchers, and visitor codegen)
fails at `syn::parse2`.

The fix lives at the offending emitter, not at the `syn::parse2`
callsite. A `try-or-fallback` path that elides invalid fragments would
ship a parser missing whichever grammar feature the emitter is
responsible for; the only acceptable resolution is a single-source
correction at the emitter that produces the malformed fragment.

The xtask regen path is the only consumer of `generate_all` for
non-checked-in output. Once W0 closes, the parser-baseline-restoration
substrate produced by the previous tranche reaches end-to-end parity:
parser, lowering, IR, codegen TokenStream, `syn::parse2`,
`prettyplease`, file write — every phase exits 0 against every grammar
in the workspace manifest.

### W0 — Codegen-emission correctness

**W0.1**: Reproduce + capture. Apply phase-instrumented xtask regen on
the worktree; save the panic context plus the emitted TokenStream
excerpt to `docs/tranches/B4/audit/W0-bbnf-regen-panic.txt`.

to identify which Rust syntax position rejects the emission. Cross-
reference against the bbnf grammar's structural features that diverge
from json: Pratt operator chains, alternation depth, recursion-
elimination dispatchers, visitor codegen scope. Pinpoint the emitter
file:line responsible.

**W0.3**: Fix at source. Apply the correction at the offending
emitter. KISS DRY single-purpose. No tangent refactors. Strip
diagnostic dumps before commit.

**W0.4**: Verify. xtask regen on json (sanity), xtask regen on bbnf
(load-bearing), workspace check, tape tests. Compare bbnf.rs line
count against the existing `generated.rs` reference (~30K lines).

**W0.5**: Cherry-pick + close. Fix commit + audit doc commit on
master.

## Escape clause

**No mid-tranche scope absorption.** If W0's investigation reveals the
defect compounds across multiple emitter shapes (i.e., the malformed
fragment surfaces in more than one independent emission path), each
additional emitter is named as a sub-phase under W0 and lands on a
fresh disposable worktree per the parallel-probe protocol. Scope
expansion records as PROGRESS.md amendments.

**No `git reset --hard` on master.** All cherry-pick failures resolve
via `git cherry-pick --abort` + manual investigation, or sub-agent
redispatch.

**No work-around at the `syn::parse2` callsite.** The W0 fix lives at
the emitter that produces the malformed fragment, not at the consumer
that rejects it.
