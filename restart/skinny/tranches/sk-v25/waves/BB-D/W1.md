# BB-D.W1 — all grammar consumers through the sealed runtime

## Goal

Prove the staged compiler/runtime on deep and broad real grammars with no hidden
grammar-specific fallback.

## Implementation

1. Use JSON, CSS, and BBNF as deep controls for recursion, heterogeneous values,
   recovery, spans, documents, prettification, and generated runtime paths.
2. Route every remaining manifest grammar through Program -> Graph -> TypeSolution
   -> AnalysisFacts -> LoweringPlan -> generated/interpreted runtime.
3. Compare acceptance, value tree, typed path, span, diagnostic, recovery,
   serialization, prettification, and reparse across approved incumbent oracles and
   intentional-breaking rulings.
4. Add negative/adversarial/deep/budget corpora and metamorphic parse-print-parse,
   incremental edit, and generated-vs-interpreter comparisons.
5. Delete per-grammar hidden dispatch/fallback/runtime modules after the same-change
   generic/generated consumer passes.

## Gates

- Every manifest grammar has total stage artifacts and a real runtime consumer.
- Differential observations match; approved breaks are explicit versioned truth.
- Budget/exhaustion/invalid host/type/layout paths publish no partial value.
- Disconnecting any sealed stage or generated schema fails a targeted gate.
- Repeated outputs and reports are byte-identical.

## Completion

The complete grammar portfolio proves breadth without semantic special cases.
