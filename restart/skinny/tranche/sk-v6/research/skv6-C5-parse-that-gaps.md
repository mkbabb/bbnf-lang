## Bottom line

The parse-that primitive layer is not missing basic semantic coverage. It already has scalar oracles for quoted strings, Unicode escape decoding, UTF-8 codepoint/block validation, number spans, integer/f64 materialization, plus AArch64 helpers for string-special masks, UTF-8 blocks, and `\uXXXX` x4 decode. The active gaps are narrower:

1. retained trusted string matching still has a generated/control-shape gap, not a raw UTF-8 validation gap;
2. Unicode escape decoding is not missing x4 SIMD semantics; escaped-string row misses are materialization/output-contract costs;
3. UTF-8 scan-boundary strictness is not admitted for hot generated JSON rows because current strictness remains view-boundary;
4. number spans and Eisel-Lemire are wired; direct number misses are generated array/emission shape;
5. direct string/unicode materialization under the current semantic digest workload is exhausted by REDRESS 66-69, and REDRESS 70 points to an explicit host/API output-schema contract rather than another local parse-that primitive.

## REDRESS implications for C5

- REDRESS 50 rejects parse-time retained aux side tables. Projection facts are real, but writing them in the SOTA parse path regressed twitter/citm/canada; admissible retained facts must remain typed event/tape consumption with string/number rescans inside grammar-neutral primitives (`REDRESS.md:715-740`).
- REDRESS 51 and 53 reject parser-local event/structural cursors and second scanners. String/number/literal bytes cannot be skipped behind a sidecar cursor; structural projection must be the parser substrate, not an add-on (`REDRESS.md:742-767`, `:784-813`).
- REDRESS 52 preserves the direct-string diagnosis: generated direct `unicode_mixed` attributes to `parse_object_value_at_direct` plus `unescape_json_string` (`REDRESS.md:769-782`).
- REDRESS 54 and 55 reject sink-local decoded stats and quote-source streaming hash. The source-hook seam remains canonical, but the default allocate-then-contiguous-hash baseline must be beaten, not replaced by another streaming hash helper (`REDRESS.md:815-882`).
- REDRESS 66-69 exhaust direct receiver/allocation/byte-output/fact-hash routes under the current semantic digest workload (`REDRESS.md:1688-1886`).
- REDRESS 70 shifts direct closure from another local parse-that primitive to output schema: for JSON-class direct-to-struct, the output schema is not in the JSON grammar and must be supplied as a host/API type contract consumed by DirectBuild field facts (`REDRESS.md:1890-1940`).

## Admissible primitive vocabulary after C5

Existing/admitted surfaces:

- `tiny_plain_string_probe`: keep; deleting it is blocked by retained short-string regressions.
- `quoted_span_match_trusted`: current trusted matcher; candidate work should collapse control/tail behavior without raw UTF-8 fusion.
- `string_special_mask_16`: existing scalar/AArch64 primitive; no new wide scanner without fresh profile proof.
- `utf8_validate_block_16` and `utf8_codepoint_validate_scalar`: semantic validators exist; scan-boundary strictness is not yet admitted for generated JSON rows.
- `hex4_to_u16`, `hex4x4_to_u16x4`, `surrogate_pair_join`: existing Unicode escape primitives; x4 SIMD is already consumed.
- `decimal_span_scan`, `decimal_span_to_i64`, `decimal_span_to_u64`, `decimal_span_to_f64`: existing number span/materializer primitives.
- `source_span_string_event` / `needs_unescape_flag`: current direct seam; source hooks are admitted but not sufficient.

Candidate/gap surfaces:

- `trusted_string_special_tail_scan` or a collapsed `trusted_quoted_span` helper: retained string-boundary/control gap, with strict no-sidecar/no-threshold guard.
- `number_sink_emit_typed` / `numeric_array_materialize_emit`: generated direct numeric emission shape, not a new number parser.
- `direct_field_materialize_event` driven by explicit host/API schema facts: output-contract gap, not an escaped-string writer.

Blocked/rejected names for future dispatch:

- parse-time retained aux table, sparse aux side table, EventCursor, parser-local structural-mask cursor;
- raw UTF-8 fused string scan as a carried SK-V5 close;
- sink-local exact decoded stats, quote-source streaming hash;
- direct source-hook receiver shortcut, parser-owned decoded scratch, byte-output `unescape_json_string` under the current `Cow<str>` API, semantic string fact hashing under the current digest workload;
- treating current `real_typed_struct` as a SOTA close without an explicit schema-source contract.
