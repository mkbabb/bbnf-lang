# BB-B.W0 — semantic algebra and mutation oracles

## Goal

Make every incumbent type/IR/analysis lie executable before building replacements.

## Implementation

1. Specify laws separately for semantic types, record/variant rows, grammar
   dependency, nullability/FIRST/width facts, storage layout, and stage identity.
   No operator may inhabit two algebras by convenience.
2. Add property tests for reflexive/symmetric/transitive equality, substitution
   idempotence, complete zonking, row permutation/extension/lacks, duplicate labels,
   occurs checks, alpha-equivalent recursion, post-solve generalization, stable
   diagnostics, and 1,000+ constraint permutations.
3. Add IR witnesses for stable identity, exact serialization, source-qualified
   spans, explicit remaps, dangling/cross-revision IDs, cycles, incremental edits,
   and deterministic traversal under insertion/hash/worker permutations.
4. Turn every silent fallback into a mutation: ignored type error, default Span,
   unknown-as-layout, missing obligation, unlawful right overwrite, contradictory
   ground loop, partial facts, and consumer disconnect.
5. Build grammar-shaped fixtures for every operator, recursive rules, generic host
   maps, parse result plus diagnostics, `CssValue`, heterogeneous alternatives, and
   all manifest grammars. Observe values/types/spans/diagnostics/generated consumers.
6. Ingest Value V-next's frozen historical BBNF host capsule only through the exact
   content receipt recorded in parse-that `VALUE-VNEXT-COORDINATION.md`. Treat its
   BBNF v1.0.5 / parse-that 0.6 CSS executions as casualty and semantic-oracle
   evidence, never as the target architecture or a compatibility duty. A deliberate
   clean break must name the changed behavior and replacement; it must not add a shim.

## Gates

- Incumbent implementations fail every named counterexample for the named reason.
- The oracle bank is deterministic and detects deletion/disconnection mutations.
- No property silently discards exhausted cases; budgets return typed evidence.
- The historical CSS host capsule is reproducible from clean archives without
  reading either active dirty worktree, and every divergence has a named disposition.
- Two critics and an adjudicator rule algebra and corpus completeness.

## Completion

The replacement can be rejected independently of its internal design. Performance
baselines are recorded but never override semantic failures.
