## Scope

W0 closed JSON peer gates; W1 closed CSS L4 typed parity +
Sheets self-parity + the AZ-I.W0 baseline absorption. W2 closes
the meta-grammar (BBNF) AND the tranche close ceremony.
Audit consolidation §MERGES item 2 folds AY-II-I.W4 + W5 into
this wave; §MERGES item 6 folds the BBNF totality + `@pretty`
byte-identity gates into the same close cycle; §MERGES item 7
folds the per-wave plus tranche-close BBNF samply duplication
into a single capture at W2.c.

BBNF is the meta-grammar. Its typed surface IS grammar
structure — Rule shapes, Body shapes (Alt / Seq / Repeat /
Optional / Group / Ref / Literal / Regex / TypeAnnotation /
Negate / Minus), Directive shapes (`@pretty`, `@token`, `@ws`,
`@import`, `@host`, `@debug`, `@recover`). Its self-host
identity is the canonical end-to-end check for the whole
language. W0 / W1 proved the post-B5 fused-substrate truth on
JSON / CSS / Sheets; W2 proves it on BBNF, the only grammar
where a substrate failure manifests as an outright inability to
regenerate the parser — and where the post-B2 `cargo xtask regen
--check` is the native gate. The close ceremony aggregates.

No external peer bench exists for BBNF. JSON has sonic-rs and
simd-json; CSS has lightningcss and cssparser; Sheets and BBNF
are unique. W2's close criteria for BBNF key against three
internal-truth anchors: (a) self-host identity via
`cargo xtask regen --check` byte-equal output (the post-B2
native gate); (b) grammar-meta projection totality under the
1:1:1 wire contract; (c) samply-verified fused-pipeline
attribution on `bbnf_self`. All three are falsifiable runtime
facts, not internal ratios. This satisfies AY-III invariant 3
("peer-first close gates only; no internal ratios") because
BBNF's identity gate is keyed against `cargo xtask regen
--check` byte-equal — the post-B2 build-time codegen
transposition's native gate, which IS the peer surface for a
self-hosting language.
