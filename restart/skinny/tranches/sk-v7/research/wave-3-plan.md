# SK-V7 Wave 3 Plan: Capacity-Hinted Numeric Vec Real-Typed Expansion

## Intervention

Capacity-hinted numeric Vec real-typed expansion.

This W3 cycle will teach the generated typed-direct schema about Vec capacity
hints, key those hints into helper identity, and add concrete same-wave
real-typed consumers for the mesh and marine_ik fixtures. The intervention is
bounded to generated typed-direct materialization and bench harness exposure; it
does not reopen retained-parse direct materializers, benchmark-private sinks, or
capacity prescans.

- `skinny/crates/codegen/src/lib.rs`

## Source Shape

- Replace `DirectTypeRef::Vec(Box<DirectTypeRef>)` with a named-field Vec
  variant carrying `inner` and `capacity_hint`.
- Extend `type_key()` so capacity-hinted Vec helpers cannot collide with
  unhinted Vec helpers or differently hinted Vec helpers.
- Emit Vec helpers with `Vec::with_capacity(capacity_hint.unwrap_or(0))`.
- Add `DirectScalar::U32` support and generated `parse_u32` lowering so integer
  array-heavy fixtures do not widen every index/color vector to `u64`.
- Add real typed schemas for the actual fixture shapes:
  - mesh uses `positions`, `tex0`, `colors`, `influences`, `normals`,
    `indices`, and `batches`.
  - marine_ik uses `geometries[].data` vectors for `uvs`, `vertices`,
    `skinWeights`, `skinIndices`, `normals`, and `faces`.
- Regenerate `generated_real_typed.rs` from `xtask`.

The W3 SPEC mentions `Vec<f32>` in the mesh sketch, but the current direct
schema exposes `F64` and not `F32`. This plan keeps floats as `f64` to preserve
the scalar substrate already present in the generated parser while adding `U32`
for the integer vector side requested by SPEC §5.

## Same-Wave Consumer Declaration

The generated helpers are consumed in the same wave by bbnf-bench
`real_typed_struct` rows for `mesh` and `marine_ik`, with Track 1 routed through
the generated typed-direct parser and Track 2 routed through the independent
typed oracle. Checksums must include the large numeric vectors so the consumers
cannot degrade into skip-only typed rows.

with a REDRESS entry and measurement table. A fail rejects the source route with
a REDRESS entry naming the measured failure mode and next candidate shape.
