**Opens after**: W2 close
**Agents**: 2 parallel (emitter + bench lane)
**Hard gate**: `parsed.to_value::<T>()` method emits for every grammar where T is the grammar-derived `<Grammar>Value` enum; new eager-lane bench `bbnf_value_<fixture>` vs `sonic_value_<fixture>` across 5 JSON fixtures; JSON twitter eager bbnf/sonic ratio ≤ 3× (invariant 24); canonical-serialize parity (W1r.2) green on materialized → serialized round-trip.

## Scope

1. **Emit grammar-derived `<Grammar>Value` enum** from IR's `TypeDesc`. One enum per grammar. Variants: one per non-transparent rule, shape determined by `TypeDesc` (scalars → primitive field, sequences → `Vec<<Grammar>Value>`, alternations → nested enum).
2. **Emit `Parsed::to_value<T>() -> T` method**. Walks tape once, materialises owned `<Grammar>Value` tree. Allocation via the existing arena hooks in `Parsed<R>`.
3. **Add eager-lane bench** `crates/core/benches/json/value.rs` (extend existing file): `bbnf_value_<fixture>` = `JsonParser::parse(src).unwrap().to_value::<JsonValue>()` vs `sonic_value_<fixture>` = `sonic_rs::from_str::<sonic_rs::Value>(src)`. Work-matched per invariant 24.
4. **Round-trip parity**: `serialize_compact(parse(src)) == serialize(parse(src).to_value())` — materialization preserves semantic tree. Add to `json_canonical_parity.rs` as a new `#[test] fn canonical_parity_via_value_<fixture>`.

## Phase sub-items

### AZ.W3.1 `<Grammar>Value` emitter (parallel agent A)

Emit one Rust enum per grammar derived from IR. Shape rules:

- For each non-transparent rule: one variant named after the rule.
- Rule body's `TypeDesc` determines the variant's payload:
  - `Span` → `&'p str` field.
  - Scalar primitive (`U8`, `F64`, etc.) → primitive field.
  - `Tuple([...])` → struct variant with named fields (named from rule's Seq child bindings, or positional if unnamed).
  - `Vec<T>` → `Vec<<Grammar>Value>` field.
  - `Named(sid)` → `<Grammar>Value` recursive.
  - Alt-rooted rules → enum-in-enum: the variant holds a sub-enum named `<RuleName>Alt`.

Emit a `pub trait ToValue<T>` in `bbnf::runtime::value` + per-rule `impl ToValue<<Grammar>Value> for <Rule>View<'_>` that walks the view + constructs the enum.

Files: `crates/core/src/backend/rust/view/value.rs` (new, ~400 LOC), `crates/core/src/backend/rust/emitter/grammar.rs` (wire-up, +50 LOC), `generated.rs` (regen).

**Sub-gate**: `cargo expand -p bbnf --test json_canonical_parity` shows `pub enum JsonValue { … }` + per-variant `impl ToValue<JsonValue> for *View<'_>`.

### AZ.W3.2 `Parsed::to_value` method (part of W3.1 scope)

Add to `crates/core/src/runtime/parsed.rs`:

```rust
impl<'p, R: Root> Parsed<'p, R> where R::View<'p>: ToValue<R::Value> {
    pub fn to_value(&self) -> R::Value {
        self.view().to_value()
    }
}
```

Plus `type Value: ToValue<Self::Value>` on the `Root` GAT so callers can name the type uniformly.

**Sub-gate**: `parsed.to_value()` compiles for any grammar; type-system forces the grammar to have emitted a `<Grammar>Value`.

### AZ.W3.3 Eager bench lane (parallel agent B)

```rust
fn bbnf_value_twitter(b: &mut Bencher) {
    let src = load_fixture("twitter.json");
    b.iter(|| {
        let parsed = JsonParser::parse(&src).unwrap();
        black_box(parsed.to_value())
```

Files: `crates/core/benches/json/value.rs` (extend existing). **Sub-gate**: `cargo bench -p bbnf --bench json_monolithic_value --profile release` produces 10 new entries.
