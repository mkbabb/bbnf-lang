# B6.W0 — Bootstrap Two-Stage Fast-Path

**Opens after**: tranche open
**Agents**: 1 serial
**Hard gate**: cold `cargo xtask regen --grammar bbnf` ≤ 3 min; post-W0 `bbnf.rs` byte- or `prettyplease`-format-equivalent.
**Status**: planned

## Scope

W0 is the highest-leverage lever in the tranche. The current
`cargo xtask regen --grammar bbnf` entry runs the full 17-pass
IR pipeline through `compile_paths_request` plus `generate_all`
plus `prettyplease::unparse` on every regen, dominated by the
`BbnfBootstrap::parse` step over the BBNF self-host source. Cold
wall measures ≥ 5 min on the post-B5 substrate. The structural
lower bound — CSP-only parse plus emit, with the IR pipeline
re-used from a cached input — is ~60–90 s. The gap is ~3 min of
recoverable wall the dev loop pays on every regen.

W0 closes the gap with a two-stage fast-path:

1. **Phase-1 CSP-only parser** — replaces the
   `BbnfBootstrap::parse` call at `xtask/src/regen.rs:222` for
   the BBNF self-host grammar. The CSP-only entry constructs the
   minimal AST surface the IR pipeline consumes; it does not
   construct the full structural tape. The IR pipeline's `compile_
   paths_request` accepts the smaller surface via the existing
   `CompileRequest` channel.
2. **Hand-written direct-descent CSP parser** — `xtask/src/csp_
   descent.rs`, ~250 LOC. Recursive-descent over the BBNF facets
   the CSP scheduler needs at xtask time: rule decls, alt /
   sequence / repeat / map-arrow / closure / call. The parser
   is intentionally narrow — it parses the BBNF self-host
   grammar only, not arbitrary BBNF; broader applicability is a
   B7 successor concern.

The legacy path preserves under `--no-fast` for one tranche
cycle. B7's named restoration wave retires the flag once the
fast-path's empirical bug rate over the AY-III tranche is
zero. Per SPEC §Transitional fallback during elimination
waves, the flag is a declared transitional path — the only
permitted shadow surface in B6 — and not a permanent shim.

The wave's combined LOC budget is ~450: ~250 for `csp_descent.rs`,
~150 for the `regen.rs` two-stage entry edit, ~50 for the
`main.rs` flag plumbing, plus the `crates/bootstrap/src/lib.rs`
documentation comment. The post-W0 `crates/core/src/grammar/
generated/bbnf.rs` regen output ships under the same wave but
counts against the per-tranche line-count budget separately.

### W0.1 csp_descent.rs creation (~250 LOC)

Direct-descent CSP parser for the BBNF self-host grammar.
Functions consumed by the phase-1 entry:

```rust
// xtask/src/csp_descent.rs

pub struct DescentResult {
    pub rules: Vec<RuleAst>,
    pub directives: Vec<DirectiveAst>,
}

pub fn parse_bbnf_source(input: &str) -> Result<DescentResult>;

// Internal recursive-descent helpers (not exported):
// - parse_rule, parse_alt, parse_seq, parse_atom
// - parse_map_arrow, parse_closure_expr, parse_call_expr
// - parse_directive (`@import`, `@host`, `@debug`)
// - skip_whitespace_and_comments
```

The parser carries a `Cursor<'a>` over the input bytes; consumes
the BBNF self-host grammar's known token set (identifiers,
operators, string literals, numeric literals, regex literals)
without constructing a full structural tape. Output is the
narrow `RuleAst` surface `compile_paths_request` accepts via the
existing CompileRequest channel.

Module structure (per `feedback_directory_modules` if file
exceeds 500 LOC during implementation): if the parser's natural
shape exceeds the LOC budget, split into
`xtask/src/csp_descent/{cursor.rs,rule.rs,expr.rs,directive.rs,
mod.rs}` along the natural concern boundary. The plan-time
budget targets one file; the implementation may split if the
shape demands.

### W0.2 regen.rs two-stage entry

Replace the `BbnfBootstrap::parse` call at `xtask/src/regen.rs:222`
with a two-stage entry. The current `compile_paths_request` call
takes a `&[PathBuf]`; the fast-path constructs the AST surface
directly via `csp_descent::parse_bbnf_source`, bypassing the
self-host structural parse, then routes the AST through the IR
pipeline's existing entry points.

Before:
```rust
let prepared = match compile_paths_request(&parser_attrs.paths, &request) {
    Ok(CompileOutput::Rust(prepared)) => prepared,
    ...
};
```

After:
```rust
let prepared = if fast_path && entry.ident == "bbnf" {
    let source = std::fs::read_to_string(&parser_attrs.paths[0])?;
    let descent = csp_descent::parse_bbnf_source(&source)?;
    compile_descent_request(descent, &request)?
} else {
    match compile_paths_request(&parser_attrs.paths, &request) {
        Ok(CompileOutput::Rust(prepared)) => prepared,
        ...
    }
};
```

The fast-path branch is gated on (a) `--fast` flag default-on,
(b) `entry.ident == "bbnf"` — only the self-host grammar
benefits at W0 scope; the other 8 grammars route through the
unchanged path. `compile_descent_request` is a new entry on the
IR pipeline that consumes the descent AST directly; it lives in
`xtask/src/regen.rs` as a thin wrapper around
`compile_paths_request`'s post-parse pipeline stages.

### W0.3 main.rs flag plumbing

Add `--fast` / `--no-fast` flags to the xtask CLI. Default
fast-path ON; `--no-fast` routes to the legacy entry. The flag
is a declared transitional path per SPEC §Transitional fallback
during elimination waves; the named restoration wave is B7.W0
(the first B7 wave once it dispatches).

### W0.4 bootstrap/src/lib.rs documentation

The current `crates/bootstrap/src/lib.rs` (19 lines) is a thin

appends a doc comment naming the W0 split point: phase-1 CSP-
only entry routes through `BbnfBootstrap::parse` only when

### W0.5 generated/bbnf.rs regen + walls capture

After W0.1–W0.4 land, run `cargo xtask regen --grammar bbnf`

## Phase

Five sub-phases, ordered serially within the single agent:

### B6.W0.1 csp_descent.rs creation

**Mechanism**: hand-written direct-descent CSP parser per the
scope above. Cursor-based; consumes the BBNF self-host token
set; emits the narrow AST surface the IR pipeline accepts.

**Files touched**: `xtask/src/csp_descent.rs` (create); optionally
`xtask/src/csp_descent/{cursor,rule,expr,directive,mod}.rs` if
the file's natural shape exceeds 500 LOC.

**Sub-gate**: parses `grammar/bbnf/bbnf.bbnf` to a `DescentResult`
without panicking; the AST surface contains every rule the
self-host grammar declares.

### B6.W0.2 regen.rs two-stage entry

**Mechanism**: replace the `compile_paths_request` call at
`xtask/src/regen.rs:222` with the conditional two-stage entry
described in scope.

**Files touched**: `xtask/src/regen.rs`.

**Sub-gate**: `cargo xtask regen --grammar bbnf` exit 0 on the
fast-path; emits a `crates/core/src/grammar/generated/bbnf.rs`
that compiles and roundtrip-tests pass.

### B6.W0.3 main.rs flag plumbing

**Mechanism**: add `--fast` / `--no-fast` to the xtask CLI;
default fast-path ON; thread the flag into `regen::run`.

**Files touched**: `xtask/src/main.rs`, `xtask/src/regen.rs`
(signature change on `run`).

**Sub-gate**: both `cargo xtask regen --grammar bbnf` (default,
fast-path) and `cargo xtask regen --grammar bbnf --no-fast`
(legacy) exit 0 and produce identical or
`prettyplease`-format-equivalent output.

### B6.W0.4 bootstrap/src/lib.rs doc

**Mechanism**: append a doc comment naming the W0 split point
and the legacy `--no-fast` route.

**Files touched**: `crates/bootstrap/src/lib.rs`.

**Sub-gate**: doc-only; no semantic change.

### B6.W0.5 generated/bbnf.rs regen + walls

**Mechanism**: `cargo xtask regen --grammar bbnf` (default fast-

1. **Cold wall**: `time -p cargo xtask regen --grammar bbnf`
   3-run median ≤ 3 min, with `make clean-incr` plus cache
   clear (`find . -name .bbnf-cache -exec rm -rf {} +`)
   between runs. Verification: `docs/benchmarks/post-B6-W0-
   walls.txt` 3 raw timings + median annotation.
2. **Output equivalence**: `crates/core/src/grammar/generated/
   bbnf.rs` byte- or `prettyplease`-format-equivalent to its
   pre-W0 state at HEAD `f34f2e80`. Verification: `git diff
   --stat` plus structural `cargo iter-check-full` exit 0;
   diff captured to `walls.txt`. Byte-equivalent is the
   primary acceptance; `prettyplease`-format-equivalent (post-
   `unparse` whitespace normalisation only, no semantic
   divergence) is the lower-bound acceptance per SPEC §Pre-
   regen vs post-regen evidence.
3. **Workspace nextest 1477/1477** post-W0 via `cargo iter-
   test`. Verification: nextest output captured to file then
   grep'd for `1477 tests run: 1477 passed`.
4. **`cargo xtask regen --check` exit 0** across all 9
   grammars post-W0; the fast-path emits the same byte
   sequence on second invocation (idempotent regen).
   Verification: `cargo xtask regen --check` exit code 0
   captured to `walls.txt`.
5. **`cargo bench-bbnf` median within 5 % of post-B5 baseline
   2.806 ms** — the fast-path is xtask-time, not parse-time;
   the gate confirms no accidental tape-side regression.
   Verification: `DIVAN_BENCH_FORMAT=json cargo bench-bbnf`
   captured to `docs/benchmarks/post-B6-W0-walls.json`; median
   diff ≤ 5 %.
6. **No `#[allow(...)]` introduced** anywhere in the diff
   outside macro contexts. Verification: `git diff master..
   | grep -E '#\[allow\(' | grep -v '#!\[allow'` returns
   empty (the inner-attribute `#![allow(...)]` block per
   per-grammar emission is the macro-context exception).

## Archaeology

The `BbnfBootstrap::parse` self-host parse path traces back to
the proc-macro retirement in B2.W0.c (commit `49656fd4` per
`docs/instructions/README.md` §Self-host circular-dependency
escape). Pre-B2 the regen ran `cargo expand -p bbnf-bootstrap`
plus a Python post-process under `scripts/bootstrap-bbnf.sh`
with cold wall ≥ 80 min; B2.W0.c retired that path in favour
of `cargo xtask regen` running the IR pipeline + emission
in-process. The post-B2 cold wall fell to ~5 min — a 16×
improvement — and the structural lower bound moved from "compile
the proc-macro twice" to "parse the self-host grammar via
`BbnfBootstrap::parse`".

W0's two-stage fast-path is the next structural improvement:
the `BbnfBootstrap::parse` step over `bbnf.bbnf` is itself the
~3 min residual; replacing it with a direct-descent CSP parser
that emits the narrow AST surface `compile_paths_request`'s
post-parse stages consume reduces cold wall to ~3 min — another
~40 % improvement over post-B2, with the structural lower bound
of ~60–90 s defining the W0 floor.

The hand-written CSP parser pattern has no prior bbnf-lang
attempt. Pre-existing CSP entry points live in `crates/csp-
solver/src/` (the general CSP substrate) and the egraph CSP
scheduler at `crates/egraph/src/csp_scheduler.rs`; W0's
`xtask/src/csp_descent.rs` is a different shape — a recursive-
descent parser scoped to the BBNF self-host facets, not a
generic CSP solver. The novelty is contained: 250 LOC of
hand-written direct-descent over a known grammar.

The risk profile of the hand-written parser is bounded by the
`--no-fast` legacy preservation: if the fast-path emits
divergent output on a real-world grammar variation, the legacy
path is one flag away. SPEC §Transitional fallback during
elimination waves declares this is the appropriate response;
the named restoration wave (B7.W0) retires the flag once the
empirical bug rate is zero across an AY-III tranche cycle.
