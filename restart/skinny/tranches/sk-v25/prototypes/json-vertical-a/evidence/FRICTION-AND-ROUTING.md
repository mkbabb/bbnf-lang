# Friction, deviations, and greater-tranche routing

## Friction

- The incumbent JSON grammar is consumed as locked bytes; the prototype does
  not reuse incumbent mutable IR sidecars, bytecode, generated runtime, or WASM.
- The source assay derives rule names, bodies, references, entry identity, and
  SCCs directly from BBNF module bytes. It accepts no schema/type/fact/lowering
  sidecar and hard-stops at the first plane the module slice cannot yet prove.
- The row assay is deliberately small: closed-row permutation and conflict laws
  are present, while open rows, lacks, occurs, level lowering, deep closure, and
  the independent V4-scale assay remain RED.

## Specification deviations and honest limits

- W2 remains RED: no type/fact/plan/value/artifact is published. Existing module
  implementations are unreachable scaffolding and earn no feature credit.
- Runtime/value choice is neither selected nor complete. There is no tape,
  recovery, rich diagnostics, serialization, CSS L4 semantics, executable WASM,
  browser/session/revision/job proof, or modular backend closure.
- The corpus is intentionally compact and no Apple PMU/profile claim is made.
- The author records implementation evidence only and credits no review or
  adjudication pass.

## Required greater-tranche RED work

Production selection requires heterogeneous BBNF, full CSS L4, regex, CSV,
math, and Google Sheets holdouts; a shared parse-that/BBNF cost model; modular
Rust/TypeScript/WASM backends; and measured ARM/aarch64 kernels. The later value
tranche must run full CSS L4 plus JSON through a grammar-derived hybrid value API
with tape and at least ten orthogonal complete, profiled implementations. It
must cover recovery, diagnostics, serialization, resource accounting, and
crossing protocols. None of those tails is authorized or implemented here.

Two fresh hostile gestalt passes must review tranche optimality, wave/spec
adherence, every implemented feature, this deviation ledger, and the exact
source/receipt ledger. Their authors and adjudicators must be independent of
this implementation session.
