## Thesis

B0 shipped the three-tier command surface (routine / profiling-prep /
final-proof) and proved each tier's warm-case speedup. B0 did NOT
establish:

1. **Cold-start ceiling invariants** — what cold `rm -rf target` costs
   on routine commands. AY-II surfaced that `cargo iter-check` was
   10+ min cold because `--workspace` pulled gorgeous (6× derives,
   serial inside one rustc); W0'.d7 excluded gorgeous/bbnf-bootstrap/
   bbnf-analysis/bbnf-lsp and restored the 11s cold target.
2. **Profiling-prep reality check** — does `make ay-prepare-profile-
   wave` + `make ay-samply-*` actually produce symbol-resolved
   profiles today? Memory notes samply symbol resolution needs
   `debug=true` + interactive `samply record`; was that covered?
3. **Test-tier invariants** — `scripts/test-tier.sh leaf` still passes
   `-p bbnf-tape` (stale name; flagged in B0's own alias comment).
4. **Incremental cache correctness** — AY-II.W0'.d7 found a
   reproducible nightly rustc ICE in `bbnf-analysis` on touch-cascade.
5. **Bench surface contract** — `make ay-bench-close WAVE=close`
   completes successfully on all 5 benches post-AY-II; measurement
   baseline survives.

B1 closes the gap with measured artefacts, not claims.

## Invariants (tentative, plan-agent may refine)

1. Every routine command (`cargo iter-*`, `make iter-*`) ≤ 2s warm,
   ≤ 30s cold.
2. Every touch-cascade iteration (touch one `.rs` → rebuild) ≤ 5s
   warm for the crates on the edit's dependency closure.
3. `scripts/bootstrap-bbnf.sh` ≤ 3 min cold; cycle-1 == cycle-2
   byte-identical.
4. Every `make ay-samply-*` target produces a profile with resolved
   symbols (top-10 self-time entries all name-decoded).
5. Every `make ay-bench-close WAVE=close` run completes all 5 bench
   binaries without panic, with throughput within ±10% of the prior
   post-wave baseline.
6. No B1 commit introduces an `#[allow(dead_code)]`, `#[ignore]`, or
   `#[cfg(false)]` to hide incomplete work.
7. No B1 commit touches parity-critical runtime architecture.
8. `iter-check-full` (workspace-sweep) succeeds cold ≤ 15 min; warm
   ≤ 2 min. This is the close-ceremony gate, not routine.
9. Documentation parity: every public alias + Makefile target
   reachable from `docs/instructions/PROFILING.md` §"Public fast-path
   commands", up-to-date with whatever B1 lands.
