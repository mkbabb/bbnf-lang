# BB-B.W1 — immutable `Program`, qualified identity, and exact serialization

## Goal

Replace mutable pointer-shaped grammar ownership with one validated revision value.

## Target values

- opaque `ProgramId`/revision digest;
- opaque revision-qualified `NodeId`, `RuleId`, and source-qualified span IDs;
- immutable interned node/rule/source stores;
- explicit `NodeRemap` between revisions;
- validation and deterministic build reports;
- exact versioned serialization of all semantic fields.

## Implementation

1. Define a closed grammar node algebra covering every shipping operator. Builders
   reject dangling/cross-program IDs, duplicate rule names, invalid ranges,
   malformed recursion/reference edges, and unbounded depth before construction.
2. Canonicalize input ordering only where order is semantically irrelevant.
   Preserve ordered choice/sequence and attach stable source provenance.
3. Derive revision identity from canonical semantic bytes plus declared source
   inputs; never from pointer addresses, insertion slots, absolute paths, or hash
   iteration.
4. Make every rewrite/edition consume one Program and return a new Program,
   `NodeRemap`, provenance, and report. No sidecar mutates identity in place.
5. Serialize every constructor/field/source/remap exactly. Reject unknown versions,
   missing fields, stale remaps, and cross-revision deserialization.
6. Parse at least one complete grammar directly into Program and round-trip it into
   a load-bearing consumer; avoid an adapter that keeps GrammarIR authoritative.

## Gates

- Two clean builds from permuted insertion orders have identical semantic bytes,
  IDs, revision digests, serialization, and reports.
- Every public malformed-ID/cycle/depth corpus returns typed errors without panic.
- Serialization round-trips all fields; mutation of any field changes or rejects
  the revision as appropriate.
- Source edits invalidate only justified IDs and remaps; stale consumers fail.
- Graph extraction shows one Program owner and no pointer/mutable-IR dependency.

## Completion

Program becomes the only admissible grammar identity for subsequent stages.
