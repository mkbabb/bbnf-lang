## Receiver Acceptance Tests

1. Add a regression where two candidates differ only by selected `BackendShape` and the generated runtime diff changes in the corresponding lowerer-owned output.
2. Assert egraph `report` observes at least one rewrite application, not only a non-empty rewrite-set id.
3. Assert CSP can return `unsat` or select a different candidate when an independent substrate/policy constraint is violated.
4. Assert `rg -n "static_css_provider_status|json_sink_only_status|gate_json_decision_csp_cascade_contract|JSON-CSS-W7-CSP-CASCADE-CONSUMED-BUT-NO-ROW-MOVEMENT" skinny/crates/passes/src skinny/crates/ir/src skinny/crates/codegen/src/lower` returns no live generic facts.
5. Assert each of `eager_tape`, `offset_tape`, `event_tape`, `sink_only`, and `collapsed_stage` emits more than a label string and is consumed by `emit_with_layout` or a shape-specific runtime emitter.

Bottom line: A5 is **NOT CLEAN**. The current implementation satisfies some fail-closed plumbing but fails the fold-integrity criterion because the decision layer is ceremonial rather than emission-driving.
