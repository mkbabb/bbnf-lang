**Opens after**: W0c close
**Agents**: 4 parallel (JSON Value, CSS StyleSheet, Sheets/BBNF Ast + named_types, tape hybrid + paired `stp`)

## Scope

1. **First-class `Value` types per grammar**, field-complete on day one per invariant 18 (no stubs):
   - `bbnf::json::Value` ↔ `sonic_rs::Value`
   - `bbnf::css::StyleSheet` ↔ `lightningcss::StyleSheet`

2. **Hybrid tape layout**: SoA primary (existing) + AoS sidecar `packed_cache: OnceCell<Vec<PackedRecord>>` populated on first random-access read per R4 §5. 32-byte aligned records.
3. **Paired-column `stp`** method on `tape::columns` replacing the reverted Lever 4 — aarch64 `stp w0, w1, [x]` for `(span_lo[i], span_hi[i])` single-instruction write. AVX x86 path via `_mm_storeu_si128`.
4. **`named_types::BINDINGS` widening** (Agent 5 L8): populate from every grammar-declared `-> input : <Name>` type, not just `Color`/`ColorMix`. Direct-to-struct path already live per AW-III.W6.4.
5. **Twitter lazy-field-extraction consumer bench** (invariant 7 wire-contract): exercises the AoS sidecar path in-wave so W1 doesn't ship AoS substrate without a consumer.

pub enum Value<'input> {
    Null,

### W1.4 Hybrid tape layout

```rust
pub struct Columns {
    pub rule_kind: Vec<u16>, pub tape_kind: Vec<u8>,
    pub span_lo: Vec<u32>, pub span_hi: Vec<u32>,
    pub child_off: Vec<u32>, pub variant_idx: Vec<u16>, pub sib_skip: Vec<u16>,
    packed_cache: OnceCell<Vec<PackedRecord>>,
}

#[repr(C, align(32))]
pub struct PackedRecord { /* 32-byte packed u16 + u8 + u32×4 + u16 */ }
```

First random-access read triggers O(n) transpose; subsequent reads are single 32-byte loads at cache-line alignment. Writes always go to SoA primary; `OnceCell::take()` invalidates on next random read.

### W1.5 Paired `stp` for span writes

On aarch64: `unsafe { vst1q_u64_x2 }` pair-store over `(span_lo[i], span_hi[i])` when both are appended together (shape emitter compound-open site). Firestorm latency L=1 rtp=0.5. On x86_64 AVX: `_mm_storeu_si128` over packed pair. Replaces the reverted Lever 4 self-alias pathology per R4 §6 Design A.

### W1.6 `named_types::BINDINGS` widening (Agent 5 L8)

Populate `BINDINGS` from every grammar-declared named type (`-> input : <Name>`), not just `Color`/`ColorMix`. The mechanism is already in AW-III.W6.4 — extend to enumerate all grammar-declared types. Direct-to-struct emission fires automatically when `TypeDesc::Named(T)` is encountered.

### W1.7 Twitter lazy-field bench (consumer for §W1.4)

`benches/twitter_lazy_field.rs`: parses twitter.json, extracts only `statuses[].text` field via `bbnf::json::Value`'s iteration API; compared against SoA-only equivalent. Asserts the AoS sidecar path exercised (via `packed_cache.get().is_some()` probe post-parse). If the hybrid doesn't fire, the substrate is untested.
