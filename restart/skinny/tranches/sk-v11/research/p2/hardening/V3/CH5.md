## Verdict

CH5 accepts the V3 S-P2 research cohort. The V3 stability fold preserves the
V2 accepted boundary: the retained substrate is the existing offset tape,
direct-only output remains `SinkOnly`, typed/direct rows are product consumers,
and SIMD masks or byte classifications are transient same-loop producers rather
than retained sidecars.

This ACCEPT is bounded. S-P3 must keep the V3 output-plane declarations intact.
A packet that turns a transient mask into a retained position vector, lets Track
2 call generated Track 1, stores decoded/string/hash facts for later parser use,
or treats old non-JSON hand runtime modules as templates reopens CH5.

## Actionable S-P3 Guardrails

1. Every shortlisted packet must name the output plane, generated Track 1 path,
   independent Track 2 or oracle path, same-output proof, and no-shared-sidecar
   assertion.

2. Byte-class, movemask, string, whitespace, container, digit, and escape work
   must consume scalar/SIMD results in the same live loop. Retained masks,
   positions, cursor state, class lanes, density tables, decoded scratch, or
   semantic hash facts are CH5 REJECT.

3. `tape_sparse_flag_delta_lane` may enter S-P3 only as an internal replacement
   for existing sparse flag encoding and only with a retained-view or typed
   consumer that observes `flags_at(cursor)`.

4. Non-JSON proof must use generated direct/typed output or an explicit
   host/oracle path on the same output plane. Old hand runtime modules and the
   current JSON-provider emission path are evidence of risk, not templates.

5. Any use of "first offset", "position", "dispatch position", or "structural"
   in S-P3 must be audited as ephemeral same-loop data unless the offset is the
   existing tape entry itself.

- Direct-only `SinkOnly` is not a retained second substrate.
- W3 union/event/class-lane/streaming-cursor/structural-position families remain
  REDRESS-closed and cannot be used as consumers.

  only.
- No V3 P2 artifact currently authorizes a parallel substrate, retained cursor,
  sidecar producer, hidden directive/schema, or Track 1 == Track 2 shortcut.
