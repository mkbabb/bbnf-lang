# Family A: immutable JSON stages

This standalone crate is an **incomplete Family A assay slice**. It implements
locked source identity, a module-derived rule graph, identity normalization,
and a small row-law kernel. It deliberately hard-stops before type/fact/plan/
value/backend publication because the current slice cannot derive those planes
solely from complete BBNF module semantics. It has no production, selection,
prototype-completion, or source-movement authority.
