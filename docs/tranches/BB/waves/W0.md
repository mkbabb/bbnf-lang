## Scope

1. Reconcile active forward docs so BB is the execution canon and BC is the downstream destination. Refresh `docs/GESTALT.md` and `docs/codegen-paths.md` cross-references for the post-BA mechanism plus the new rule-discovery substrate.
2. Make `cargo xtask regen --check` green live for all manifest grammars (BA close should leave it green; verify and fix any drift introduced by post-BA edits).
3. Recreate `crates/ir/src/rewrites/` clean: `mod.rs` (Rule, RuleSet, provenance types), `schema.rs` (RON validator), `rank.rs` and `tiering.rs` (skeleton — implementations land in W3), `base/*.ron` (the seed fleet-wide rules: `Concat(x, Epsilon) → x`, `Alt(Alt(a,b), c) → Alt(a, b, c)`, identity folds, bounded unrolling). The module compiles standalone; the schema validator rejects malformed RON with file/line diagnostics.
4. Land the cost extractor: `crates/egraph/src/cost.rs` (or extension thereof) consumed by W1's enumerator and W3's ranker. The cost model has a path-aware dimension (a rule with negative cost delta cannot auto-accept; the ranker enforces).
5. Refresh the `crates/ir/tests/substrate_audit.rs` denominator: every new BB substrate (`rewrites/`, `ruler/`, `oracle/`, `ranker/`, `tiering/`, `schema/`) must pass at every wave close. The W0 close commit cites the consumer for each new substrate.
6. Decide on `merge_path_seed` carry from BA.W0: if the W3.0 path-shape rewrites were preserved as a seed bag, consume them as enumeration seeds in BB.W1; otherwise BB.W1 enumerates fresh.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the `crates/ir/src/rewrites/` recreation surfaces an architectural decision that BB.W0 cannot make alone (e.g., the Rule schema needs additional fields for path-rewrite candidate enumeration);
- the cost extractor extension breaks an existing egraph saturation invariant (the path-aware dimension regresses an existing rule's cost);
- the substrate-audit denominator refresh reveals that one of the BA-deleted substrates was actually load-bearing for a BB substrate's intended consumer (the BA.W0 deletion was premature; route to BA-thesis triumvirate);
- regen drift requires changing more than `xtask` and the new `rewrites/` module to clear;
- three diagnostic-loop iterations fail to isolate the schema-validator's failure mode on a base RON file;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).
