# AZ.W3 — Incremental Reparse + Substrate Splice

**Opens after**: W2 close
**Agents**: 2 parallel
**Hard gate**: Edit-local incremental reparse produces substrate-identical results to cold reparse on the canonical edit suite.
**Status**: planned

## Scope

1. Localize edits against AY spans and stable boundaries.
2. Reparse only the affected region and splice the same substrate.
3. Prove incremental-versus-cold substrate identity on canonical edit
   suites.

## File bounds

| File | Access |

| `crates/core/src/runtime/incremental.rs` | create |
| `crates/core/src/runtime/snapshot.rs` | modify |
| `crates/core/src/runtime/parsed.rs` | modify |

**Do NOT touch**: recovery semantics, build/profile tooling, any `.bbnf` grammar, throughput-only optimization code.

## Phase sub-items

### AZ.W3.1 Edit localization

Mechanism: map edits to AY node spans and admitted resume boundaries,
producing a minimal incremental work region.

Files touched: `crates/core/src/runtime/incremental.rs`,
`crates/core/src/runtime/snapshot.rs`.

Sub-gate: canonical edit cases produce localized regions and admitted
re-entry points.

### AZ.W3.2 Reparse and splice

Mechanism: resume from the nearest stable boundary, rebuild the affected
region, and splice the canonical substrate back into place.

Files touched: `crates/core/src/runtime/incremental.rs`,
`crates/core/src/runtime/parsed.rs`.

Sub-gate: incremental reparse returns a canonical substrate object.

### AZ.W3.3 Incremental identity suite

Mechanism: compare incremental output against full cold reparse on a
canonical edit suite.

Files touched: `crates/core/tests/incremental_parity.rs`,
`crates/core/src/runtime/incremental.rs`.

Sub-gate: incremental identity tests pass on the suite.

## Hard gate

1. `cargo test -p bbnf --test incremental_parity --profile ax-iter`
   passes on the canonical edit suite. Artefact:
   `docs/benchmarks/post-AZ-W3-incremental.txt`.
2. Incremental results are substrate-identical to cold reparse.
   Artefact: `docs/benchmarks/post-AZ-W3-incremental.txt`.
3. Feature-off regression versus AY close remains `<= 4%` on the eager
   JSON 5-fixture geomean. Artefact:
   `docs/benchmarks/post-AZ-W3-mid.json`.
