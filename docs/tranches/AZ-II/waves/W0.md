1. Author `docs/tranches/AZ-II/BOOTSTRAP-CUTOVER.md` — the binding
   cutover design doc. Specifies Stage A / Stage B mechanics, the
   byte-equal reproducibility harness, and the drift-source
   enumeration (AST ordering, trivia handling, numeric formatting)
   with mitigations that land before W1 opens. No partial-closure
   floor is declared; W2 byte-equal failure is a re-plan trigger.
2. Apply AZ-I.W0's classifier disposition to BBNF. If AZ-I.W0
   declared a unified surface, extend it to cover BBNF's regex-HIR
   + structural-alphabet references. If AZ-I.W0 locked the three-
   classifier split, land a scoped BBNF classifier plug-in that
   preserves the split at the BBNF boundary.
3. Extend the IR audit pass from AZ-I.W0 to enumerate typed `->`
   markers in `grammar/bbnf/bbnf.bbnf`. Initial red state is
   expected; W1/W2 drive it to 100%.
4. Capture AZ-II baseline bench: the full 17-entry matrix against
   AZ-I close. Emit `docs/benchmarks/AZ-II/W0/baseline.json` and
   `docs/benchmarks/profiles/AZ-II/W0/`.
5. Run the executable preflight packet: actual live tape-symbol
   census (`tape`, `TapeRec`, `TapeBuilder`,
   `TapeCursor`, `::bbnf::runtime::tape`, `FusedOutput`, `DTA`,
   `PSI`), `project_types_bbnf` command existence, Stage A/B runner
   skeleton, and injected-drift negative test. The grep gate must
   scan live symbols, not only a fictional `bbnf_tape` import.

### AZ-II.W0.5 — Executable preflight

Run the machine-checkable packet before W1 opens. It is acceptable for
some commands to be red at W0 opening; W0 closes only when the
preflight exists and its red rows are assigned to W1/W2/W3 owners.

Mechanism:

```bash
test -f docs/tranches/AZ-II/BOOTSTRAP-CUTOVER.md
find grammar crates -name '*.bbnf' -print | LC_ALL=C sort
rg -n '::bbnf::runtime::tape|bbnf::runtime::tape|use tape::|\btape::|\bTape(Rec|Builder|Cursor|Offset|Kind)\b|\bColumns\b|\bFinaliser\b|\bDTA\b|\bPSI\b|Fused(Build|Output)' crates --glob '*.rs'
cargo test --profile ax-iter -p bbnf-ir --test project_types_bbnf
cargo check --profile ax-iter -p bbnf_derive --features struct-emit
cargo test --profile ax-iter -p bbnf --test bbnf_bootstrap_reproducibility
```

Sub-gate: command outputs captured under
`docs/benchmarks/AZ-II/W0/preflight.txt`; every red row is assigned
to a later AZ-II wave before W1 dispatch.
