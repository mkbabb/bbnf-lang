# BB-C.W4 — sealed `LoweringPlan`

## Goal

Make every backend/runtime decision one immutable, validated product of the sealed
semantic stages.

## Implementation

1. Consume only Program, DependencyGraph, TypeSolution, AnalysisFacts, target
   capabilities, and explicitly retained optimizer-island results.
2. Record selected recognizers/scanners, semantic-to-layout mapping, materialization,
   control strategy, recovery, runtime capabilities, costs, proofs/provenance, and
   all target-specific decisions in `LoweringPlan`.
3. Validate revision equality, total node coverage, layout soundness, hard global
   constraints, and required runtime capabilities before construction.
4. Serialize canonically with semantic/config/toolchain digests and a complete run
   report. No backend may reread mutable or earlier ambient state.
5. Add consumer API gates so generators/runtime take only the plan plus declared
   source tables; missing decisions cannot trigger defaults.

## Gates

- Every lowering decision has one provenance path and one validated consumer.
- Missing/wrong-revision/unknown-layout/capability mutations fail construction.
- Plan bytes match across order/hash/worker repeats and clean serialization.
- Graph projection has no backend back-edge into mutable analysis/IR organs.

## Completion

LoweringPlan is the sole code-generation/runtime contract.
