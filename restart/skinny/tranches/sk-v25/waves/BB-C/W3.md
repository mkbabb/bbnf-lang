# BB-C.W3 — genuine bounded global decisions

## Goal

Use CSP/search only where correct decisions are actually coupled and a simpler
method loses on a real load-bearing case.

## Implementation

1. Define variables, finite domains, hard constraints, objective tuple, tie-break,
   provenance, and consumer for each candidate decision family.
2. Run W1 enumeration/branch-and-bound and candidate CSP on the same immutable
   inputs. Validate every returned assignment independently against all constraints.
3. Make unsat, exhausted, invalid assignment, objective overflow, and ambiguous
   tie typed outcomes with complete run reports.
4. Test constraint/variable/domain order permutations, adversarial contradictions,
   and mutation of every hard constraint.
5. Retain CSP only when it changes a correct decision, expands tractable scale, or
   wins measured cost sufficiently to justify the organ. Delete fake substitution,
   pinned minima, and fallback assignments.

## Gates

- Every solution independently satisfies all hard constraints.
- No failure path publishes independent/local minima.
- Deterministic objective/tie results and reports reproduce.
- A named real consumer proves each retained solver necessary.

## Completion

Global search is explicit, bounded, and exceptional—not the default place to hide
underspecified decisions.
