## Scope

1. Reconcile active forward docs so AZ-IV is the execution canon and BA/BB are historical inputs until reopened.
2. Fix active workspace topology claims: wasm derive residue, parse-that derive residue, `csp-solver` source of truth, npm lock drift, docs sync drift.
3. Make `cargo xtask regen --check` green live for all manifest grammars.
4. Replace literal parser-name strategy binding with manifest/registry-driven binding or prove totality with a synthetic grammar test.
5. Preserve egraph `Map { fn_id }` semantics through extraction.
6. Harden manifest metadata and staged regen triggers so metadata changes cannot bypass regen checks.
7. Produce a BA/BB lossless coverage ledger before implementation waves open: every BA/BB requirement is marked absorbed, retired with evidence, or routed with an exact successor.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- regen drift root cause requires changing more than `xtask`, strategy registry, and one lowering/emitter surface;
- parser binding totality cannot be proven without a second runtime path;
- egraph `Map` preservation requires changing the rewrite language rather than cost/extraction/writeback semantics;
- sibling topology repair requires deleting or moving a sibling repo path outside declared bounds;
- BA/BB coverage reveals a requirement that cannot fit AZ-IV's grammar-derived StructDirect thesis;
- an agent hits three diagnostic loops without isolating root cause.

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.
