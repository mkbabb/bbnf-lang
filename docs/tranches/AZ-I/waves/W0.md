# AZ-I.W0 — Research + classifier-unification study + IR audit baseline

**Opens after**: AZ-I open (AY-II close)
**Agents**: 2 parallel (post-B2 amendment — derive-cache + Watt sub-agents retire)
**Hard gate**: `CLASSIFIER-UNIFICATION.md` lands with a binding
disposition (unified or locked-split); IR audit pass lands and
reports baseline `->` coverage across JSON, CSS L4, and Sheets;
AZ-I baseline bench captured.
**Status**: planned

## Scope (post-B2 amendment)

The pre-B2 derive-cache lift + Watt proc-macro precompilation items
are T3-superseded. B2.W2 retired the `bbnf_derive` proc-macro crate
outright; there is no proc-macro to relocate the cache for, no
proc-macro to wrap with Watt; the substrate they presupposed
ceases to exist at B2's close. Drift detection moved to standard
"diff after regen" hygiene via `cargo xtask regen --check` (CI +
pre-commit gate; B2.W4). AZ-I.W0 retains the load-bearing core:

1. Author `docs/tranches/AZ-I/CLASSIFIER-UNIFICATION.md` — the
   research note on whether the regex-HIR classifier, the
   structural-alphabet classifier, and the payload-kind classifier
   can unify on a single decision surface for JSON, CSS L4, and
   Sheets. Outcome is binding: either a unified design spec (with
   pluggable components per `feedback_pluggable-components`) or a
   declaration of intractability that locks the three-classifier
   split.
2. Land IR audit pass at
   `crates/ir/src/passes/audit/payload_coverage.rs`. The pass
   enumerates every typed `->` in JSON, CSS L4, and Sheets and
   reports emitter coverage. Gates the build on these three
   grammars; BBNF is exempt in AZ-I.
3. Capture AZ-I baseline bench: three-data-grammar slice of the
   17-entry cold-parse matrix, samply fleet, parity harness summary.
   Emit `docs/benchmarks/AZ-I/W0/baseline.json` and
   `docs/benchmarks/profiles/AZ-I/W0/`.

## Phase sub-items

### AZ-I.W0.1 — Classifier unification research

Read the three classifiers (`crates/regex/src/hir/classifier.rs`,
`crates/ir/src/passes/alphabet.rs`, `crates/ir/src/types/payload.rs`);
author the unified decision surface or lock the split. If unified,
specify the driver struct and the plug-points; if locked, enumerate
the invariants that must be preserved at the boundaries to prevent
leakage.

Sub-gate: note lands with explicit disposition + rationale; cited
from W1 and AZ-II.W0.

### AZ-I.W0.2 — IR audit pass

Enumerate every `->` marker reachable from JSON, CSS L4, and Sheets
grammars; report emitter coverage (the `StructLayout` write for
each). Initially returns `100% coverage: pending project_types
closure` — that is, the audit pass runs and reports, and W1 then
drives the count to true 100% by landing the `StructRegistry`
entries.

Sub-gate: pass runs on `cargo check`; emits
`docs/benchmarks/AZ-I/W0/audit-coverage.json` with per-grammar
coverage percentages.

### AZ-I.W0.3 — Baseline bench capture

Run the 17-entry matrix on the AZ-I branch pre-migration; capture
samply traces; confirm AU-baseline parity on all three data
grammars + BBNF. This is AZ-I's opening floor; every subsequent
wave gates against it.

Sub-gate: `docs/benchmarks/AZ-I/W0/baseline.json` shows AU-baseline
parity or better on all 17 entries.

## Archaeology

The pre-B2 W0 plan carried a third sub-agent (W0.2 — derive-cache
lift to `$XDG_CACHE_HOME/bbnf-derive/` with composite fingerprint
+ invalidation test suite that would have lived alongside the
proc-macro crate) and a Watt proc-macro precompilation item.
Both retired at B2.W2 by direct supersession: the proc-macro
contract retired; the proc-macro crate deleted outright; the
cache location, fingerprint scheme, and Watt wrapper all became
moot substrates. Drift detection moved to `cargo xtask regen
--check` (B2.W4) — regen idempotence is asserted by the xtask
itself, not a separate test directory. The AZ-I.W0 sub-agent
count drops from 3 to 2; the hard-gate item count drops from 5
to 4.
