# B7.W2 — pprint: divan migration + nextest CI + `.cargo/config` patch resolution

**Opens after**: tranche open (parallel with W0 + W1)
**Repo**: `pprint` (`/Users/mkbabb/Programming/pprint`)
**Agents**: 3 parallel (A6, A7, A8)
**Status**: planned

## Scope

W2 closes pprint's modernization gap on three axes:

1. **Bench harness consolidation onto divan.** Both bench targets
   (`pprint.rs` ~24 fns; `digit_count.rs` ~14 fns) retire
   `#![feature(test)]` + `extern crate test`; the dev-dep
   replaces with `divan = "0.1"`; each bench file ports to
   `#[divan::bench]`.
2. **CI rewire onto nextest.** The CI workflow invokes
   `cargo nextest run`.
3. **`bbnf-ser` patch single-source-of-truth.** pprint's local
   `rust/.cargo/config.toml` deletes its redundant `bbnf-ser`
   patch entry; bbnf-lang's `.cargo/config.toml` retains the
   canonical patch.

## Phase sub-items

### B7.W2.1 — Divan migration: `pprint.rs` ~24 bench fns (A6, 4 h cap)

Owner: A6.

Files: `rust/Cargo.toml`, `rust/benches/pprint.rs`.

Mechanics:

- `rust/Cargo.toml`: add `divan = "0.1"` as a dev-dep; declare
  `[[bench]] name = "pprint" harness = false`.
- `rust/benches/pprint.rs`: remove `#![feature(test)]` and
  `extern crate test`; rewrite each `fn bench_<name>(b: &mut
  test::Bencher) { b.iter(|| ...) }` as `#[divan::bench] fn
  bench_<name>(bencher: divan::Bencher) { bencher.bench(|| ...)
  }` (or the parameterized `#[divan::bench(args = [...])]` form
  where the original used `b.iter` over multiple inputs).

Sub-gate: `cargo bench -p pprint --bench pprint` runs under
divan; `grep -F '#![feature(test)]' rust/benches/pprint.rs`
returns no hit; `grep -F 'extern crate test' rust/benches/
pprint.rs` returns no hit; pre/post bench-median delta within
±5 % per fixture.

### B7.W2.3 — CI nextest + `.cargo/config` patch resolution (A8, 2 h cap)

Owner: A8.

Files: `.github/workflows/ci.yml`, `rust/.cargo/config.toml`.

Mechanics:

- `.github/workflows/ci.yml`: rewrite test step to
  `cargo nextest run --workspace`. (pprint does not pin a
  toolchain via `rust-toolchain.toml`; the CI step inherits the
  workspace default. If a pin is needed, A8 reads
  `rust-toolchain.toml` per A4's pattern.)

  `[patch.crates-io] bbnf-ser = { path = "..." }` entry. The
  canonical patch lives in `/Users/mkbabb/Programming/bbnf-lang/
  .cargo/config.toml`; pprint's redundant entry shadows it when
  bbnf-lang includes pprint as a path-dep.
- Verification: `grep -F 'bbnf-ser' /Users/mkbabb/Programming/
  bbnf-lang/.cargo/config.toml` returns the canonical patch line;
  `grep -F 'bbnf-ser' /Users/mkbabb/Programming/pprint/rust/
  .cargo/config.toml` returns no hits.

Sub-gate: pprint CI green on a probe commit; pprint's local
`.cargo/config.toml` carries no `bbnf-ser` patch entry; bbnf-lang's
`.cargo/config.toml` retains the canonical patch.
