visits = calls + selected_edge_count + explicit_cluster_internal_edge_count

not the helper/receipt formula. This is also internally self-contradictory: the
receipt says the `Refs` path removed the recursive SCC calls at
`AUTHOR-R11.md:201-204` while retaining those same removed calls in the formula.

**Disposition:** replace the helper with topology that excludes
