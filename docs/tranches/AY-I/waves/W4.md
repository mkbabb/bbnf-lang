## Scope

Per AU archaeology (AU.3.1 SIMD unescape landed, AU.5.2 missed decoded-path gate; AU.3.2 canada 0.61 vs 0.80 target; Eisel-Lemire bridge identified as AV-scale work) + user directive BEAT sonic-rs:

1. **SIMD unescape for JSON strings** (BEAT-sonic lever #1). sonic-rs and simdjson both use SIMD `vpcmpeqb` to locate `\` + `"` within strings, then fast-path the no-escape case with byte-borrow. bbnf has `decode_json_string_to_arena` + `push_leaf_borrowed_string` but the fast path has gaps — emit the SIMD-path directly in the `parse_string_<Grammar>_string` call site rather than routing through the generic scanner.

2. **Eisel-Lemire direct-to-column for numbers** (BEAT-sonic lever #2). sonic-rs inlines Clinger fast path + Eisel-Lemire then writes f64 directly to its Value. bbnf has Eisel-Lemire via `parse_that::parsers::eisel_lemire::compute_f64` but the emit site goes through `PayloadData::WideScalar(f64_bits)` → `push_leaf_with(...)` → arena wide-slot write. Bypass the arena: write f64 bits directly to a dedicated numeric payload column. Saves one load + one store per number literal.

3. **Regex-scan specialisation** (pre-existing scope; still warranted on CSS + Sheets). Byte-class pre-filter + property-name PHF + DFA table hoist. Per A2 §7 + A4 §L-B / §L-D.

4. **BoundedRegex** absorbed from AX.W6 per A7. `last_byte_set` narrowing — scanner can skip regex engagement when input byte is known-not-in-regex's-follow-set. Narrow enablement per-rule; saves ~10% on CSS L4 selector-heavy paths.

5. **L1/L2 miner inheritance** absorbed from AX.W4 per A7. Per-rule scanner configurations (e.g. `RegexClass::Numeric { allow_leading_dot }`) inherit from miner outputs rather than grammar-author annotations. Reduces emitted regex variants.

6. **Structural-scan consumer landing** absorbed from AY.W1 deferral per `docs/tranches/AY/audit/AYW1-structural-scan-consumer-coverage.md`. The W1 substrate (`tape::structural_scan::{scan_structural, next_structural_at_or_after}`) shipped without consumers because eager parse-entry call regressed twitter -64%. W4 absorbs the proper consumer: CTNS-style regex emissions on CSS L4 + Sheets where the structural alphabet has > 0 cardinality AND the per-rule profile shows ≥ 1% self-time on `consume_to_next_structural` patterns. JSON skips per W1-fix evidence (zero CTNS hot-path on twitter). Lazy-init the structural index on first per-grammar consumer call so cold-cost is amortised.

## Phase sub-items

### AY.W4.1 SIMD unescape for JSON strings (parallel agent A — BEAT lever)

Per sonic-rs + simdjson approach:

- At `parse_string_JsonParser_string` emission site, inline the SIMD scan for `\` + `"`.
- Fast path (no escape bytes found via vpcmpeqb bitmap): emit `push_leaf_borrowed_string` — zero arena copy, zero unescape work. Span points at the input bytes between the outer quotes.
- Slow path: fall through to existing `decode_json_string_to_arena` which handles escapes.
- Expected: twitter's 100K string leaves → 90%+ take the fast path (JSON is mostly unescaped-ASCII). Save ~5-10% on twitter parse.

Files: `crates/core/src/backend/rust/emitter/shapes/string.rs` (or whatever emits parse_string). **Sub-gate**: fresh samply on JSON twitter shows `decode_json_string_to_arena` self-time ≤ 1% (from typical 4-6% baseline).

### AY.W4.2 Eisel-Lemire direct-to-column for numbers (parallel agent B — BEAT lever)

Per AU.3.2 path + sonic-rs Clinger+Eisel-Lemire pattern:

- Add dedicated `pay_f64: Vec<u64>` column to `Columns` struct (AoS `Vec<TapeRec>` already restored in W1; this is an additional parallel f64 column).
- `TapeRec::child_off` for numeric leaves stores the index into `pay_f64` (rather than arena byte offset).
- At `parse_number_<Grammar>_number` emission site: run `compute_f64` → write `f64::to_bits()` directly to `pay_f64.push()` → `push_leaf(kind, span, variant, meta, child_off = pay_f64.len() - 1)`. No arena round-trip.
- Value-materialize path reads `pay_f64[child_off]` and `f64::from_bits()` in-register.

Files: `crates/tape/src/columns.rs` + `crates/tape/src/builder.rs` + `crates/core/src/backend/rust/emitter/shapes/number.rs`. **Sub-gate**: canada bench ≥ +15% vs post-W3 baseline (heavy f64 fixture shows direct-column gain); samply shows `Eisel-Lemire` + `compute_f64` self-time unchanged (work is the same; only the destination changed).

### AY.W4.3 Regex-scan specialisation (parallel agent C)

Per A2 §7 + A4 §L-B / §L-D + BoundedRegex:

- **Byte-class pre-filter**: `match first_byte { ascii_alpha => dispatch_ident_scan, digit => dispatch_number_scan, hyphen => dispatch_negnum_scan, ... }` before full DFA engagement. Saves cold-branch tax.
- **Property-name PHF** (CSS L4): ~400 property names → `phf::Map<&str, u32>` lookup with longest-match + fallback to generic regex. Dispatch on first-byte then match.
- **DFA table hoisting**: `dfa_codegen.rs` emits inline match ladders currently; hoist to `pub(crate) const DFA_<rule>_<regex_id>: [u8; N]` at module top-level. Per-rule parse fns reference the const. Reduces code-size + improves BTB.
- **last_byte_set narrowing (BoundedRegex)**: per-regex, mine the set of bytes the regex can END on. If the current input byte is not in that set, skip engagement. Inserts a fast-path before the DFA walk.
- **Operator byte-class dispatcher (Sheets)**: `<`, `>`, `=`, `<<`, `>>`, `<=`, `>=`, `<>` disambiguated via first-byte then second-byte match; faster than generic regex.

Files: `crates/core/src/generate/regex/{emit,dfa_codegen,phf,byte_class,last_byte_set}.rs`.

**Sub-gate**: fresh samply on CSS L4 tailwind: `__regex_scan_CssL4Parser` ≤ 12% (from 26% baseline). Sheets parse_stress: `__regex_scan_GoogleSheetsParser` ≤ 6% (from 12%). JSON + BBNF no regression.

## Archaeology

- SIMD unescape via vpcmpeqb + bitmap scan for `\` + `"`. Byte-borrow on no-escape path.
- Clinger fast-path + Eisel-Lemire number parse; result written directly to Value::Number.
- arena-allocated DOM with unified decode — hot-path never round-trips through an intermediate buffer.

simdjson OnDemand:
- Stage 1 structural index via SIMD scan.
- Stage 2 lazy materialization; numbers parse via Eisel-Lemire on-demand.

- Inlined SIMD scan (parse-that's `first_quote_or_backslash`).
- Inlined Eisel-Lemire (parse-that's `compute_f64`).
