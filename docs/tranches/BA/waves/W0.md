## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- regen drift root cause requires changing more than `xtask`, strategy registry, and one lowering/emitter surface;
- the substrate-audit denominator refresh reveals a substrate whose deletion would invalidate a BA wave's file bounds;
- module-cluster retirement reveals that one of the three clusters has a live consumer outside `crates/core` (e.g., in `parse-that` or `csc411`);
- `merge_path_seed` decision cannot resolve cleanly (deletion blocks BB; wiring requires changing the egraph saturation site outside W0 bounds);
- worktree fixture contract codification surfaces a sibling-repo dependency outside declared bounds;
- an agent hits three diagnostic loops without isolating root cause;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate.
