Date: 2026-05-27.

Disposition: ADMIT for `json/unicode_escapes/direct_to_struct/main` and
`json/unicode_escapes/real_typed_struct/main`.

## Material Differential

W11U adds a generated raw JSON string lexeme scalar for the
`unicode_escapes` product surface. Track 1 validates each JSON string through
the generated parser, preserves the exact quoted source lexeme, and folds raw
lexeme fingerprint + length into the strict product. The serde sidecar uses
`serde_json::value::RawValue`; the sonic sidecar uses `sonic_rs::LazyValue`.

This is not W11M's decoded string product, W11P's decoded codepoint facts, or
W11R's fixed-shape floor parser. The route is schema-owned and generated by
`regen-real-typed`.
