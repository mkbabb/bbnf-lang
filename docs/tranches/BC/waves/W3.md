# BC.W3 - Samply 7-Artefact Contract Canonicalization

**Name**: W3 - Samply 7-Artefact Contract Canonicalization
**Opens after**: W2 - Worktree Fixture Symlink Contract
**Agents**: 5 parallel
**Hard gate**: `.github/workflows/perf-claim.yml` gates every PR with a perf claim; environmental-gating retired; standing close discipline documented; `xtask perf-claim-check` exists and is invoked from CI
**Status**: planned

## Scope

1. Promote BA's W6.2-canonicalised samply 7-artefact contract to a CI-gated discipline. Every PR that adds a perf claim (anything in FINAL.md, PROGRESS.md, or `docs/benchmarks/*.json` claims a measurable perf delta) must include the 7-artefact contract: binary symbol map, gz profile, profile JSON, top-N hotspot table, samply HTML, claim row reference, profile run command.
2. Implement `xtask/src/perf_claim_check.rs` that walks PR-changed files, identifies perf claims, and verifies the 7-artefact contract is present per claim.
3. Create `.github/workflows/perf-claim.yml` that invokes `cargo xtask perf-claim-check` on PRs.
4. Retire environmental-gating: every former env-gated row's resolution is documented in `docs/tranches/BC/audit/W3-env-gating-retired.md`. The previous pattern of routing perf claims to "wait for samply environment" stops; the contract is the gate.
5. Update `docs/precepts/instructions/PROFILING.md` (submodule update if needed) with the standing contract definition.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- the perf-claim heuristic surfaces a claim in a doc the wave cannot decide is a perf claim or not (false positives or false negatives at > 5%);
- the contract requires a sub-tool that doesn't currently ship in CI (e.g., samply itself; if samply must install in CI, the workflow scope expands);
- environmental-gating retirement reveals a row that genuinely cannot be measured under CI's environment (the contract has an environment dependency W3 cannot resolve);
- three diagnostic-loop iterations fail to isolate why the CI gate's exit-code-driven check produces a false positive;
- JSONL transcript quiet >15 minutes;
- first-pass return with no commit and no evidence (after one verbatim redispatch).
