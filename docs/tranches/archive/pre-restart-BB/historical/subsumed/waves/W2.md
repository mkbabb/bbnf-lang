# BB.W2 — Wide alphabet: CSS L4 + BBNF

**Opens after**: W1 close
**Agents**: 2 parallel
**Hard gate**: Wide-alphabet enumeration runs land accepted rules for
CSS L4 and BBNF self-hosting grammars — ≥ 5 per grammar, ≥ 90% Class
1 + 2, at least one grammar's `generated.rs` shrinks by ≥ 10 LOC, no
regression on the 17-entry matrix.
**Status**: planned

## Scope

1. Open the enumerator alphabet to CSS L4 declaration forms
   (declaration list flatten, selector alternatives, at-rule folds,
   shorthand expansion).
2. Open the enumerator alphabet to BBNF self-hosting rules
   (grammar-function closure fold, rule inlining when acyclic, regex
   alt merge).
3. Run the W0 enumerator + residue split + VM oracle + ranker + tier
   classifier on each grammar under a per-wave e-graph node-count
   ceiling.
4. Accept rules via the W0 tiered pipeline. Class 1 auto-accepts; Class
   2 batched review; Class 3 individually reviewed.
5. Re-emit `generated.rs` for both grammars; confirm cost-config
   integration; measure shrink.

## Phase sub-items

### BB.W2.1 — CSS L4 enumeration run

Wide alphabet for CSS L4. Target N = 50 candidates post-residue.

Sub-gate: ≥ 50 validated candidates; ≥ 5 accepted; ≥ 90% in Class 1+2;
e-graph node count under the declared ceiling.

### BB.W2.2 — BBNF self-hosting enumeration run

Wide alphabet for BBNF. Target N = 40 candidates post-residue.

Sub-gate: ≥ 40 validated candidates; ≥ 5 accepted; ≥ 90% in Class 1+2.

### BB.W2.3 — Generated.rs shrink verification

Re-emit CSS L4 and BBNF; measure shrink.

Sub-gate: at least one grammar shrinks by ≥ 10 LOC; neither regresses;
17-entry matrix at or above AZ close everywhere.

### BB.W2.4 — Review ledger

Per-rule docs and rejected rationales as in W1.

Sub-gate: every accept / reject has its markdown.

## Hard gate

1. `cargo test --workspace --profile ax-iter` green.
2. At least one grammar's `generated.rs` shrinks ≥ 10 LOC.
3. 17-entry AU-baseline matrix at or above AZ close on every entry.
4. E-graph node count during each enumeration under declared ceiling;
   any crossing triggers alphabet narrowing for the next wave.
5. lightningcss parity harness green for CSS L4.
