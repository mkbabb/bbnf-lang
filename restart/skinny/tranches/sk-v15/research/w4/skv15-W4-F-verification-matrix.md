Line-1 scan:

```sh
find crates/core/src/runtime -mindepth 2 -type f -name '*.rs' -print0 \
  | sort -z \
  | xargs -0 awk 'FNR==1 && $0 !~ /^\/\/ @generated by xtask regen-(css|math|csv|bbnf|bnf|ebnf|css-pretty|google-sheets|json); do not edit by hand\.$/ { print FILENAME ":1:" $0; bad=1 } END { exit bad }'
```

Intrinsic-block W4 if any of these remain true after redress:

- no non-writing root runtime check command exists;
- line-1 headers are not generator-owned;
- a destructive runtime deletion happens without delete-plus-regen proof;
- the Pattern H count changes;
- the dirty runtime baseline cannot be separated from W4 output;
- dirty skinny CSS generated files are used as either proof or blocker for root
  Pattern H.
