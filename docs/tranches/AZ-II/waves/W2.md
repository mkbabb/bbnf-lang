# AZ-II.W2 — Stage B (candidate rebuilds itself + byte-equal close gate)

**Opens after**: AZ-II.W1 close
**Agents**: 1 (close-verification + reproducibility harness)
**Hard gate**: W1-candidate compiler rebuilds itself from its own
source; Stage B output is byte-equal to Stage A output across the
full BBNF fixture corpus; `tests/bbnf_bootstrap_reproducibility.rs`
lands as permanent CI gate; full 17-entry matrix at or above AZ-I
close on the struct-only path.
**Status**: planned

## Scope

1. Stage B build: `cargo clean && cargo build -p bbnf` using the
   W1-candidate compiler as the bootstrap toolchain. The resulting
   xtask regen pipeline is built from a struct-writing parser
   (produced by the W1-candidate's struct-emission mode) and itself
   produces struct-writing parsers. Tape is unwired in both
   directions for BBNF's bootstrap.
2. Stage B output capture: run the Stage B
   `cargo xtask regen --emit-mode struct` on every `.bbnf` fixture
   in the tree; archive to
   `docs/benchmarks/AZ-II/W2/stage-b-output/<fixture>/`.
3. Byte-equal close gate: `diff -r
   docs/benchmarks/AZ-II/W1/stage-a-output/
   docs/benchmarks/AZ-II/W2/stage-b-output/` returns zero byte
   differences on every fixture. Any divergence triggers the
   escape clause.
4. Land `tests/bbnf_bootstrap_reproducibility.rs` as a permanent
   CI test. Runs the Stage A / Stage B diff on every commit post-
   W2. Any break fails the build.
5. Re-run the full 17-entry matrix on the Stage B compiler;
   confirm no regression from AZ-I close.

## Phase sub-items

### AZ-II.W2.1 — Stage B build + output capture

Execute the Stage B sequence per `BOOTSTRAP-CUTOVER.md` §Stage B.
Capture per-fixture output under `stage-b-output/`.

Sub-gate: Stage B build completes; every fixture parses without
error under the Stage B compiler.

### AZ-II.W2.2 — Byte-equal diff

`diff -r stage-a-output/ stage-b-output/` → zero byte differences.
Any divergence is investigated against the drift-source enumeration
in `BOOTSTRAP-CUTOVER.md` §3. If the drift is fixable within the
wave (ordering, trivia, numeric), fix and re-run both stages. If
the drift is intractable, invoke the escape clause.

Sub-gate: zero byte differences across the full corpus.

### AZ-II.W2.3 — Reproducibility harness

`tests/bbnf_bootstrap_reproducibility.rs` encodes the Stage A /
Stage B diff as a repeatable test. Runs on every CI invocation
post-W2.

Sub-gate: test lands; green on the current commit; fails on an
injected drift (verified via a test-of-the-test).

### AZ-II.W2.4 — Full matrix re-run

Re-run the full 17-entry matrix on the Stage B compiler. Confirm
AZ-I close parity or better.

Sub-gate: full matrix at or above AZ-I close on every entry
(JSON, CSS L4, Sheets on struct path; BBNF self-parse within
10% of AU baseline).

## Hard gate

1. Stage B build succeeds; every fixture parses without error.
2. Byte-equal check passes: `diff -r stage-a/ stage-b/` → zero.
3. `bbnf_bootstrap_reproducibility` test green; test-of-the-test
   confirms it fails on injected drift.
4. Full 17-entry matrix at or above AZ-I close.
5. `cargo nextest run --workspace --profile ax-iter` ≥ 1480 pass
   (post-B4 baseline per `docs/tranches/B4/FINAL.md` test summary).

## Reversal criteria

Byte-equal fails on any fixture → wave reverts and AZ-II re-plans.

1. Revert the W1 struct-emission substrate for the BBNF bootstrap.
2. Capture the specific drift source(s) observed: which fixture,
   which class (AST ordering / trivia / numeric / other),
   minimised reproducer.
3. Author a re-plan brief that folds the observed drift sources
   back into `BOOTSTRAP-CUTOVER.md` with concrete mitigations;
   W1 re-opens against the refined design.
4. Full tape abrogation remains the close gate; no partial-close
   floor is accepted.

A 10%+ regression on BBNF self-parse throughput triggers the same
reversal-and-re-plan sequence; BBNF self-parse perf is internal
build cost, but regression is still a re-plan trigger and does
not permit a partial-closure state.
