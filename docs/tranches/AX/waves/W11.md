## Scope

Per-shape rewrites with new `GrammarENode` variants + emitter routes. Per aw5-r6-depart §3 + aw5-n1 R4.

1. **G5 Ref-to-leaf inline (leaf-predicate guardrail)**: `Ref(id) ≡ body` when `extracted_body is leaf ∧ ref_count > 1`. **The leaf-predicate (`Literal | Regex | Epsilon | KwWs`) is the guardrail distinguishing this from the 2026-04-08 `inline_acyclic` failure** — bounded by construction, saturation-cap-bounded in aggregate.
2. **G6 PhfLoop**: `Repeat { inner: Alt([Lit_1, …, Lit_N]) } ≡ PhfLoop(sids, lo, hi)` when every branch is `Literal`. New variant.
3. **G7 ClassifyByteLoop**: `Repeat { inner: Alt_disjoint_first } ≡ ClassifyByteLoop(disjoint_table, lo, hi)`. New variant.
4. **G8 OperatorChain**: nested `Seq/Alt` operator-precedence chain ≡ `OperatorChain(ranges, ops)`. New variant. Sheets 6-rung tower collapses; existing Pratt miner already produces facts.
5. **G9 HeadwordFolding (aw5-n1 R4)**: `Alt([Seq(L, a), Seq(L, b), …]) ≡ Seq(L, Alt([a, b, …]))`. Mirror of existing `CommonSuffixFactor`. Fires on CSS `atRule` (common `@` prefix), Sheets function names.

Plus **W11.2 rewrite fuzz**: every rewrite × 100 sampled grammars from `grammar/**.bbnf` × all corpus fixtures. Every rewrite's pre/post-rewrite tape MUST be identical. Wave fails on any divergence.

## Phase sub-items

### W11.1 Per-rewrite rule files

Five rule files, ~50 LOC each. Each registers in `default_rules()`. Each has a cost-fn arm (G6 cheaper than Repeat-over-Alt; G7 cheaper than linear dispatch; G8 cheaper than nested Seq chain; G9 cheaper than N × Seq-with-lead; G5 leaf-predicate-bounded).

### W11.2 Per-variant emitter routes

Each new `GrammarENode` variant must have a shape-emitter lowering:

- `PhfLoop` → `shapes/keyword.rs` emits PHF-in-loop form.
- `ClassifyByteLoop` → `shapes/unordered.rs` emits byte-class dispatched loop.
- `OperatorChain` → `shapes/pratt.rs` consumes the canonical form (collapses current Pratt detector's wrapper-zoo matcher into 1-LOC query).
- `HeadwordFold` output: G9 produces `Seq(L, Alt([a, b, ...]))` — existing `shapes/*` paths handle this (no new variant needed).
- `KwWs` (W10) → `shapes/keyword.rs` (already wired in W10).

**Per-variant emitter route verified via `cargo expand` BEFORE wave close** — else extracted variants have no lowering and silently break bench.

### W11.3 Rewrite fuzz (W11.2 in AX.md numbering)

Harness:

```rust
#[test] fn rewrite_fuzz_tape_parity() {
    let sampled_grammars = sample_100_from("grammar/**.bbnf");
    for grammar in sampled_grammars {
        for fixture in load_corpus_for(grammar) {
            let tape_pre = parse_without_rewrite(grammar, fixture);
            let tape_post = parse_with_rewrite(grammar, fixture);  // full e-graph pass
            assert_eq!(tape_pre, tape_post, "divergence on {} × {}", grammar, fixture);
        }
    }
}
```

Any divergence = wave fails. This is the correctness safety net for the rewrite cluster — catches silent tape drift that W2 parity harness wouldn't exercise if no external comparator has the specific pattern.

### W11.4 G5 confluence check

Per aw5-r6-depart §8: "G5 is non-confluent with G1"; G5 + G1 + G9 composition could cascade. Explicit test case: `Ref(R)` where `R.body = Alt([Seq(L, a), Seq(L, b)])`. G5 inlines `Ref`; G9 folds headword; G1 flattens Alt — observe extraction reaches a unique fixed point under `egraph_iter_limit = 64`. Test fails if iteration cap hit without convergence.
