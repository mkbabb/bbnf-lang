## Unresolved blockers

### 1. Dynamic canonical-error byte admission

Success-path allocation is exact, but all reachable error paths are not.
`GraphArtifact::validate_canonical` can still format input-dependent node-kind,
conflicting-node, missing-endpoint, graph-size, and privacy diagnostics.
Staticizing those authoritative errors would exceed R11's frozen `fact.rs`
authorization, which permits only the five nested-vector laws.

Even literal `anyhow 1.0.102` errors box a private repr-Rust
`ErrorImpl<MessageError<&str>>` and call
`std::backtrace::Backtrace::capture()`. Enabled backtraces can allocate
dynamically, so neither serialized JSON length nor a guessed fixed box
constant is an independent capacity proof. Closing this requires broader
authority for a non-allocating typed canonical error and controlled conversion
boundary, or another explicitly pinned backtrace policy. It is routed to
adjudication/R12.

### 2. Whole-validation aggregate work

The four final failures show that the sealed R10 aggregate totals no longer
match the multi-effect R11 implementation. Updating them to measured-current
literals would violate the independent-oracle requirement. Until every delta
is derived from named source operations and caller topology, evidence
validation and the full suite remain RED. This independently denies R11 CLEAN
credit even apart from dynamic error allocation.
