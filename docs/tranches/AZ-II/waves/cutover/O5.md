## Pre-dispatch audit synthesis

O5 opens from O4 commit `8040bd69`. The pre-dispatch sidecar audits
split the deletion graph into these ordered lanes:

1. **Scanner-owned primitive relocation**: move `StructuralIndex` out
   of `crates/tape` and into `crates/simd-scan`, because `simd-scan`
   produces and already re-exports the stage-1 index. Delete
   `StructuralAlphabet::from_profile` if it has no live Rust callers;
   emit scanner config directly instead of moving broad
   `GrammarProfile` into `simd-scan`.
2. **Runtime primitive re-ownership**: retarget remaining generated
   `runtime::tape` references that are not tape data structures
   (`DtaError`, `DtaStateId`, `DtaRuleId`, precedence/profile/scan
   policy structs) to their natural core/IR owner before severing the
   tape crate.
3. **Consumer deletion/recode**: delete tape-only tests and helpers
   (`tape_walker_allocs`, `visitor_reduce`, bench validation helpers,
   tape golden fixtures). Recode only document/direct JSON value bench
   lanes and emitter contract tests that remain load-bearing.
4. **Prototype/JIT removal**: archive then delete `json-prototype`;
   delete the Gorgeous derive-backed JIT CLI/help/cache dispatch. Do
   not retain feature gates, compatibility shims, or a repaired
   prototype parser.
5. **Manifest severance and crate deletion**: remove every `tape`
   dependency edge, delete `crates/tape`, regenerate, and prove cargo
   metadata has no tape package or dependency.
