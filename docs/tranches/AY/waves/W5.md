# AY.W5 — Canonical Packed Substrate + Direct JSON Write

**Opens after**: W4 close + B0 close
**Agents**: 3 parallel
**Hard gate**: Default JSON parse writes the canonical packed substrate directly; `finalise::finalise` is no longer a hot JSON cost center and the eager JSON geomean improves versus post-W4.
**Status**: planned

## Scope

1. Define the canonical packed node/header contract in the tape/runtime
   substrate with explicit tag, span, skip/count, and payload lanes.
2. Retarget the JSON RD/shape-emitted parser to write that substrate
   directly for object, array, string, number, and literal shapes.
3. Update the read-side contract just enough that the new substrate is
   exercised by production consumers and verified by the existing value
   API harness.

## Phase sub-items

### AY.W5.1 Packed node contract

Mechanism: replace the residual generic tape-first record contract with
one packed node/header layout that carries explicit tag, byte span,
subtree skip/count metadata, object/array run metadata, and direct
scalar payload storage. Land write-time close stamping at
`close_compound` so subtree/run closure metadata is stamped while the
parser still has the live structural context, rather than recovered by
an O(N) post-pass. Carve or delete overloaded lanes whose meaning
depends on post-parse reconstruction.

Files touched: `crates/tape/src/tape.rs`, `crates/tape/src/columns.rs`,
`crates/tape/src/builder.rs`.

Sub-gate: `cargo test -p bbnf --test value_api_apples_to_apples --profile ax-iter`
type-checks and runs against the new substrate without compatibility
shims.

### AY.W5.2 Direct JSON write emission

Mechanism: retarget JSON shape emission so the default parser path
writes packed nodes directly at parse time for object, array, string,
number, and literal shapes, including direct close-time subtree/run
metadata where write-time facts permit it.

Files touched: `crates/core/src/backend/rust/emitter/grammar.rs`,
`crates/core/src/backend/rust/emitter/shapes/compound.rs`,
`crates/core/src/backend/rust/emitter/shapes/string.rs`,
`crates/core/src/backend/rust/emitter/shapes/number.rs`,
`crates/core/src/backend/rust/emitter/shapes/literal.rs`.

Sub-gate: `cargo expand -p bbnf --bench json_monolithic` shows the
generated JSON parser writing packed nodes directly rather than routing
through a generic finalize/rebuild step.

### AY.W5.3 Read-contract activation

Mechanism: update cursor and parsed-runtime access so production reads
exercise the new packed layout, then refresh the value API apples-to-
apples harness so the new substrate is the exercised runtime contract,
not a latent scaffold.

Files touched: `crates/tape/src/cursor.rs`,
`crates/core/src/runtime/parsed.rs`,
`crates/core/tests/value_api_apples_to_apples.rs`.

Sub-gate: the apples-to-apples harness passes without falling back to
legacy cursor reconstruction logic.

## Hard gate

1. `cargo expand -p bbnf --bench json_monolithic` shows the generated
   JSON parser calling packed-node builder entrypoints directly.
   Artefact: `docs/benchmarks/post-AY-W5-expand-json.txt`.
2. Samply on eager JSON twitter shows `finalise::finalise` at `<= 1%`
   self-time. Artefact:
   `.profiles/samply/AY-W5/json_twitter_eager/profile.json`.
3. `cargo asm -p bbnf <json-close-fn>` or equivalent expanded output
   shows write-time close stamping at the generated `close_compound`
   path rather than post-pass subtree closure. Artefact:
   `docs/benchmarks/post-AY-W5-close-stamp.txt`.
4. `cargo test -p bbnf --test value_api_apples_to_apples --profile ax-iter`
   passes on the new substrate. Artefact:
   `docs/benchmarks/post-AY-W5-value-api.txt`.
5. The eager JSON 5-fixture geomean improves versus post-W4. Artefact:
   `docs/benchmarks/post-AY-W5-mid.json`.

## Archaeology

- AU recovered significant write-side throughput by optimizing the
  executing parser rather than post-parse abstractions; W5 keeps that
  lesson and applies it to the runtime substrate itself.
- The prior AY tail waves targeted compile-time and document-parallel
  work; this wave replaces that stale scope with the actual parity-
  critical substrate rewrite.
- B0 exists only to shorten the execution loop into this wave. Any
  runtime or semantic work required for the `W8` ratios still belongs
  here, not in the annex.
