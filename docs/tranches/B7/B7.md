# Tranche B7 — Cross-Repo Modernization Annex

## Opening

B7 closes the cross-repo modernization gap so AZ-I dispatches against
a coherent build, test, and bench discipline across all three repos
that compose the bbnf-lang ecosystem: `bbnf-lang`, `parse-that`, and
`pprint`. Three repo-isolated waves run in parallel — W0 inside
bbnf-lang, W1 inside parse-that, W2 inside pprint — with ten agents
across them. B7 owns no parity-critical runtime architecture; every
edit lands in benches, CI workflows, test-surface routing, and
`.cargo/config.toml` patch resolution. AZ-I.W0 opens against a fleet
where divan is the only bench harness, nextest is the only test
runner, and the bbnf-ser patch lives in exactly one place.

## Architectural thesis

Three invariants compose. Each closes a measurable cross-repo drift
the post-B6 substrate inherited from divergent build/test/bench
ecosystems; together they retire the modernization debt that would
otherwise force AZ-I.W2 onto an inconsistent runway.

1. **One bench harness per repo, one harness across repos.** divan
   is the bench substrate fleet-wide. parse-that retires `bencher
   = "0.1.5"` across 16 bench targets; pprint retires `#![feature
   (test)]` + `extern crate test` across 38 bench targets; bbnf-lang
   completes its already-divan migration by porting
   `crates/simd-scan/benches/stage1_throughput.rs` off manual
   `std::time::Instant` timing. Cross-bench inlining and regression
   analysis run on a single harness contract.
2. **One test runner per repo, one runner across repos.** `cargo
   nextest run --profile ax-iter` is the test-execution substrate
   fleet-wide. parse-that and pprint each rewire their CI from bare
   `cargo test --workspace` to nextest with the same profile
   conventions bbnf-lang already enforces. Inline `#[test]` inside
   parse-that's `src/` migrates to `tests/` so the test-surface
   discipline is uniform.
3. **One source of truth for the cross-repo `bbnf-ser` patch.**
   The patch entry lives in `/Users/mkbabb/Programming/bbnf-lang/
   .cargo/config.toml` only; pprint's local `.cargo/config.toml`
   stops shadowing it. bbnf-lang owns the patch graph; sibling
   repos consume.

Composition: invariant 1 unifies the bench substrate so the AZ-I.W2
twitter ≥ 1967 MB/s gate runs on the same divan harness across
every cross-repo regression run; invariant 2 unifies the
test-execution substrate so iteration speed and isolation
guarantees match across repos; invariant 3 retires the patch-shadow
class of cross-repo drift entirely. The bbnf-lang internal
sub-stream within W0 — simd-scan divan completion plus the
test-surface partition that re-routes `bench_lsp::bench_lsp_actions`
off the `[[test]]` surface and sample-caps the simd-scan proptest
fuzzers — is the in-repo half of the same modernization cohort.

## Invariants (cross-tranche preserved + tranche-specific)

Ten numbered invariants the tranche enforces. Cross-tranche
preserved (1, 2, 9) carry from B6 and the README §Code discipline;
tranche-specific (3, 4, 5, 6, 7, 8, 10) close the cross-repo
modernization debt.

1. **Workspace nextest 1477+/1477+ green** at every wave close in
   bbnf-lang. No wave closes red. parse-that and pprint each
   maintain master green at their own wave close.
2. **`cargo xtask regen --check` exit 0** across all 9 grammars at
   every wave close in bbnf-lang. Generated files remain output of
   fresh regen.
3. **No bare `cargo test` anywhere in CI.** All three repos
   (`bbnf-lang`, `parse-that`, `pprint`) invoke `cargo nextest
   run` exclusively in their workflows.
4. **No legacy bench harness anywhere.** No `bencher`, no
   `feature(test)`, no `extern crate test`, no manual
   `std::time::Instant` timing in any `benches/` directory across
   the three repos.
5. **No inline `#[test]` in `src/`** in parse-that. All tests
   reside under `tests/`. (bbnf-lang and pprint already conform.)
6. **No `#[allow(...)]` introductions outside macro contexts.**
   The B5 invariant carries verbatim into B7; no modernization edit
   has warrant to mask a lint surface.
7. **Toolchain pin honored everywhere.** Every CI workflow reads
   `rust-toolchain.toml` as the authoritative pin source. No
   `dtolnay/rust-toolchain@nightly` floating reference survives.
8. **The `bbnf-ser` patch lives in `bbnf-lang/.cargo/config.toml`
   only.** pprint's local `.cargo/config.toml` carries no
   `[patch.crates-io]` entry for `bbnf-ser`.
9. **AY-III's substrate presupposition (post-B5 `Tape<R>` over
   `Columns`) preserved.** B7 is build/test/bench-surface only; no
   tape, columns, lower, or emitter source lines change.
10. **Post-B7 warm `cargo nextest run --profile ax-iter` wall ≤
    14 s** in the bbnf-lang main checkout, down from the post-B6
    22.353 s baseline (37 % reduction). The lever is W0's
    test-surface partition; the floor check sits at the structural
    minimum (post-A9 surface minus 16.5 s `bench_lsp_actions` minus
    the sample-capped fuzz tests).

## Operational posture

1. B7 dispatches three repo-isolated wave pools in parallel. Each
   pool has its own worktree set, its own `target/` directory, and
   its own git history; cross-wave orchestrator conflict reduces to
   zero.
2. Each repo's master HEAD advances independently as the wave's
   commits cherry-pick onto it. bbnf-lang's main checkout owns the
   tranche-close artefact (the workspace warm-wall measurement).
3. The orchestrator owns cross-repo coordination at wave close —
   the `bbnf-ser` patch resolution, the cross-repo bench-median
   delta reconciliation — but every per-agent edit lands inside its
   single repo.
4. B7 is bounded: 3 waves, no successor debt tree of its own, no
   parity-critical runtime architecture. AZ-I.W0 names B7 in its
   open precondition.

## Hard-gate measurement methodology

Per SPEC §Bench contract and §Three-tier command surface. Every
numeric gate cites a single measurement procedure:

- **Bench-median delta**: divan harness, `DIVAN_BENCH_FORMAT=json`,
  100 samples × 100 iters, captured to per-agent JSON artefacts.
  ±5 % allowance accommodates divan's distinct sample-and-warmup
  defaults vs `bencher` / `feature(test)`; tuning with explicit
  `#[divan::bench(sample_count = N, sample_size = M)]` is the
  remedy when the noise floor is exceeded.
- **Warm wall (bbnf-lang)**: `cargo nextest run --profile ax-iter`
  3 runs after warm target, median, captured to
  `docs/benchmarks/post-B7-W0-walls.txt`.
- **CI green**: each repo's CI workflow runs to completion on a
  probe commit; the artefact is the workflow run URL recorded in
  the wave's audit notes.

## Floor checks

Per SPEC §Gate floor-check. Each numeric gate sits above its
structural lower bound by a defensible margin:

- **W0 floor.** Warm nextest wall ≤ 14 s. Pre-B7 baseline 22.353 s.
  Re-routing `bench_lsp_actions` removes 16.5 s in isolation;
  sample-capping the simd-scan fuzz tests removes ~17–20 s when
  saturating. The 14 s gate sits ≥ 30 % above the structural floor
  (post-A9 surface minus ~16.5 s `bench_lsp_actions` minus
  sample-capped fuzz tests at < 1 s each).
- **W1 floor.** Bench-median delta within ±5 %. divan vs bencher
  default sample/warmup configurations differ; the ±5 % allowance
  is the noise floor on a clean port. A divergence above the
  allowance signals a divan tuning miss (sample count, warmup),
  not an architectural failure.
- **W2 floor.** Bench-median delta within ±5 %. Same noise-floor
  argument as W1; `feature(test)` and divan diverge on warmup but
  converge on the per-iter median for the typical pprint micro-
  benchmark workload.

## Indefatigability

The directive on B7 is unambiguous: cross-repo modernization
expedites uniformly, the bench substrate consolidates onto divan
fleet-wide, the test runner consolidates onto nextest fleet-wide,
and the cross-repo patch graph collapses to a single source of
truth. Each wave's hard gate is a measurable artefact reduction or
configuration-drift retirement with a structural floor check; a
wave that cannot close at gate halts the tranche. The plan above
carries no "stretch goals" and no "if-time-permits" carve-outs.
Every item enumerated is mandatory; the orchestrator dispatches
sub-agents that carry the same discipline. The triumvirate
(research / plan / redress) stands by for any wave that meets
contact and discovers the synthesis is incomplete; the response is
to widen the synthesis, not to retreat. B7 closes before AZ-I.W0
opens; the post-B7 substrate is the cross-repo runway AZ-I.W2's
twitter ≥ 1967 MB/s gate dispatches against.
