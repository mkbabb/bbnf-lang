## Direct pipeline

1. `src/membership.py` rederives Snapshot/Current-Work membership from retained
   authority bytes, checks all selected CSSWG source bytes, classifies every
   source reference occurrence with comment/edit state, validates 96 dated
   publication objects and eight external parsing authorities, and replays the
   compact WPT commit/tree/path-OID receipt.
2. `src/scanner.py` provides one byte-state source tokenizer for comments, tags,
   raw text, Bikeshed references, edit state, dependency occurrences, and source
   maps. `src/extract.py` admits source-native carrier classes and only explicitly
   reviewed legacy sites; generic equations, programs, markup, and other `<pre>`
   material remain negative fixtures.
3. `src/dialects.py` separately validates CSS Value Definition Syntax, Bikeshed
   railroad, legacy Yacc/Lex, WebIDL declarations, entity fields, and structural
   algorithm steps. A blocked stage cannot flow downstream.
4. `src/modules.py` keeps all definitions source-qualified, preserves conflict and
   extension decisions, and records one explicit closure decision for every AST
   reference occurrence. No scalar profile winner or handwritten prelude exists.
5. `src/matrix.py` emits exact semantic source rows with closed status enums and
   routes every unresolved plane to VT.W1. Incumbent BBNF name matches remain
   non-authoritative observations: every BBNF plane and every owner plane stays
   `UNMAPPED`; no BBNF type or owner is fabricated. Source-declared WPT routes
   yield only `UNRUN`, `UNMAPPED`, or `NO_DIRECT_TESTS`; no WPT outcome is
   fabricated.
6. `src/boundary.py` records that no candidate exists and exposes the future
   candidate input allowlist/crater. `src/regen.py` writes six deterministic
   artifacts only into an empty output root. `src/manifest.py` verifies the
   cache-free, symlink-free owned subject.
