# B2.W3 — Script Simplification

**Opens after**: W2 close (proc-macro deleted)
**Agents**: 1 agent
**Hard gate**: `scripts/bootstrap-bbnf.sh` deleted; xtask absorbs cargo-expand + post-process logic; Makefile/CI references update; `target/.bbnf-cache/` no longer created or read by any code path
**Status**: planned

## Scope

`scripts/bootstrap-bbnf.sh` (the cargo-expand wrapper that invoked the
proc-macro + post-processed via Python) was the canonical regen
entrypoint pre-B2. With the proc-macro retired and `cargo xtask regen`
the new entrypoint, the script is dead code.

W3 deletes the script, absorbs its post-processing logic into
`xtask/src/regen.rs` as native Rust functions (using `syn` +
`prettyplease` rather than the script's regex-style sed), retires
`make ay-prime` (the proc-macro cache priming target — no proc-macro
to prime), and updates Makefile + CI references.

## Phase sub-items

### B2.W3.a — Script retirement + xtask absorption

**Hard cap**: 90 min.

Mechanism:

1. **Audit `scripts/bootstrap-bbnf.sh` post-process logic**: the script
   does:
   - `cargo expand -p bbnf-bootstrap --lib > /tmp/raw_expand.rs`
   - Python regex post-process to:
     - Strip unstable features (e.g., `#![feature(...)]` lines).
     - Collapse `#[automatically_derived]` boilerplate.
     - Filter macro-hygiene compiler-internal symbols (e.g., `_::ANON_CONST`).
     - Reformat via `prettyplease`-equivalent.
   Document each transformation in
   `docs/tranches/B2/audit/W3-post-process-inventory.md`.

2. **Implement equivalent in xtask**: `xtask/src/regen.rs::post_process(
   token_stream)` runs each transformation as a native Rust function
   over `proc_macro2::TokenStream` + `syn::File`:
   - `strip_unstable_features(file: &mut syn::File)`: walks `file.attrs`
     and removes `#![feature(...)]` items.
   - `collapse_automatically_derived(file: &mut syn::File)`: walks impl
     items and rewrites `#[automatically_derived]` to standard
     `#[derive(...)]` annotations where possible.
   - `filter_macro_hygiene(file: &mut syn::File)`: removes
     compiler-internal symbols.
   The xtask runs this BEFORE writing per-grammar `generated/<ident>.rs`,
   so the on-disk output is post-processed.

3. **Validate post-process equivalence**: regenerate every grammar via
   the xtask + diff the output against the W0 reference snapshot. The
   post-process step should not introduce drift; the xtask emitter
   already produces clean output for most cases (the `#![feature]`
   stripping is the main concern since rustc's expand emits these
   from the proc-macro crate's edition).

4. **Delete `scripts/bootstrap-bbnf.sh`**: `git rm scripts/bootstrap-
   bbnf.sh`.

5. **Audit `scripts/check-bootstrap-clean.sh`**: this script verifies
   the committed `generated.rs` matches a fresh regen. Post-B2, the
   equivalent is `cargo xtask regen --check` (W4's CI gate). Two
   options:
   - (a) Delete `check-bootstrap-clean.sh` outright; W4's CI invokes
     `cargo xtask regen --check` directly.
   - (b) Keep `check-bootstrap-clean.sh` as a thin shim that invokes
     the xtask; ~5 lines.
   Pick (a). Cleaner.

6. **Edit `Makefile`**:
   - Retire `ay-prime` target (the proc-macro cache priming was
     specific to `crates/derive/.bbnf-cache`; with no proc-macro,
     priming is meaningless).
   - Retire `clean-cache` target's `target/.bbnf-cache` reference (the
     directory no longer exists post-B2).
   - The `clean-cache` target's `$XDG_CACHE_HOME/bbnf-derive/`
     reference (added in B1.W4 for forward compatibility) also
     retires — the AZ-I.W0 derive-cache relocation no longer applies.
   - Add a `regen` Make target that delegates to `cargo xtask regen`
     (convenience wrapper).
   - Add a `regen-check` Make target that delegates to `cargo xtask
     regen --check`.

7. **Edit `docs/instructions/PROFILING.md`**: update §Bootstrap regen
   to reference `cargo xtask regen` (removing the bootstrap-bbnf.sh
   recipe + the .bbnf-cache discussion). Update §Dev-host setup to
   drop the proc-macro-cache mention.

8. **Append to `docs/benchmarks/post-B2-W3-walls.txt`**:
   - `cargo xtask regen` cold wall (full-grammar regen).
   - `cargo xtask regen --check` wall (regen + git-diff).
   - `cargo xtask regen --grammar bbnf` wall (single grammar).
   These become the new wall-clock truth, replacing the pre-B2
   80-min `bootstrap-bbnf.sh` cycle.

## Archaeology

`scripts/bootstrap-bbnf.sh` was authored at tranche AC.2 (per
`meta-audit/08-abrogation-catalog.md`) as a 338-line shell + Python
post-processor. The catalog's verdict was KEEP-MODERNIZE: shrink to a
~40-line shell wrapper invoking a Rust `post_expand` bin. B2.W3
realises that modernization but dispatches it differently — the
script doesn't shrink, it RETIRES, because the IR pipeline no longer
runs inside rustc + cargo expand. The xtask owns both the IR pipeline
AND the post-process; the entire bootstrap-bbnf.sh role retires.

`scripts/check-bootstrap-clean.sh` (43 lines) similarly retires; its
role (CI gate verifying generated.rs matches fresh regen) becomes the
xtask's `regen --check` subcommand.
