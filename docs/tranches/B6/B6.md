# Tranche B6 — Dev-Loop Expedite

## Opening

B6 is a bounded prelude annex for AY-III. Three waves. Its job is to
remove the build, bench, and command-surface drag the post-B5 substrate
inherited from the proc-macro retirement window — drag that would
otherwise force AY-III's wave schedule onto a slow toolchain. B6 owns
no parity-critical runtime architecture, no parser semantics, no tape
or substrate work. The bootstrap regen wall halves; the iteration
surface gains a CSP-only carve-out; the JSON test surface partitions
along its real fixture-class boundary. AY-III opens against a
substrate that builds, benches, and tests on a fast truthful runway.

## Architectural thesis

Three invariants compose. Each follows an SPEC anti-pattern correction
made concrete by a single-wave architectural move; together they retire
the residual dev-loop debt the post-B5 substrate carried forward.

1. **One xtask path.** The two-stage bootstrap fast-path replaces the
   current entry; it does not add beside it. The phase-1 CSP-only
   parser plus the hand-written direct-descent CSP parser are the
   single regen entry for `cargo xtask regen --grammar bbnf` after
   W0 lands. Per SPEC §Code discipline (no shadow surface) and rule 1
   of the prelude annex contract (no parity-critical runtime
   architecture).
2. **One iteration surface per workload.** The `iter-check-az` carve-
   out targets the AY-III workspace — the egraph + CSP + IR pipeline
   the next tranche actually exercises — not a generic bin set. Lazy
   pass deferral in the egraph scheduler folds into the same carve-
   out; gorgeous default features verify minimal. Per SPEC §Three-
   tier command surface and §No god modules.
3. **One test surface per fixture-class.** JSON monolithic benches
   partition along the data-fixture boundary the suite already
   declares (`twitter`, `canada`, `citm`, `data`, `data_xl`); IR
   audit passes (payload coverage, projection totality) feature-
   gate behind `ir-audit` so close-ceremony runs them while routine
   iteration does not. Per SPEC rule 5 of the prelude annex contract
   (annex is not a refuge for hard work — only the surface split
   moves).

These three compose: invariant 1 retires the cold xtask wall (the
single largest dev-loop tax post-B5); invariant 2 carves the warm
iteration surface to the working set AY-III actually consumes;
invariant 3 narrows the test wall to the close-ceremony scope it
belongs in. Each wave's hard gate is a measurable wall-clock or
artefact reduction; no wave introduces a parallel system.

## Invariants (cross-tranche preserved + tranche-specific)

Eight numbered invariants the tranche enforces. Cross-tranche
preserved (1, 2, 8) carry from B5 and the README §Code discipline;
tranche-specific (3, 4, 5, 6, 7) close residual debt the prelude
annex contract bounds.

1. **Workspace nextest 1477/1477 green** at every wave close. No
   wave closes red.
2. **`cargo xtask regen --check` exit 0** across all 9 grammars at
   every wave close. Generated files remain output of fresh regen.
3. **`cargo iter-check` warm ≤ 0.5 s** preserved across the tranche.
   The post-B1 routine surface holds; B6 narrows further with
   `iter-check-az`, never widens.
4. **`cargo bench-bbnf` median within 5 % of post-B5 baseline
   (2.806 ms)**. The bootstrap fast-path landing in W0 and the lazy
   passes in W1 are not permitted to bloat the hot parse path; the
   wave gates verify non-regression.
5. **No `#[allow(...)]` introductions** outside macro contexts. The
   B5 invariant carries verbatim into B6; the dev-loop work has no
   warrant to mask a lint surface.
6. **No source-code path duplications.** The W0 fast-path replaces
   the current entry; legacy preserves under a `--no-fast` flag for
   one tranche cycle (named restoration in B7 successor) and is not
   permanent. Per SPEC §Edicts no-shim rule.
7. **Same-grammar regen output is byte- or `prettyplease`-format-
   equivalent pre/post W0.** The fast-path's structural correctness
   is gated on parity with the current entry's output for the BBNF
   grammar; semantic equivalence after `prettyplease::unparse` is
   the lower-bound acceptance.
8. **AY-III's substrate presupposition (post-B5 `Tape<R>` over
   `Columns`) preserved.** B6 is doc-and-build-surface only; no
   tape, columns, lower, or emitter source lines change.

## Operational posture

1. B6 measures cold xtask wall, cold iter-check-full wall, and warm
   iter-test wall separately; each wave's hard gate cites a single
   measurable threshold against the pre-tranche baseline.
2. Every command-surface change must shorten a named AY-III loop,
   not improve "developer experience" abstractly.
3. B6 closes before AY-III dispatches; AY-III's wave schedule names
   B6 explicitly in its open gate (`opens after B6 close`).
4. B6 owns no parity-critical AY-III work. If a candidate item is
   load-bearing for AY-III's close gates, it stays in AY-III.

## Hard-gate measurement methodology

Per SPEC §Bench contract and §Three-tier command surface. Every
numeric gate cites a single measurement procedure with no inter-
run variance allowance beyond the median's stability:

- **Cold wall**: `make clean-incr`; `find . -name .bbnf-cache -exec
  rm -rf {} +`; then `time -p <command>` 3 runs, median. Single-host,
  no concurrent cargo (per README §Concurrent cargo — one per
  target).
- **Warm wall**: 3 runs after warm target, median.
- **Bench wall**: `cargo bench-bbnf` per the existing `cargo bench`
  alias surface, `ay-final` profile, divan harness, 100 samples ×
  100 iters; capture `DIVAN_BENCH_FORMAT=json` to
  `docs/benchmarks/archive/post-B6-W{N}-walls.json`.

## Floor checks

Per SPEC §Gate floor-check. Each numeric gate sits above its
structural lower bound by a defensible margin:

- **W0 floor.** ≤ 3 min cold xtask wall. Pre-B6 baseline measured
  at 5+ min; structural lower bound (CSP-only parse + emit) is
  ~60–90 s. The 3-min gate is 100 % margin above the structural
  floor — defensible.
- **W1 floor.** ≥ 30 % `iter-check-full` cold reduction. Pre-B6 wall
  > 660 s; the `iter-check-az` carve-out drops ~80 % of the link
  surface (gorgeous, bbnf-bootstrap, bbnf-analysis, bbnf-lsp out;
  egraph, CSP, IR pipeline in). 30 % is conservative against the
  measured surface ratio.
- **W2 floor.** ≥ 20 % `iter-test` warm reduction. Pre-B6 ~20 s
  warm; partitioning removes the per-fixture macro-expansion cost
  and the IR audit lazy-gate removes two large compile-time
  symbol dependencies. The 25–30 % aspirational target reduces to
  20 % as the conservative floor.

## Cross-tranche debt

**Inherited (closed in B6):**

- Cold `cargo xtask regen --grammar bbnf` wall ≥ 5 min — the post-
  B2 proc-macro-retirement entry runs the full IR pipeline through
  `compile_paths_request` + `generate_all` + `prettyplease::unparse`
  on every regen, dominated by the `BbnfBootstrap::parse` step over
  the `bbnf.bbnf` source (W0).
- Cold `iter-check-full` wall > 660 s — the workspace-full ax-iter
  surface links the four heavy crates (gorgeous, bbnf-bootstrap,
  bbnf-analysis, bbnf-lsp) plus the egraph + CSP scheduler with all
  passes eager (W1).
- Warm `iter-test` wall ~20 s — the JSON monolithic bench's macro-
  expanded fixture surface plus the IR audit tests (`payload_
  layouts.rs`, `projection_totality.rs`) at the routine tier (W2).

**Forwarded (post-B6, opens AY-III.W0):**

- The `--no-fast` flag preserves the legacy regen path for one
  tranche cycle as a regression escape valve. B7's named
  restoration wave retires the flag and the legacy entry; B6
  cannot retire it because two-stage CSP correctness verifies
  against the legacy output for the first cycle of operation.
  Per SPEC §Transitional fallback during elimination waves —
  the flag is a declared transitional path, not a permanent
  shim.

## Defensible floor

After W2 closes, the dev-loop surface is the post-B5 surface minus
three drag categories:

1. The bootstrap regen wall halves: cold ≥ 5 min retires to ≤ 3 min
   on the fast-path with byte-equivalent output; legacy preserves
   under `--no-fast` for one tranche cycle.
2. The iteration carve-out lands: `iter-check-az` cold ≤ 30 s
   covers the AY-III working set; the egraph scheduler defers
   passes whose `--check` consumer count is zero.
3. The test partitioning lands: JSON benches split per-fixture; IR
   audits feature-gate behind `ir-audit` so close ceremony runs
   them, routine iteration does not. Warm iter-test ≥ 20 %
   faster.

Workspace nextest stays at 1477/1477. `cargo bench-bbnf` median
holds within 5 % of B5 baseline. AY-III.W0 dispatches against this
floor.

## Post-tranche review candidates

Decision at B6 close, not mid-wave:

- Whether the `--no-fast` flag retires inside B7's first wave or
  carries forward (the empirical bug rate of the fast-path across
  the AY-III tranche is the discriminator).
- Whether the `iter-check-az` alias merges with `iter-check`
  outright or stays as a named carve-out (the AY-III consumer
  pattern decides).
- Whether `ir-audit` graduates into a dedicated test profile (the
  close-ceremony cadence decides).

## Escape clause

W0 may extend into a sub-wave W0a if the byte-equivalence gate
fails on the first cycle but the structural correctness gate
passes — the legacy path stays under `--no-fast`, the fast-path
emits its diff for orchestrator review, and W0a's named
restoration is "byte-equivalent or `prettyplease`-equivalent
on second cycle". The transitional path is declared per SPEC
§Transitional fallback during elimination waves; tranche close
binds at W2, not at W0.

## Indefatigability

The directive on B6 is unambiguous: no quick solutions, no
workarounds, no shadow surfaces, no over-optimising superfluous
nonsense. Each wave's hard gate is a measurable wall-clock or
artefact reduction with a structural floor check; a wave that
cannot close at gate halts the tranche. The plan above carries
no "stretch goals" and no "if-time-permits" carve-outs. Every
item enumerated is mandatory; the orchestrator dispatches sub-
agents that carry the same discipline. The triumvirate (research /
plan / redress) stands by for any wave that meets contact and
discovers the synthesis is incomplete; the response is to widen
the synthesis, not to retreat. B6 closes before AY-III opens; the
post-B6 substrate is the floor AY-III.W0 dispatches against.
