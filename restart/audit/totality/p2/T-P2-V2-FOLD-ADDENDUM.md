## Lock 1 / Substrate-Kind Contract

Every e-graph candidate, backend rewrite, imported scanner plan, union
candidate, and SIMD consumer declares:

```text
substrate_target = local_temp_only | existing_tape | direct_sink | admitted_fact_output
retention_lifetime = local_loop | generated_function | output_row
policy_owner = generated_grammar | caller_data | none
```

Any route requiring retained class/mask streams, parser-owned cursor/list state,
public substrate API, `UnionTape`, or a second tape is rejected unless the user
amends Lock 1. `CollapsedStage` is an emitted-kernel strategy: masks and FSM
state are local temporaries unless they are emitted as the admitted row output.
`bbnf-regex` may import compile-time HIR, automata facts, byte classes, and
scanner plans; runtime masks/classes/cursors are consumed by generated grammar
code in-loop.

Fact streams are valid only as output planes with strict comparator/oracle
provenance and gate-consumed telemetry. They are not hidden internal sidecars.

## Union / PMULL / CSSC Material-Differential Checklist

The labels `Union-C`, `PMULL+CSSC`, or `SIMD-first union` are not
shortlist-safe unless every item below is true:

1. Prior REDRESS routes cited: 88, 89, 96, 97, 98.
2. The route does not globally replace `bitmap_prefix_xor_64` or
   `bitmap_next_set_bit` default bodies.
3. The route does not replay retained class-column, streaming cursor,
   class-lane-only, parser-owned sidecar, or `UnionTape` shapes.
4. The old scalar cost source is deleted or bypassed inside the named row
   consumer, not merely renamed.
5. The consumer owns masks/positions in one loop and emits into
   `existing_tape`, `direct_sink`, or `admitted_fact_output`.
6. Scalar reference, checkasm cell, feature gate, and isolated microbench are
   named before S-P3 scoping.
7. Strict row gate, guard rows, rollback path, and abort criteria are named.
