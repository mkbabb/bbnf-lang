2. Require active measured rows for `json.data_xl`, `css.tailwind`, and `compile_css_l4`; commented-out or watchdog-only rows cannot close.

8. Produce `FINAL.md` only at close.

## Triumvirate Dispatch

Dispatch a triumvirate if any of these occurs:

- a watchdog row remains, a benchmark row is commented out, or profiling does not isolate a root cause;
- benchmark evidence contradicts parity evidence;
- same-harness sonic-rs projection rows beat bbnf projection rows without a routed root cause;
- post-AU or post-AZ floors fail without a profile-backed disposition;
- generated output drifts after W6 measurement;
- close docs cannot cite resolving artefacts for every MET gate;
- a residual item lacks a named next destination;
- three diagnostic-loop iterations fail to isolate a regression root cause;
- a non-routable carry from `AZ-IV.md` §Non-Routable Carries cannot close in W6 with the evidence available; this is a thesis-invalidating scope reveal and triggers triumvirate review of the AZ-IV thesis itself, not a successor routing (per `audit/HARDENING-2026-05-01-boole.md` Amendment 3);
- a profiling sub-agent reports any of the seven required artefacts missing (per `docs/instructions/PROFILING.md` §Profile a single entry), or reruns `cargo expand` / `cargo bench` after `prepare-profile-wave.sh` has finished (forbidden per §Forbidden in sub-agents), or writes retained artefacts outside `.profiles/` (also forbidden).

## Profiling Discipline

W6 measurement is samply-driven where regressions or watchdog rows surface. The canonical contract is `docs/instructions/PROFILING.md` — read it before W6.1 dispatches. The salient suffusions:

- **Prepare once per wave.** The orchestrator runs `scripts/prepare-profile-wave.sh` to prebuild every bench binary, run `cargo expand` per bench, reserve ports, and emit `.profiles/samply/prebuild/wave.tsv`. Sub-agents consume the prepared artefacts; they MUST NOT rerun `cargo expand` or `cargo bench` after prepare finishes.
- **One sub-agent per bench harness.** The five canonical bench harnesses (`json_monolithic`, `css_l4`, `google_sheets_monolithic`, `bbnf_monolithic`, `json_value`) get one sub-agent each, sequenced inside `AZ-IV.W6.1 Benchmark Matrix`'s owner worktree. Each sub-agent receives its `wave.tsv` row verbatim and runs `scripts/profile-bench-headless.sh` against the prebuilt binary, never the source tree.
- **Seven required artefacts per entry.** Per `PROFILING.md` §Profile a single entry: `bench.txt`, `build.txt`, `record.txt`, `load.txt`, `profile.json.gz`, `profile.json.syms.json`, `syms-proof.txt` — every file present and non-empty. A missing artefact is a profiling-sub-agent halt (triumvirate trigger above).
- **Samply rules.** `--unstable-presymbolicate` always; `--save-only` never; ports preflighted; bench binaries run from `crates/core` (cwd-sensitive); `--bench <filter>` is a substring match (avoid name prefixes like `data` vs `data_xl`).
- **Codegen inspection on substrate-activation rows.** `cargo expand` (already performed by prepare) feeds the manual review of any row that activated a new substrate (CSP, ruler, alt_dispatch typed-leaf push, regex-scan adapter). `cargo asm` per `make ay-asm-close-compound FN=<sym>` is the symbol-level verification path for hot-path leaves.
- **Shared target dir contract.** One absolute `CARGO_TARGET_DIR` exported before `prepare-profile-wave.sh`. Sub-agents export the same path. Profile artefacts retained only at `.profiles/samply/post-AZ-IV/` (one prepared wave dir per close); never `/tmp`.
- **Profile-claim grounding.** Every claim in a sub-agent's report cites a saved file: bench source, provided `expand.rs`, saved profile/log, or `syms-proof.txt`. Inference-only conclusions are forbidden (per `PROFILING.md` §Forbidden in sub-agents).

The five-sub-agent profiling pass sequences inside `AZ-IV.W6.1`'s owner worktree, not as a sixth parallel slot — it preserves the W6 three-writer-slot layout (W6.1 / W6.2 / W6.3) while honouring `PROFILING.md`'s 5-agents-per-bench-harness contract for the duration of the matrix close.

Empty/no-evidence returns get one verbatim redispatch with the same worktree pointer. A second empty/no-evidence return triggers mandatory triumvirate. JSONL transcript quiet >15 minutes is an orchestrator-side auto-trigger; record the condition and dispatch time in `PROGRESS.md` alongside the wave's evidence ledger.
