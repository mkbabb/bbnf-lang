AZ-IV.W4.3 — Shape SIMD Consumption — Decision Record
=======================================================

Decision: DELETE
Mechanism: GrammarIR::shape_dict_templates and
GrammarIR::shape_dict_selection are excised from the IR; the
ShapeDictMiner recognizer pass and the
csp_strategy::constraints::shape_dict installer are retired
wholesale; the test that exclusively read the deleted fields is

in place.

WIRE Path Considered, Rejected
==============================
Wiring would have required inventing a runtime tape encoding
(ShapeRef record + per-template payload-blob layout), a per-grammar
emitter projection from `shape_dict_selection` indices to the new
record, and a runtime decoder. Per non-negotiables:

* KISS DRY: delete unused over invent-a-consumer.
* No-workarounds-arch and no-deferrals: the WIRE path is a wholly
  new runtime substrate, not a small carve. Triumvirate-trigger
  bullet "shape_dict or structural scan needs a new runtime
  substrate not already present" applies — the W4.3 dispatch
  forecloses this without orchestrator authority.

Therefore the DELETE path is mechanically forced by W4 scope item
4 ("consume or retire generic shape dictionary and structural scan
claims") composed with the disposition matrix.
