O4 conclusion
-------------

O4 closes the live generated/strategy/return-model surface:

- EmitStrategy is StructDirect-only for production grammars.
- Unknown production grammars fail closed instead of falling back.
- Generated parse entrypoints return concrete documents.
- StructDirect shape success returns unit, not TapeOffset.
- Parsed is absent from production Rust code.
- Generated grammars have no TapeOffset return payloads.
- The direct Ref-call helper is named emit_ref_call_shape, not the
  tape-era emit_ref_call_tape.

O5 is unblocked but remains mandatory. It must delete or relocate the
remaining runtime::tape primitives, simd-scan tape-owned structures,
visitor/tape-only emitters, json-prototype, Gorgeous JIT, manifests,
and crates/tape without compatibility shims.
